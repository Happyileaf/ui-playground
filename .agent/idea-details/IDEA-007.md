## 创意概述

生产环境最高频也最常被做坏的组件之一：一个自动播放可暂停、支持滑动/箭头/圆点导航、遵循 WAI-ARIA Carousel 模式的轮播，演示画面全部由 CSS 渐变与内联图形构造（零外部图片），并把可访问性与“不自动动效干扰”作为核心卖点。

## 预期展示效果

- **构图与整体风格**：深色或中性色舞台，每张幻灯片为一句标题 + 一段文案 + 几何/CSS 渐变插画的构图；底部圆点指示器与左右箭头；整体克制不花哨。
- **主要视觉元素**：幻灯片轨道、当前圆点、渐隐或横向位移过渡、进度提示；可选缩略图条。
- **层次、材质、光影与关键细节**：过渡期间文字与图层轻微视差错位；箭头与圆点命中区域充足；自动播放时圆点上有细微进度环。

## 动态与交互

- 左右箭头、圆点跳转、指针拖拽/触控滑动（含阈值判定与回弹）、键盘左右方向键；`Tab` 可进入幻灯片内链接而不被轮播劫持。
- 自动播放默认开启但鼠标悬停 / 键盘聚焦 / 触摸时暂停，并提供显式播放/暂停按钮；尊重 `prefers-reduced-motion`（默认不自动播放、关闭位移动画）。
- ARIA：`role="group"` + `aria-roledescription="carousel"`、幻灯片 `aria-roledescription="slide"`、圆点 `aria-label` 与 `aria-current`。

## 核心亮点

- 完整 WAI-ARIA 轮播语义 + 焦点不劫持，区别于“能滚就行”的常见实现；
- 自动播放的防打扰策略（悬停/聚焦/触控暂停 + reduced-motion 默认关）；
- 零图片依赖，便于独立离线运行与审查代码。
