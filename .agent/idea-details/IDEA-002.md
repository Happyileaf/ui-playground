# IDEA-002：标签输入芯片（Tag Input Chips）

- **更新时间**：2026-10-11

## 创意概述

邮件收件人、兴趣标签、技能录入等表单场景的高频控件：在输入框内将已确认条目渲染为可删除的“芯片”，支持键盘增删、粘贴批量拆分、去重与上限管理，是案例库表单域尚未覆盖的复合输入模式。

## 预期展示效果

- **构图与整体风格**：克制浅色或深色表单卡片，一枚多行自适应高度的输入容器，内部从左到右排列芯片与一枚常驻文本光标输入格；下方给出“从粘贴板一次导入多个标签”的演示按钮与当前数量/上限提示。
- **主要视觉元素**：芯片 = 小圆角标签 + 文本 + 关闭 ×（内联 SVG）；聚焦态芯片有描边高亮；非法/重复输入时对应芯片或输入格短暂出现警示色抖动；有效输入时芯片弹入（轻微 scale 过冲）。
- **层次、材质、光影与关键细节**：容器聚焦时整框描边增强并带微弱阴影；芯片与输入格基线对齐；超长标签省略号 + `title`；输入容器高度随芯片换行平滑增长。

## 动态与交互

- 输入文本后按 `Enter` / 逗号（可配置分隔符）确认成芯片；Backspace 在输入为空时回删最后一个芯片。
- 方向键在芯片间移动焦点，Delete/Backspace 删除聚焦芯片；鼠标点击 × 删除。
- 粘贴 `"a, b; c\nd"` 这类文本时按分隔符批量拆分、trim、去重、过滤空项；超过上限的部分给出提示。
- 提供受控的初始标签与上限（如最多 10 枚）；实时输出当前标签数组（演示区回显，可复制）。
- 可访问性：芯片使用按钮语义并提供可访问名（如“删除标签 设计，按 Backspace”），容器 `role="group"`/列表语义，屏幕阅读器播报新增/删除；reduced-motion 下无弹跳。

## 核心亮点

- 完整的“批量粘贴拆分 + 去重 + 上限 + 键盘回删”真实表单工程细节；
- 芯片弹入/删除与容器高度联动的平滑微交互；
- 面向屏幕阅读器的增删播报与芯片焦点漫游，达到可直接投产的可访问性。

## 历史案例对比（进入 Ready 前必填）

- **检查范围**：src/playground.js 全部 59 个注册案例 + playground 目录 + rejected.md（空）。
- **相似案例**：
  - `otp-input`（分段验证码）——同样是多格输入，但定长 6 位、一格一字符、自动前进/粘贴拆分到固定格；
  - `combo-box`（可搜索下拉）——结果以浮层列表呈现并单选回填，不产生常驻芯片集合。
- **差异说明**：核心创意是“**自由多值集合录入**”，与 OTP 的“固定长度凭证”和 combo-box 的“从候选集单选”均不同；视觉表达为芯片流式排布与容器自适应高度；交互方式的关键差异在多值增删、去重、上限、批量粘贴拆分与芯片级键盘焦点管理，这些在两个相似案例中都不存在。
