## 创意概述

利用 `stroke-dasharray / stroke-dashoffset` 与路径长度计算，让一组线性图标或一幅线稿插画“被一笔笔画出来”，并支持滚动进入视口触发、悬停重绘、描边后填充淡入，填补技术域 8（SVG 滤镜与形态形变）在案例库中几乎空白的短板。

## 预期展示效果

- **构图与整体风格**：深色画板上一组 6–8 个线性图标（如灯泡、火箭、心形、齿轮、叶子、图表等，内联 SVG 绘制），中央可放一幅由多段路径组成的较完整线稿小插画；克制的单色描边 + 一个点缀主题色。
- **主要视觉元素**：描边轨迹、绘制完成后轻微的填充淡入、节点圆点在收笔处弹一下；右上角符合 HUD 规范的 Title 胶囊。
- **层次、材质、光影与关键细节**：线宽与端点（round cap/join）统一；多条路径按长度错峰起笔，形成连贯运笔节奏；可切换“单色 / 渐变描边 / 手绘抖动”三种质感；背景保持极简，突出线条。

## 动态与交互

- 触发：进入视口自动播放一次（IntersectionObserver）；悬停某图标对其重绘；点击重播全部。
- 控制：Micro-HUD（默认折叠，H/Esc 切换）提供播放速度、错峰间隔、“描边后填充”开关。
- 路径长度由 `getTotalLength()` 动态获取，避免硬编码；reduced-motion 下直接呈现最终完整线稿。
- 键盘：图标可聚焦（按钮语义），聚焦时重绘；按钮 44px 命中区。

## 核心亮点

- 真实的路径长度驱动而非固定 dash 值，任何内联 SVG 都可套用；
- 多路径错峰运笔 + 收笔节点弹跳 + 填充淡入，构成“会呼吸的线稿”；
- 三种描边质感（单色 / 渐变 / 手绘抖动）一键切换，展示 SVG 表现力且零外部资源。
