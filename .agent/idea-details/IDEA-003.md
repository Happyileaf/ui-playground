## 创意概述

以滚动位置本身作为进度轴的沉浸式叙事页：文字段落随滚动依次淡入钉住、配图/图层产生视差与缩放、顶部进度与章节指示同步推进，展示“滚动即动画时间线”的现代落地页叙事手法，弥补案例库在 scroll-timeline / 滚动编排方向的空白。

## 预期展示效果

- **构图与整体风格**：纵向长页，深色背景上 4–5 个章节；大字号留白充足的排版，每章一句主标题加一段说明，配图区域由纯 CSS 渐变/几何图形构造（零外部图片）。
- **主要视觉元素**：章节序号、钉住（pinned）的章节舞台、分层视差图形、一条随滚动生长的纤细进度线与右侧章节点（含当前章节名）。
- **层次、材质、光影与关键细节**：前后景图层以不同速率移动形成纵深；段落从模糊+下移到清晰定格；章节切换有柔和的色彩色温迁移（克制，非蓝紫霓虹）；进度线末端微光。

## 动态与交互

- 触发：鼠标滚轮 / 触控滑动 / 键盘 PageUp·PageDown·Space / 拖动滚动条。
- 动效：优先使用原生 CSS scroll-driven animations（`animation-timeline: scroll()/view()`），在不支持的浏览器用 IntersectionObserver + rAF 平滑回退，两条路径视觉一致。
- 视差图层与滚动位置绑定；右侧章节点可点击跳转（`scroll-behavior: smooth`）并实时高亮当前章。
- reduced-motion：关闭视差与位移动画，内容直接完整可见，仅保留颜色态。

## 核心亮点

- 用现代 scroll-driven animations 把“滚动”变成动画时间线，并提供不支持环境下的等价回退，兼具先进性与稳健性；
- 钉住舞台 + 多层视差 + 色温迁移组成的纵深叙事，而非单纯的 fade-in 列表（与 scroll-reveal 明确拉开层级）；
- 纯 CSS 构造画面保证零资源依赖、独立离线可跑。

## 历史案例对比（进入 Ready 前必填）

- **检查范围**：src/playground.js 全部 59 个注册案例 + playground 目录 + rejected.md（空）。
- **相似案例**：
  - `scroll-reveal`——IntersectionObserver 触发的元素入场（上移/缩放/滑入/模糊），一次触发后解除观察；
  - `scroll-progress-bar`——顶部进度条 + 章节圆点导航 + 回顶按钮；
  - `vertical-timeline`——滚动揭示时间线卡片、脊柱填充。
- **差异说明**：scroll-reveal 只做“进入视口一次”的入场、与滚动量不连续绑定；scroll-progress-bar 以进度指示为主体、不编排舞台内容；vertical-timeline 是固定时间线结构的卡片揭示。本案例核心创意是“**滚动位置连续驱动的整页叙事编排**”：钉住舞台、随滚动量连续插值的多层视差、段落 scrub（来回滚动可逆）、章节色温迁移，并以 scroll-timeline 原生能力为主、IO 回退为辅，整体表现与三者有实质差异。
