# IDEA-005：明暗主题切换（Theme Toggle）

## 基本信息

- **状态**：Ready

- **创建时间**：2026-10-11
- **更新时间**：2026-10-11

## 创意概述

现代网站标配的深浅色切换：以一枚日/月形变切换控件为核心，配合整页色彩变量的平滑过渡、`prefers-color-scheme` 初始跟随、`localStorage` 记忆与 View Transitions 圆形扩散转场，演示“主题系统”该有的完整工程闭环与高级微动效。

## 预期展示效果

- **构图与整体风格**：同一套示例界面（顶栏、卡片、按钮、正文段落、代码块）在浅色/深色两套精致配色间切换，强调中性色与微弱色温倾向、避免蓝紫俗套；切换按钮固定在顶栏右侧。
- **主要视觉元素**：太阳与月亮之间带形变/旋转的切换图标（内联 SVG，光线收缩、月牙滑入）、主题色变量驱动的各界面元素、可选的圆形遮罩扩散揭示（View Transition）。
- **层次、材质、光影与关键细节**：切换过程中背景、文字、边框、阴影按变量插值柔和过渡而非生硬跳变；图标形变有明确的运动弧线与节奏；深色下投影更深、浅色下层次依靠细边框与柔阴影。

## 动态与交互

- 触发：点击切换按钮 / 键盘聚焦后回车或空格。
- 图标：太阳光线收缩 + 整体轻微旋转，月牙滑入覆盖；反向对称。
- 页面转场：支持时使用 View Transitions API，以点击点为圆心做圆形 clip-path 扩散（`startViewTransition` + 自定义伪元素）；不支持时退化为整体颜色过渡。
- 初始化：首次访问读取 `prefers-color-scheme`，之后以 `localStorage` 选择为准并避免 FOUC（内联首屏脚本在绘制前设置 `data-theme`）。
- 可访问性：按钮带 `aria-pressed`/可访问名（“切换到深色/浅色模式”）；reduced-motion 下关闭扩散与形变、仅即时换色。

## 核心亮点

- 点击点圆心的 View Transition 圆形扩散转场 + 优雅回退，是少有人做完整的现代 API 实战；
- 日/月形变图标的运动编排与整页变量插值联动；
- “系统偏好 → 用户选择 → 无闪烁首屏”的完整主题工程闭环，可直接搬到生产站点。

## 历史案例对比（进入 Ready 前必填）

- **检查范围**：src/playground.js 全部 59 个注册案例 + playground 目录 + rejected.md（空）。
- **相似案例**：`menu-morph`（汉堡/关闭图标形变）、`capsule-tabs`（胶囊切换器）。
- **差异说明**：menu-morph 只做两图标形变且服务于全屏导航开合，不含任何页面级配色系统；capsule-tabs 聚焦分段选择器的多种运动曲线，主题/换色不是其对象。本案例核心创意是“**整站主题系统与其转场体验**”：CSS 变量双主题、View Transition 圆形扩散、系统偏好与持久化、无 FOUC 首屏，交互方式与整体表现（同一样板界面在两套主题间转换）与上述案例有实质差异。

## 实现约束（仅记录该案例必要的约束）

- 纯原生、零框架、零 CDN；双击 index.html 可离线运行（localStorage 在 file:// 下不可用时需静默降级）。
- 需要一段置于绘制前的内联防闪烁脚本；View Transitions 必须特性检测回退。
- 两套配色对比度均满足 WCAG AA；遵循统一 HUD / reduced-motion 规范。
