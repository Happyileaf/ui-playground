## 创意概述

做一套开发者向的「代码差异查看器」：给定左右两段文本（旧版 / 新版），现场计算逐行差异并以**并排（Split）**与**统一（Unified）**两种专业视图呈现，具备增 / 删 / 改（含行内字符级高亮）的完整语义、差异块（hunk）折叠与上一处 / 下一处跳转、行号对照、差异统计徽标、忽略空白与仅看变更等开关，以及一组可切换的真实内置代码片段（如函数重构、配置变更、样式调整）与左右双编辑器**实时编辑即时重算 diff** 的互动模式；配完整 ARIA 语义、键盘导航、语法级配色与 `prefers-reduced-motion` 降级。

解决的核心体验问题：代码审查（Pull Request / Code Review）、配置变更确认、版本对比是开发者与技术类网页中最高频的场景之一，主流平台（GitHub / GitLab / IDE）都把差异查看器作为核心组件，但当前案例库 60 个注册案例与在池 46 个 Idea 中**没有任何文本 / 代码差异比对组件**——最接近的 `image-comparison-slider` 只做图像 A/B 裁剪对比，不具备行配对、增删改语义、行内差异、hunk 导航与文本编辑能力。本创意同时具备「真实可落地的工程组件」属性与「算法 + 视觉 + 交互」的展示深度：行级 LCS 配对、行内字符级 diff、并排对齐连线带来可感知的技术含量，语义色与等宽排版带来克制、专业的编辑器美学。

## 预期展示效果

- **构图与整体风格**：
  - 单屏呈现一张「代码审查卡片」：顶部为工具栏（文件标签 / 片段切换、Split 与 Unified 视图切换、忽略空白开关、仅看变更开关、差异统计 `+x −y`、上一处 / 下一处跳转），其下为差异主体；左右并排时两栏等宽、中间一条细分隔 gutter，统一视图时单栏纵向流动。
  - 深色、克制的编辑器 / IDE 视觉语言（遵循 Anti-Slop 准则，拒绝蓝紫渐变与霓虹滥用）：低饱和中性底色、细边框、大圆角与沉稳投影，像一个嵌入网页的迷你代码评审面板。
  - 语义色克制而明确：新增行用低明度绿色系底 + 左侧状态槽、删除行用低明度红色系底、被修改的一对行用同一组柔和琥珀 / 中性提示并在行内以更饱和的底色标出真正变化的字符区间；强调色仅用于当前 hunk 定位、焦点与活动开关。
  - 顶部保留项目统一的点阵色 Title 胶囊；可配默认折叠的 Micro-HUD，用于切换内置片段、切换实时编辑模式、显隐行内字符高亮等，便于观察不同状态。
- **主要视觉元素**：
  - 行号槽：旧 / 新两侧各自的行号列，未变更行两侧行号自然递增，被删除 / 新增的一侧对应位置留空或置灰，形成清晰的「左右行对应」阅读节奏。
  - 行首状态槽：每侧行首一条细色条（增 / 删 / 改的状态编码），配 `+` / `−` 符号；并排视图中被配对的「删旧增新」行在垂直方向严格对齐，可选在 gutter 中以极细引导线连接对应块。
  - 行内字符高亮：修改行内部再做一次词元 / 字符级 diff，把真正改变的 token（如变量名、数值、运算符、配置值）以更强的底色块标出，而不是整行平铺同色。
  - hunk 折叠条：连续的未变更上下文行可折叠为一条「展开 N 行未变更上下文」的细条；差异块之间有清晰的分隔与统计。
  - 工具栏与统计：`+新增 / −删除` 计数徽标、视图切换分段控件、开关、跳转按钮；切换片段或编辑时差异统计即时更新。
- **层次、材质、光影与关键细节**：
  - 以行底色、行首状态槽、行内高亮三级层次表达差异强度，避免大面积高饱和铺色造成阅读疲劳；等宽字体、合理行高与留白保证长代码可读。
  - 当前跳转定位的 hunk 有短暂、克制的强调（如左侧细指示条 + 轻量底色提亮），跳转平滑但不喧宾夺主。
  - 并排两栏纵向滚动严格同步；统一视图滚动单栏；超长行横向滚动时两侧 gutter / 行号保持视觉一致，不错位。
  - 切换 Split ⇄ Unified、展开 / 折叠 hunk、实时编辑重算时，差异区域的出现 / 消失以短促的透明 / 高度过渡呈现，保持结构稳定不跳动。

> 设计文档约束最终体验与设计意图；具体色值、尺寸、缓动参数、diff 算法的具体实现（LCS / Myers 等）与语法着色的词元规则由实现阶段按整体视觉统一决定，不在此过早钉死。

## 动态与交互

- **差异计算与视图**：
  - 加载或切换内置片段后，自动计算逐行差异并渲染；并排（Split）视图左右对照、统一（Unified）视图单栏按 hunk 顺序排列，工具栏可随时在两种视图间切换且保持当前浏览位置 / 当前 hunk。
  - 增 / 删 / 改三类语义完整：纯新增、纯删除、以及「删除旧行 + 新增新行」的修改配对；修改行内部展示行内字符级高亮。
  - 双栏纵向滚动同步；行号、状态槽与行内高亮在两栏对齐；统一视图下每个 hunk 带范围标识。
- **hunk 折叠与跳转**：
  - 长段未变更上下文可一键折叠 / 展开；提供「上一处差异 / 下一处差异」跳转按钮与键盘快捷键，定位时高亮当前 hunk 并自动滚动到可视区，循环或到边界有明确终态反馈。
- **开关与统计**：
  - 「忽略空白差异」开关：切换后重新计算，仅空白变化的行不再计为变更；「仅看变更 / 折叠未变更」开关：隐藏上下文只留差异块。
  - 差异统计徽标实时显示新增 / 删除行数（及修改块数），随视图切换、折叠、编辑即时更新。
- **实时编辑模式（核心互动）**：
  - 可切换为左右双 `textarea` / 可编辑面板，用户直接改动任意一侧文本，差异以防抖方式即时重算并高亮，差异统计同步变化；提供「还原片段」与在多个内置片段间切换。
  - 内置片段贴近真实评审场景（如函数重构、配置项变更、CSS 调整），让增 / 删 / 改 / 行内变化 / 大段移动等情况都有可感知的演示。
- **键盘与可访问性**：
  - 组件可被键盘完整操作：Tab 在工具栏、开关、片段、可折叠 hunk 与可编辑面板间合理流转；跳转上 / 下一处差异、切换视图、折叠 / 展开均有快捷键或按钮焦点支持；可编辑区域支持常规文本编辑与 IME 输入。
  - 具备正确 ARIA 语义：差异区域以表格 / 列表语义表达「左右成对」关系，行 / 按钮 / 开关具备可被屏幕阅读器理解的标签与状态（如「新增行」「删除行」「第 3 处差异，共 8 处」），当前跳转结果通过 `aria-live` 播报位置与统计变化；可见焦点环。
  - 色彩不作为唯一信息载体：除底色外同时以行首 `+`/`−` 符号与状态槽编码增 / 删 / 改，兼顾色觉障碍用户。
  - 尊重 `prefers-reduced-motion`：关闭 / 减弱 hunk 定位、视图切换与重算的过渡动画，但所有差异计算、跳转、折叠、编辑功能完整。
- **响应式 / 移动端触控**：桌面宽屏默认并排；窄屏（手机）下并排可降级为上下分栏或自动切到统一视图以保证可读，触控热区 ≥ 44px，滚动 / 拖拽不与页面手势冲突；平板 / 手机三视口下排版均不错位。

## 核心亮点

1. **真实工程组件，可直接落地**：差异查看器是代码托管平台、CI/CD、配置中心、版本管理类网页的高频刚需组件，具备完整的增 / 删 / 改语义、Split / Unified 双视图、hunk 折叠跳转、忽略空白与仅看变更、差异统计，达到主流代码评审产品的核心完成度，而非玩具式「两段文字找不同」。
2. **行配对 + 行内字符级双层 diff 的技术与视觉深度**：行级 LCS 配对保证并排两侧严格对齐，修改行内部再做词元级 diff 精确定位真正变化的 token，配合三级语义色与 gutter 引导线，让「哪里改了、改成什么」一目了然，具备明显高于普通文本展示的技术含量与专业美感。
3. **实时编辑即时重算的强互动**：内置真实代码片段 + 左右可编辑面板，用户的每次键入都以防抖即时驱动差异重算、视图更新与统计变化，把一个看似静态的「展示组件」变成可操作、可探索的实验台，满足实用性 / 交互 / 美学三优先级。
4. **高可访问、零资源、离线可用**：纯文本与等宽排版即可呈现，不依赖任何外部词法库 / CDN / 字体；ARIA 成对语义、符号 + 颜色双通道编码差异、键盘全覆盖、减弱动效降级与三视口响应式完整，符合项目铁律且可直接用于生产网页。

## 历史案例对比（进入 Ready 前必填）

- **相似案例**：
  - `image-comparison-slider`（图片对比滑块）：同为「前后 / 新旧两版对比」母题，是最相近的交互概念。但它对比的是**两张图像**，以 `clip-path` 裁剪 + 单条滑块揭示左右画面，**没有文本行概念、没有逐行 LCS 配对、没有增 / 删 / 改语义、没有行内字符级 diff、没有行号、没有 hunk 折叠 / 跳转、没有差异统计、没有文本编辑重算**；本案例是结构化的代码 / 文本差异审查组件，数据模型（行序列比对）、视觉语言（等宽代码 + 三级语义色 + 行号槽）与交互（双视图、hunk 导航、实时编辑）完全不同。
  - `rich-text-toolbar`（富文本工具条）：同样包含可编辑文本与生成内容，但它面向**富文本排版编辑**（加粗 / 标题 / 列表 / 颜色、输出 HTML），不含任何「新旧两版文本逐行比对」能力，无差异视图与配对语义。
  - `resizable-table`（列宽可调数据表）/ `virtual-list`（万级虚拟滚动）/ `tree-view`（文件树）：同属「结构化信息展示」且含行 / 列表排版，但分别服务于数据行列、长列表窗口化与层级目录，均不消费「旧文本 → 新文本」两份输入，也没有差异计算与增删改表达。
  - 在池 IDEA-037（文本乱码解码器）：同属文字排版动效域，但它是**单向的标题字符随机解码视觉特效**，没有双输入、没有比对、没有审查交互，纯表现型。
  - 在池 IDEA-009（SVG 数据图表动效仪表盘）：同为开发者 / 数据向可视化，但它表达的是统计数据（描边生长图表），不涉及文本逐行差异。
  - 其余注册案例（表单、媒体、卡片、粒子、导航等）与在池 Idea 经逐条核对均无文本差异比对语义；`rejected.md` / `completed.md` 当前为空，无历史淘汰 / 完成项需规避。
- **差异说明**：核心创意差异在「**以行序列差异算法（LCS 配对）为内核、面向代码评审的结构化文本差异审查器**」，提供行级配对 + 行内字符级双层 diff、Split / Unified 双视图、hunk 折叠与跳转、忽略空白 / 仅看变更开关、差异统计与实时编辑重算。与 `image-comparison-slider` 的差异体现在数据对象（文本行序列 vs 位图图像）、核心机制（逐行 LCS + 行内 diff vs clip-path 裁剪）、交互方式（hunk 导航 / 双视图 / 可编辑重算 vs 单滑块揭示）与整体形态（代码审查面板 vs 图像对比舞台）；与 `rich-text-toolbar` / 表格列表类在「是否对两份文本做版本比对」上有本质分界。不属于仅换颜色 / 文案 / 微调参数的重复。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库、零 CDN，双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 零外部资源：不引用任何远程词法 / diff 库、字体或图片；行级差异（如 LCS 类）与行内字符 / 词元级 diff 均自行实现；语法着色如需呈现，以轻量、自包含的方式处理或退化为克制的等宽纯文本，不引入外部高亮库。
- 内置演示片段以纯字符串常量内置（覆盖函数重构、配置变更、样式调整等真实场景），不读取本地文件、不依赖网络；实时编辑基于原生可编辑元素，差异重算须防抖并控制复杂度，避免大文本下卡顿（可对内置 / 输入规模做合理上限与提示）。
- 并排两栏滚动同步、Split ⇄ Unified 切换保持浏览位置、行号与状态槽对齐；折叠 / 展开 hunk 与重算过程布局稳定不跳动。
- ARIA 成对语义、`aria-live` 跳转 / 统计播报、可见焦点环、键盘全覆盖、符号 + 颜色双通道编码、`prefers-reduced-motion`、桌面 / 平板 / 手机响应式与 ≥44px 触控热区完整。
- 图标使用内联 SVG；遵循项目统一的右上角点阵色 Title 胶囊与默认折叠 Micro-HUD 规范。
