## 创意概述

移动端与现代响应式 Web 中最高频的标准容器之一「底部弹层（Bottom Sheet）」：从屏幕底部升起的圆角浮层，用户可以直接抓住顶部抓手（drag handle）在多个预设吸附高度（detent，如：贴边小窗 peeking / 半屏 / 近全屏）之间连续拖拽，松手后依据位移与甩动速度自动吸附到最近档位；面板内内容可独立滚动，且只有当内容滚动到顶部、用户继续下拉时才把拖拽手势「交接」给面板收合，避免滚动与拖板互相抢手势。它同时具备遮罩点击 / Esc 关闭、焦点管理与键盘可达性，并在桌面宽屏下优雅呈现。

解决的体验问题：现有 `drawer` 案例是「四向、按钮触发、开 / 合二态」的抽屉，适合桌面侧边面板，但没有移动端 Bottom Sheet 的核心语言——**多档吸附高度、抓手直接拖拽、速度甩动、内层滚动与拖板的手势交接、底部安全区适配**。这些恰是 iOS/Android 原生 Sheet、各类外卖 / 地图 / 音乐 / 支付 App 里最常用的交互，当前案例库尚缺这一标准组件；用纯原生 Pointer Events + 弹簧物理实现一套可复用、可访问、跨输入设备一致的 Bottom Sheet，具备直接落地真实网页的价值。

## 预期展示效果

- **构图与整体风格**：
  - 单屏呈现一个贴近真实 App 的演示场景（如地图 / 音乐播放 / 详情列表 / 操作菜单中的一种情境），背景内容被半透明暗色遮罩压暗，底部浮层自屏幕下沿升起，占据视觉重心。
  - 浮层顶部为大圆角（仅上方左右圆角）、毛玻璃或高质感实色表面，顶部居中一条圆润的抓手（drag handle），下方是标题栏与可滚动内容区；浮层在最高档仍留出顶部安全间距，不顶满到屏幕最上沿。
  - 深色、克制、中性微色温的视觉语言（遵循 Anti-Slop 准则，拒绝蓝紫渐变与刺眼霓虹）；浮层投影随升起高度增强，与背景拉开层级。
  - 顶部保留项目统一的点阵色 Title 胶囊；可配默认折叠的 Micro-HUD 用于切换吸附档位演示 / 开关回弹手感等，便于对比不同形态。
- **主要视觉元素**：
  - 抓手 handle：居中的胶囊形小条，拖拽时有轻微形变 / 高亮反馈，是「这里可以拖」的直接暗示。
  - 吸附档位指示（可选，演示态）：当前处于 peeking / half / full 哪一档的轻微视觉反馈（如 handle 区状态点、或内容区露出比例），切换有清晰但克制的过渡。
  - 遮罩：随浮层高度联动的不透明度（低档遮罩更浅、高档更深），点击遮罩可关闭。
  - 内容区：长度超过面板可滚动区域的真实列表 / 详情内容，用于演示「内层滚动到顶再下拉才收板」的手势交接。
- **层次、材质、光影与关键细节**：
  - 浮层表面采用与项目一致的深色玻璃 / 实色质感与细边框，圆角、阴影随高度平滑变化；升起过程底部不露出穿帮缝隙，尊重设备底部安全区（`safe-area-inset-bottom`）。
  - 拖拽中面板严格跟手（1:1 或带极轻阻尼），松手吸附时使用带轻微过冲的弹簧曲线，档位之间过渡连贯；快速上甩可直接跨档吸附到更高档，快速下甩可直接关闭，手势「跟手感」是质感核心。
  - 内容滚动与面板拖拽的边界处理自然：内容未到顶时下拉，滚动事件不被面板吞掉；到顶继续下拉才进入拖板态并伴随细微的橡皮筋阻尼。

> 设计文档约束最终体验与设计意图；具体吸附高度比例、阻尼 / 弹簧参数、圆角与色值、演示情境的具体内容由实现阶段按整体视觉统一决定，不在此过早钉死。

## 动态与交互

- **打开与关闭**：
  - 点击触发按钮，浮层自底部以弹簧曲线升起并默认吸附到初始档（如半屏）；遮罩同步淡入。
  - 关闭途径：拖拽到关闭阈值以下松手 / 快速下甩、点击遮罩、按 `Esc`、点击关闭按钮；关闭后浮层落回屏幕下沿并归还焦点到触发按钮。
- **多吸附点拖拽（Pointer Events 统一鼠标 / 触控 / 手写笔）**：
  - 在抓手（及可定义的拖把头区域）按下并拖动时，浮层实时跟手上 / 下移动；正确处理 `touch-action`，拖拽期间不触发页面滚动或误选内容。
  - 松手依据当前高度与甩动速度，选择目标吸附档（peeking / half / full）或关闭：位移主导就近吸附，速度足够大时顺手势方向跨档 / 关闭；吸附动画带轻微回弹。
  - 吸附档之间也可通过点击 / 双击抓手快捷切换，并支持程序化设置当前档位。
- **内层滚动交接**：内容区可独立纵向滚动；仅当内容滚动到顶部且指针继续向下拖时，才把后续位移交给浮层进入收合拖拽，其余垂直拖拽由内容滚动消费；在更高档向下滚动内容不会意外收板。
- **键盘与可访问性**：
  - 浮层具备正确的对话框语义（`role="dialog"`、`aria-modal`、`aria-labelledby` 等），打开时焦点进入面板并在面板内循环（Tab / Shift+Tab 焦点陷阱），关闭后焦点归还触发元素。
  - 键盘可完整操作：`Esc` 关闭；抓手 / 头部按钮可聚焦，方向键或特定键可在吸附档之间切换；不使用指针的用户能展开到最高档查看全部内容。
  - 尊重 `prefers-reduced-motion`：开启减弱动效后，升起 / 吸附 / 关闭退化为即时或极短的无弹跳过渡，但档位、滚动与关闭功能完整。
- **响应式与移动端触控**：在手机视口模拟器与真机上为底部全宽浮层；桌面宽屏下可保持居中超大宽度上限或仍贴底的卡片形态，保证两种环境都美观可用；触控热区（尤其抓手）不小于 44px，适配底部安全区，不与浏览器手势 / 页面滚动冲突。

## 核心亮点

1. **多吸附点（detent）连续拖拽 + 速度甩动**：不是非开即合的二态抽屉，而是 peeking / half / full 多档、可连续跟手、按位移与甩速智能吸附并跨档，复刻原生 App Sheet 的跟手高级感。
2. **滚动与拖板的手势交接**：精确处理「内层可滚动内容」与「面板拖拽」的边界（到顶才交接、橡皮筋阻尼、未到顶不吞滚动），这是 Bottom Sheet 最容易做糙、也最体现工程质感的细节。
3. **跨输入设备一致 + 高可访问性**：Pointer Events 统一鼠标 / 触控 / 手写笔，完整对话框语义、焦点陷阱与焦点归还、Esc / 方向键操作、减弱动效降级、安全区与响应式适配，可直接作为真实网页通用组件。
4. **真实场景承载**：以贴近真实 App 的内容场景演示长列表滚动与多档面板，而非空壳弹层，具备即取即用的落地价值。

- **相似案例**：

  - `app-layout`（应用布局）：内含移动端遮罩抽屉作为布局骨架的一部分，是导航用途的二态侧边抽屉，并非可多档拖拽的 Bottom Sheet 组件。
  - 在池 IDEA-032（节点流编辑器）仅在响应式描述中提到「控件收进底部抽屉」，并未定义 Bottom Sheet 组件本身；其余在池 Idea（IDEA-001～044，含各类选择器 / 弹层 / 表单 / 图表等）经逐条核对无底部弹层主题。
- **差异说明**：核心创意差异在「**多吸附点、可被抓手连续拖拽并按位移 / 甩速智能吸附的底部专用面板，以及内容滚动与面板拖拽的手势交接**」。与 `drawer` 的二态四向抽屉相比，差异体现在交互方式（直接拖拽 vs 按钮开合）、状态空间（多 detent vs 开 / 合）、手势处理（滚动交接、速度甩动）与场景（移动端底部 Sheet vs 桌面边缘抽屉）；视觉上也有底部圆角浮层、抓手、安全区与随档遮罩等专属表达。不属于仅换颜色 / 文案 / 微调参数的重复。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库、零 CDN，双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 拖拽统一用 Pointer Events（`setPointerCapture` 等），位移使用 transform 走合成层，配合 rAF 与阻尼 / 弹簧曲线；拖拽与吸附过程不触发密集布局计算、不造成页面抖动。
- 必须正确处理 `touch-action` 与内层滚动交接（内容到顶才接管）、背景滚动锁定、`safe-area-inset-bottom` 安全区与窄屏 / 宽屏响应式。
- 对话框 ARIA 语义、焦点陷阱与焦点归还、Esc 关闭完整；尊重 `prefers-reduced-motion` 做降级。
- 内联 SVG 图标，不使用任何外部图片 / 字体资源；遵循项目统一的右上角点阵色 Title 胶囊与默认折叠 Micro-HUD 规范。
