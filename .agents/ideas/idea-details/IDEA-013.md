## 创意概述

时间输入是预约挂号、会议日程、酒店/航班预订、外卖与营业时间设置等表单里的高频刚需，而原生 `<input type="time">` 在不同浏览器里只有简陋的步进器或滚动列，体验割裂、难以承载「时 → 分」连贯选择与可视化确认。全仓 60 个已注册案例覆盖了日期（活动池 IDEA-001 Date Picker）、区间滑块、取色、OTP、可搜索下拉、银行卡等大量表单控件，却**没有任何「时间 / Time」选择控件**，也从未演示过「把指针绕圆心的连续角度量化（quantize）到离散刻度」这一经典拨盘交互。本案例做一个纯原生、零依赖、可直接投产的**环形拨盘时间选择器**：点击输入框在其下方浮出弹层，先在表盘上选「时」，再一键/自动过渡到选「分」，指针（或高亮扇区）随指针绕轴拖拽、靠近刻度时磁吸吸附并给出刻度触觉感，底部实时回显 `HH:MM`，确认后回填输入框；支持 12/24 小时制（含 AM/PM 切换）、分钟步进（1/5/15 分钟）、键盘全操作与完整 WAI-ARIA `dialog` + `slider` 语义。用一个**拟真的「预约 / 日程安排」场景**承载（如预约到店时间选择卡片），让它是真实页面模块而非孤立 demo。

## 预期展示效果

- **构图与整体风格**：
  - 用一个**拟真预约场景**承载：深色玻璃质感卡片（半透明深底 + 细描边 + 柔和投影，延续项目统一语言），卡片中有标题（如「预约到店时间」）、一枚只读样式的**时间输入框触发器**（显示当前 `HH:MM`，右侧时钟小图标，点击/聚焦唤起拨盘弹层），以及预约说明/已选时段摘要等真实信息。
  - 弹层为浮在输入框附近的**玻璃 Popover**：上半部分是大号时间回显（时与分两个可点区块，当前正在选择的一段高亮带下划线，点击可在时/分间切换；12 小时制下右侧有 AM/PM 切换），下半部分是**圆形表盘**——外圈均匀排布 12（或 24）个时刻数字，圆心有一枚指针/手柄从圆心延伸到当前刻度，被选中的刻度处有圆形高亮抓手；底部一行「取消 / 确定」操作。
  - 弹层带轻投影与细描边，并能在视口空间不足时自动翻转到输入框上方（复用项目已有的边缘避让思路）；右上角统一点阵色 Title 胶囊（遵循 HUD 规范）。
  - 配色克制：表盘刻度数字为低对比次要色，当前选中刻度、指针与抓手用有明度层次的强调色（具体色值不在本阶段限定），强调只服务于「当前值」表达；面板与背景退居其次。
- **主要视觉元素**：
  - **拟真圆形表盘（核心视觉）**：刻度数字沿圆周排布；分针态可在每 5 分钟位置放大数字、其余分钟用小圆点；指针从圆心指向当前值对应角度，选中刻度处有一枚明显的圆形抓手（handle），抓手与指针是主要可拖拽热区。
  - **角度量化与磁吸**：指针随指针绕圆心旋转，角度被量化到最近刻度（小时 12/24 等分；分钟按步进等分 60），靠近目标刻度时有轻微吸附与刻度「咬合」反馈（可选极轻的刻度咔嗒感，但音频须手势懒激活、默认克制）。
  - **时/分双态切换**：表盘在「选时」与「选分」间切换时，刻度数字与指针做一次简短的旋转/淡入过渡（如整体轻微转动 + 数字淡入淡出），回显区中 `时`/`分` 的高亮下划线同步移动，明确告知当前正在编辑哪一段。
  - **大号时间回显**：弹层顶部 `HH:MM` 大字号等宽数字（tabular-nums，避免切换跳动），正在编辑的一段为强调色并带下划线；12 小时制下 AM/PM 为可点切换的小胶囊。
  - **预约场景摘要**：卡片在确认后显示「已预约 14:30（下午 2:30）」之类的结果文案与状态，让选择有落点。
- **层次、材质、光影与关键细节**：
  - Popover 玻璃面板负责层级与浮起感（投影 + 背景模糊 + 细描边），表盘本身保持扁平、刻度清晰、抓手立体但不喧宾夺主；指针与抓手的强调色和回显区高亮一致，形成「表盘 ↔ 数字」的视觉绑定。
  - 动效统一使用一条舒展的缓出/轻弹性曲线：拖拽跟手即时（不做拖沓补间），吸附与切换表盘用短促过渡；弹层出现/消失用轻微位移 + 透明度过渡，避免生硬闪现。
  - 状态清晰可辨：触发器有 hover/focus 态；表盘当前刻度（强调）、非当前刻度（次要）、正在悬停预览的刻度（中间态）三级对比明确；键盘焦点有 `focus-visible` 环且抓手可被聚焦。
  - 回显数字等宽不抖动；窄屏下弹层不超出视口、触控目标（刻度抓手、AM/PM、确定/取消）足够大；弹层避让边缘时不遮挡输入框自身。

## 动态与交互

- **唤起与关闭**：点击/聚焦时间输入框触发器在其附近浮出 Popover（默认先选「时」或选中回显中的某一段）；点击弹层外、按 Esc 或「取消」关闭且不提交，「确定」提交并回填；打开时焦点进入弹层、关闭后焦点归还触发器，弹层内做 Tab 焦点循环。
- **指针绕轴选时（核心交互）**：在表盘上按下并拖动（Pointer Events 统一鼠标/触控/手写笔，圆心计算角度），指针实时跟随并量化到最近刻度；也支持直接点击某个刻度数字/点跳转选中；吸附到刻度时给轻微视觉咬合（与可选的极轻触觉音效）。分钟按当前步进量化（如 5 分钟步进则 60/5=12 个吸附点，1 分钟步进则 60 个）。
- **时 → 分连贯流程**：选完小时后可自动（短延迟）或点击回显「分」区块过渡到分针态，表盘刻度与指针做切换动效；两段都确定后「确定」可用；随时可点回显的「时/分」区块回到对应表盘，已选值保留。
- **12/24 小时制与步进**：24 小时制表盘展示 0–23（可内圈 13–23/外圈 0–12 或分页表达，具体形式实现阶段定，但须能选全 0–23）；12 小时制提供 AM/PM 切换；分钟步进可在 1/5/15 分钟间切换演示，切换步进时当前分钟按明确规则就近收敛、不留非法值。
- **键盘与可访问性**：触发器可用 Enter/Space 唤起；表盘以可聚焦抓手承载 `role="slider"`（或等价 spinbutton 语义）+ `aria-valuemin/max/now` 与「14 时 30 分」的 `aria-valuetext`，方向键（左右/上下）以 1 个步进增减、Home/End 到极值、Tab/点击在时与分抓手及 AM/PM、按钮间移动；值变化通过 `aria-live`/`aria-valuetext` 播报；时间结论由**数字 + 文本（上午/下午）+ 指针位置**多重表达，不单靠颜色。
- **减弱动态与移动端**：遵循 `prefers-reduced-motion`——关闭表盘旋转切换、弹性吸附与弹层位移动效，刻度与值直接呈现；选时、切换、键盘、提交功能完整。窄屏下 Popover 宽度自适应、必要时转为贴近底部的表单层，刻度与按钮触控达标，拖拽与点按行为一致。

## 核心亮点

1. **补上全仓「时间选择控件」类型空白**：60 个案例有日期（IDEA-001）、滑块、取色等大量表单控件却无 Time Picker；环形拨盘选时是预约/日程/预订类产品的高频刚需，可直接作为生产表单模块落地，而非一次性炫技。
2. **把「连续角度 → 离散刻度」的拨盘量化做扎实**：以圆心角映射时间值并量化到小时/分钟刻度，配合磁吸吸附与可拖拽圆形抓手，实现跟手又有「机械咬合」触感的选时，而非简单的滚动列或步进器。
3. **时/分双态表盘的连贯切换叙事**：同一表盘在选时与选分间做刻度 + 指针的过渡，回显区高亮下划线同步移动，配合大号等宽数字与 AM/PM，让「先选时再选分」成为一条清晰流畅的单线流程。
4. **完整工程化与可达性**：Popover 边缘避让、焦点陷阱与焦点归还、12/24 小时制、分钟步进与非法值收敛、Pointer Events 鼠标触控统一、WAI-ARIA dialog/slider + 方向键/Home/End + aria-live 播报、数字/文本/指针三重非颜色编码、reduced-motion 降级，达到可投产组件完整度。

## 历史案例对比（进入 Ready 前必填）

- **检查范围**：src/playground.js 全部 60 个注册案例（id / 标题 / 描述 / tags，components 45 / effects 12 / pages 3）+ playground/effects、playground/components、playground/pages 三个目录 + rejected.md（当前为空）+ completed.md（当前为空）+ 活动池 IDEA-001~012。并以 `time-pick|clock|timepicker|dial|时间|拨盘|时钟` 关键字全仓检索。
- **相似案例**：
  - `range-slider`（双拇指区间滑块）：同有「按指针位置映射连续值」的控件思维，也用 Pointer Capture 与键盘步进，但它是**一维水平滑轨**（线性最小/最大值区间），本案例把指针位置映射为**绕圆心的极坐标角度**并量化到环形刻度，含时→分双态表盘、AM/PM 与弹层 Popover，几何模型、视觉表达与控件语义均不同。
  - `color-picker`（HSL 色彩工作台）：同样有「把连续输入量化到离散反馈 + 滑块/取色」与多滑块联动，但它是 HSL 线性滑块与色彩值输出，无圆形表盘、无时间分段语义；不构成重复。
  - `otp-input` / `combo-box` / `payment-card-input` / `file-dropzone`：同属表单控件家族，但分别是验证码分段、可搜索下拉、银行卡、上传，均无绕轴选时模型与时间值。
  - `modal` / `drawer` / `context-menu` / `mega-menu` / `notification-center`：本案例的弹层复用其「浮层 + 边缘避让 + Esc/外点关闭 + 焦点管理」的成熟手法，但这些是通用容器/菜单，不提供任何时间输入；浮层只是承载，主体是拨盘选时。
  - `dynamic-dock`（鱼眼坞台）：圆形抓手拖拽与磁吸在「跟手吸附」手感上略有相近，但它是水平坞台图标鱼眼放大，无角度量化、无刻度、无时间值；交互几何完全不同。
  - `contribution-graph`（贡献热力图）/ `breathing-dot`（呼吸光点）：圆形/点阵视觉元素相近，但前者是只读数据网格、后者是状态指示动效，均无指针绕轴选值。
  - 活动池 `IDEA-001`（Date Picker 日历日期选择器）：最易被误认为重复——它是**日历网格上选「年月日/日期」**，本案例是**环形表盘上选「时分/时刻」**，输入维度（日期 vs 当日时刻）、视觉载体（月历网格 vs 圆形拨盘）、交互（点选日期格 vs 绕轴拖拽量化）均不同，二者互补而非重复；其余 IDEA-002~012（Carousel、Toast、Tags、Step Wizard、Speed Dial、Gooey 按钮、Chat、SVG Charts、Cascader、Star Rating、Pagination）均非时间控件。
- **差异说明**：核心创意是**「以圆心角极坐标映射并量化时间值的环形拨盘，配合磁吸抓手、时/分双态表盘连贯切换与大号时间回显，做成带焦点管理与边缘避让的可投产时间选择组件」**。与最接近的 range-slider（一维线性区间 vs 绕轴环形刻度）、color-picker（色彩线性滑块 vs 时间极坐标拨盘）、IDEA-001（月历网格选日期 vs 表盘选时分）在核心创意、视觉表达（圆形表盘、圆周刻度、圆心指针抓手、时/分切换动效、AM/PM）、交互方式（绕轴拖拽量化、磁吸、点击刻度、双段切换、键盘 slider）与整体表现（预约场景表单模块）上均有实质差异；不属于换色、换文案或微调参数类重复。全仓检索 time/clock/dial/时间/拨盘/时钟 等关键字无历史（含已删除）id 冲突，案例 id 定为 `time-picker`。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生零 CDN、双击 index.html 独立离线运行（通用项目铁律，详情不重复）。
- 表盘刻度、数字、指针与抓手一律使用**内联 SVG 或语义 HTML + CSS + 原生 JS** 绘制与变换，**不得引入日期/时间库、图表库、图标库或外部 SVG/字体/图片资源**；演示预约数据为内置静态数据，不发起网络请求。
- 统一使用 Pointer Events 处理鼠标/触控/手写笔的按下拖动与点按，合理使用 `setPointerCapture`；角度基于指针相对表盘圆心的 `atan2` 计算并量化到最近刻度，分钟步进切换时的就近收敛规则须明确且无非法中间值。
- 弹层定位需做视口边缘检测（空间不足翻转到上方/偏移），打开时焦点移入并循环、关闭后焦点归还触发器、支持 Esc 与外点关闭；动效优先 transform / opacity 合成友好属性，组件在 iframe 挂载/卸载时统一清理事件监听、rAF 与定时器，无残留。
- 可访问性为硬性要求：弹层具备 `dialog` 等价语义与模态焦点管理，表盘抓手具备 `slider`（或等价）语义与 `aria-valuemin/max/now`、「时/分 + 上午下午」的 `aria-valuetext`/aria-live 播报；焦点可见可达；时间结论由数字 + 文本 + 指针位置多重编码，不单靠颜色。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊；如需调节（12/24 小时制、分钟步进、重播入场、减弱动效），常驻演示控件 + 默认折叠 Micro-HUD（`H`/`Esc`、事件防穿透）。任何刻度音效须 Web Audio 手势懒激活、默认克制可关。
- 尊重 `prefers-reduced-motion`：降级为表盘/弹层最终态直出（或极短淡入），选时、时/分切换、步进切换、键盘与提交功能完整。
