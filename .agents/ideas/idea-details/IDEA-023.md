## 创意概述

作品集、摄影/设计案例、产品精选、新闻杂志等页面普遍使用「图片网格 + 悬停浮现标题/描述」的卡片，但绝大多数实现的覆盖层只会**固定从底部淡入或上滑**——无论鼠标从卡片的哪一条边进入、从哪一条边离开，动画方向都一样，缺乏空间连贯性，显得机械。本案例做一个纯原生、零依赖、可直接投产的**方向感知悬停图廊**：实时计算指针相对卡片中心的位置，判断其从**上 / 右 / 下 / 左**哪一条边进入，信息遮罩就**从同一条边滑入**；指针离开时再根据它实际离开的边缘，让遮罩**朝那条边滑出**。于是快速横向扫过一排卡片时，遮罩会像被指针「带着」从一侧掀开、又向另一侧退场，形成连贯的空间呼应。用一个**拟真的「精选作品集 / 案例网格」场景**承载（图卡 + 分类标签 + 标题 + 一句描述 + 查看动作），让它是真实页面模块而非孤立 demo；同时保留键盘聚焦等价反馈与触屏点按行为，避免做成只服务鼠标的炫技。

## 预期展示效果

- **构图与整体风格**：
  - 用一个**拟真作品集/精选内容场景**承载：克制的深色中性背景（延续项目统一语言，微弱色温倾向、拒绝蓝紫霓虹渐变），页头有区块标题与一句副文案，主体是响应式图片卡片网格（桌面多列、平板两列、手机单列，CSS Grid + gap）。
  - 每张图卡为统一圆角、细描边、柔和投影的图片卡：底层是一张构图完整的封面图，上层叠加一层信息遮罩（半透明深色材质 + 背景模糊），遮罩内自上而下为**分类小标签、标题、一句描述、一个「查看案例」动作**；遮罩默认不可见，悬停/聚焦时按进出方向滑入。
  - 右上角统一点阵色 Title 胶囊（遵循 HUD 规范），主题指示灯固定不随卡片内部色彩变化；底部居中可配一条极简操作指引胶囊（说明「从任意边缘移入试试」）。
  - 配色克制：遮罩为带模糊的半透明深色材质，文字为高对比浅色（正文对比满足 WCAG AA），仅用一处有明度层次的强调色服务于分类标签/动作，强调不泛滥。
- **主要视觉元素**：
  - **方向感知遮罩（核心视觉）**：同一块遮罩通过四个方向的进入/退出位移（从上/右/下/左滑入并反向滑出）表达空间方向感，而非单一淡入；遮罩与图卡边缘严丝合缝、圆角一致，滑动时不露白、不溢出。
  - **信息层次**：分类标签为小号字距拉开的胶囊/大写小字，标题为醒目大字，描述为次级浅色一行或两行，动作以文字链或细描边按钮呈现；文字随遮罩分方向做轻微错峰（stagger）进入，增强「掀开」感但节奏短促。
  - **封面图本身的品质**：图片在卡片内以 `object-fit: cover` 充满、焦点居中；由于案例须零外部资源离线运行，封面图一律用**内联 SVG / 纯 CSS 渐变与几何图形构造的抽象或拟物画面**（不同卡片用不同但协调的画面与主题色），不引用任何外链图片。
  - **网格的整体节奏**：卡片间距、圆角、描边统一；悬停卡片可有极轻微的上浮/阴影加深作为次级反馈，但主角是遮罩方向，不喧宾夺主。
- **层次、材质、光影与关键细节**：
  - 遮罩用半透明深色 + `backdrop-filter: blur` 营造压在图上的玻璃/磨砂材质层级；其投影/描边与卡片统一，浮起感来自模糊与压暗而非重阴影。
  - 动效统一使用一条舒展的缓出曲线（`cubic-bezier` 类似 ease-out/轻回弹），遮罩位移用 transform、显隐用 opacity，全部合成友好；进入跟手即时、时长短促，不拖沓。
  - 边缘判定要稳：在卡片边界附近抖动时不应出现遮罩方向来回闪烁——进入方向只在「从无到有（enter）」那一刻计算一次并锁定，离开方向只在「从有到无（leave）」那一刻计算一次；相邻卡片间快速划过时按真实出入边分别得到连贯方向。
  - 状态可辨：默认（遮罩隐藏、图完整可见）、悬停/聚焦（遮罩从对应边进入、信息可读）、键盘焦点（`focus-visible` 清晰环 + 遮罩展开）三级明确；非颜色编码（信息以文字 + 遮罩呈现，不仅靠色彩）。
  - 窄屏与触屏：卡片不超出视口、文字不尴尬折行（动作单行），触控目标足够大；触屏首次点按展开遮罩、再次点按动作跳转/再次点按空白收起的行为自然（具体取舍实现阶段定，但须有明确可用的触屏路径）。

## 动态与交互

- **进入方向判定（核心交互）**：指针在卡片上触发 `pointerenter`/`pointermove`（用 Pointer Events 统一鼠标/触控/手写笔），取指针相对卡片中心的坐标 `(x, y)`，比较水平与垂直偏移的绝对值：水平差更大则来自左/右边（由 x 符号决定），垂直差更大则来自上/下边（由 y 符号决定）；据此把遮罩的初始偏移设为「位于该边外侧」，再过渡到归位，实现**从进入边滑入**。进入方向在一次 enter 周期内只计算一次，避免中途翻转。
- **离开方向判定**：指针移出触发 `pointerleave` 时用同一算法计算其离开的边缘，遮罩过渡到「朝离开边外侧」的偏移并淡出，实现**向离开边滑出**；快速横向扫过相邻卡片时，前一张向右退场、后一张从左入场，形成连续的方向叙事。
- **遮罩内信息错峰**：遮罩滑入的同时，标签/标题/描述/动作按索引做极小延迟的位移 + 淡入；滑出时整体快速收起，不做拖沓的逐项退场。
- **拟真场景动作**：点击「查看案例」/卡片主操作给出明确反馈（在纯前端演示里可切换为该作品的详情态或轻提示，不发起真实跳转/请求）；网格支持多卡片、方向互不干扰。
- **键盘与可访问性**：卡片以可聚焦元素（卡片本身或其主操作链接/按钮）承载，Tab 聚焦时遮罩以一个确定的默认方向（如自下而上）展开并保证标题/描述/动作可读可达，`focus-visible` 焦点环清晰；失焦按对应方向收起。卡片信息在遮罩隐藏时仍应通过可读文本/`aria-label` 或 `figcaption` 等方式对辅助技术可得，不仅依赖悬停。动效遵循 `prefers-reduced-motion`：关闭方向性滑动与错峰，遮罩直接淡入/淡出（或直接呈现），但悬停、聚焦、键盘、动作功能完整。
- **移动端触控**：Pointer Events 下点按可展开遮罩（enter 方向由触点相对卡片中心位置推断，或在点按场景采用稳定的默认方向），再次点按主操作执行、点按卡片外或关闭控件收起；窄屏网格自适应单列/两列，不溢出、触控达标。

## 核心亮点

1. **补上全仓「方向感知悬停（direction-aware hover）」这一经典高投产微交互空白**：60 个注册案例与 22 个 Ready Idea 覆盖了 3D 倾斜、聚光描边、图片对比/放大、跑马灯等大量卡片与图片交互，却没有任何「遮罩随指针出入边缘方向滑入滑出」的方向感知悬停；它是作品集/产品/资讯网格可直接复用的生产级模式，而非一次性炫技。
2. **把「进入边 + 离开边」的空间方向感做扎实**：基于指针相对卡片中心的位置判定上/右/下/左，进入方向只在 enter 瞬间锁定、离开方向在 leave 瞬间计算，既实现「被指针带着掀开/退场」的连贯叙事，又避免边界抖动导致的遮罩翻转闪烁。
3. **零资源约束下仍保持高质感画面**：封面图全部用内联 SVG / CSS 渐变与几何构造、零外链零网络请求，配合玻璃磨砂遮罩、信息错峰与统一缓动，做到独立离线双击即开却不廉价。
4. **完整可达与多端**：键盘聚焦等价展开 + 清晰焦点环 + 遮罩信息对辅助技术可读 + `prefers-reduced-motion` 降级 + 触屏点按路径，使其不是只服务鼠标的 demo，而是可投产组件完整度。

  - `image-zoom`（商品放大镜）：同样作用于图片并跟随指针，但反馈是**圆形镜片的局部放大**，无信息遮罩、无出入边方向滑动。
  - `avatar-stack`（头像堆叠名片）/ `tooltip`（智能提示）：悬停浮出信息卡片且有边缘避让，但其浮层是**跟随触发元素定位的小气泡**（碰撞检测翻转），不是铺满图卡、按指针出入边方向滑动的遮罩，触发与定位逻辑不同。
  - `scroll-reveal`（滚动入场揭示）/ `vertical-timeline` / `infinite-feed`：关键字 `reveal` 命中来源，均为**进入视口时一次性的滚动入场动画**，与指针在单一卡片上的方向感知悬停无关，触发方式（滚动 IO vs 指针进出）与方向逻辑（预设方向 vs 实时四方向）不同。
  - `cursor-follow`（多层跟随光标）：全页自定义光标与磁吸，作用域是全局光标样式，不是卡片信息遮罩；本案例不改写系统光标。
  - `logo-marquee`（跑马灯）/ `swipe-card-deck` / `guided-tour`：分别是无缝平移、卡牌拖飞、聚光灯挖空遮罩，均无「指针出入边 → 遮罩四方向滑动」机制。
  - 活动池 `IDEA-002`（Carousel 内容轮播）、`IDEA-015`（View Transition Gallery 共享元素转场）、`IDEA-016`（Image Lightbox 全屏灯箱）：同含「图/画廊」字样，但分别是轮播、跨视图共享元素形变、点击进入全屏查看，均非网格内悬停方向感知遮罩；其余 IDEA-001、003~014、017~022 为日期/通知/输入/向导/菜单/图表/选择器/评分/分页/时钟/开关/灯箱/缓动/翻牌/表情/提及/滑删/验证码等，无方向感知悬停。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生零 CDN、双击 index.html 独立离线运行（通用项目铁律，详情不重复）。
- 封面图、图标、分类图形一律使用**内联 SVG 或纯 CSS 渐变/几何**构造，**不得引用外部图片/字体/图标库，不发起任何网络请求**；网格与演示文案为内置静态内容。
- 方向判定与遮罩位移使用原生 JS（指针相对卡片中心的坐标比较）+ CSS transform/opacity 过渡；统一使用 Pointer Events 处理鼠标/触控/手写笔，进入方向在一次 enter 周期只计算一次、离开方向在 leave 时计算一次，避免边界抖动翻转。
- 动效仅使用 transform / opacity 等合成友好属性，统一缓动曲线与短促时长；组件在 iframe 挂载/卸载时统一清理事件监听与定时器，无残留；不默认使用 Web Audio（如加入极轻音效须手势懒激活、默认关闭可关，非必需）。
- 可访问性为硬性要求：卡片/主操作可聚焦，键盘聚焦时遮罩以确定默认方向展开且信息可达、`focus-visible` 清晰；遮罩内信息对辅助技术可读（语义标签或等价文本），结论不仅靠颜色；`prefers-reduced-motion` 下关闭方向滑动与错峰，改为直接淡入淡出/直出，全部功能保留。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊（主题指示灯固定不随卡片内部颜色变化）；如需调参（动效开关、减弱动效、方向模式演示）可用常驻演示控件 + 默认折叠 Micro-HUD（`H`/`Esc`、事件防穿透），非必需不强行加面板。
