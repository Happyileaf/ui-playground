## 创意概述

评分是电商商品页、影评/书评、内容社区与满意度反馈中出现频率极高的表单控件，但全仓 60+ 已注册案例覆盖了 OTP、标签、取色器、区间滑块、银行卡等大量表单与微交互，却**没有任何「评分 / Rating」控件**，也没有演示过「两层图形叠加按宽度裁切表达连续分值（半星）」这一经典纯 CSS 评分技术。本案例做一个纯原生、零依赖、可直接投产的**星级评分组件**：支持整星与半星两种精度、指针移动实时悬停预览（含半星左右半区判定）、点击/触控提交后被选中星做弹性缩放与微光迸发、上方一枚随当前分值联动的情绪文案胶囊、可清空重选、可只读展示；具备完整 WAI-ARIA `radiogroup/slider` 语义与键盘操作。同时用一个**拟真的「商品评价 / 满意度反馈」场景**承载评分组件，含平均分、评分人数与评价摘要，让它是一个真实页面模块而非孤立 demo。

## 预期展示效果

- **构图与整体风格**：
  - 用一个**拟真的评价场景**承载：场景中心是一张深色玻璃质感卡片（半透明深底 + 细描边 + 柔和投影，延续项目统一语言），卡片顶部有标题/对象名（如商品名或「本次服务您打几分」），其下是一枚**大号主评分控件**（一排 5 颗星，可在整星/半星精度间切换），星星上方或下方是一枚**情绪文案胶囊**（随悬停/已选分值在「很不满意 / 一般 / 还不错 / 很满意」等档位间切换，带小图标，不单靠颜色）；卡片底部展示**评分摘要区**：大号平均分、5 颗只读小星、评分人数，以及若干条分布条（5 星到 1 星占比条，悬停看百分比），营造真实评价氛围。
  - 面板提供少量常驻演示控件：整星/半星精度切换、允许清空开关（或再评一次按钮）、只读态切换，用于反复触发不同交互；另有统一的右上角点阵色 Title 胶囊（遵循 HUD 规范）。
  - 配色克制：未选星为低饱和描边/暗填充的「空态」，选中星为有明度层次的暖调强调色（具体色值不在本阶段限定），强调色只出现在分值表达上，背景与面板退居其次。
- **主要视觉元素**：
  - **双层星图形（核心技术）**：每颗星位置由「底层空态星」+「上层实心星」叠加，上层以纯 CSS `width`（百分比，0/50%/100%）或 `clip-path/overflow` 裁切表达 0、半星、整星三态，5 星共用或逐星控制；星路径用内联 SVG 绘制，圆角线帽与描边统一，保证放大不糊。
  - **悬停预览层**：指针在星排上移动时，预览填充（含半区判定：指针落在某星左半给半星、右半给整星）实时跟随，与「已确认分值」在视觉上区分（如预览为半透明描边/淡填充，已选为实心强调）；指针移出后预览消失、回到已确认分值。
  - **弹性确认动效与微光**：点击提交后，从第 1 颗到被选星做一个很短的**错峰弹性缩放**（按下回弹），被点亮的星可伴随极克制的高光/小光点迸发（数量受控、动画结束回收），避免廉价满屏粒子。
  - **情绪文案胶囊**：随分值档位切换文本与表情/图标，切换有轻微位移或淡入，文字是主要载体、颜色仅辅助。
  - **评分摘要**：大号平均分（可选 count-up 入场）、只读星、评分人数与 5→1 星分布条；分布条用宽度表达占比，悬停显示百分比文案。
- **层次、材质、光影与关键细节**：
  - 玻璃面板负责层级，星星本身保持扁平、轮廓清晰；空态星与实心星对比足够明确，半星边界锐利但自然（同一星路径裁切，而非两个半张拼接造成错位）。
  - 动效统一使用一条舒展的弹性/缓出曲线，错峰仅用于「确认」瞬间的 5 颗星依次点亮，悬停预览则即时跟手、不做拖沓动画，保证控件响应感。
  - 焦点、悬停、按下、禁用/只读四种状态清晰可辨：键盘焦点有明确 `focus-visible` 环；只读态无指针响应、呈现为数据展示；被禁用操作时给出非破坏性的克制反馈。
  - 文案胶囊与分布 tooltip 带轻投影并自动避让视口/卡片边缘；星排在窄屏下不换行不溢出，触控目标足够大。

## 动态与交互

- **指针悬停预览**：指针进入星排后，依据落点星索引与左右半区（半星精度下）实时计算预览分值，预览填充即时跟随；移动到情绪档位边界时文案胶囊同步预演；指针完全移出星排，预览撤销、显示回当前已确认分值（未评分则空态）。触屏无 hover，以点按/拖动经过直接选中对应分值（Pointer Events 统一鼠标与触控，热区不小于触控标准）。
- **确认与清空**：点击/点按提交分值，触发错峰弹性点亮 + 克制微光，情绪胶囊落定为该分值文案，摘要区平均分/人数可按演示数据联动刷新；支持再次点击同一分值（或专门按钮）清空回到未评态，清空同样有回收动画。
- **精度切换**：整星模式下半区判定关闭（最小步进 1）；半星模式步进 0.5；切换精度时若当前值含半星而新精度不支持，按明确规则（四舍五入或就近）收敛并即时反馈，不留非法中间值。
- **只读 / 摘要**：只读态用于摘要区小星与可切换的主控件演示，纯数据展示、不响应输入；分布条悬停/键盘聚焦显示该星级占比。
- **键盘与可访问性**：组件暴露清晰的可访问语义（推荐 `role="radiogroup"` 整星单选，或在半星连续值时用 `role="slider"` + `aria-valuemin/max/now` 与 `aria-valuetext` 表达「4.5 星·很满意」）；Tab 可聚焦，方向键（左右/上下）以精度步进调整、Home/End 到极值，空格/回车确认，调整过程通过 `aria-live` 或 `aria-valuetext` 播报当前分值与文案；评分结果不以颜色为唯一载体（星数 + 数字 + 文案三重表达）。
- **减弱动态与移动端**：遵循 `prefers-reduced-motion`——关闭弹性缩放、错峰与微光迸发，直接呈现最终填充；所有评分、清空、精度切换、键盘功能保持完整。窄屏下卡片纵向自适应，星排与文案不溢出、触控目标达标。

## 核心亮点

1. **补上全仓「评分控件」类型空白**：60+ 案例有大量表单与微交互却无 Rating；星级评分是电商/评论/满意度的高频刚需，可直接作为生产页面模块落地，而非一次性炫技。
2. **把「双层叠加按宽度裁切」的半星技术做扎实**：同一星路径上下层叠加，纯 CSS 宽度/裁切表达 0 / 半星 / 整星，配合指针左右半区判定实现真正的半星精度，而非常见的只能整星或用两张半星硬拼。
3. **跟手预览 + 弹性确认的双层反馈节奏**：悬停（半透明即时预览）与确认（错峰弹性点亮 + 克制微光）在视觉与时间上明确分层，既跟手又有「落定」的满足感，情绪文案胶囊让分值带语义。
4. **完整工程化与可达性**：整星/半星精度、清空、只读、评分摘要分布条、Pointer Events 鼠标触控统一、WAI-ARIA（radiogroup/slider）+ 方向键/Home/End + aria-live 播报、数字/星数/文案三重非颜色编码、reduced-motion 降级，达到可投产组件完整度。

## 历史案例对比（进入 Ready 前必填）

- **相似案例**：
  - `like-button`（双击点赞迸发）：同属「正反馈类微交互」且都有心形/碎片迸发，但它是**二值（赞/不赞）的社交按钮**，核心是双击手势与单颗心形迸发；本案例是 **0.5 步进、0–5 的连续评分控件**，核心是双层星图形裁切、半区判定、悬停预览与评分摘要，信息量、交互模型与控件语义完全不同。
  - `range-slider`（双拇指区间滑块）/ `image-comparison-slider`（对比滑块）：同样有「按指针位置映射连续值」的控件思维，但它们是**一维滑轨**（区间/图片裁剪位置），无星形双层图形、无档位语义文案、无评分摘要；本案例把连续值映射到离散星视觉并叠加情绪语义。
  - `avatar-stack`（头像堆叠名片）/ `tooltip`（智能提示）/ `guided-tour`（新手引导）：都使用边缘感知气泡，但仅借用其「气泡避让」手法；它们不提供评分输入。
  - `confetti-burst` / `fireworks`（彩带/烟花粒子）：本案例确认瞬间的「微光迸发」在表象上与粒子庆祝相近，但**数量严格受控、从属于评分确认的一次性微反馈**，主体是控件而非粒子作品；不使用其物理粒子系统。
  - `count-up`（数字滚动）：摘要区平均分可能复用数字滚动入场，但仅为从属点缀；count-up 是单一文本动效，无任何评分输入与半星图形。
  - `otp-input` / `tags-input 相关（IDEA-004）` / `payment-card-input` / `combo-box`：同属表单控件家族，但分别是验证码分段、多值芯片、银行卡、可搜索下拉，均不含评分模型；不存在重复。
  - 活动池 `IDEA-001~010`（Date Picker、Carousel、Toast、Tags Input、Step Wizard、FAB Speed Dial、Gooey 下载按钮、Chat Workspace、Animated Charts、Cascader）：依次为日期选择、内容轮播、轻提示、多值输入、多步表单、角部动作菜单、液态任务 CTA、即时通讯、SVG 数据图表、逐级联动选择，**均非评分控件**；其中 IDEA-009 的图表分布条与本案例摘要分布条都表达占比，但本案例分布条只是评分摘要的从属元素，主体是评分输入控件，不构成创意重复。
- **差异说明**：核心创意是**「以双层星图形宽度裁切实现整星/半星连续评分，配合跟手悬停预览、弹性确认微光与情绪文案，做成带评分摘要的可投产评价组件」**。与最接近的 like-button（二值社交点赞 vs 0.5 步进 0–5 结构化评分）、range-slider（一维滑轨 vs 双层星视觉 + 档位语义）、confetti-burst（粒子作品 vs 受控从属微反馈）在核心创意、视觉表达（双层 SVG 星裁切、半区填充、情绪胶囊、评分摘要分布条）、交互方式（半区悬停预览、确认/清空、精度切换、只读、键盘 slider/radiogroup）与整体表现（评价场景模块）上均有实质差异；不属于换色、换文案或微调参数类重复。全仓检索 rating/rate/star/score/review 等关键字无历史（含已删除）id 冲突，案例 id 定为 `star-rating`。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生零 CDN、双击 index.html 独立离线运行（通用项目铁律，详情不重复）。
- 星图形一律使用**内联 SVG + 原生 JS/CSS** 手工绘制与裁切表达半星，**不得引入图标库、评分库、动画库或外部 SVG/字体/图片资源**；演示评价数据为内置静态数据，不发起网络请求。
- 统一使用 Pointer Events 处理鼠标/触控/手写笔的移动与点按，合理使用 `setPointerCapture`（如采用拖动评分）；半区判定基于指针在星单元内的相对水平位置，精度切换时步进与非法值收敛规则明确。
- 动效优先使用 transform / opacity 等合成友好属性；确认微光粒子须设数量上限并在动画结束后回收 DOM；组件在 iframe 挂载/卸载时统一清理事件监听、rAF 与定时器，无残留。
- 可访问性为硬性要求：整星模式 `radiogroup`（或等价）、半星连续值 `slider` 语义，`aria-valuemin/max/now` 与「分值 + 文案」的 `aria-valuetext`/aria-live 播报齐备；焦点可见、可达；评分结论由星数 + 数字 + 文案三重编码，不单靠颜色。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊；如需调节（精度、清空、只读、重播入场、减弱动效），常驻控件 + 默认折叠 Micro-HUD（`H`/`Esc`、事件防穿透）。
- 尊重 `prefers-reduced-motion`：降级为最终填充直出（或极短淡入），评分、清空、切换、键盘功能完整。
