## 创意概述

苹果发布会产品页（AirPods / iPhone / Vision Pro 页面）把「滚动」这种最朴素的页面动作变成了一台放映机：页面向下滚，画面却被**定格在视口中央**，一台产品随滚动进度旋转、亮起、拆解、推近，卖点文案在正确的帧上逐段浮现——用户滚到哪里，故事就精确地讲到哪里，可以随时停下、往回倒、再看一遍，节奏完全握在用户手里。这是当代高端产品发布页、硬件众筹页、品牌故事页里最具辨识度、也最被实际验证的落地页范式（实用性极高，设计师与前端日常需求旺盛），但它与普通「滚动入场动画」有本质区别：不是元素一次性淡入后再也不动，而是一段**滚动位置与画面状态一一映射、可正放可倒放、任意时刻定格都自洽**的连续编排（scroll-scrubbed choreography）。

本案例做一个纯原生、零依赖、零 CDN、零外部图片/字体、双击离线即用的**视口定格滚动叙事产品页**：页面纵向是一条数屏高的滚动轨道（track），轨道内部用原生 `position: sticky` 把一个舞台（stage）钉在视口中；JS 以 `requestAnimationFrame` 读取轨道滚动进度（0→1，可用 Lerp 做轻微阻尼平滑），把连续进度映射为一段**归一化时间线**（timeline，按章节划分为若干区间），驱动舞台上全部图层：一台全部由 CSS/SVG 构造的虚构产品（抽象设备本体：圆角机身、屏幕、材质高光，零产品照片）做 3D 倾斜/旋转/位移/缩放，屏幕内容逐层点亮，功能卖点标注（callout）按章节交叉淡入淡出并以引导线指向产品对应部位，背景氛围（径向光斑、细网格、漂浮微粒）随章节色温缓慢流动，侧边章节圆点导航与百分比读数实时联动，结尾章节产品落定、浮现完整名称与 CTA。交互多路径：滚轮/触控板/触屏纵向滑动（原生滚动，不劫持、不 transform body）、键盘 PageDown/PageUp/Space/方向键（浏览器原生）、Tab 到章节圆点后 Enter 用 `scrollIntoView` 跳转、可拖拽/点击的进度轨道直接 scrub 到任意帧；画面状态完全由滚动位置决定（确定性），同一位置永远呈现同一帧，正滚倒放均成立。全部编排尊重 `prefers-reduced-motion`：检测到偏好时退化为普通纵向分节产品页（各章节静态堆叠、卖点全部直接可读、导航锚点照常工作），不做定格与位移动画，但信息与 CTA 一个不少。

当前案例库 60 个已注册案例中，滚动相关仅有 `scroll-reveal`（IntersectionObserver 触发的一次性入场：上移/缩放/滑入/模糊，进入视口播放一次即解除观察）、`scroll-progress-bar`（顶部 scaleX 细进度条 + 右侧章节圆点 + 回顶按钮，进度只读、不驱动任何画面）、`vertical-timeline`（左右交替时间线卡片的滚动揭示，中央脊柱填充），在池 39 个 Ready 中，IDEA-015 视图转场画廊是点击导航触发的 View Transitions API 跨页共享元素形变，IDEA-038 是点击展开的 Bento FLIP 网格，均非滚动驱动；全仓与活动池检索 `scroll / sticky / pin / scrub / 叙事 / story / 发布页 / parallax`，无任何「sticky 定格 + 连续进度时间线映射 + 多图层逐帧编排」主题，`pages` 分类仅 auth / pricing / app-layout 三个案例、池中仅 IDEA-008 一个页面级 Ready，产品发布页这一最高频商业页面形态完全空白。

## 预期展示效果

- **构图与整体风格**：
  - 一镜到底的深色产品发布页：滚动轨道高约 4～6 屏，内含一个占满视口的 **sticky 定格舞台**；舞台中心是 CSS/SVG 构造的抽象产品（居中偏上），产品四周分布当章卖点标注（左/右错落，细引导线连向产品对应部位），侧边固定一列章节圆点导航（带当前章标签与百分比），顶部为极简产品名锚栏，底部为极细进度轨道。
  - 延续项目暗色、低饱和、Anti-Slop 审美：近黑深空背景配极弱工业细网格与随章节流动的克制色温光斑（每章一个微弱主色倾向，不做彩虹轮转）；产品为哑光金属/玻璃拟态质感（分层渐变、极细描边、柔和投影、一道随滚动位移的扫光），卖点标注是小型毛玻璃胶囊（描边 + 半透明底 + 小字），数字读数用系统等宽字体栈；全部图形/图标/产品本体/引导线内联 SVG 或纯 CSS 构造，零外部图片、零外部字体、零网络请求。拒绝霓虹满屏、拒绝粒子烟花式堆砌、拒绝廉价大字渐变。
  - 桌面宽屏产品居中、标注左右分布；平板标注收到单侧或产品下方；手机上产品占上半屏、标注在下半屏纵向排列且字号/热区适配，sticky 定格在移动端同样成立（不依赖桌面滚轮），触屏纵向滑动即原生 scrub；任何宽度下文案不溢出、引导线指向不明显错位。
- **主要视觉元素**：
  - **CSS/SVG 虚构产品**：抽象设备本体（圆角机身分层：金属外框、玻璃屏幕、镜头/按键等少量可辨识细节），随时间线做 3D 倾斜旋转、推进推远与局部放大；屏幕在「点亮」章节由暗到亮浮现 UI 图层（通知卡片、环形仪表等纯 CSS 图形）；某一章镜头推近一个局部细节（如由 SVG 描边环表示的续航/性能仪表，环的描边进度随该章滚动进度连续填充）。
  - **章节卖点标注（callout）**：每章 1～3 个标注，带小标题 + 一行说明 + 指向产品部位的引导线；按章节进度交叉淡入淡出/轻位移（非滚到就永久定格，倒滚时正确退回），非当前章标注不可见或弱化，保证画面任何帧都干净。
  - **进度与导航系统**：右侧章节圆点（章名 + 当前章高亮 + 实时百分比）、底部极细进度轨道（可点可拖直接 scrub）、顶部锚栏当前章节名轻切换；当前章指示不仅靠颜色（圆点大小/描边/标签显隐多重编码）。
  - **背景氛围**：随章节色温缓慢流动的径向光斑与极弱网格纵深漂移，仅作环境，不抢产品焦点；结尾章产品归位、完整产品名与双 CTA（主按钮 + 次链接）浮现。
- **层次、材质、光影与关键细节**：
  - 视觉四层：深空背景与氛围光斑（最底）→ sticky 舞台产品本体（核心）→ 引导线与卖点标注（解说层）→ 导航/锚栏/进度（固定 HUD 层）；层级靠明度、模糊与投影明确区隔。
  - **进度映射必须确定性是底线**：产品与标注的每个可视状态都由「当前滚动进度归一化到时间线区间」计算得出（含正向与反向），同一滚动位置刷新、正放、倒放结果完全一致；不允许进入视口后改由独立 CSS 无限动画自行播放导致状态与滚动位置脱钩，也不允许累积型 transform（越滚越偏）。
  - 滚动驱动只走 rAF + 原生 scroll，读取/写入在同一帧内完成（写仅用 transform/opacity，避免布局抖动），Lerp 阻尼可选且不破坏「定格自洽」（阻尼在滚动停止后须收敛到真实进度，不长期漂移）；章节交叉过渡有轻微缓动而非硬切，但区间边界处状态明确。
  - 高光与材质变化克制：一道扫光随产品旋转角位移，屏幕亮起有柔和内辉，SVG 描边环随章节进度连续生长；信息不能仅靠颜色传达（标注显隐、引导线、图标形状共同编码）。

> 设计文档约束最终体验与设计意图；章节数量与每章具体卖点文案、产品具体品类造型（抽象手机/耳机/音箱均可，但必须纯 CSS/SVG 可实现）、时间线分段比例、Lerp 系数、缓动函数、HUD 暴露哪些参数，由实现阶段按叙事节奏与手感统一决定，不在此过早钉死；但「纵向原生滚动 → sticky 定格舞台 → 连续进度映射归一化时间线 → 产品/标注/背景多图层逐帧正反向联动、任意帧自洽 → 多输入可 scrub、reduced-motion 下退化为静态分节页」这条链路必须真实成立，不允许用一次性 IO 入场动画冒充滚动叙事、不允许滚动停止后画面与位置脱钩、也不允许引入任何外部图片/字体或劫持原生滚动。

## 动态与交互

- **触发方式（滚动主导、多输入统一，非自动播放）**：
  - **滚轮/触控板/触屏**：页面纵向原生滚动（轨道为真实文档高度，**不**用 transform 伪造滚动、不锁页面、不禁断默认行为），舞台 sticky 钉住，手指/滚轮即为逐帧推进与倒放，触屏同样成立。
  - **键盘**：PageDown/PageUp/Space/方向键走浏览器原生滚动即自然 scrub；Tab 可聚焦各章节圆点与 CTA，Enter 触发 `scrollIntoView` 平滑跳到该章；焦点环始终可见。
  - **指针**：点击侧边圆点跳章；点击或拖拽底部进度轨道直接 scrub 到任意帧（Pointer Capture，拖拽时页面跟随）；CTA 按钮有克制 hover/press 反馈（演示性质，不跳真实业务）。
- **滚动时间线引擎（核心逻辑）**：
  - rAF 循环中读取轨道相对视口的滚动进度并钳制在 0～1，按预设章节边界切成归一化时间线；每个图层定义自己在时间线上的关键态（区间/值/缓动），由统一的进度求值驱动 transform、opacity 与少量 CSS 变量（如扫光角度、描边环 dashoffset、背景光强）；切换标签页（visibilitychange）或卸载时取消 rAF，回到页面后从真实滚动位置重新求值，状态不漂。
  - 可选 Lerp 平滑：渲染进度跟随目标进度做轻阻尼，滚动停止后必须收敛；`prefers-reduced-motion` 或用户在 HUD 关闭时直接取真实进度（无插值）。
  - 不做自动播放/自动轮播；演示入口只能通过用户自身的滚动、拖拽或跳章操作推进故事。
- **控制与可配置项（Micro-HUD 默认折叠，`H`/`Esc` 切换、事件防穿透）**：实时显示原始进度与（开启阻尼时的）渲染进度、当前章节索引/名称、reduced-motion 生效状态；可切换 Lerp 阻尼开关/强度（实时可感知画面跟随差异）、标注引导线显隐、背景氛围强度；提供「回到首帧/末帧」按钮。右上角统一点阵色 Title 胶囊为强制项。
- **可访问性（一等路径）**：
  - 语义结构：轨道各章为带标题的真实 `<section>`（文案在 DOM 中完整存在，非仅画在图形里），圆点导航为锚点列表（`aria-current` 标记当前章），进度轨道有可读的 `aria-valuenow`/角色或等效语义；CTA 与可聚焦元素 Tab 顺序符合视觉。
  - `prefers-reduced-motion: reduce` 时**整页降级为普通静态分节产品页**：取消 sticky 定格与位移/3D/缩放编排，章节在文档流中纵向堆叠，产品取每个章节的代表性静态姿态（或统一姿态 + 各章静态图示），全部卖点文案、仪表、CTA 直接可读，锚点导航与键盘浏览完整保留——信息获取零损失，只是不再随滚动逐帧运动。
  - 文字/控件对比度达 WCAG AA，焦点可见，当前章/状态不仅靠颜色；HUD 与 CTA 不遮挡核心文案。
- **移动端与触控**：sticky 定格在真机移动浏览器成立（规避部分旧浏览器 sticky + 高度计算坑，做特性降级：不支持时直接呈现静态分节流）；触屏纵向滑动即 scrub、不与圆点/进度条的点按拖拽冲突；横竖屏与动态工具栏伸缩导致的视口变化要实时重算进度，不错帧、不跳章。
- **生命周期**：案例卸载（iframe 销毁）/页面隐藏时取消 rAF、释放 Pointer Capture 与全部监听；重新进入从干净状态、真实滚动位置开始；不产生持续后台动画或音频（本案例默认无音频，若加入极轻的滚动触感反馈也必须手势内懒激活、可在 HUD 关闭）。

## 核心亮点

1. **补齐最高频商业页面形态的空白**：sticky 定格 + 滚动逐帧叙事是苹果及一线硬件产品发布页的标志性手法，可直接用于产品发布、品牌故事、众筹与特性介绍页（实用性 5 分）；库内 60 案例与在池 39 个 Ready 无一覆盖，`pages` 分类本身也最薄弱（仅 3 个实现案例、池中仅 IDEA-008）。
2. **真实的「进度 ↔ 画面」确定性时间线，而非一次性入场**：难点与亮点都在——全部图层状态由统一归一化时间线按滚动位置求值，正放、倒放、刷新、拖拽跳帧在任意位置定格都自洽，区别于 `scroll-reveal` 式「进视口播一次」与独立 CSS 动画导致的声光/位置脱钩；仅写 transform/opacity 的同帧 rAF 管线保证长页面顺滑不掉帧。
3. **零资源的产品级视觉**：产品本体、扫光、屏幕 UI、描边环仪表、引导线、背景氛围全部 CSS/SVG 构造，零产品照片、零外部字体、零图片请求，双击离线即可完整演示；哑光材质、章节色温流动与毛玻璃标注保持项目统一的 Anti-Slop 高级感。
4. **完整交互面，严格规避纯自动播放**：故事只能由用户的滚轮/触屏/键盘/拖拽/跳章推进，可正放倒放、任意帧停留；侧边圆点、可拖拽进度轨道、键盘锚点跳转、HUD 阻尼实时调节构成多输入闭环，杜绝「加载即自动放完」的自嗨演示。
5. **可访问性与工程鲁棒作为设计的一部分**：reduced-motion 下整页优雅降级为信息完整的静态分节页（而非简单禁用动画后留下一堆空画面），移动端 sticky 真机成立、视口变化实时重算，不支持 sticky 的环境自动退回文档流，切后台/卸载彻底回收 rAF 与监听。

## 历史案例对比（进入 Ready 前必填）

- **检查范围**：src/playground.js 全部 60 个注册案例（id / 标题 / 描述 / tags）+ playground/effects、playground/components、playground/pages 物理目录（实测 12 effects / 45 components / 3 pages）+ 活动池 IDEA-001～IDEA-039（全部 Ready）+ rejected.md（当前为空）+ completed.md（当前为空）；另全仓检索 `scroll / sticky / pin / scrub / parallax / narrative / story / 发布页 / 产品页 / timeline / progress`。
- **相似案例**：
  - `scroll-reveal`（滚动入场揭示）：库内最基础的滚动动画案例。机制是 IntersectionObserver 监听元素进入视口，给元素加 class 播放**一次性**入场（上移/缩放/滑入/模糊），播完即解除观察；元素入场后状态固定，不随滚动继续变化，不能倒放、不存在连续进度概念，也没有定格舞台与多图层时间线编排。本案例是**连续映射模型**：画面任意状态都是滚动位置的函数，正反向、任意帧联动且自洽；两者是「触发式一次性补间」与「逐帧 scrub 时间线」的本质差异。
  - `scroll-progress-bar`（阅读进度条与章节导航）：包含顶部 scaleX 进度条、右侧章节圆点 scroll-spy 与回顶按钮，视觉元素上与本案例的「圆点导航 + 进度」最像。但它的进度是**只读指示物**——只告诉用户读到哪，不驱动任何画面；没有 sticky 定格舞台、没有产品/标注随进度逐帧变化，章节圆点仅高亮不构成叙事编排。本案例中导航只是时间线的附属控件，主体是被进度连续驱动的多图层产品舞台；可类比「进度条 UI」与「被进度驱动的动画放映机」之别。
  - `vertical-timeline`（垂直时间线）：同样滚动触发，有中央脊柱填充与卡片 IO 揭示。但它承载的是**时间线信息列表**（左右交替事件卡），脊柱填充是简单的长度增长装饰，卡片仍是一次性入场；无定格舞台、无统一时间线求值、无 3D 产品/标注引导线的逐帧编排，信息架构（按时间排列的事件）与本案例（一个产品的多章节卖点叙事）不同。
  - 在池 **IDEA-015 视图转场画廊**：同属「高级转场叙事」气质，但其机制是 **View Transitions API + 点击导航**的跨页/跨视图共享元素形变，用户通过点击在离散视图间切换，转场由浏览器在两个状态间补间；本案例是**单一连续滚动轨道**上的连续 scrub，无路由切换、不依赖 View Transitions API（兼容性更好、可离线降级），驱动输入是滚动位置而非点击离散导航。
  - 在池 **IDEA-038 Bento 形变特性网格**：FLIP 展开特性墙，同为产品特性展示，但触发是点击展开单个格子的离散布局形变，无滚动时间线、无定格舞台、无正反向逐帧映射。
  - `pages/auth`、`pages/pricing`、`pages/app-layout` 与在池 IDEA-008 实时对话工作台：分别为鉴权表单、定价结算、应用骨架、聊天界面，均为功能性页面，无滚动叙事编排；其中 app-layout 虽有外壳布局与顶栏，但不具备任何 scroll-scrubbed 舞台。
  - 其余注册案例与在池 IDEA 逐一核对：`count-up`（进视口一次的数字爬升）、`logo-marquee`（CSS 无缝跑马灯，与滚动无关）、`top-loading-bar`（假路由 trickle 进度条，非用户滚动驱动）、`cursor-follow`/`spotlight-cards`（指针 Lerp，非滚动 Lerp）等均无滚动定格叙事；确认无历史（含已删除）`scroll-product-story` id 或物理目录冲突，rejected.md/completed.md 为空无淘汰/完成记录。
- **差异说明**：核心创意是「**一条纵向滚动轨道内 sticky 定格舞台，滚动进度经 rAF 归一化为章节时间线，逐帧确定性地驱动纯 CSS/SVG 产品的 3D 姿态、屏幕点亮、描边仪表、卖点标注与背景氛围正反向联动，且任意帧定格自洽的离线产品发布页**」。差异同时体现在：核心创意（连续 scrub 时间线 vs 一次性 IO 入场/只读进度指示/离散点击转场）、视觉表达（深空定格舞台 × 纯 CSS 拟物产品 × 引导线标注 × 章节色温流动）、交互方式（滚轮/触屏原生 scrub + 可拖拽进度轨道 + 键盘锚点跳章，正放倒放任意帧停留）与整体表现（一镜到底的产品发布长页，属最薄弱的 pages 分类）；不属于换颜色、文案或微调参数类重复。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库、零图标库/图标字体、零 CDN、零外部图片/字体/音频，产品本体与全部图形（机身、屏幕 UI、仪表环、引导线、图标、背景纹理）由 CSS 与内联 SVG 构造；双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 叙事必须基于**原生文档滚动 + `position: sticky` 定格**：滚动轨道为真实可滚动高度，禁止 transform 伪造滚动、禁止锁页面/阻止默认滚动等劫持行为；画面状态由 rAF 读取的轨道滚动进度经统一归一化时间线求值（仅写 transform/opacity 等不触发布局的属性），保证同一滚动位置在正放、倒放、刷新、拖拽跳帧后呈现一致状态，无累积漂移、无停止后脱钩自走；可选 Lerp 阻尼在滚动停止后必须收敛到真实进度。
- 故事推进只能由用户输入驱动（滚轮/触控板/触屏滑动、键盘原生滚动、圆点锚点跳转、进度轨道点击/拖拽 scrub），**不得自动播放**；首次进入停在首帧；Pointer Capture 用于进度轨道拖拽；visibilitychange/卸载时取消 rAF、释放捕获与监听，无后台动画泄漏；若引入任何音效必须手势内懒激活 AudioContext 且默认关闭。
- `prefers-reduced-motion: reduce` 必须降级为信息完整的普通静态分节产品页（取消定格与位移动画，章节文档流堆叠，全部文案/仪表/CTA 直接可读，锚点导航保留）；不支持 sticky 的环境同样回退静态分节；移动端真机 sticky 与动态视口变化需实时重算进度、不错帧；语义化 section 标题、圆点锚点 `aria-current`、AA 对比、可见焦点、状态不仅靠颜色。
- 视觉为暗色克制产品发布页美学：章节色温微弱流动但不彩虹轮转，毛玻璃标注/哑光材质/扫光/描边仪表服务于焦点，拒绝霓虹与粒子堆砌；桌面/平板/手机自适应（窄屏标注重排、热区充分、不横向溢出）。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊（强制）；原始/渲染进度、当前章节、reduced-motion 状态、Lerp 开关与强度、引导线与氛围显隐、首尾帧跳转等通过默认折叠的 Micro-HUD 提供（`H`/`Esc`、事件防穿透）。
