## 创意概述

开关（Switch / Toggle）是设置中心、通知偏好、功能启用、主题切换等场景里出现频率最高的表单控件之一，而原生 `<input type="checkbox">` 默认样式简陋、跨平台不一致，几乎每个真实产品都需要一套可投产、可键盘操作、语义正确的自定义开关。全仓 60 个已注册案例已覆盖 OTP、区间滑块、取色、可搜索下拉、银行卡、上传、验证码、富文本等大量表单控件，活动池 IDEA-001~013 也已排期日期、轮播、Toast、标签、步骤、拨盘等组件，却**唯独没有最基础的开关控件族**。本案例做一个纯原生、零依赖、可直接投产的**开关合集**：以一张拟真的「设置 / 偏好」卡片承载多款不同形态与动效的开关，其中的旗舰款是**日夜主题形变开关**——拨动瞬间，滑块本身在太阳与月亮之间做 SVG 路径/圆形形变，轨道内的天空、星辰与云层随切换转场，整组开关的状态用颜色、图标、文案与位置多重编码；其余款式覆盖日常最常用的开关形态（基础弹性、图标内嵌、加载/异步态、描述文案、危险态、尺寸规格等）。它既是真实页面里的设置模块，也是一套可复用的开关设计语言，而非孤立炫技。

## 预期展示效果

- **构图与整体风格**：
  - 用一张**拟真「偏好设置」卡片**承载（延续项目统一的深色玻璃质感：半透明深底 + 细描边 + 柔和投影），卡片分若干设置行（如「深色模式」「消息通知」「自动保存」「高对比度」等真实偏好项），每行左侧为标题 + 可选的一行次要描述，右侧为对应款式的开关；旗舰「深色模式」行置于顶部并给足呼吸空间。
  - 旗舰**日夜主题形变开关**居中放大呈现：一条胶囊轨道（天空），内部有可滑动的圆形滑块。关态为白昼——浅暖天空、滑块是带光芒的太阳、轨道内可有一缕云；开态为夜晚——深靛天空、滑块形变为带环形山的弯月、轨道内浮现星辰；拨动时天空底色、滑块位置、太阳↔月亮、云↔星同时转场。
  - 其余设置行使用一组风格统一、形态各异的开关，形成「一套设计语言、多种状态表达」的合集观感；右上角统一点阵色 Title 胶囊（遵循 HUD 规范）。
  - 配色克制有层次：强调色（开态）与危险态（红系）语义明确，关态为低对比中性色；动效与色彩只服务于「当前状态」表达，不做满屏装饰。
- **主要视觉元素**：
  - **太阳 ↔ 月亮形变（核心视觉）**：滑块以圆形为基底，关态是太阳（外圈光芒可用旋转/缩放的短线或锥形高光表达），开态通过 CSS/SVG 手法形变为弯月（如一个圆形叠加位移遮罩切出月牙，月面可有几个低对比圆形环形山）；形变与滑块沿轨道平移同步进行，节奏舒展。
  - **天空轨道转场**：轨道背景在白昼浅暖与夜晚深靛之间做颜色过渡；夜晚态轨道内以若干小圆点（星辰）淡入并可带极轻微闪烁，白昼态可有一缕简化的云淡出；星/云均为纯 CSS/SVG 构造，零图片。
  - **开关合集的多态表达**：至少覆盖——基础弹性开关（带按压/释放回弹）、图标内嵌开关（滑块或轨道内勾/叉或电源图标随态切换）、异步加载开关（拨到开态后滑块进入短暂 loading 转圈再定格，模拟请求）、带标题与描述文案的设置行、危险操作态（红色语义）、以及不同尺寸规格；每行开关状态变化可在卡片内给一行轻量的状态回显（如「通知已开启」）。
  - **多重编码**：开关状态绝不仅靠颜色——开/关同时由滑块位置（左/右）、图标、文案与 `aria` 状态表达，满足色弱用户与可访问性。
- **层次、材质、光影与关键细节**：
  - 玻璃卡片负责层级浮起，开关本体保持扁平清晰、投影轻薄；滑块是视觉焦点，带轻微立体阴影与按下时的缩放反馈，轨道为柔和内陷/填充感。
  - 动效统一使用一条舒展的缓出/轻弹性曲线：滑块平移与形变速率匹配、同时起步同时落位；星辰淡入略滞后于天空变色，形成「入夜」层次；按压时滑块轻微收缩、释放回弹，给出机械触感。
  - 状态对比三级明确：关（中性、滑块在左、图标为昼/关）、开（强调色、滑块在右、图标为夜/开）、加载（滑块中性 + 转圈、暂不可重复触发）、危险（红系强调）；键盘焦点有清晰的 `focus-visible` 环。
  - 窄屏下设置行不溢出、标题与描述截断合理，触控目标（开关热区）足够大；合集在桌面与移动端排布均稳定。

## 动态与交互

- **点击 / 触控切换**：点击开关轨道或其可点标签区域即切换状态，滑块沿轨道平移并同步完成太阳↔月亮形变与天空/星云转场；使用 Pointer Events 统一鼠标与触控，热区为整行或开关本体（具体实现阶段定，但须点按容易、不依赖精确点中小圆）。
- **（可选增强）拖拽拨动**：允许按住滑块水平拖动，越过轨道中点即吸附到开态、未越界回弹关态；拖拽跟手即时，松手用短缓动归位。该增强若实现须与纯点按、键盘操作三者行为一致，不得只支持拖拽。
- **异步加载态**：其中一款开关（如「同步到云端」）拨到开后进入短暂 loading（滑块内转圈或轨道内小进度），模拟一次请求后定格为开（也可演示失败回弹到关），loading 期间禁止重复触发并对外表达忙碌状态。
- **设置行联动回显**：每次切换更新该行/卡片的状态文案（如「深色模式 · 已开启」），让开关变化有真实落点；旗舰开关切换时可让卡片整体氛围（背景明暗倾向）有极轻微呼应，但不必实现整站换肤，避免喧宾夺主。
- **键盘与可访问性**：所有开关以原生 checkbox（视觉隐藏）或 `role="switch"` + `aria-checked` 承载，Tab 可逐个聚焦、Space/Enter 或方向键切换，`focus-visible` 清晰；状态变化通过 `aria-checked` 与可选的 `aria-live` 文案播报；危险态有文本提示，不仅用红色。
- **减弱动态与移动端**：遵循 `prefers-reduced-motion`——关闭太阳↔月亮形变、星空闪烁与弹性回弹，切换为最终态直出（或极短淡入），点按、拖拽、键盘、异步态功能完整；窄屏合集自适应、触控达标。

## 核心亮点

1. **补上全仓「开关控件族」类型空白**：60 个案例与活动池 IDEA-001~013 覆盖大量表单/设置类组件，却唯独缺最高频的 Switch/Toggle；开关合集是设置中心、通知偏好、功能启用页的刚需，可直接作为生产模块落地。
2. **旗舰「日夜形变」的强叙事微交互**：把一次普通拨动做成「太阳↔月亮形变 + 天空变色 + 星云转场」的连贯昼夜叙事，滑块平移与形变同步、星辰入夜层次延迟，兼具工程规整度与视觉记忆点，区别于只会左右滑动的普通开关。
3. **一套设计语言覆盖多态开关**：基础弹性、图标内嵌、异步加载、描述文案、危险态、尺寸规格同框呈现，并各有真实设置项承载，展示的是「组件系统」而非单个漂亮按钮，可复用性强。
4. **完整工程化与可达性**：原生 checkbox / `role="switch"` 语义、键盘全操作、多重非颜色编码、异步与危险态、Pointer Events 鼠标触控统一、reduced-motion 降级、卸载清理，达到可投产组件完整度。

- **相似案例**：
  - `button`（现代按钮系统，含波纹/炫光/霓虹/毛玻璃）：同属「可点按的小控件 + 微交互」，但按钮触发的是一次性动作，本案例是**带持久开/关状态的双态控件**，含滑块轨道平移、状态语义（aria-checked）、日夜形变与多态合集，控件模型与交互完全不同。
  - `capsule-tabs`（胶囊标签动效展厅）：形式上也是「胶囊轨道内指示器滑动」的合集式展厅，最易被认为相近——但它是**多选项间互斥切换的导航标签**（6 种切换曲线、多 Tab），本案例是**布尔开/关的表单开关**（每行独立二元状态），且核心创意是太阳↔月亮形变与昼夜天空叙事，服务于设置表单而非导航；二者控件语义（tablist vs switch/checkbox）、状态模型（多选一 vs 二元）与视觉叙事均不同，互补而非重复。
  - `range-slider`（双拇指区间滑块）/ `otp-input` / `combo-box` / `payment-card-input` / `file-dropzone`：同属表单控件家族，也用 Pointer Capture/键盘操作，但分别是区间、验证码、下拉、银行卡、上传，均无「双态开关」控件与轨道滑块形变；不构成重复。
  - `like-button`（双击点赞迸发）：同为「在两种状态间切换」的交互（赞/未赞），但它是带粒子迸发的媒体社交动作按钮，无轨道滑块、无表单开关语义、无键盘 switch 角色；状态表达方式不同。
  - `breathing-dot` / `notification-center`：呼吸光点是状态指示动效（只读），通知中心内部虽有「全部已读」等开关式交互但其主体是下拉通知面板，二者都不是可复用开关控件；本案例的开关合集不与它们重叠。
  - `embossed-foil-card` 描述中的 `gallery-switcher` 标签、外壳层 `toggleCodeBtn`、typewriter 的「循环开关」文案：仅为图片画廊切换/外壳按钮/控制项用词，非开关组件案例；全仓无 toggle-switch/switch/checkbox 类 id 或目录。
  - 活动池 IDEA-001~013（Date Picker、Carousel、Toast、Tags Input、Step Wizard、Speed Dial、Gooey 下载按钮、Chat、SVG Charts、Cascader、Star Rating、Pagination、Time Picker）：IDEA-011 Star Rating 也是「离散取值输入」，但它是 1–5 星评分（非二元开关、无轨道滑块、无主题形变）；其余均非开关控件，无重复。
- **差异说明**：核心创意是**「以一张拟真设置卡承载的多态开关合集，旗舰款用太阳↔月亮 SVG/CSS 形变与昼夜天空转场把布尔拨动叙事化，并以图标/文案/位置/颜色多重编码、完整 switch 语义做成可投产开关系统」**。与最接近的 capsule-tabs（多选项互斥导航 vs 二元表单开关）、button（一次性动作 vs 持久双态）、like-button（社交迸发动作 vs 规整开关控件）在核心创意、视觉表达（胶囊轨道 + 日夜天空 + 星月形变 + 多态合集）、交互方式（点按/可选拖拽过中吸附/键盘 Space 切换/异步 loading 态）与整体表现（设置偏好模块）上均有实质差异；不属于换色、换文案或微调参数类重复。全仓检索 toggle/switch/checkbox/day/night/sun/moon/theme 等关键字无历史（含已删除）id 冲突，案例 id 定为 `toggle-switch`。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生零 CDN、双击 index.html 独立离线运行（通用项目铁律，详情不重复）。
- 太阳/月亮、星辰、云、光芒、勾叉等视觉元素一律使用**内联 SVG 或语义 HTML + CSS** 构造与变换，**不得引入图标库、动画库、图片/字体等外部资源**；演示设置项为内置静态数据，不发起网络请求（异步 loading 态用 `setTimeout` 模拟并在卸载时清理定时器）。
- 可访问性为硬性要求：每个开关以视觉隐藏的原生 `<input type="checkbox">`（推荐，自动获得键盘与表单语义）或 `role="switch"` + `aria-checked` 承载；可通过标签点击、Tab 聚焦 + Space/Enter（或方向键）操作，`focus-visible` 清晰；状态由滑块位置 + 图标 + 文案 + 颜色多重编码，不仅靠颜色；异步态对外表达忙碌（如 `aria-busy`）。
- 如实现拖拽，统一使用 Pointer Events + `setPointerCapture`，并保证与纯点按、键盘操作行为一致（过中吸附、未越界回弹）；动效优先 transform / opacity 合成友好属性；组件在 iframe 挂载/卸载时统一移除事件监听并清理 rAF 与定时器，无残留。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊；如需调节（重播入场、减弱动效预览、切换尺寸、异步演示开关等），用常驻演示控件 + 默认折叠 Micro-HUD（`H`/`Esc`、事件防穿透）。本案例默认不需要音效；若加入任何触感音效，须 Web Audio 手势懒激活、默认克制可关。
- 尊重 `prefers-reduced-motion`：降级为开关最终态直出（或极短淡入），关闭日月形变、星空闪烁与弹性回弹，点按、拖拽、键盘与异步态功能完整。
