## 创意概述

为酒店入住/退房、机票往返、数据报表筛选等高频场景提供一个纯原生的**两段式区间日期选择器**：两次点击即可确定起止日期，第一次点击后鼠标在日历网格上移动时实时预览区间高亮，第二次点击确认结束日。核心要解决的体验问题是：原生 `<input type="date">` 只能选单日、无法表达"区间"语义，而常见自制日历普遍缺少悬停预览、区间连续高亮带与完整键盘无障碍。

## 预期展示效果

- **构图与整体风格**：页面中央或表单区域放置一个只读的区间输入框（显示「开始日期 ~ 结束日期」与已选晚数），点击后在其下方（空间不足时自动向上）弹出日历浮层；浮层为克制的深色毛玻璃质感卡片，带细微描边与柔和投影。桌面端默认双月并排以减少翻月成本，窄屏自适应为单月并保证触控目标足够大。整体视觉语言对齐项目既有组件案例的高级感（细描边、低饱和高亮色、克制动效），拒绝廉价大圆角与堆砌渐变。
- **主要视觉元素**：
  - 星期表头与 6×7 日期网格，非本月日期弱化为静音态；
  - 今日以细环描边标记；不可选日期（过去日期、超出允许区间）为禁用态；
  - 区间**连续高亮带**：首、尾日期为实心圆形端点，中间日期以较低不透明度的圆角块首尾相接，形成一条贯穿整行、跨周不断裂的色带；
  - 悬停预览态与已确认区间态在视觉层级上可区分（预览为虚线/半透明，确认态为实色）；
  - 浮层底部或侧栏提供快捷预设（如今日起 7 天、本月、最近 30 天）与「清除」操作；
  - 右上角固定点阵色 Title 胶囊（遵循项目统一 HUD 规范）。
- **层次、材质、光影与关键细节**：浮层用半透明深色底 + backdrop blur；入场为轻微缩放加淡入并带一点弹性；月份切换时网格内容做短暂横向位移动效（快速、克制）；端点圆形在跨月、跨周换行时色带仍保持连续；键盘焦点日有清晰但不喧宾夺主的焦点环；输入框聚焦时与浮层产生联动高亮，明确两者归属关系。

## 动态与交互

- **触发方式**：
  - 鼠标/触控：点击输入框唤起浮层；第一次点击日期选定开始日，随后悬停（触控下为滑动到）日期实时预览区间，第二次点击选定结束日并提交；若第二次点击早于开始日，则自动交换两端。
  - 键盘：输入框与浮层完整可操作——方向键在日期网格间逐日/逐周移动焦点，Enter/Space 选定，PageUp/PageDown（可含 Shift）切换月份/年份，Home/End 跳到当前周首末，Esc 关闭；焦点在关闭后归还输入框。浮层打开时焦点移入网格，Tab 顺序合理。
- **反馈与动效节奏**：悬停预览跟随指针即时更新且不引起重排闪烁；确认区间后浮层可保持打开便于微调，或短暂延迟收起（以实现时体验为准）；选择完成后输入框文案与晚数即时更新；禁用日期点击无反应且有静音视觉反馈。
- **规则反馈**：支持最短/最长跨度限制（如至少 1 晚、至多 N 晚），违反时结束日不可选并有明确的不可用态；快捷预设一键填充并正确联动翻月到对应区间。
- **边界与移动端**：自动处理大小月、闰年 2 月、跨年；浮层做视口边缘检测翻转；窄屏单月布局、日期格满足触控尺寸；尊重 `prefers-reduced-motion`，减弱动效时浮层与色带动效降级为即时呈现。

## 核心亮点

1. **悬停实时预览的两段式区间状态机**：start → hover 预览 → end，第二次点击自动处理反向交换与跨度约束，交互闭环完整自然。
2. **跨周不断裂的连续高亮带**：首尾圆形端点 + 中间日期圆角块拼接为连续色带，正确处理周换行与跨月，是该控件最具辨识度的视觉表达。
3. **完整 WAI-ARIA 键盘网格**：日期网格具备 grid/gridcell 语义、`aria-selected` / `aria-disabled` / `aria-current="date"`，全键盘可完成选择，达到可直接用于生产表单的成熟度。
4. **零依赖日期数学**：日历网格、闰年、跨月、晚数全部用原生 `Date` 自行计算，不引入任何第三方日期库，契合项目纯原生、离线自包含铁律。

- **相似案例**：
  - `range-slider`（双拇指区间滑块）：同属"区间选择"范式，但操作对象是连续数值轴，没有日历网格、日期语义、月份翻页与悬停区间预览；
  - `payment-card-input`（银行卡输入）：含到期月/年的文本录入与格式化校验，但无日历面板、无区间概念；
  - `combo-box` / `context-menu` / `mega-menu`：同属浮层 + 键盘导航类组件，浮层定位与键盘漫游的工程手法可借鉴，但均无日期网格生成与区间高亮；
  - 其余表单控件（`otp-input`、`color-picker`、`file-dropzone` 等）与日期选择无重叠。
- **差异说明**：本案例的核心创意是"日历网格 + 两段式区间状态机 + 连续高亮带"，需要新增的关键能力——按周历排布生成月网格（大小月/闰年/跨年）、首尾端点与跨周色带渲染、悬停预览与自动交换、最短/最长跨度规则、快捷预设与晚数统计——在全部历史案例中均不存在；浮层定位与键盘管理虽与既有浮层组件共享通用模式，但不构成核心创意重复，视觉表达（日期网格与色带）与交互方式（两次点击定区间）均为全新。

## 实现约束（仅记录该案例必要的约束）

- 纯原生 HTML5 + CSS3 + ES6+，零框架、零 CDN、零第三方日期库，双击 `index.html` 完整离线可用。
- 日期/日历数学全部用原生 `Date` 自行计算；示例场景（如酒店预订或报表筛选）以静态演示数据呈现，不请求任何后端。
- 遵循项目统一案例 HUD：右上角固定点阵色 Title 胶囊；如引入参数控制面板，按 Micro-HUD 规范默认折叠并支持 H/Esc 且事件防穿透。
- 键盘与语义对齐 WAI-ARIA Date Picker 模式（grid 角色、`aria-selected` / `aria-disabled` / `aria-current`），并适配 `prefers-reduced-motion`。
- 案例目录遵循注册约定：`playground/components/date-range-picker/` 下 `index.html`、`style.css`、`script.js` 三文件自包含。
