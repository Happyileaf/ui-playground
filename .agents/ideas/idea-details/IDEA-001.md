## 创意概述

一个以「3D 封面流」空间布局为核心的图库轮播组件：中央卡片正对观者、两侧卡片沿纵深向后旋转退移，形成真实舞台透视；配合拖拽过冲、阈值吸附、弹性回弹与惯性余动，把原本单调的「上一张/下一张」变成像拨动实体唱片架一样可抓、可甩、有手感的交互。解决内容展示类页面中轮播组件普遍「能点但不好玩、无空间纵深感、拖拽生硬」的体验问题，可直接用于作品展示、产品推荐、封面墙等真实网页场景。

## 预期展示效果

- **构图与整体风格**：
  - 页面中央为一个水平 3D 舞台（perspective 容器），5 张左右卡片沿一条向远处收拢的虚拟弧线/直线排列：当前卡居中、最大、最亮；两侧相邻卡依次缩小、向后方旋转约 30°–50° 并降低亮度/饱和度；更远的卡作为纵深背景若隐若现。
  - 整体延续项目已有的深色高级质感：舞台背景为低明度渐变与柔和环境光斑，卡片表面有细腻光泽与边缘高光，避免大色块与廉价投影；风格克制、现代、有材质层次（参考项目 holo/spotlight 系列的光影语言，但以内容卡而非收藏卡为载体）。
  - 舞台下方为指示区：细线圆点指示器（当前点拉长或填充）与左右两枚克制的圆形/幽灵箭头按钮；底部可配一条操作指引胶囊（拖拽 / ← → / 滚轮）。
  - 右上角遵循统一 HUD 规范：32px 毛玻璃点阵色 Title 胶囊（固定主题色光点，不随轮播内容变色）。

- **主要视觉元素**：
  - 一组内容封面卡（建议 6–8 张）：每张卡包含封面视觉区、标题与简短副文案；封面视觉**零外部图片**，由纯 CSS 渐变、网格、光斑、内联 SVG 几何图形构造（沿用 image-zoom / image-comparison-slider 的零图片做法），保证双击离线可用。
  - 卡片表面的斜向流光（sheen）与随舞台位置变化的明暗；中央卡与两侧卡之间通过 scale / translateX / translateZ / rotateY / opacity / filter(亮度、模糊) 拉开层级。
  - 舞台地面可有极淡的接触阴影/倒影，增强「卡片立在空间中」的纵深感（倒影为可选项，注意性能）。
  - 切换时指示器圆点弹性形变、箭头按钮短暂高光。

- **层次、材质、光影与关键细节**：
  - 层级完全由 3D 变换参数驱动，而非简单横移：侧卡 `rotateY` 朝内收拢、`translateZ` 后退、`scale` 缩小，并加 `z-index` 与亮度衰减，形成明确前后遮挡。
  - 卡片采用 preserve-3d 舞台；中央卡表面有一层随视角/切换轻微游移的高光，切换瞬间有一道柔和扫光，强调「被选中」。
  - 阴影分层：环境柔影 + 接触阴影，避免单一生硬 box-shadow；两侧越远的卡阴影越虚、对比越低。
  - 色彩以中性深色舞台承托每张封面卡自身的主题色，主题色仅出现在封面与指示器，不污染 HUD。

## 动态与交互

- **指针拖拽（核心手感）**：在舞台上按住左右拖动，卡片跟随指针产生实时横向位移与轻微过冲（rubber-band）：未超过切换阈值松手时弹性回弹到当前卡；超过阈值或甩动速度足够快时，按速度方向吸附到相邻卡，使用阻尼弹簧曲线（cubic-bezier 弹性或 rAF 弹簧），带轻微惯性余动。拖拽过程中指针捕获（setPointerCapture），防止拖出元素丢失。
- **点击侧卡**：点击任意可见侧卡，舞台平滑旋转把该卡转到正中；点击中央卡可触发一个轻微的「聚焦确认」反馈（如下沉回弹或扫光），不跳转、不强依赖链接。
- **箭头按钮**：左右箭头切换到边界时有克制的「到头」反馈（轻微抖动/禁用态），不做越界空切。
- **指示器**：点击圆点直达对应卡片；当前圆点以弹性动画拉长/填充。
- **键盘**：← / → 切换、Home / End 跳到首尾；舞台容器可聚焦（tabindex 与可见焦点环），具备 `aria-roledescription="carousel"`、`aria-label`、当前页与总页数的可感知状态（如 `aria-live` 礼貌播报或 roving tabindex 的 slide 语义）。
- **滚轮 / 触控板**：舞台区域内横向滚动（shift+wheel 或 trackpad 横滑）可切换，做方向判定与节流，避免纵向滚动被劫持。
- **自动播放（可选，默认关闭或缓速且可暂停）**：若提供自动播放，悬停/聚焦即暂停，并尊重 `prefers-reduced-motion`（减弱动效时禁用自动播放并改为即时/极短淡入切换）。
- **移动端触控**：与指针拖拽统一走 Pointer Events；窄屏下减少两侧可见卡数量、加大中央卡占比，保证不溢出、不错位。
- **动效节奏**：切换动画短而有弹性（约 300–600ms 区间的弹簧感），拖拽跟手零延迟、释放后才播放吸附动画；任何动画都在切换完成后正确清理 rAF / 过渡句柄。

## 核心亮点

1. **真实 3D 封面流空间**：不是横移列表，而是有透视、后退、旋转、明暗衰减的舞台纵深，视觉表达与普通轮播拉开档次。
2. **可抓可甩的物理手感**：拖拽过冲 + 速度阈值 + 弹性吸附/回弹 + 惯性余动，让轮播具备实体唱片架般的操作质感（交互创意亮点）。
3. **生产可用的完整轮播能力**：箭头、圆点直达、键盘、滚轮、触控、边界反馈、焦点管理与播报语义齐备，可直接搬进真实作品/产品展示页。
4. **零资源依赖的封面美学**：纯 CSS/内联 SVG 构造封面，配合斜向流光与分层光影，在零图片、零 CDN 约束下仍保持高级质感。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML/CSS/ES6+，零框架、零 CDN、零外部图片：封面视觉用纯 CSS 渐变 + 内联 SVG 构造，双击 `index.html` 完整离线运行。
- 3D 布局依赖 CSS `perspective` / `transform-style: preserve-3d` 与 transform；拖拽与弹性动画以 Pointer Events + `setPointerCapture` + `requestAnimationFrame`（或弹簧缓动）实现，并在组件销毁/切换时正确清理监听与动画帧。
- 必须实现右上角统一 HUD Title 胶囊（固定 32px 毛玻璃、固定主题色点阵光点、单行不换行）；如提供参数控制面板，须为默认折叠的 Micro-HUD 并支持 H/Esc 与事件防穿透（遵循 MAINTENANCE_GUIDELINES HUD 规范）。
- 必须适配 `prefers-reduced-motion`：减弱动效下关闭弹性/自动播放，改为即时或极短淡入切换；窄屏需响应式减少侧卡数量。
- 需满足可访问性：键盘 ← → Home End、可见焦点环、carousel ARIA 语义与当前页状态播报。
- 控制动画元素数量与滤镜开销，避免密集计算导致卡顿（侧卡数量有限、复用 transform/opacity 走合成层）。
