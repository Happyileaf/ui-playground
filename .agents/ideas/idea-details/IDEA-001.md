## 创意概述

日期选择是网页表单中最高频的输入原语之一（预订、筛选、注册、任务截止日），但原生 `<input type="date">` 视觉不可控、无法表达区间选择与禁用规则，交互体验也无法统一。本案例做一个纯原生、零依赖的弹出式日历日期选择器：输入框与日历浮层双向同步，支持**单日选择**与**日期区间选择**双模式，具备完整 WAI-ARIA grid 语义与全键盘操作、视口边缘翻转、快捷日期选项与细粒度禁用规则，可直接作为生产环境表单控件使用。

## 预期展示效果

- **构图与整体风格**：
  - 以一个真实表单/筛选场景承载（如「预约试听」或「订单筛选」条），避免出现脱离上下文的孤立日历；页面留白克制、信息层级清晰，延续项目深色玻璃质感工作台风格。
  - 控件本体为一个带日历图标的输入框（占位符或已选日期文本 + 可选清除按钮）；点击/聚焦后在输入框附近弹出日历浮层（Popover 形态，非全屏模态）。
  - 浮层内部结构：顶部为「上一月 / 年月标题 / 下一月」切换头，标题可快速跳月/跳年；其下为星期表头与 6×7 日期网格；底部或侧边为快捷操作区（今天 / 昨天 / 最近 7 天 / 最近 30 天 / 清除）。
- **主要视觉元素**：
  - 日期单元格按状态分：普通日、hover/键盘焦点日、选中日、今日、非本月日、禁用日；区间模式额外有「起点 / 终点 / 区间内连接日」。
  - 状态徽标与按钮遵循项目既有圆角语言；月份切换使用细腻的位移过渡而非生硬跳变。
- **层次、材质、光影与关键细节**：
  - 浮层采用毛玻璃背景（半透明深色 + backdrop blur）、1px 高光描边与柔和投影，明确悬浮于内容之上。
  - 选中日为主色实心圆角填充；区间起点/终点为实心圆形（或圆角块），区间内日期为低饱和主色横向连接带，起止与连接带视觉上连续。
  - 「今天」用主色描边的圆环与小字标识区别于选中态；非本月日期降透明度弱化；禁用日明显变暗且不可点击（可用删除线/斜纹表达「不可约」语义）。
  - 键盘焦点环与鼠标 hover 态分开表达，焦点环清晰可见。
  - 浮层入场为 opacity + 轻微 scale + 方向位移的弹性缓动；视口下方空间不足时向上弹出，横向超界时向内侧翻转，过渡有明确方向感。

## 动态与交互

- **唤起与关闭**：点击输入框或聚焦后按方向键/Enter 唤起浮层；点击外部、按 Esc 关闭；关闭后焦点归还输入框；切换案例或卸载时清理全部监听。
- **鼠标/触控选择**：单击日期选中；区间模式下第一次点击定起点、第二次定终点（终点早于起点时自动校正或提示）；触控目标足够大，窄屏下浮层可转为贴近输入框的加宽弹层或底部 sheet 形态。
- **键盘操作（WAI-ARIA Date Picker 模式）**：
  - ↑↓←→ 在日期网格中按周/天移动焦点；
  - Enter / Space 选定当前焦点日；
  - PageUp / PageDown 切换上一月/下一月，加 Shift 切换年份；
  - Home / End 跳到本周首尾；
  - 快捷键回到「今天」；
  - 网格使用 roving tabindex，面板打开时焦点进入日历，Tab 顺序正确。
- **输入与日历双向同步**：输入框允许手动键入日期，按统一格式实时解析，合法则同步高亮日历，非法格式给出克制的内联错误提示但不阻断操作。
- **快捷选项与规则**：快捷选项一键填入（单日模式：今天/昨天；区间模式：最近 7 天/最近 30 天/本月）；演示一组禁用规则（如部分日期不可选、可选范围上下限），禁用日键盘不可达或不可选。
- **月份/年份导航**：连续切月跨年正确（闰年、月末 28/29/30/31 日不错位）；提供「回到今天所在月」。
- 适配 `prefers-reduced-motion`：关闭弹性位移动效，保留即时状态切换。

## 核心亮点

1. **完整无障碍键盘模型**：不是只能点的日历，而是 ARIA grid 语义 + roving tabindex + 全套方向键/翻页键/快捷键，屏幕阅读器可播报日期与选中状态。
2. **单日 / 区间双模式**：同一控件两种真实业务形态，区间起止圆点 + 中间连接带的连续视觉是明确的设计亮点。
3. **输入与日历双向绑定**：手动输入解析、格式化、校验与日历高亮实时联动，覆盖真实表单的完整使用路径。
4. **边缘感知与焦点闭环**：浮层碰撞翻转、弹性方向入场、打开接管焦点/关闭归还焦点，达到可直接投产的完成度。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生零 CDN、双击 index.html 独立离线运行（通用项目铁律，详情不重复）。
- 日期计算以「年-月-日」本地三元组为内部模型，规避时间戳与时区/夏令时错位；月末、闰年边界必须正确。
- 浮层定位与碰撞翻转使用原生 JS 计算（不引入定位库）；不依赖外部日期库。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊；如有模式/规则切换控制，使用默认折叠的 Micro-HUD。
- 尊重 `prefers-reduced-motion`；移动端满足触控热区标准。
