## 创意概述

一个纯原生实现的**拟物旋转旋钮控制器**：用户像拧真实硬件旋钮一样，按住指针做圆周拖拽（或滚动滚轮、按方向键）来连续调节音量、亮度、温度、增益等数值，旋钮指针在约 270°~300° 的物理行程内带惯性阻尼与刻度吸附地转动，配合环绕刻度弧、数值读数与可选 Web Audio 刻度反馈，呈现「软件里的硬件手感」。它补齐本项目连续输入控件只有线性双拇指滑块（`range-slider`）、缺少**非线性旋转输入范式**的空白，可直接用于音频工作台、视频播放器、智能家居面板、DJ/合成器界面等真实网页场景。

## 预期展示效果

- **构图与整体风格**：
  - 页面中央为一个贴近真实产品的**多旋钮控制面板**演示场景（如「迷你音频混音台」或「智能灯光/温控面板」）：2~4 个旋钮横向或成组排列（如音量 / 高音 / 低音 / 平衡），每个旋钮下方有数值读数与参数名，旋钮间有明确的分组与主次，而不是孤立摆一个转盘。
  - 延续项目克制的暗色高级感：深色磨砂金属/玻璃质感面板，旋钮本体用径向渐变塑造圆柱体积，顶部有一条清晰的指针刻线或荧光指示点；强调色仅用于已走过的弧形进度、指针与当前刻度，对比度满足 WCAG AA，不使用泛滥蓝紫渐变与高饱和霓虹堆砌。
  - 桌面端旋钮直径约 72~96px、周围留有圆周拖拽手势空间；窄屏自适应缩放到触控热区不小于 44×44px，多旋钮在移动端可纵向成组排列。
- **主要视觉元素**：
  - **旋钮本体**：带金属/磨砂质感的圆形旋钮，径向高光与底部投影塑造可「拧」的立体感，顶面一条指针刻线指示当前角度。
  - **环绕刻度环**：旋钮外圈一圈刻度（主刻度 + 次刻度），从最小角到最大角约 270°~300°（底部留出死角，符合真实硬件习惯）；已走过的弧段用强调色弧线点亮，未走过段为暗色轨道。
  - **刻度标签与读数**：两端标签（如 `0` / `100` 或 `MIN` / `MAX`）、旋钮下方或中央实时数值（支持可选单位 dB / % / °C）。
  - **吸附标记点（可选）**：如 12 点方向的默认位、平衡控制的中点，带轻微凹槽视觉；拖拽经过时手感与视觉同时提示吸附。
- **层次、材质、光影与关键细节**：
  - 旋钮静止时通过径向渐变 + 内阴影体现圆柱体；按下拖拽时旋钮轻微下沉（阴影收紧、顶面高光位移），释放后回弹，建立明确的「被抓住」反馈。
  - 弧光进度随角度平滑扫过，经过每个主刻度时有一次克制的脉冲/发光呼吸；当前值变化时读数做轻微的数字滚动或高亮过渡。
  - 鼠标悬停时外圈轨道微微提亮；键盘聚焦时出现清晰但克制的 focus ring；禁用态整体降透明度且不可交互。
  - 面板背景可带极轻微的噪点/网格质感与分区分割线，让多个旋钮构成可信的「设备」而非一堆孤立圆片。

> 设计文档约束最终体验与设计意图；具体角度数学、DOM/SVG 组织、惯性曲线参数、精确尺寸与色值不在创意阶段锁定，实现时遵循项目原生规范与 Anti-Slop 准则。

## 动态与交互

- **核心圆周拖拽（垂直/环形两种映射取向，实现时择一并保持一致）**：
  1. Pointerdown 抓住旋钮 → 旋钮进入按下态（轻微下沉）；
  2. 移动指针时，按「指针相对旋钮中心的夹角」映射到有效行程（推荐环形角度映射，最贴合直觉；也可用上下拖拽距离映射，便于精细微调），角度换算成最小~最大值；
  3. 带轻微阻尼/惯性与刻度吸附：靠近主刻度时自动对齐并给一次细微触觉式反馈（视觉脉冲 + 可选轻音效），越过最小/最大角后进入硬止点，不继续无限旋转；
  4. Pointerup 释放 → 旋钮回弹到正常高度，最终值稳定。
- **滚轮调节**：旋钮或其面板 hover/聚焦时，滚轮每格递增/递减一个步长（配合 `preventDefault` 且仅在指针位于组件上时拦截，不影响页面正常滚动）。
- **键盘可操作性（重点亮点，与滑块等价的无障碍能力）**：旋钮聚焦后 ↑/→ 增、↓/← 减一个步长，PageUp/PageDown 大步进退，Home/End 直达最小/最大值，双击或专用按键可回到默认值；旋钮具备 `role="slider"`（或 `spinbutton`）+ `aria-valuemin/max/now` 与 `aria-orientation`，焦点可见。
- **多旋钮联动场景**：在混音台演示中，调节某旋钮时其所属通道的电平条/读数实时响应（如音量旋钮联动一条轻量 level meter），让旋钮作用可被直观看见；面板提供「复位全部」。
- **可选音效反馈**：首次用户手势后懒激活 Web Audio（遵循项目手势解锁铁律），刻度吸附时播放极轻的机械「哒」声或在音调类参数上给短促反馈音；不自动播放、可静音，无音频依赖时视觉反馈必须独立完整。
- **移动端触控**：统一 Pointer Events 与 `setPointerCapture`，拖拽期间防止页面滚动与文字选择；触控热区 ≥44px，环形映射在小屏上仍可单手操作。
- **减弱动效偏好**：尊重 `prefers-reduced-motion`，关闭惯性/下沉回弹与发光脉冲，仅保留角度与读数的即时切换。

## 核心亮点

1. **真实硬件手感**：270°+ 物理行程、硬止点、刻度吸附与阻尼、按下下沉/释放回弹，把「拧旋钮」的肌肉记忆搬进网页，是纯线性滑块无法提供的非线性旋转输入范式。
2. **环绕弧光 + 拟物材质**：径向渐变塑造圆柱体积、已走弧段点亮、经过刻度的克制脉冲，暗色磨砂面板上的成组旋钮构成可信设备，视觉辨识度高且符合 Anti-Slop 的材质与克制造诣。
3. **生产级场景包装**：以多通道混音台/灯光温控面板呈现，旋钮实时联动电平条/读数并支持复位，参数名、单位（%/dB/°C）、默认位/中点一应俱全，可直接迁移到真实网页。
4. **完整无障碍等价能力**：环形拖拽之外提供滚轮与全套键盘操作，`role="slider"` + aria 值语义 + 可见焦点，与项目现有 tooltip、drawer、range-slider 等可访问组件水准对齐，做到「拟物但不牺牲可达性」。

- **相似案例**：
  - `range-slider`（Dual Range Slider · 双拇指区间滑块）——同属「连续数值输入」大类，是最接近的一个。
  - `image-comparison-slider`（图片对比滑块）——同样是按住指针沿轨道拖动。

- **差异说明**：
  - `range-slider` 与 `image-comparison-slider` 的交互范式是**一维线性轨道拖拽**，数据映射为直线位置；本案例是**极坐标旋转输入**：指针相对圆心的夹角映射、约 270°~300° 行程与硬止点、刻度吸附与阻尼、按下下沉的拟物反馈，二者在数据模型（角度 vs 线性位置）、视觉表达（圆柱旋钮 + 环绕弧光 vs 直轨道）、交互方式（圆周拧动 + 滚轮 + 方向键微调 vs 线性拖动）上均有实质差异，并非换皮或微调参数。
  - `scroll-progress-bar` / `top-loading-bar` 是**只读、被动反映进度**的指示器，无任何用户输入与状态控制；本案例是**可操作的输入控件**，用户拖拽/滚轮/键盘主动设定值并联动场景，定位完全相反。
  - `count-up` 仅有数字滚动展示，无旋钮本体、角度行程与输入语义。
  - 全库 60 个案例无任何旋转输入/旋钮/拨盘类控件；远端在途 Idea（轮播、视图过渡、Toast、翻牌、拖拽排序、开关、日期选择器等）与历史批次（含旧 IDEA-006 翻牌时钟——其翻页为被动时间显示而非输入控件）均不覆盖本方向；`rejected.md` 中亦无旋钮相关淘汰记录。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零 CDN、零第三方旋钮/手势/物理库；双击 `index.html` 完整离线可用。
- 角度换算需正确处理最小/最大角死角、跨 0°（12 点方向）的夹角计算与硬止点，避免拖拽时指针跳变或无限旋转。
- 统一 Pointer Events + `setPointerCapture`；滚轮拦截仅限组件区域；键盘与 `role="slider"`（或等价 ARIA 角色）语义为必备能力；尊重 `prefers-reduced-motion`。
- 若使用 Web Audio 反馈，必须在首次用户手势后懒激活 AudioContext 并可静音，且视觉反馈在无音频时完整独立。
- 文件结构遵循案例标准三件套：`index.html` / `style.css` / `script.js`。
