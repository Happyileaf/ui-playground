## 创意概述

翻页钟（split-flap / flip clock）是机场时刻表、火车站大屏与复古桌面钟上最具记忆点的机械显示语言：数字不是“跳变”，而是一张被水平铰链切成上下两半的卡片，在重力感十足的半秒内“啪”地向下翻过，中缝扫过一道阴影，伴随一声沉闷的机械咔嗒。全仓 60 个已注册案例中，与“数字随时间变化”沾边的只有 `count-up`（入场时一次性缓动爬升的统计数字）与若干线性进度条（`top-loading-bar` / `scroll-progress-bar`、OTP 重发倒计时），**没有任何以拟真机械翻牌为视觉核心、持续走时并指向某个目标时刻的计时器 / 时钟类特效**。本案例做一个纯原生、零依赖、双击即用的**机械翻页倒计时**：天 / 时 / 分 / 秒四组翻牌模块以真实墙钟时间为基准向目标时刻倒数，每秒仅翻动真正变化的那一位，翻页具备 3D 透视、铰链阴影扫掠与（手势解锁后的）轻量 Web Audio 机械咔嗒；提供“快速演示 / 下一个整点 / 今天午夜 / 自定义目标时刻”等预设、暂停继续与重置、归零完成态，以及遵循统一 HUD 规范、默认折叠的参数面板（翻页时长、音效、卡片尺寸等）。它可直接用于产品发布页（Coming Soon）、促销活动倒计时、年会 / 新年倒计时与数据大屏，是技术域 2「微交互与光影动效」与技术域 7「文字排版与动效」交叉处一个高辨识度、高实用性的常青特效。

## 预期展示效果

- **构图与整体风格**：
  - 延续项目统一深色质感，但视觉主体是一块**克制的复古机械翻牌板**：画面中央水平排列「天 : 时 : 分 : 秒」四组模块，模块间以细冒号分隔（冒号亦可做轻微的呼吸点亮），模块下方是小号大写标签（DAYS / HOURS / MINUTES / SECONDS）。整组翻牌板以居中卡片 / 展台形式呈现，背后留出深色留白与极淡的环境光晕，不堆砌粒子。
  - 每位数字是一张竖向矩形翻牌卡，沿**水平中缝**分成上下两个半区：上半区底色略亮、下半区略暗，形成受光面与背光面；中缝有一条近黑的细铰链线，两端各有一枚微小的轴心圆点。数字使用等宽（tabular）字形，翻页前后数字宽度一致、绝不左右抖动。
  - 上方是目标时刻与状态说明（“距 2027-01-01 00:00 还剩 …” / 暂停态 / 已结束态），下方是一排极简控制：预设目标胶囊、自定义目标时刻输入、暂停 / 继续、重置、静音切换。右上角为统一点阵色 Title 胶囊（遵循 HUD 规范）。
  - 窄屏下翻牌板整体等比缩放并允许换行，标签与冒号收敛，触控热区达标；任何视口下中缝、铰链与数字对位不错乱。
- **主要视觉元素**：
  - **拟真翻页（核心视觉）**：某位数字变化时，呈现严格的两段式机械动作——先是“上半页”从中缝向前下方翻转（旧数字的上半随卡片翻走，露出静止的新数字上半），紧接着“下半页”从中缝向下翻落到位（盖住旧数字下半、呈现新数字下半），两段动作有极短交叠，末端带一丝过冲回弹，像被重力甩到位而非匀速滑过。
  - **铰链阴影扫掠**：翻转过程中一层渐变阴影沿翻牌面随角度扫过（起始几乎无阴影，90° 时最暗，落位后迅速退去），静止状态下上下半区保留稳定的细微明暗差与内阴影，让卡片始终有厚度而非两张平涂色块。
  - **四组模块与分隔符**：天 / 时 / 分 / 秒模块等宽对齐，冒号分隔符纤细、与翻牌板同色系；模块与标签间距有清晰的网格节奏。
  - **归零完成态**：到达目标时刻后所有位稳定停在 00，翻牌板做一次克制的整体高亮（描边 / 微光，非满屏彩带），状态文案切换为“已结束 / 时间到”，并提供“再来一次（重置为某预设）”。
- **层次、材质、光影与关键细节**：
  - 材质关键词：**磨砂烤漆面板 + 微凸塑料翻牌 + 金属细铰链**。翻牌卡有极轻投影浮在底板上；上下半区分色、中缝黑线与轴心圆点三个细节共同建立“机械可信度”，缺少任何一个都会显得像普通 CSS 数字切换。
  - 数字是绝对主角：字号大、字重稳、字距居中，使用系统自带等宽数字特性（`font-variant-numeric: tabular-nums`），不引入外部字体；未翻动的位完全静止，避免“所有位一起抖”的廉价感。
  - 光影克制：翻页阴影服务于“翻过一块有厚度的板”的物理暗示，落位后立即收敛；不使用彩色霓虹描边、不叠加全屏光斑。整体可在深色与（HUD 可选的）浅色底板两套配色间切换，但点阵指示灯颜色保持固定，不随面板配色联动（遵循 HUD 规范）。
  - 遵循 `prefers-reduced-motion`：偏好减弱时取消 3D 翻转，改为即时切换（或极短的上下半区淡入淡出），阴影扫掠一并去除，但走时准确性、目标设置、暂停重置与播报全部保留。

## 动态与交互

- **走时驱动（核心机制）**：以**墙钟时间戳之差**（目标时刻 − 当前时刻）为唯一数据源，每秒对齐到真实时间计算一次剩余天 / 时 / 分 / 秒，而不是靠 setInterval 累加（避免后台节流造成的漂移）；仅当某一位的数字真正改变时才为该位挂载一次翻页动画，动画由 CSS 3D transform 驱动（`perspective` + `rotateX` + `backface-visibility`），结束后卸载动画类并把静止层更新为新数字。页面从后台切回（`visibilitychange`）或标签页被节流后，下一tick直接对齐真实剩余时间，不补排一堆过期翻页。
- **两段式翻页节奏**：上半页先翻（约占总时长前半，呈现旧值离开），下半页随后翻落（后半，呈现新值落位），末端轻微过冲回弹；分、秒连续进位时（如 01:00 → 00:59）多位在同一秒按“低位先动、高位紧随”的自然次序翻动，而不是生硬同时翻转。翻页时长等参数可在 HUD 中实时调节。
- **目标设置（用户可操作，非纯自动播放）**：
  - 预设胶囊：快速演示（默认，目标为“此刻 + 一个很短时长”，保证双击打开立刻能看到连续翻页并在可接受时间内看到归零完成态）、下一个整点、今天午夜、新年（下一个 1 月 1 日 00:00）；
  - 自定义目标：原生 `datetime-local` 输入任意未来时刻并立即应用，非法 / 过去时间给出明确校验提示而非进入异常倒数；
  - 切换目标时翻牌板以一次自然的多位翻页过渡到新剩余值。
- **暂停 / 继续 / 重置**：暂停时冻结倒数（记录暂停时刻与剩余时长），翻牌停在当前数字，状态文案与按钮 `aria-pressed` 同步；继续时基于剩余时长重新推算目标时刻，走时不跳秒、不丢秒；重置回到当前所选目标的初始剩余值。到达目标时刻进入完成态，停止翻页并可一键再来一次。
- **音效（可选、手势懒激活）**：首次用户手势后才可创建 / 恢复 `AudioContext`，每次落位播放一声极短、低沉的机械“咔嗒”（可用很短的滤波噪声 / 振荡器包络合成，零音频文件），不同位不叠加爆音；提供静音切换且默认克制，`prefers-reduced-motion` 或无手势时不发声。音效只是增强，不影响任何功能。
- **可访问性**：计时器容器具备 `role="timer"` 与可访问名称；一个视觉隐藏的 `aria-live`（polite）区域以合理粒度播报剩余时间（如每分钟整点变化与暂停 / 完成时播报，避免每秒刷屏）；所有控制可 Tab 到达、有可见焦点环与图标按钮的可访问名称，状态不仅靠颜色传达。
- **Micro-HUD**：默认折叠的演示控制面板（遵循统一 HUD 规范：常驻触发入口 + `H` / `Esc` 快捷键、事件防穿透），可调翻页时长、回弹强度、音效开关与音量、翻牌板尺寸 / 配色、秒位显隐等；这些是“把玩项”，核心走时与目标控制始终直接可见可达，不藏在 HUD 里。
- **移动端触控**：翻牌板等比自适应，预设、输入与按钮触控目标足够大；单指即可完成全部操作，翻页动画在低端机上保持顺滑（每拍最多少量几位参与 3D 变换，无持续 rAF、无全屏粒子）。

## 核心亮点

1. **填补全仓“机械翻牌 / 时钟显示”空白，且实用性直达生产**：60 个历史案例与活动池 IDEA-001~017 无一是持续走时的拟真翻页钟或倒计时（仅有一次性 count-up 与线性进度条）。翻页倒计时是发布页、促销、年会、数据大屏的高频常青模块，实用性 5/5，成品可直接嵌入真实页面。
2. **拟真机械可信度的细节组合**：水平铰链上下分卡、两段式翻转（旧值离开 → 新值落位）、随角度扫掠的铰链阴影、末端重力过冲、连续进位时高低位的自然翻动次序、tabular-nums 保证的零抖动——这些细节共同把“数字改变”做成有重量、有惯性的机械动作，而非普通切换，视觉表现 5/5，精准规避“AI 廉价感”。
3. **工程上严谨的走时模型**：以墙钟时间戳之差为唯一事实源、逐位按需挂载 CSS 翻页、无持续 rAF、后台 / 节流后按真实时间对齐而不补排过期动画、暂停以剩余时长重算目标不丢秒——兼顾准确、性能与离线可用。
4. **完整交互面与零依赖离线**：多预设 + 自定义目标（含过去 / 非法校验）、暂停继续重置、归零完成态、可选手势懒激活机械音效、完整键盘与 aria-live 播报、减弱动效降级；全部用原生 CSS 3D 与 Web Audio 合成实现，零图片、零字体、零音频文件、零网络请求，断网双击 index.html 即为完整作品。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生零 CDN、零框架、零库，双击 index.html 独立离线运行（通用项目铁律，不重复）。
- 翻页用原生 CSS 3D（`perspective` / `transform-style: preserve-3d` / `rotateX` / `backface-visibility`）实现上下半页两段式翻转与末端回弹；不使用持续运行的 `requestAnimationFrame` 循环或全屏粒子，走时以每秒一次、对齐墙钟的定时器驱动，翻页动画仅挂载到当前真正变化的位上，动画结束即清理。
- 时间计算必须基于时间戳之差（目标 − 当前）而非增量累加；`visibilitychange` / 定时器被后台节流后，下一次计算直接对齐真实剩余时间，不补排过期翻页；暂停以“剩余时长”重算目标时刻，继续后不跳秒、不丢秒。
- 数字使用等宽数字（`tabular-nums`）保证翻页前后不左右位移；不引入外部字体、图片或音频文件，机械咔嗒声以 Web Audio 短包络（滤波噪声 / 振荡器）合成，并在首次用户手势后懒激活 `AudioContext`，提供静音开关，无手势或减弱动效时不发声。
- 自定义目标使用原生 `datetime-local`，对空值、非法值与过去时间做明确校验与提示；页面首次打开须有“快速演示”类默认目标，保证离线双击即可立即看到翻页并能观察到归零完成态。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊（指示灯颜色不随面板配色联动）；翻页时长 / 回弹 / 音效 / 尺寸配色等调节项放在常驻入口 + 默认折叠的 Micro-HUD（`H` / `Esc`、事件防穿透），核心走时与目标控制不依赖 HUD。
- 可访问性为硬性要求：`role="timer"`、按合理粒度的 `aria-live` 播报、全部控件键盘可达且有可见焦点环与可访问名称、状态不单靠颜色；`prefers-reduced-motion` 下取消 3D 翻转为即时 / 极短淡切，走时、设置、暂停重置、播报完整保留。
