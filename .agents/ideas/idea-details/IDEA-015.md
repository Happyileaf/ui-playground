## 创意概述

复刻老式机场/火车站出发牌（Solari boards）的机械翻牌（split-flap / flap display）效果：每一位字符沿水平中轴分上下两半，切换时上半瓣向下翻落、露出下一位字符，配合细微的错峰节奏与机械咔嗒声。一个案例内提供实时时钟、倒计时、自定义文案三种实用模式，让纯展示性的复古动效同时具备直接可落地的使用场景（站点出发牌、活动倒计时、营销大字）。

## 预期展示效果

- **构图与整体风格**：暗色、克制、高级感的展台中央，一块横向拼接的多位翻牌模块阵列，背后留有充足负空间；模块间有细而均匀的物理缝隙，整体像一块嵌入墙面的精密机电设备，而不是屏幕 UI。展台可带极简的环境标签（如“DEPARTURES”风格小标题或模式说明），但不喧宾夺主。
- **主要视觉元素**：
  - 每位独立翻牌模块，字符沿水平中线被分割为上下两瓣，中缝处有一道清晰的暗铰链线；
  - 模块面板呈微凸的哑光塑胶/烤漆质感，四角小圆角、外圈细暗边；
  - 支持数字、大写字母与少量标点（空格、冒号分隔符可呈现为固定的双圆点冒号“牌”）；
  - 冒号可作为不翻动的独立分隔模块，增强时钟真实感。
- **层次、材质、光影与关键细节**：
  - 牌面用细微的上下明暗渐变模拟弧形瓣叶受光（上瓣略亮、下瓣略暗），中缝压一条最暗的阴影；
  - 翻动过程中运动瓣叶带真实投影与速度变化（启动快、末端略带回弹/顿挫），落定时有极轻的沉降；
  - 不同位的翻动沿字符“步进序列”产生天然错峰（如从 09 翻到 10，个位先转完一整圈、十位再落位；多位翻牌按从右到左的级联顺序依次动作），形成机械队列感；
  - 可加极轻微的环境内发光与牌面反光，避免脏旧，保持精致现代而非廉价贴图；
  - 零外部图片与字体资源，所有形体用纯 CSS（渐变、box-shadow、transform）构造。

## 动态与交互

- **触发方式**：
  - 自动：时钟模式按秒跳动；倒计时模式逐秒递减，归零时全部模块做一次连续翻动（或整体定格闪烁）作为完成反馈；
  - 手动：输入自定义文案后逐位翻牌切换；提供“立即翻一次/重播”等操作；
  - 模式切换：时钟 / 倒计时 / 自定义文案三种模式可切换，切换时所有位以错峰瀑布方式翻到新模式内容。
- **反馈与动效节奏**：单次翻瓣动画短促有力；多位变化按位级联，级联间隔短到像真实机械联动而非逐个人工延迟；可选 Web Audio 轻量机械咔嗒声（懒激活、首次用户手势后才解锁 AudioContext，可静音），咔嗒声与翻瓣落定对齐。
- **控制能力**：默认折叠的 Micro-HUD 控制面板（遵循项目统一 HUD 规范，支持 `H` / `Esc` 呼出收起、事件防穿透），可切换模式、调整翻动速度/级联间隔、开关音效；倒计时模式可设置目标时长，自定义模式可输入文案。
- **移动端触控**：触控目标足够大，模式切换与输入在窄屏可用；模块阵列在空间不足时允许等比缩放或换行，保持中缝对齐。
- **键盘与可访问性**：面板控件可键盘操作；`prefers-reduced-motion` 下不做翻瓣动画、直接切换字符（或仅保留极淡的淡入），同时关闭音效；当前显示文本以可读形式提供给辅助技术（如视觉隐藏的实时文本或 aria-live 区域，时钟类高频更新需节制播报）。

## 核心亮点

1. **拟真机械翻瓣表现形式**：水平中轴分瓣翻落、中缝铰链阴影、弧形瓣叶受光与落定顿挫，区别于项目内所有平面数字/文字动效，视觉记忆点强。
2. **机械级联队列**：多位联动时按真实 split-flap 的步进序列翻动（逐位走完字符轮盘、右到左级联），配合对齐落定的机械音效，呈现“一整块机电设备”的整体感。
3. **三模式实用落地**：同一组件覆盖实时时钟、倒计时（含归零反馈）、自定义出发牌文案三个真实网页场景，复古动效不沦为纯摆设。
4. **零资源依赖的材质感**：牌面形体、光影、铰链全部用原生 CSS 构造，零图片、零字体文件、零 CDN，保持案例独立离线可用。

## 实现约束（仅记录该案例必要的约束）

- 纯原生 HTML + CSS + JavaScript，零框架、零 CDN、零外部图片/字体文件；双击 index.html 完整可用。
- 翻瓣动画优先使用 transform（rotateX / 3D 变换）实现并保持 GPU 友好；页面不可见或暂停时停止不必要的计时循环。
- Web Audio 必须在首次用户手势后懒激活，提供静音开关；不使用任何外部音频资源（可用合成噪声/短包络模拟咔嗒声）。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊；控制面板默认折叠、`H`/`Esc` 切换、事件防穿透。
- 必须适配 `prefers-reduced-motion` 与移动端触控。
