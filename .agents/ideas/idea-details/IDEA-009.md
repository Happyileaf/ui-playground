## 创意概述

数据看板是 SaaS 后台、运营大屏与报表页的高频刚需，但全仓目前只有「热力网格 / 数字滚动 / 数据表」三种数据表达，没有任何环形占比、柱状对比与折线趋势类图表，也从未演示过 SVG `stroke-dasharray / stroke-dashoffset` 描边生长这一经典图表动效技术。本案例做一个纯原生、零依赖、零图表库、可直接投产的**数据图表动效仪表盘**：一个拟真的运营数据看板，包含环形占比图（描边生长 + 中心总数 count-up）、柱状对比图（柱体错峰生长）、折线/面积趋势图（路径描边生长 + 面积淡入 + 数据点浮现），以及迷你 KPI 指标卡；支持悬停/键盘聚焦读数、图例点击过滤序列、周期切换时数据补间重绘，进入视口仅播放入场一次，全部动效尊重减弱动态偏好。它同时补上「第 8 域 SVG 形态语言用于数据可视化」与「实用数据可视化组件」两个空白。

## 预期展示效果

- **构图与整体风格**：
  - 用一个**拟真的运营/产品数据看板场景**承载：顶部一排 KPI 摘要卡（指标名 + 大数字 + 迷你趋势/环比语义），其下是主图区——左侧或上方一张**环形占比图**（如「流量来源构成」），右侧一张**多序列柱状对比图**（如「各渠道本周/上周对比」），下方或通栏一张**折线/面积趋势图**（如「近 7 日 / 30 日活跃趋势」，可多序列）；所有图表共享同一套坐标轴、网格、留白与色彩语言，像一张真实后台报表而非孤立 demo。
  - 整体延续项目深色玻璃质感：卡片为半透明深色圆角面板 + 细描边 + 柔和投影，背景克制；图表配色取一组有明度层次、彼此可区分的同调性强调色（具体色值不在本阶段限定），网格线极淡，数据是绝对视觉主角。
  - 面板提供「周期 / 口径切换」控件（如 本周 / 本月、或两组预置数据集）与每张图的图例，让数据变化与补间动效可被反复触发；另有「重播入场」入口。
- **主要视觉元素**：
  - **环形占比图（核心 1）**：内联 SVG 多个圆环段（`circle` + `stroke-dasharray/stroke-dashoffset` 计算弧长占比），入场时每段从 0 沿圆周**描边生长**并错峰启动，段间留细微间隙；环心展示总数/主指标，数字随入场做 count-up；段末端可带小圆点或圆角线帽。
  - **柱状对比图（核心 2）**：纯 SVG 矩形（`<rect>`，圆角顶），按值映射高度，自基线向上错峰生长（transform/scaleY 或高度补间）；分组柱并列、成组出现；带极淡的横向网格线与坐标轴标签；悬停柱体高亮其余降透明。
  - **折线 / 面积趋势图（核心 3）**：SVG `path` 折线，入场以 `stroke-dashoffset` 由满到 0 **描边画出整条曲线**；其下面积（同路径闭合填充、低透明渐变）随后淡入；数据点小圆点按序浮现；多序列时各曲线错峰描边。
  - **读数层**：悬停或键盘聚焦任一数据元素时，出现一枚边缘感知的小气泡 tooltip，展示系列名、类别、数值与环比/占比语义；折线图上显示一根追随光标的垂直参考线并高亮最近数据点。
  - **KPI 迷你元素**：顶部摘要卡大数字 count-up，配迷你折线/迷你环或带方向语义的涨跌微标（图标 + 文案，不单靠颜色）。
- **层次、材质、光影与关键细节**：
  - 玻璃面板负责层级，图表内部保持扁平克制：强调色只给数据（环段/柱/线/点），网格与坐标退到很弱的次级灰，避免「彩色噪点」式 AI Slop 观感；同一序列在三张图中颜色一致，建立跨图阅读联系。
  - 描边动画要有节奏：统一使用一条舒展的 ease-out 曲线，各序列/各柱按索引小延迟错峰，形成「数据依次就位」的编排感而非一齐硬切；数字 count-up 与图形生长在时间上大致同步收束。
  - 数据切换时图形不是硬切：环段弧长、柱高、折线路径在旧值与新值之间做短补间（数值映射后插值重绘），中心/坐标轴标签数字同步滚动；过滤掉某序列时其余元素平滑重排。
  - 线帽、圆角柱顶、点的 hover 放大与环段 hover 微加粗等细节统一；tooltip 带轻投影与小箭头，自动避让视口与面板边缘；右上角固定点阵色 Title 胶囊（统一 HUD 规范）。

## 动态与交互

- **入场触发**：整个看板或各图表面板进入视口时，由 IntersectionObserver 触发一次入场编排（环段描边生长、柱体错峰升起、折线描边 + 面积淡入 + 数据点浮现、KPI 数字 count-up），播完即解除观察；提供「重播」按钮可再次播放；案例在 iframe 中挂载/卸载时正确清理观察器、rAF 与定时器。
- **悬停 / 触控读数**：指针移入环段 / 柱 / 数据点时高亮当前元素、淡化同图其他元素，弹出读数气泡并显示名称、数值、占比或环比语义；折线图显示垂直参考线吸附最近点。触屏以点按元素触发同等读数，热区不小于触控标准，气泡不遮挡被点元素。
- **图例过滤**：点击图例项切换对应序列显隐，被隐藏项的环段/柱/折线段平滑收起，其余数据与坐标轴（必要时含环形归一化）平滑重排；再次点击恢复；图例项为可聚焦控件并有明确选中/停用态。
- **周期 / 数据切换**：顶部控件在预置数据集（如本周/本月或 A/B 两套口径）间切换，所有图表在旧值→新值间做统一时长的补间重绘，标签数字滚动联动；切换期间重复点击以最新目标值为准，动画不打架。
- **键盘与可访问性**：每张图提供可聚焦的数据浏览方式（推荐原生可聚焦元素或支持方向键在数据点/柱/环段间漫游），焦点项有清晰 `focus-visible` 环并同步触发读数气泡；图表关键结论通过图表标题、`aria-label`/`role="img"` 的文字摘要与（可选）随焦点移动的 `aria-live` 读数传达，图形不承担唯一信息；涨跌、开关态同时由图标/文案承载，不单靠颜色；遵循 `prefers-reduced-motion`——关闭描边生长、错峰与补间，直接呈现最终图形（或仅做极短透明度淡入），所有读数、过滤、切换功能完整。
- **响应式**：桌面多面板网格，窄屏纵向堆叠；SVG 以 `viewBox` 自适应缩放（或按容器宽度重算坐标），文字标签在窄空间自动精简/旋转/抽样但不重叠、不溢出；高 DPR 下描边与文字保持清晰。

## 核心亮点

1. **补上全仓数据图表的类型空白**：现有数据表达仅有 contribution-graph（热力网格）、count-up（数字）、resizable-table（表格），无环形/柱状/折线；本案例一次提供三种最常用图表，且以同一张拟真看板串联，落地即可用于真实后台报表。
2. **把 SVG 描边语言做深做透并服务于数据叙事**：`stroke-dashoffset` 环弧生长、柱体错峰升起、折线整条描边 + 面积淡入 + 数据点浮现构成统一的「数据依次就位」入场编排；数据切换时弧长/柱高/路径全程补间，而非常见的硬切重绘。
3. **完整工程化交互而非一次性动效**：悬停/触控/键盘三路径读数、边缘感知气泡、图例序列过滤与重排、多数据集周期切换补间、入场仅一次 + 重播、IO 触发与资源清理，达到生产组件的完整度。
4. **零图表库的纯原生实现与可访问性**：不引任何图表/动画库与 CDN，坐标映射、弧长、路径与补间全部用内联 SVG + 原生 JS 计算；同时具备文字摘要、焦点漫游读数、aria-live、双编码语义与 reduced-motion 降级，视觉炫技不牺牲可达性。

## 历史案例对比（进入 Ready 前必填）

- **检查范围**：src/playground.js 全部 60 个注册案例（id / 标题 / 描述 / tags，components 45 / effects 12 / pages 3）+ playground/effects、playground/components、playground/pages 三个目录 + rejected.md（当前为空）+ completed.md（当前为空）+ 活动池 IDEA-001~008。
- **相似案例**：
  - `contribution-graph`（贡献热力图）：同属数据可视化，但是**53 周×7 天的离散方格热力矩阵**，表达的是「日期 → 强度等级」，无环形占比、柱体高度映射、折线趋势，也无描边生长/路径补间；本案例是连续坐标体系下的占比/对比/趋势三类统计图，图表类型与 SVG 技术均不同。
  - `count-up`（数字滚动）：本案例的 KPI 数字与环心总数会复用「数字滚动」这一手法，但 count-up 只是**单一文本的入场数字动效**，没有任何图形、坐标系、序列、读数与数据切换；在本案例中 count-up 仅作为图表的从属元素，主体是三类 SVG 图表。
  - `resizable-table`（列宽可调数据表）：以行列**表格**承载任务数据，侧重列宽拖拽/排序/过滤的表格交互，不含任何统计图与描边动画。
  - `color-picker`（HSL 色彩工作台）：含**环形色相滑块与色轮**，但那是表单取色控件（角度↔色相映射），不表达数据占比，无数值弧长、无图表读数与趋势。
  - `image-cropper` / `signature-pad` / `watermark`：使用 Canvas 2D 绘制，但分别服务裁剪、手写与水印，与数据统计图无关；本案例明确选用内联 SVG（描边动画、可访问性、矢量自适应更契合图表）。
  - `range-slider` / `image-comparison-slider` / `split-pane`：同有「按值映射几何尺寸」的控件思维，但服务区间选择、图片对比与分栏拖拽，不是数据图表。
  - `infinite-feed`（骨架屏）、`top-loading-bar`（进度条）：有「生长/进度」视觉，但与数据驱动的统计图无共同核心创意。
  - 活动池 `IDEA-001~008`（Date Picker、Carousel、Toast、Tags Input、Step Wizard、FAB Speed Dial、Gooey 下载按钮、Chat Workspace）：依次为日期选择、内容轮播、轻提示、多值输入、多步表单、角部动作菜单、液态任务 CTA、即时通讯界面，均非数据图表；其中 IDEA-007 的 SVG Gooey 属滤镜形变域，与本案例的描边/坐标可视化技术不重叠。
- **差异说明**：核心创意是**「以一张拟真运营看板承载环形占比 / 柱状对比 / 折线趋势三类 SVG 统计图，并用描边生长—错峰就位—数据补间的统一动效语言把数据变化连续叙事出来」**。与最接近的 contribution-graph（离散日历热力矩阵 vs 连续坐标三类图表）、count-up（单文本数字动效 vs 完整图表系统且其仅为从属）、color-picker（色相表单控件 vs 数据占比表达）在核心创意、视觉表达（环弧/柱/折线路径、网格坐标、读数气泡、参考线）、交互方式（悬停/触控/键盘读数、图例过滤、周期切换补间、IO 入场重播）与整体表现（多图联动的数据看板）上均有实质差异；不属于换色、换文案或微调参数类重复。全仓检索 chart/graph/donut/bar/line/dashboard 等关键字无历史（含已删除）id 冲突，案例 id 定为 `animated-charts`。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生零 CDN、双击 index.html 独立离线运行（通用项目铁律，详情不重复）。
- 图表一律使用**内联 SVG + 原生 JS** 手工完成坐标映射、环形弧长（`stroke-dasharray/stroke-dashoffset`）、柱高与折线路径 `d` 的计算与补间；**不得引入任何图表/动画/D3 类库或外部 SVG/字体/图片资源**，演示数据为内置静态/伪随机数据集，不发起网络请求。
- 图形需随容器宽度自适应（`viewBox` 等比缩放或按 ResizeObserver 重算坐标），高 DPR 下描边与文字清晰；窄屏标签精简不重叠。
- 动效优先使用 transform / opacity / stroke 属性等合成友好方式，rAF 驱动补间并在卸载、切换案例时统一取消 rAF、定时器与 IntersectionObserver / ResizeObserver；如使用可选触感音效，Web Audio 须手势懒激活并随卸载关闭。
- 数值格式（千分位、百分比、环比）统一格式化；读数气泡需边缘/面板碰撞避让；所有信息不只靠颜色编码。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊；如需调节（动画速度、减弱动效、重播、数据集切换），使用默认折叠的 Micro-HUD（`H`/`Esc`、事件防穿透），周期切换与重播也应有常驻可见控件。
- 尊重 `prefers-reduced-motion`：降级为最终态直出（或极短淡入），读数、图例过滤、数据切换功能保持完整。
