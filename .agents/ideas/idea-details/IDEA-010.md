## 创意概述

中后台表单与电商场景里，「省 / 市 / 区」「商品一级 / 二级 / 三级类目」「公司 / 部门 / 小组」这类**有层级归属、必须选到叶子**的数据随处可见，用普通下拉无法表达归属、用一串平铺下拉又割裂且易错。全仓已有「单层可搜索下拉（combo-box）」「右键多级菜单（context-menu）」「文件树（tree-view）」，但**没有任何一个以多列逐级钻取、完整路径回填为核心的数据录入控件**。本案例做一个纯原生、零依赖、可直接投产的**级联选择器**：点击触发后浮层逐级向右生长出多列，当前路径高亮联动；支持完整路径回填与可清除、任意层级关键词搜索并命中补全、选任意层级或强制叶子两种模式、悬停/点击两种展开触发、浮层视口边缘自动翻转、完整键盘（方向键逐级钻取/回退、输入搜索、Esc、Tab）操作与 ARIA 层级语义，并放进一个拟真的「收货地址 / 商品类目」表单场景承载。它补上第 1 域「现代高可访问性表单组件」中**层级化数据选择**这一明确空白。

## 预期展示效果

- **构图与整体风格**：
  - 以一个**拟真表单卡片**承载（深色玻璃质感面板 + 细描边 + 柔和投影，延续项目既有审美），表单内含至少一个真实级联字段（如「所在地区：省 / 市 / 区」）与一个类目字段（如「商品类目」），配合若干普通输入/按钮构成完整提交语境，避免控件悬空 demo；提交后以克制的方式回显所选完整路径（路径数组 + 连接文案）。
  - 控件本体为一个类输入框的**触发器（trigger）**：左侧展示选中项的完整路径（以分隔符连接，如 `浙江省 / 杭州市 / 西湖区`），右侧为展开箭头与清除按钮；未选时显示占位提示。触发器在打开、聚焦、禁用、校验等状态下有清晰但克制的视觉区分。
  - 打开后浮出**多列级联面板**：首列为根级选项，选中含子级的项后紧邻其右侧滑入下一列，逐级生长；已选路径在各列中以高亮态标记，当前列自动滚动到选中项。浮层带轻投影、圆角、细描边与可选的小箭头，层级列之间以细分隔线区隔。
- **主要视觉元素**：
  - **多列钻取面板（核心 1）**：每列是一组垂直选项列表；含子级的项右侧出现「箭头 chevron」，叶子项无；选中（路径）态、当前激活项、悬停/焦点态、禁用态四态分明；新一列从右侧短距滑入（transform/opacity，合成友好）。
  - **路径回填触发器（核心 2）**：触发器内用统一分隔符展示从根到所选节点的完整路径；支持一键清除（出现空态占位）；支持「选任意层级即完成」与「必须选到叶子」两种模式（后者在非叶子上不触发完成，仅展开下一列）。
  - **路径搜索（核心 3）**：触发器或面板顶部输入关键词，按选项名（可含全路径文本）过滤，命中结果以**完整路径行**形式列出并高亮命中片段，键盘可选定后直接回填该叶子/节点；无结果有空状态。
  - **边缘感知定位**：浮层默认向下展开并向右生长列；当下/右空间不足时自动向上翻转、向左生长或整体横向回移，保证不溢出视口；滚动与窗口缩放时重新定位或收起。
- **层次、材质、光影与关键细节**：
  - 玻璃面板承载表单与浮层层级，选项列表内部保持扁平、克制造色：仅用一组同调性强调色表达「路径选中 / 当前激活」，其余文字走层级化的主/次/三级文本灰阶，避免高饱和彩虹式 AI Slop 观感。
  - 多列生长要有节奏：新列以短时长 ease-out 滑入 + 淡入，旧列不整体重绘，路径高亮沿列「接力」传递，形成明确的逐级深入方向感；路径回填/清除同样以轻微位移或淡入淡出反馈，不生硬硬切。
  - 统一细节：chevron 形态、列宽与行高、选中勾标记、键盘焦点环（`focus-visible`）、禁用项降透明度且不可达；浮层与触发器的连接线/箭头对齐；右上角固定点阵色 Title 胶囊（统一 HUD 规范）。

## 动态与交互

- **打开 / 选择 / 关闭**：点击（或可切换为悬停意图）触发器打开浮层；在含子级的项上选择即展开下一列并沿路径高亮；到达「完成条件」（叶子，或任意层级模式下的任一项）后按模式回填并可自动收起；点击触发器、选择叶子、按 Esc 或点击外部关闭；关闭后焦点归还触发器。
- **路径回填与清除**：选中后触发器显示完整路径；悬停/聚焦出现清除按钮，点击清空已选并恢复占位（可停止冒泡，避免误触打开）；再次打开时浮层定位回上次路径、各列恢复展开与选中。
- **搜索**：输入关键词即时过滤，命中项以完整路径行呈现并高亮匹配片段；↑↓ 在结果间移动、Enter 确认回填；Esc 清空搜索或关闭；搜索态与浏览态切换不丢已选值。
- **键盘与可访问性**：触发器支持 Enter/Space/↓ 打开；面板内 ↑↓ 在当前列移动、→ 进入子级、← 回到上一级、Enter 选定、Esc 关闭、Tab 顺序合理；提供符合层级语义的 ARIA（推荐 `combobox` + `listbox/option` 或 `menu/menuitem` 等价层级角色）与 `aria-expanded`、`aria-activedescendant`（或等价焦点管理）、`aria-label`；选中结果对辅助技术以完整路径可读；搜索与选择状态变化通过 `aria-live` 适度播报。
- **边缘与响应式**：浮层做视口碰撞检测，自动上/下翻转与横向回移；窄屏下多列可横向滚动或改为单列堆叠钻取（带当前层级标题与返回），不产生页面横向溢出；触控热区不小于触控标准，移动端以点按展开、不用悬停依赖。
- **资源生命周期**：浮层关闭/案例卸载时清理文档级事件、定时器与 rAF；动画尊重 `prefers-reduced-motion`——关闭列滑入与淡入，直接呈现最终列与高亮，选择、搜索、键盘功能完整。

## 核心亮点

1. **补齐全仓层级化数据选择的控件空白**：现有 combo-box 只解决扁平单层选择、context-menu 是动作菜单、tree-view 是内联垂直结构，均无「多列向右逐级钻取 + 完整路径回填 + 选值模型」的数据录入控件；本案例是省市区/类目等真实表单的高频刚需，可直接投产。
2. **把级联的「路径」做成交互主角**：多列接力高亮、完整路径回填、清除与二次打开路径复原、关键词按全路径搜索并高亮命中、任意层级/仅叶子两种选择模式，覆盖真实业务中最常用的级联交互变体。
3. **生产级完整度而非静态 demo**：浮层视口边缘自动翻转、窗口滚动/缩放重定位、外部点击/Esc 关闭与焦点归还、全键盘逐级钻取、完整 ARIA 层级语义与 aria-live、窄屏单列钻取适配、reduced-motion 降级，达到可访问表单控件标准。
4. **零依赖纯原生实现**：不引任何 UI 框架、下拉库或 CDN，层级数据、路径匹配、定位碰撞、键盘漫游全部用原生 JS + CSS 完成；内置静态层级数据集（省市区/类目），无网络请求，双击 index.html 完整离线运行。

## 历史案例对比（进入 Ready 前必填）

- **检查范围**：src/playground.js 全部 60 个注册案例（id / 标题 / 描述 / tags，components 45 / effects 12 / pages 3）+ playground/effects、playground/components、playground/pages 三个目录 + rejected.md（当前为空）+ completed.md（当前为空）+ 活动池 IDEA-001~009。
- **相似案例**：
  - `combo-box`（可搜索下拉选择框）：同属「选择型表单控件 + 键盘/搜索」，但它是**单层扁平 listbox**，选项平级、即时过滤，没有逐级向右钻取、没有父子层级与完整路径回填、没有多列生长浮层；本案例核心是**层级数据的多列逐级联动与路径选值模型**。
  - `context-menu`（右键上下文菜单）：虽支持**三级嵌套子菜单与边缘翻转、键盘方向键**，但它是触发在光标处、承载动作命令的浮动菜单，无输入框触发器、无选中值/路径回填、无清除、无搜索、无表单语义与提交模型；视觉与交互骨架（逐级右出子菜单）思路相近，但用途、状态模型与可访问性目标根本不同。
  - `tree-view`（可访问文件树）：同具**层级 + 展开收起 + 过滤 + 方向键**，但它是常驻内联的垂直目录树（分支 expand/collapse），表达的是文件系统浏览；本案例是输入框触发的多列横向钻取浮层，强调「选一条从根到叶子的路径并回填为表单值」，布局结构（内联树 vs 多列浮层）、数据模型（浏览 vs 录入）均不同。
  - `mega-menu`（全宽下拉导航菜单）：含多列与悬停展开，但是**站点导航链接集合**（hover-intent、特色推荐侧栏），不选数据、无值模型/路径回填/搜索。
  - `breadcrumb`（面包屑导航）：以分隔符展示**层级路径**并有折叠省略，但纯导航展示/钻取文件系统，不是选择器、无多列选择浮层与选值；本案例的「路径回填」只是触发器中的结果呈现，主体是选择交互。
  - `range-slider` / `otp-input` / `payment-card-input` / `file-dropzone`：同为表单控件，但分别解决区间、验证码、银行卡、上传，与层级选择无关。
  - `tooltip` / `drawer` / `guided-tour`：含碰撞避让/遮罩浮层经验，但不构成选择器功能重复；浮层边缘翻转可复用同一类碰撞思路但实现对象不同。
  - 活动池 `IDEA-001~009`（Date Picker、Carousel、Toast、Tags Input、Step Wizard、FAB Speed Dial、Gooey 下载按钮、Chat Workspace、Animated Charts）：依次为日期选择、轮播、轻提示、多值芯片输入、多步表单、角部动作菜单、液态 CTA、即时通讯、SVG 图表看板，均非层级级联选择；其中 Tags Input 是多值自由录入、Step Wizard 是分步流程容器，与「单条层级路径选择」的控件模型不同。
- **差异说明**：核心创意是**「为层级归属数据提供多列向右逐级钻取、完整路径回填、可搜索、可键盘全操作的表单选择控件，并以省市区/类目的拟真表单承载」**。与最接近的 combo-box（扁平单层 vs 层级多列 + 路径）、context-menu（动作菜单 vs 有值模型的选择器）、tree-view（内联垂直浏览 vs 触发式横向钻取录入）在核心创意、视觉表达（多列接力生长浮层 + 触发器路径回填 + 命中路径搜索）、交互方式（逐级 →/← 钻取、任意层级/仅叶子模式、边缘翻转、焦点归还）与整体表现（拟真地址/类目表单）上均有实质差异；不属于换色、换文案或微调参数类重复。全仓检索 cascader/cascade/级联 等关键字无历史（含已删除）id 冲突，案例 id 定为 `cascader-select`（规避与已有 `combo-box` 重名）。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生零 CDN、双击 index.html 独立离线运行（通用项目铁律，详情不重复）。
- 层级数据使用**内置静态 JSON 结构**（如省市区三级、商品类目三级），不发起任何网络请求、不引第三方地区库/下拉库/框架。
- 浮层定位与碰撞检测用原生 `getBoundingClientRect()` + 视口尺寸计算，自动处理上/下翻转与横向溢出；不得依赖 Popper 等定位库。
- 动效优先使用 transform / opacity，由 rAF/ CSS transition 驱动，卸载或切换案例时清理文档级监听、定时器、rAF；如使用可选触感音效，Web Audio 须手势懒激活并随卸载关闭。
- 键盘漫游与焦点管理需保证打开/关闭焦点归还、Tab 顺序合理、焦点不丢失到浮层背后；遵循统一 HUD 规范（右上角固定点阵色 Title 胶囊；调参使用默认折叠 Micro-HUD，`H`/`Esc`、事件防穿透）。
- 尊重 `prefers-reduced-motion`：关闭列滑入/淡入改为最终态直出，选择、搜索、键盘、清除功能保持完整；窄屏触控不依赖 hover。
