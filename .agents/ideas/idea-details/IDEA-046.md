## 创意概述

做一套「影院级」的自定义 HTML5 视频播放器：不用浏览器默认控件，而是围绕 `<video>` 自建一整套深色、克制、有电影感的播放界面——底部半透明控制栏在播放后自动隐入、移动鼠标或暂停时优雅浮现；进度条同时表达**已播放 / 已缓冲 / 可跳转**三段状态，悬停时浮出时间预览气泡与章节刻度；配播放 / 暂停（居中大播放键 + 底栏键）、音量 / 静音、倍速菜单、全屏（含双击画面切换）、键盘快捷键（空格、J/L、←/→、↑/↓、F、M）、缓冲加载态、播放结束重播态，以及完整的 ARIA 语义、焦点管理与 `prefers-reduced-motion` 降级。

解决的核心体验问题：原生 `<video controls>` 各浏览器样式割裂、无法承载品牌化与增强交互（缓冲预览、章节标记、自动隐栏、统一快捷键），是真实网页中最高频被自定义替换的媒体组件之一，但当前案例库**没有任何时间媒体（音视频）播放器**。更关键的工程难点是项目铁律「零 CDN、零外部资源、双击 `index.html` 离线完整可用」——播放器必须有真实片源才能演示，却不能内置 mp4 文件或链接远程流。本创意用 **Canvas 程序化影像（`canvas.captureStream()`）+ Web Audio 程序化音轨（`AudioContext` 合成）现场合成一路带画面、带声音、带章节、带缓冲语义的「虚拟影片」作为 `<video>`/媒体流的播放源**，从而在零字节媒体文件的前提下完整演示播放器的全部能力。

## 预期展示效果

- **构图与整体风格**：
  - 单屏呈现一个 16:9 影院画幅播放器，居中放置、深色环境底（页面四周压暗），播放器本体带细边框与大圆角、深邃投影，像一间微型放映厅里的银幕。
  - 播放器内部：上方是完整的画面区域（程序化影像随播放时间呈现不同段落：如片头标题、运动的几何 / 光影场景、章节切换字幕、片尾），底部悬浮一条毛玻璃控制栏；未播放时画面中央有一枚醒目的圆形大播放键，右上角为标题信息。
  - 深色、低饱和、中性微色温的电影感视觉语言（遵循 Anti-Slop 准则，拒绝蓝紫渐变与霓虹滥用）；克制的单一强调色仅用于进度、焦点与关键状态。
  - 顶部保留项目统一的点阵色 Title 胶囊；可配默认折叠的 Micro-HUD，用于切换「程序化片源主题 / 显隐章节标记 / 演示缓冲态」等，便于观察不同状态。
- **主要视觉元素**：
  - 三段式进度条：底层已缓冲条（更亮的半透明）、中层可跳转轨道、顶层已播放强调色条，播放头为可拖拽手柄；上方叠加章节刻度小刻线。
  - 悬停时间预览气泡：指针在进度条上移动时，跟随浮出该位置时间（与可选章节名）的小气泡，类似主流流媒体。
  - 控制栏：左侧播放 / 暂停、音量与静音；中间或右侧为时间读数（当前 / 总时长）、倍速菜单、全屏按钮；图标统一内联 SVG。
  - 状态层：居中大播放 / 暂停键、缓冲时的加载指示、播放结束的重播界面；自动隐藏时控件整体淡出、画面获得纯净观感。
- **层次、材质、光影与关键细节**：
  - 控制栏采用毛玻璃 / 渐变压暗质感，与画面拉开层级且不割裂影像；浮现 / 隐入用短促的透明度过渡，不做大幅位移。
  - 进度条拖拽与悬停有清晰的吸附 / 高亮反馈，播放头在悬停时轻微放大；缓冲条随缓冲进度真实增长。
  - 程序化影像本身要具备「电影段落感」：随播放时间推进呈现明显不同的画面段落与章节字幕，让章节标记、跳转、倍速都有可感知的反馈，而非一块静止色块。

> 设计文档约束最终体验与设计意图；具体色值、尺寸、缓动参数、程序化影像的具体画面脚本与音轨音色由实现阶段按整体视觉统一决定，不在此过早钉死。

## 动态与交互

- **播放 / 暂停**：
  - 点击画面中央大播放键、底栏播放键或画面本身均可切换；播放时中央大键隐去，暂停或结束时重新出现。
  - 播放后静止一段时间（且无指针移动）控制栏与（桌面端）光标自动隐入；移动鼠标、暂停、键盘操作或触控时立即优雅浮现。
- **进度条（核心）**：
  - 实时显示已播放比例、已缓冲比例与可跳转范围；支持指针按下拖拽 scrub（拖拽时画面 / 时间读数即时跟随，松手提交跳转），正确处理 `setPointerCapture` 与 `touch-action`。
  - 悬停浮出该位置时间预览气泡（含章节名）；章节刻度在轨道上以刻线标注，点击 / 跳转可定位章节；播放到章节边界时画面与信息有轻量反馈。
- **音量 / 静音**：底栏音量键 + 可展开音量滑轨；`M` 键静音切换，记忆上次非零音量。
- **倍速**：倍速菜单在一组常用倍率间切换（如 0.5× / 1× / 1.25× / 1.5× / 2×），切换后画面、音高 / 节奏与时间读数一致。
- **全屏**：底栏全屏按钮、`F` 键、双击画面均可进入 / 退出全屏；全屏下控件行为与画幅适配保持一致，退出后状态正确归还。
- **键盘与可访问性**：
  - 完整快捷键：`Space`/`K` 播放暂停；`←/→`（或 `J/L`）快退 / 快进固定步长；`↑/↓` 调节音量；`M` 静音；`F` 全屏；快捷键仅在播放器获得焦点时生效，不劫持页面其他输入。
  - 各控件具备正确的 `role`/`aria-label`（播放、静音、全屏、滑块 `role="slider"` 含 `aria-valuenow` 等）、可见焦点环、合理 Tab 顺序；进度滑块可由键盘方向键操作。
  - 尊重 `prefers-reduced-motion`：减弱控件隐入与气泡 / 状态层动效，但所有播放、跳转、音量、全屏功能完整。
- **状态与响应式 / 移动端触控**：缓冲等待时显示加载态并禁用无效重复操作；播放结束显示重播界面；手机视口下控件热区 ≥ 44px、进度条与按钮适配窄屏、触控即唤出控制栏，双击全屏在触屏可用；不与页面滚动 / 浏览器手势冲突。

## 核心亮点

1. **零媒体文件的「真实播放器」**：用 `canvas.captureStream()` 程序化合成带电影段落感的影像、用 Web Audio 合成音轨，在不内置任何 mp4 / 外链流、双击离线可用的前提下，让播放、缓冲、章节、倍速、全屏全部可被真实操作与感知——这是把项目「零资源」约束转化为创意亮点的关键设计。
2. **三段式时间轴 + 悬停预览 + 章节标记**：进度条同时承载已播放 / 已缓冲 / 可跳转语义，悬停出时间气泡、轨道带章节刻度、可拖拽 scrub 与键盘微调，达到主流流媒体播放器的时间轴完成度，远非普通进度条。
3. **影院级隐栏与状态语言**：播放自动沉浸（控件 + 光标淡出）、交互即唤回，居中大播放键 / 缓冲加载 / 结束重播三态完整，毛玻璃控制栏与电影感画幅统一。
4. **高可访问、可直接落地**：完整键盘快捷键映射、ARIA 滑块语义与焦点管理、减弱动效降级、桌面 / 平板 / 手机三视口与触控一致，是可直接用于生产网页的通用媒体组件。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库、零 CDN，双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- **零媒体文件**：不内置任何 mp4/webm/音频文件、不引用任何远程流或图片 / 字体；演示片源由 Canvas（`HTMLCanvasElement.captureStream()`）程序化生成影像、Web Audio（`AudioContext` + 振荡器 / 缓冲等）程序化生成音轨，并须妥善合成与驱动媒体播放（须验证以 `srcObject = MediaStream` 或等价方式驱动 `<video>` 在目标浏览器的可行性与降级，保证时间、缓冲、seek、倍速、全屏行为可被真实演示；若纯流无法可靠支持 seek，应以可寻址的程序化时间线模型模拟并保证交互语义完整，具体实现方案在开发阶段验证定稿）。
- Web Audio 必须手势解锁后懒激活，不自动发声；离开 / 销毁时关闭 AudioContext、停止 rAF 与流轨道，避免 iframe 沙箱内残留。
- 拖拽统一用 Pointer Events（`setPointerCapture`、`touch-action`），动画走 transform / opacity 合成层与 rAF，避免拖拽与隐栏过程引发布局抖动。
- 进度条须正确表达 buffered / seekable 语义并支持键盘操作；全屏使用 Fullscreen API 并处理状态变化；ARIA 语义、焦点管理、`prefers-reduced-motion`、桌面 / 平板 / 手机响应式与 ≥44px 触控热区完整。
- 图标使用内联 SVG；遵循项目统一的右上角点阵色 Title 胶囊与默认折叠 Micro-HUD 规范。
