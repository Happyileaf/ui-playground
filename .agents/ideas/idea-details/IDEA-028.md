## 创意概述

「字段在页面上以纯文本呈现，点击（或键盘激活）后原地变为输入控件，回车 / 失焦保存，Esc 撤销，无需跳转弹窗或整页表单」是 Notion、Airtable、GitHub 个人资料、Linear、各类设置页与数据表格里最高频的就地编辑原语（click-to-edit / edit-in-place）。它的体验核心不是把一个 `input` 摆到页面上，而是一套完整的**查看态 ↔ 编辑态就地切换语言**：查看态是干净的排版文本并带有可编辑暗示（hover 轻底纹 / 铅笔提示），激活时在**原位置、不产生布局位移（CLS 为零）**地切换为控件，自动选中可编辑内容并把光标交给用户；保存时有异步「保存中 → 成功 / 失败」反馈，失败可重试且不丢输入，未改动或按 Esc 则无损还原；全程不需要弹窗、不离开当前上下文。

当前案例库在表单方向已覆盖常驻输入（otp-input / payment-card-input / color-picker / range-slider / combo-box）、富文本工具条（rich-text-toolbar）、行内触发的 @ 提及（在池 IDEA-020）与各种弹层确认，却没有「**默认只读、按需就地变可编辑并回写**」这一原语；富文本工具条解决的是「对一段常驻 contenteditable 选区施加格式」，@ 提及解决的是「在连续文本里插入实体胶囊」，二者都没有查看/编辑双态、保存/取消状态机与异步回写。本案例做一个纯原生、零依赖、可直接投产的 Inline Edit：以一个**拟真「个人资料 / 设置」卡片**承载单行文本、多行文本（textarea 自适应增高）、带校验字段、可选项（select 化就地切换，如状态 / 时区）等多种字段，用统一的状态机与键盘 / 指针 / 失焦交互实现原地编辑，并遵循减弱动效与统一 HUD 规范。

## 预期展示效果

- **构图与整体风格**：
  - 画面中央是一张**拟真设置卡片**（延续项目深色玻璃质感、圆角、克制留白与柔和投影）：左侧或顶部为简短身份区（头像 + 标题，头像与占位全部内联 SVG / CSS 构造），下方是一组「标签 + 值」的字段行——昵称（单行文本）、个人简介（多行文本）、邮箱（带格式校验）、状态 / 时区（就地可选枚举）等；每个值默认以**只读排版文本**呈现。
  - 卡片外（桌面宽屏）留白处放置极简的**用法提示小样**（如「点击任意值即可编辑 · Enter 保存 · Esc 取消」），引导用户直接点按；窄屏下卡片占满宽度、字段行转为上下结构。
  - 右上角按工作台 HUD 规范放置点阵色 Title 胶囊（固定于案例视口内）。
- **主要视觉元素**：
  - **查看态（view）**：纯文本值，行高与排版与编辑态严格一致，保证切换不跳动；hover / 键盘聚焦时，文本区域出现低对比度轻底纹与圆角，并在末端浮现一枚克制的铅笔图标，提供「这里可改」的可操作暗示（非 hover 时不可见，保持界面干净）。
  - **编辑态（edit）**：点击 / 激活后**在同一外框内**原地替换为输入控件（单行 input / 自适应增高的 textarea / 枚举选择控件），外框高亮为强调色细描边；进入时自动聚焦并**选中文本**（或光标置于末尾，二选一并保持一致），文本与查看态基线对齐、尺寸一致，因此不产生位移。
  - **操作区**：编辑态在字段旁 / 下方浮现紧凑的确认（对勾）与取消（叉）两枚图标按钮，保证纯鼠标用户也有显式入口（不仅依赖键盘）；按钮有可见焦点态。
  - **保存反馈**：触发保存后控件进入「保存中」（克制的小型旋转 / 进度反馈 + 禁用重复提交），成功后回写为查看态并给一次极轻的成功提示（字段边缘短暂成功色或一枚转瞬即逝的对勾，配合 aria-live 播报）；失败时停留在编辑态、保留用户输入，呈现克制的错误文案与「重试」，不仅靠颜色表达。
- **层次、材质、光影与关键细节**：
  - 查看态与编辑态共用同一外框尺寸与内边距模型，仅切换内部呈现，避免布局抖动；编辑态描边用强调色低透明亮线 + 极轻内投影，与仓库 tooltip / popconfirm 等浮层语言一致但更轻。
  - 动效节奏克制：态切换为快速的透明 / 底纹过渡与可选的极轻微缩放，时间在百毫秒量级，不做炫技弹性；保存成功反馈短暂出现后自动收敛。
  - 校验在提交时触发（邮箱格式、必填、长度等），错误信息就近显示在字段下方、不使用原生 alert；枚举类字段的就地选择复用既有下拉设计语言（毛玻璃浮层 / 边缘避让），但语义是「选中即写回」而非「输入」。
  - 可在 Micro-HUD 注入「保存失败」分支与异步时延，演示保存中 / 失败重试；所有区分同时伴随图标 / 文案语义。

## 动态与交互

- **激活方式（多输入统一）**：查看态可点击（pointer）激活；也可 Tab 聚焦后按 Enter / Space / 直接键入字符进入编辑（键入字符时以该字符替换/起始，符合常见就地编辑习惯）；标签通过 `for` / 点击关联。激活即聚焦控件并选中文本。
- **保存与取消**：
  - Enter 保存（多行 textarea 中 Enter 为换行，改用 `Ctrl/Cmd+Enter` 保存，并在编辑区给出该快捷键的低调提示）；点击对勾按钮同样保存。
  - **Esc 取消**：丢弃本次修改、还原原值、退出编辑态并把焦点归还查看态触发元素（焦点不丢失）。
  - **失焦（blur）保存或取消的策略需明确且可预期**：默认失焦即尝试保存（与主流就地编辑一致），但在点击显式「取消」、按 Esc 或校验失败时不退出；Micro-HUD 可切换「失焦保存 / 失焦取消」策略以便演示。
  - 值未变化时保存应直接安静退出（不产生无意义请求与成功提示）。
- **异步保存状态机**：`view → editing → saving（禁用控件与重复提交，显示保存中）→ view（成功回写）/ editing（失败，保留输入 + 错误 + 可重试）`；保存为纯前端模拟（定时器占位，可注入失败与时延），真实环境可直接替换为 Promise 型保存回调；保存中组件不响应会造成状态错乱的二次操作。
- **校验**：必填、长度、邮箱格式等规则在保存时校验；不通过则留在编辑态、就近提示、聚焦首个问题字段并允许继续修改或取消；枚举字段只有合法选项可写回。
- **可访问性**：查看态以可聚焦按钮 / 带角色的可编辑触发器承载，提供可访问名（结合字段标签，如「编辑昵称」）；进入编辑后焦点移入控件，确认 / 取消按钮可 Tab 到达；结果与状态通过容器上的 `aria-live="polite"` 礼貌播报（如「昵称已保存」「保存失败，请重试」）；错误以 `aria-invalid` 与错误关联表达；Esc 后焦点还原。键盘是一等路径，不依赖鼠标。
- **减弱动效**：遵循 `prefers-reduced-motion`——关闭底纹 / 缩放过渡，态切换即时呈现，功能、状态机与播报完整。
- **可选 Micro-HUD**（默认折叠，`H` / `Esc` 切换、事件防穿透）：模拟保存时延、成功 / 失败注入、失焦策略切换（保存 / 取消）、保存音效开关；非必需时至少保留右上角 Title 胶囊。
- 移动端触控：热区为整行可编辑值区域，点击即改；编辑态操作按钮足够大可点按；页面不产生横向溢出，多行控件增高不撑破布局；不触发误选 / 缩放干扰（必要的 user-select 与字号约束仅限交互区）。

## 核心亮点

1. **补齐高频生产原语空白**：库内 60 个案例与在池 27 个 Ready Idea 中没有任何「默认只读、点击原地变可编辑并回写」的 Inline Edit；它是 Notion / Airtable / GitHub / Linear / 设置页与数据表格的通用交互，成品可直接嵌入真实网页对接保存接口，实用性 5/5。
2. **零布局位移的双态无缝切换**：查看态与编辑态共用外框尺寸、基线与内边距，激活时原地替换、自动聚焦选中文本，避免就地编辑最常见的跳动 / 闪烁（CLS）瑕疵；hover/聚焦的可编辑暗示克制不喧宾夺主。
3. **完整状态机与边界，而非输入玩具**：覆盖 Enter / 对勾保存、Esc 还原并归还焦点、失焦策略、未改动安静退出、必填/格式校验就近提示、异步「保存中—成功—失败重试」、保存中防重复提交、失败不丢输入等生产级分支。
4. **多字段类型 + 键盘一等路径**：同一原语贯穿单行、自适应多行、校验字段与枚举就地切换；指针、键盘（Tab/Enter/Space/Esc/Cmd+Enter）与触控都能完成完整任务，aria-live 播报与焦点管理到位，避免「只能鼠标点着玩」。
5. **拟真场景零资源依赖**：设置卡片、头像与图标全部内联 SVG / CSS 构造，双击离线即用；保存时延 / 失败可由 Micro-HUD 注入，成功回写与错误态肉眼可验。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库、零 CDN，双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 查看态与编辑态必须共用外框尺寸 / 内边距 / 排版基线模型，切换不产生布局位移（避免 CLS）；激活时自动聚焦并选中文本，Esc / 取消后焦点归还查看态触发器。
- 实现可信单一状态机（view / editing / saving / 成功回写 / 失败停留重试），保存中禁用重复提交；异步保存为纯前端模拟，可注入时延与失败分支；值未变化时安静退出。
- Pointer 与键盘均可完成完整流程（Tab 聚焦、Enter/Space 激活、Enter 或 Cmd/Ctrl+Enter 保存多行、Esc 取消、显式确认/取消按钮可 Tab 到达）；提供 aria-live 结果播报、aria-invalid 与可访问名，错误不仅靠颜色。
- 演示卡片、头像、图标与枚举数据全部内联 SVG / CSS / 本地数据构造，无外部图片 / 字体 / 网络请求；多行控件自适应增高且不撑破窄屏布局。
- 如引入音效，Web Audio 必须在用户手势内懒激活 AudioContext，并允许在 Micro-HUD 关闭。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊（强制）；如需参数控制使用默认折叠的 Micro-HUD（`H` / `Esc`、事件防穿透）。
- 尊重 `prefers-reduced-motion`（态切换即时呈现、关闭底纹/缩放，功能与播报完整）；卸载或切换案例后清理事件监听、定时器与悬挂的异步保存回调。
