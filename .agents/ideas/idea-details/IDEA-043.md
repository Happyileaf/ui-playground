## 创意概述

「选座」是在线票务（电影票、演出、高铁/民航选座、剧场/体育场馆）下单链路里体验权重最高、也最考验前端空间信息表达能力的一步：用户要在一张二维网格上，同时理解**银幕/舞台朝向、座位的空间位置（居中/靠边/前后排）、座位类型与价格、已售不可选、自己已选**这几层信息，并在「最佳观影位置」「连座」「同伴相邻」「预算」之间做权衡。它天然是高频、可直接用于生产环境的交互组件，但库内 60 个已注册案例与在池 42 个 Ready Idea 中，**没有任何「在二维座位网格上点选多个离散位置、维护一个多选集合并实时联动订单」的空间选位组件**：IDEA-041 甘特图是一维时间轴任务条、IDEA-021 横滑列表是线性手势、IDEA-024 穿梭框/IDEA-010 级联是表单式列表选择、IDEA-029 幸运转盘是概率结果——它们都不表达「行列坐标 + 朝向 + 可选/已售/已选空间状态」。

本案例做一个纯原生、零依赖、零 CDN、零外部图片/字体、双击离线即用的**影院选座图**：一张拟真影厅纵剖视角的座位图——顶部是弧形银幕（带透视光感），其下按排（A、B、C……）× 列组织座位，中轴可选地留出过道，座位有普通/优选（中后排黄金区）/情侣座或无障碍座等类型与差异化价格；部分座位预置为「已售」不可选。用户在座位图上点选/取消座位，已选集合实时维护，受最大购票数与「不可选已售座」约束；侧栏（或底部条）同步呈现已选座位号、分区票价、数量与合计金额，并提供清空、推荐连座辅助；悬停/键盘聚焦的座位有非颜色的位置提示（排号列号+类型+价格）。组件具备完整的网格键盘漫游（方向键在座位矩阵中移动焦点）、ARIA 网格/单选语义与屏幕阅读器播报，并在移动端支持单指平移/双指缩放查看大图与足够的触控热区。视觉为克制的深色影厅氛围（暗场 + 银幕柔光 + 座位微高光，已选态用高对比强调色 + 描边/勾选形状多重编码，不靠颜色 alone），右上角统一点阵色 Title 胶囊，Micro-HUD 默认折叠。

## 预期展示效果

- **构图与整体风格**：
  - 主体是一张**影厅纵剖座位图**：最上方为向观众方向微弧的银幕（弧形亮面 + 由银幕向座位区衰减的柔和环境光，暗示光从银幕来）；银幕下方是座位矩阵，按「排」自上而下、由前向后排布（前排靠近银幕、后排远离），每排左侧（或两侧）有排号标识；中轴可有一条纵向过道把左右座区对称分开，局部可有横向安全通道；座位以紧凑网格排列，优选区（通常中后排居中）以极淡的底色或顶部小标签提示「黄金观景区」。
  - 侧栏/底部为**订单联动条**：展示当前影片/场次占位信息、已选座位芯片（排号-座号 + 票价，可逐个移除）、已选数量/最大可购、分区小计与合计金额、「清空重选」「（模拟）确认选座」按钮，以及一个轻量「推荐连座」入口；信息随座位图操作即时一致更新。
  - 延续项目深色美学（与 modal/drawer/guided-tour 的暗场质感、IDEA-042 硬件面板的克制成品质感协调）：近黑背景、银幕为唯一较亮光源、座位是顶面受光的微立体单元（圆角小块 + 顶部高光 + 底部接触阴影）；强调色克制，仅用于已选态、焦点与合计等关键信息，避免满屏高饱和的廉价售票页观感。
  - 桌面端座位图 + 右侧订单栏并排（信息密度贴近真实选座页）；平板等比缩放；手机上订单栏收为底部吸附概览条、座位图占满宽度并支持触摸平移/缩放，座位触控热区不小于可点标准、排号与图例不溢出。
- **主要视觉元素**：
  - **座位单元（核心）**：以行列坐标定位的微立体座位块，用**形状 + 明度 + 颜色 + 图标/纹理**共同编码至少四种状态——可选（普通/优选等类型以细微明度或角标区分，非只靠颜色）、已售（明显降明度/斜纹/禁用质感且不可点）、已选（高对比强调填充 + 清晰描边/对勾或凸起选中造型）、焦点悬停（高亮外框 + tooltip 式位置标签）；不同座位类型（普通、优选、情侣座/无障碍）在造型或角标上可辨识。
  - **银幕与空间提示**：弧形银幕 + 环境光、排号、中轴过道、优选区淡底与图例（Legend，解释各颜色/造型含义，含已售/可选/已选/优选）；图例是理解座位图的必备钥匙。
  - **订单联动区**：已选座位芯片列表、数量与票价合计、约束提示（如达到最大购票数时的说明）、空态引导（「请在座位图上选择」）。
- **层次、材质、光影与关键细节**：
  - 视觉四层：暗场背景与银幕光（最底）→ 过道/优选区淡底/排号等空间结构 → 座位单元（唯一可点对象，按状态分层着色与造型）→ tooltip、图例、订单栏、HUD（信息层）；座位靠顶部高光与接触阴影微浮于地面，已选态有轻微抬起/放大的选中层级。
  - **状态必须是单一数据源驱动的确定性渲染**：所有座位（造型/颜色/aria/tooltip）与订单栏（芯片/数量/合计/按钮可用性）都由同一份「座位矩阵 + 已选集合」状态计算，刷新后同一状态呈现同一画面；不允许座位图显示已选而订单栏漏计、或重复点击产生不一致。
  - 手感细节：点选即时切换并伴极克制的缩放/弹入反馈；连续多点（拖选相邻可选座）可作为增强但单击必须成立；已售座点击给出明确但不刺眼的否定反馈（轻微抖动/禁止提示）而非无响应；达到最大购票数时再点可选座给出文案解释；合计金额用 tabular-nums 避免跳宽。
  - 右上角统一点阵色 Title 胶囊为强制项；Micro-HUD 默认折叠。

> 设计文档约束最终体验与设计意图；影厅具体排数/列数、过道位置、各座位类型与票价数值、最大购票数、银幕弧度、座位像素尺寸、是否提供连座推荐算法及其策略、具体色值等由实现阶段按拟真度统一决定，不在此过早钉死；但「二维行列座位图 + 银幕朝向与空间结构 + 可选/已售/已选多状态（多重编码）+ 已选集合受约束维护 + 订单实时联动 + 网格键盘漫游与 ARIA + reduced-motion 与触控等价」这条链路必须真实成立，不允许摆一张不能点或点了不联动订单的静态座位图，不允许只支持鼠标，也不允许引入任何框架、图表/座位图库或外部资源。

## 动态与交互

- **触发方式（指针点选主导，键盘完全等价，非自动播放）**：
  - **指针（鼠标/触控/手写笔统一 Pointer Events）**：点击可选座位即加入已选（座位变为已选态、订单栏即时增加该座位与票价）；再次点击已选座位取消；点击已售座位不改变集合，给出克制的否定反馈；离开座位图后状态保留。移动端座位图可单指平移、双指缩放（或提供缩放控件）以查看大影厅，点按与滚动手势按起点/阈值正确区分，不误触选座。
  - **选择约束**：维护一个已选有序集合，受「最大购票数」约束（达到上限再选给出文案提示、不静默失败）；已售座永不可选；可选提供「相邻连座」校验或推荐（如提示当前已选是否连座、一键填充推荐连座），但推荐为辅助、不强制。
  - **键盘（ARIA grid 漫游）**：座位区以网格语义暴露，方向键在「逻辑相邻的可选/不可选座位」间移动焦点（跨过道/换行行为符合直觉），Home/End 到排首排尾、可附加 PageUp/PageDown 跳排，Enter/Space 切换当前焦点座位的选中；焦点环始终清晰可见；Tab 能进入/离开座位图与订单栏控件，不劫持 Tab。
  - **订单联动**：每次集合变更，已选芯片、逐座票价、数量、合计金额、确认/清空按钮可用性即时更新；芯片可单独取消并反向同步座位图；「清空重选」一次性还原；「确认选座」为演示用模拟动作（给出已选清单反馈，不产生真实交易、不发网络请求）。
- **状态与数据模型**：
  - 以行列矩阵描述座位：每格含排号、座号、类型（普通/优选/特殊）、价格、是否已售、是否已选；派生「是否可聚焦/可选」「是否连座」等视图状态；座位渲染与订单渲染只从同一状态读取。
  - 集合变更走唯一提交入口：校验（已售/上限）→ 更新集合 → 同步座位 DOM 与订单 DOM 与 aria，高频触摸移动用 rAF 合帧；初始可预置若干已售座与一个合理默认场次。
- **控制与可配置项（Micro-HUD 默认折叠，`H`/`Esc` 切换、事件防穿透）**：影厅规模（排/列）、已售比例或重新随机已售分布、最大购票数、优选区范围、座位类型/票价方案、连座推荐开关、reduced-motion 生效状态、一键重置为初始场次；常用操作（清空、确认、图例）直接可见，核心控制不藏进 HUD。
- **可访问性（一等路径）**：
  - 座位具可读名称（如「H 排 12 座，优选区，58 元，可选/已选/已售」）与网格语义；选中/取消、达到上限、点到已售等离散结果经 aria-live（polite）克制播报（如「已选 H 排 12 座，共 3 座，合计 174 元」），不在拖动/滑过时逐格刷屏；状态不仅靠颜色（造型/描边/图标/文案多重编码）；文字与非文字对比度达 WCAG AA。
  - `prefers-reduced-motion: reduce`：关闭座位弹入/抖动、银幕光呼吸等非必要运动，状态切换与订单联动即时到位（点选、约束、键盘、连座、清空、缩放平移等功能一个不少）。
- **移动端与触控**：座位与可点区域满足触控热区；大图支持触摸平移/缩放或缩放控件，排号/图例/订单条在窄屏不遮挡选座、不横向溢出；横竖屏与容器尺寸变化后座位坐标与点击命中不错位。
- **生命周期**：案例卸载（iframe 销毁）/页面隐藏时取消 rAF、释放 Pointer Capture、移除全部监听；本案例默认不发声，如加入极轻触感音须在首次手势内懒创建 AudioContext、可静音、零音频文件；重新进入从干净初始场次开始；无自动播放动画。

## 核心亮点

1. **补齐全仓唯一的「二维空间选位」空白**：60 个注册案例（components 45 / effects 12 / pages 3）与在池 42 个 Ready 中，选择类控件都是线性/列表/弹层/概率范式（range-slider、cascader、transfer、combo-box、swipe-action-list、lucky-wheel 等），没有「行列坐标 + 朝向 + 空间状态多选集合」的选座图；它是电影/演出/航司/高铁票务下单链路的高频生产组件，成品可直接落地真实选座页，实用性 5/5。
2. **空间信息的多层表达**：弧形银幕与由银幕衰减的光、排号、中轴过道、优选观景区淡底、四态座位（可选分类型/已售/已选/焦点）与配套图例，让「我选的位置好不好、和谁相邻、什么价格」一眼可读，而非一堆等权格子。
3. **单一状态源驱动的座位图—订单实时联动**：座位矩阵 + 已选集合是唯一数据源，座位态、aria、已选芯片、逐座票价、数量、合计、按钮可用性同源派生，刷新/快速点选/清空/连座推荐下永不脱钩；最大购票数与已售约束给出明确反馈而非静默失败。
4. **生产级可达性与触控等价**：ARIA grid 方向键漫游（跨过道/换行）、Enter/Space 选中、可读座位名与 aria-live 离散播报、状态多重编码 + AA 对比、清晰焦点环；移动端单指平移/双指缩放 + 充分触控热区；reduced-motion 只去动效不降功能。
5. **零依赖工程约束**：零框架、零座位/图表库、零图标字体、零外部图片/字体（座位、银幕、纹理全部 CSS/内联 SVG 程序化绘制），双击 `index.html` 离线完整可用。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库（明确禁止任何座位图/选座/图表/网格库）、零图标库/图标字体、零 CDN、零外部图片/字体/音频文件；银幕、座位、过道、纹理、特殊座图标全部用 CSS（渐变/transform/clip-path）与内联 SVG 程序化绘制，金额/排号用系统字体栈 + tabular-nums；双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 必须以「座位行列矩阵 + 已选有序集合」为唯一状态源，座位渲染（状态/造型/aria/tooltip）与订单渲染（芯片/逐座票价/数量/合计/按钮可用性）只从同一状态派生；任何选择先经校验（已售不可选、最大购票数、可重复点击取消）再提交；初始预置若干已售座与默认场次，刷新后同状态同画面。
- 指针交互统一 Pointer Events：单击点选/取消必须成立，已售点击有克制否定反馈，上限有文案反馈；移动端座位图支持触摸平移/双指缩放（或等价缩放控件），点选与滚动手势按热区/阈值区分；只改 transform/合成友好属性，rAF 合帧；卸载/隐藏时取消 rAF、释放捕获并移除监听。
- 必须具备 ARIA grid（或等价）键盘漫游：方向键在逻辑相邻座位间移动、Home/End/跳排、Enter/Space 切换选中、可见焦点环、Tab 不被劫持；每座有可读名称（排/座/类型/价格/状态）与离散 aria-live 播报；状态不仅靠颜色（描边/造型/图标/文案多重编码），对比度达 WCAG AA；`prefers-reduced-motion: reduce` 下仅去除弹入/抖动/光呼吸等运动，全部选择、约束、联动、键盘、缩放、清空、连座辅助功能完整。
- 默认不发声；如加入极轻触感音须在首次用户手势内懒创建/恢复 AudioContext、可静音、零音频文件（Web Audio 实时合成），页面隐藏/卸载时挂起或关闭。
- 视觉为克制深色影厅暗场美学（银幕为主光源、强调色有明度层次而非彩灯堆砌），桌面/平板/手机自适应（座位触控热区充分、订单栏窄屏收为底部吸附条、大图可平移缩放、排号图例不溢出、坐标命中不随容器变化错位）。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊（强制）；影厅规模、已售分布重随、最大购票数、优选区、票价方案、连座推荐开关、reduced-motion 状态与一键重置等通过默认折叠的 Micro-HUD 提供（`H`/`Esc`、事件防穿透）。
