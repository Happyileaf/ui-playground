## 创意概述

一个拟真的「刮开涂层揭晓结果」互动券卡组件（电商促销、会员签到、线下核销、游戏抽奖等营销场景中最常见的刮刮乐形态）。卡片正面是一张被银灰色不透明涂层完整覆盖的奖区，涂层上印有「刮开有惊喜 / 用手指或鼠标刮开」之类的引导与纹理质感；用户用鼠标或手指在涂层上往复涂抹，涂层被**像真实银漆一样成段擦除**，逐渐透出底层预先渲染好的奖品结果。当被刮开的面积达到设定阈值时，剩余涂层以一次顺滑的扩散动画自动清开，完整揭晓结果，并触发克制的中奖反馈（光扫、结果强调、领取按钮亮起）；提供「再刮一张」重置入口，奖品结果与涂层全部纯前端程序化生成、零外部图片。

解决的体验问题：相比直接弹窗告知「恭喜中奖」，刮开动作本身把「揭晓」变成一段由用户亲手完成、带不确定期待感的仪式，显著提升营销券卡的参与度与惊喜感；同时这是一种当前案例库完全缺失的**笔刷式擦除（destructive painting / eraser gesture）**交互范式——库内 Canvas 案例集中在粒子、流体、签名、图表与水印，没有任何「基于指针轨迹对一层表面做累积式擦除并做面积统计」的组件，本 Idea 补齐这一兼具强实用性与独特手感的方向。

## 预期展示效果

- **构图与整体风格**：
  - 单屏居中一张实体券卡（圆角矩形，可带票根式缺口 / 虚线分栏的「优惠券」气质），卡面上方是品牌与活动标题区，中间为方形或宽幅的**刮奖涂层区**，下方是结果揭晓后才激活的「立即领取 / 使用」操作区；卡片右上角按工作台 HUD 规范放置点阵色 Title 胶囊。
  - 外层延续工作台深色高级质感，券卡本体采用克制的高饱和品牌色 + 细腻材质，让银漆涂层与透出的奖品成为绝对视觉焦点；同屏可陈列「未刮 / 刮中 / 未中奖」三种状态的缩略小样，体现组件的多态完整性。
- **主要视觉元素**：
  - 银漆涂层：Canvas 覆盖的一层**金属磨砂质感不透明膜**（带细腻颗粒、微妙的高光扫向与边缘压印描边），膜面印有引导图标（硬币 / 手指刮动示意）与引导文案，未刮时完全遮挡结果。
  - 笔刷擦痕：指针轨迹以带压感 / 速度感的圆头笔刷做 `destination-out` 挖空，刮开处边缘呈真实银漆被推开后的**不规则锯齿与残漆颗粒**，而非整齐的几何空洞；已刮区域透出底层结果，并能看到涂层被推薄时的半透明过渡。
  - 底层结果：涂层下方预先绘制好的奖品格（如优惠券面额、礼品图标、中奖 / 谢谢参与），带描金或品牌强调色；不同奖品等级在结果揭晓瞬间有差异化的视觉强调。
  - 进度反馈：不强制用数字打扰体验，可在涂层边缘以一圈极细的进度光或低调百分比暗示「再刮一点」；达阈值后剩余涂层自动清开。
- **层次、材质、光影与关键细节**：
  - 涂层与结果是清晰的上下两层（上层可擦除金属膜、下层结果卡面），刮开瞬间的材质对比（哑光金属膜 vs 鲜亮奖品格）是核心视觉爽点。
  - 笔刷边缘做硬度 / 间距 / 随机抖动处理，配合随指针速度变化的笔刷直径，形成「快刮带飞白、慢刮更干净」的手写质感；涂层上保留被刮动方向带起的细微拉丝。
  - 达阈值自动揭晓时，剩余涂层不是生硬消失，而是沿已刮区域做一次柔和的径向 / 模糊扩散清场（或像膜被整体掀起一角后抽走），结果层同时做一次轻微的上浮 + 光扫强调；中奖结果可在不浮夸的前提下加一道克制的流光或星点。
  - 未中奖与中奖在结果层有明确但不依赖纯色的区分（图标 + 文案 + 结果版式），操作区按钮文案与状态也相应变化（领取奖品 / 再试一次）。

> 设计文档约束最终体验与设计意图；笔刷直径、面积阈值百分比、颗粒密度、自动清场时长与具体色值由实现阶段按整体视觉统一决定，不在此过早钉死。

## 动态与交互

- **触发方式（Pointer Events 统一鼠标 / 触控 / 手写笔）**：
  - 指针在涂层区按下（pointerdown）并移动（pointermove）时持续累积擦除：以相邻采样点连线方式插值铺圆头笔刷，避免快速移动出现断孔；通过 setPointerCapture 保证指针短暂离开涂层 / 卡片仍不丢失手势，并正确设置 `touch-action: none`，使手机上单指刮动不触发页面滚动或选择。
  - 刮动过程中以**节流 / 降采样**方式（如每隔若干帧、或分块抽样统计）计算被擦除像素占涂层有效面积的比例，达到阈值即触发自动揭晓，避免每帧全画布 `getImageData` 造成卡顿。
  - 达阈值后的自动清场动画结束前锁定输入（防止重复触发），结束后激活操作区；「再刮一张」按钮重新生成涂层与（可随机的）结果，完整复位到未刮态。
- **桌面端与跨输入兜底**：鼠标按住涂抹是主路径；卡片 / 涂层可获得键盘焦点，提供键盘等价路径（如方向键移动一个虚拟刮点、或一键「全部刮开」的揭晓快捷键），保证不使用指针的用户也能完成体验；结果变化通过 `aria-live` 礼貌播报中奖信息。
- **可访问性**：
  - 涂层视为带明确可访问名称的可交互区域（如「刮奖区，按下并拖动刮开涂层」），结果层与按钮具备语义标签；色彩不是唯一的中奖信息载体（奖品名、图标、文案同时表达）。
  - 尊重 `prefers-reduced-motion`：减弱动效下去掉笔刷飞白、自动清场扩散与中奖流光，改为刮到阈值后即时清开涂层、即时显示结果，核心功能完整保留。
- **移动端触控**：Pointer Events + setPointerCapture + `touch-action: none`，在手机视口模拟器与真机上单指即可顺滑刮擦；DPR 适配保证高清屏上涂层与刮边缘不糊。

## 核心亮点

1. **全新的笔刷式擦除交互范式**：库内首个「对一层表面沿指针轨迹做累积式擦除并实时统计面积」的组件，圆头笔刷插值、速度 / 压感式粗细、飞白与残漆颗粒共同还原真实刮银漆手感，而非简单的轨迹画线。
2. **由用户亲手完成的揭晓仪式**：涂层（哑光金属膜）与结果（鲜亮奖品格）的双层材质对比、刮开过程的期待感、达阈值后自动扩散清场与中奖光扫，把营销通知升级为一段有节奏的互动体验。
3. **完整、可落地的营销券卡闭环**：未刮 / 进行中 / 中奖 / 未中奖多态，结果驱动的操作区（领取 / 再试）、「再刮一张」复位、可配置奖品与阈值，可直接用于电商促销、签到、抽奖等真实页面。
4. **性能与可达性同样成立**：分块降采样统计擦除面积、DPR 高清渲染、减弱动效与键盘等价路径、aria-live 结果播报，在强效果组件上不牺牲流畅度与可访问性。

## 历史案例对比（进入 Ready 前必填）

- **检查范围**：`src/playground.js` 全部 60 个注册案例（id / 标题 / 描述 / tags）+ `playground/effects`、`playground/components`、`playground/pages` 物理目录 + 活动池 IDEA-001～IDEA-024 + `rejected.md`（当前为空）+ `completed.md`（当前为空）。
- **相似案例**：
  - `signature-pad`（电子签名板）：同样是 Pointer Events + Canvas + DPR、沿指针轨迹落笔，是最接近的技术近亲；但它是**累积「绘制」黑色笔迹并导出 PNG**，笔刷只做正向上色，本 Idea 是对一整层金属膜做 `destination-out` **累积擦除 / 挖空**、需要**实时统计被擦面积并在阈值触发自动揭晓**，且核心是双层材质揭示与营销结果态，交互目标、渲染合成方式与结果完全不同。
  - `image-comparison-slider`（图片对比滑块）：同有「遮住一部分、随操作露出底层」的揭示感，但它是单条 `clip-path` 裁剪线跟手平移、对比两张前后图，无笔刷、无自由轨迹、无面积累积与自动揭晓。
  - `watermark`（防泄密水印）：同用 Canvas 生成铺面层，但它是只读平铺水印 + MutationObserver 防篡改自愈，方向相反（守护不被去除），无任何指针擦除交互。
  - Canvas 粒子 / 流体类（`fireworks`、`confetti-burst`、`kinetic-silk`、`living-constellation`、`particle-text`、`cursor-follow`）：均为自动 / 指针扰动的动画或粒子，不构成对静态表层的物理擦除与面积判定；其中奖场景可能用到彩带，但本 Idea 不依赖粒子，反馈以涂层揭示为主。
  - 表单 / 营销相关：`slider-captcha` 来自在池 IDEA-022（尚未实现）属**水平拖块对位校验**，`otp-input`、`payment-card-input`、`like-button`（双击点赞迸发）等均不含刮擦揭示；活动池 IDEA-001～IDEA-024（日期 / 轮播 / Toast / 标签 / 步骤 / FAB / 液态下载 / 聊天页 / SVG 图表 / 级联 / 评分 / 分页 / 时间选择 / 开关合集 / View Transitions / 灯箱 / 贝塞尔工坊 / 翻牌 / 表情 / 提及 / 横滑列表 / 滑块验证码 / 方向感知图廊 / 穿梭框）无任何刮刮乐或涂层揭示主题。
- **差异说明**：核心创意差异在「**沿自由指针轨迹对一层金属涂层做累积式擦除，按擦除面积阈值驱动自动揭晓的双层揭示交互**」。与最接近的 `signature-pad` 相比，渲染合成（擦除挖空 vs 正向绘制）、状态机（未刮 / 刮动中 / 达阈值自动清场 / 中奖或未中奖 / 复位）、面积统计与营销结果闭环均为全新；与 `image-comparison-slider` 的单裁剪线、`watermark` 的只读守护层也有本质区别。视觉表达（金属银漆膜 + 奖品格双层材质）与交互方式（自由涂抹而非拖动滑块 / 画线 / 抛掷）在历史与在池案例中均无重复，不属于换颜色、文案或微调参数。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库、零 CDN，双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 涂层与奖品结果零外部图片：金属磨砂涂层、颗粒 / 高光与底层奖品格（含礼品图标）全部由 Canvas（DPR 适配）与 / 或内联 SVG、CSS 渐变程序化生成。
- 擦除使用 Canvas 合成（如 `globalCompositeOperation: 'destination-out'`）；面积统计必须分块 / 降采样节流，禁止每帧全画布高频 `getImageData` 密集扫描；指针轨迹需在采样点间插值铺刷，避免快速刮动断孔。
- 手势统一 Pointer Events + setPointerCapture 并设置 `touch-action: none`，避免与页面滚动 / 文本选择冲突；内联 SVG 图标，不使用任何外部图片 / 字体资源；纯前端模拟，不发起网络请求。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊；如需控制面板（调节笔刷大小、揭晓阈值、切换奖品 / 中奖率演示等）默认折叠并支持 `H` / `Esc` 快捷键且事件不穿透。
