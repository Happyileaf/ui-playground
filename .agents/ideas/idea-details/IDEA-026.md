## 创意概述

「点击一个有后果的动作（删除、退订、清空、移出成员、放弃编辑）前先轻量确认一次」是后台管理、列表操作、设置页中最高频的确认原语。它有两种经典重量：用 `modal` 做**强阻断居中弹窗**（打断感强、适合不可逆高危操作），以及用 **Popconfirm 气泡确认框**——紧贴触发元素、带指向小箭头、只问一句「确定删除吗？」并给出「取消 / 确定」两个按钮的**锚定式轻确认**，不抢走整屏注意力、不做大幅遮罩，确认完即就地消失。

当前案例库的浮层体系已覆盖 modal（强阻断对话框）、drawer（四向抽屉）、context-menu（右键嵌套菜单）、tooltip（纯信息提示）、mega-menu / notification-center / guided-tour 等，却唯独缺少这个介于 Tooltip 与 Modal 之间、在 Ant Design / Element 等生产组件库中与 Popover 并列的**轻量确认原语**。本案例做一个纯原生、零依赖、可直接投产的 Popconfirm：以一个**拟真后台列表 / 设置场景**承载（多行可删除记录、危险与普通两类触发），气泡从触发点智能弹出、自动检测视口边缘翻转方位、带弹性入场与指向箭头、危险态语义色、异步提交 loading 态、完整 ARIA 与焦点管理（打开聚焦取消、Tab 陷阱、Esc/外点关闭、确认或取消后焦点归还触发器），并以「确认后就地给出结果反馈」收尾。

## 预期展示效果

- **构图与整体风格**：
  - 以一个**真实操作场景**承载（推荐「成员管理 / 通知列表 / 草稿箱」一类拟真后台：标题区 + 若干带操作按钮的列表行），让 Popconfirm 长在真实按钮旁而非空背景上；整体延续项目深色玻璃质感、圆角、克制留白与柔和投影语言。
  - 每行危险操作（如「删除」「移出」）与一个普通确认操作（如「退订」「标记已读」）作为触发元素；点击触发元素后，一个**小型气泡卡片**锚定在该元素旁（默认上方），不出现全屏重遮罩（最多一层极淡、可忽略的压暗，或干脆无 scrim，靠外点 / Esc 关闭），列表内容仍清晰可辨。
  - 同屏可陈列「默认（上）/ 下方翻转 / 危险语义 / 异步提交中」等形态小样，体现组件的多态完整性；卡片右上角按工作台 HUD 规范放置点阵色 Title 胶囊。
- **主要视觉元素**：
  - **气泡体（Pop）**：深色玻璃 / 高对比实心小卡片，圆角、细描边与层级投影；内部结构为「引导图标 + 一句标题（可选一行补充说明）+ 取消 / 确定按钮组」，信息密度克制、一屏读完。
  - **指向箭头（caret / arrow）**：气泡朝向触发元素的一侧带小三角，几何中心对准触发元素；气泡因边缘翻转方位时，箭头位置随之重算，始终指向锚点。
  - **语义与图标**：危险确认使用克制的警示色（确定按钮实心危险色、引导图标为警示形），普通确认为主强调色；图标统一内联 SVG，不依赖外部资源。
  - **触发元素**：列表行内的文字按钮 / 图标按钮，打开确认时触发元素保持 `aria-expanded` 高亮关联态，让用户清楚气泡属于哪个操作。
- **层次、材质、光影与关键细节**：
  - 气泡投影高于列表行、低于全屏 modal，形成「轻量浮层」的明确层级；玻璃 / 磨砂质感与现有毛玻璃语言一致，但卡片边界要足够清晰以承载可点击按钮。
  - 入场使用短促的弹性 / 阻尼缓动（与项目 spring 语言一致）：位移（从触发方向数像素）+ 透明度 + 轻微缩放组合，约 150–250ms 量级；关闭反向略快；箭头与气泡整体一起运动，不错位。
  - 点击「确定」进入**异步提交态**：确定按钮显示内联 loading（旋转指示，纯 CSS / SVG）、按钮组临时禁用，模拟一次短暂请求后气泡关闭、触发所在行以列表内变化（行滑出 / 状态更新）或统一轻提示收尾；纯前端演示，不发起真实网络请求。
  - 危险态的红色克制使用（只在确定按钮与小图标），不把整张气泡刷成大红，避免廉价警报感；focus-visible 焦点环清晰且独立于 hover。

## 动态与交互

- **打开 / 关闭触发（多路径）**：
  - 指针：点击触发元素打开气泡；点击气泡外区域、或点击「取消」关闭；点击「确定」执行业务确认（先走异步态再关闭）。
  - 键盘：触发元素聚焦时按 `Enter` / `Space` 打开；打开后焦点移入气泡内**默认安全按钮（取消）**，避免回车直接触发危险操作；`Tab` / `Shift+Tab` 在「取消、确定」之间循环（轻量焦点陷阱）；`Esc` 关闭气泡；确认或取消后焦点**精确归还触发元素**。
  - 同一时刻只存在一个打开的 Popconfirm；打开另一个时先关闭当前一个。
- **智能定位与边缘碰撞**：默认在触发元素上方弹出；基于实时视口 / 元素几何计算，上方或两侧空间不足时自动翻转到下方 / 左右方位并钳制，气泡与箭头始终完整可见、不溢出视口；窗口 `resize` / 页面滚动时重新定位或直接关闭（以状态一致、不发生错位为准）。
- **异步确认态**：点击确定后按钮进入 loading 并锁定重复提交（防止连点产生多次删除），模拟请求结束后关闭气泡并在场景内呈现结果（对应列表行删除动画 / 状态变化 + 可选的统一轻提示）；提供方式演示「请求失败」时气泡不关闭、给出错误反馈且可重试。
- **可访问性**：气泡具备弹层语义（`role="dialog"` + `aria-modal="false"` 或等价的非模态对话语义）与可访问名称（标题 / `aria-labelledby`）；触发元素带 `aria-haspopup="dialog"`、`aria-expanded`、`aria-controls` 关联气泡 id；打开 / 关闭、确认结果对读屏友好（结果可经 `aria-live` 礼貌播报）；色彩不是唯一的危险 / 普通区分手段（图标 + 文案共同表达）；动效遵循 `prefers-reduced-motion`（关闭弹性位移，改为即时或仅淡入淡出，功能与语义完整）。
- **可选 Micro-HUD**：默认折叠的统一 Micro-HUD（`H` / `Esc` 切换、事件防穿透），可切换弹出方位策略（自动 / 强制上 / 强制下）、scrim 开关、是否开启异步态演示等；非必需时至少保留右上角 Title 胶囊。
- 移动端触控：点按触发元素弹出、点按按钮或外点关闭；气泡在窄屏不溢出、按钮触控热区达标，必要时在小屏上保持锚定气泡而非强行升级为全屏 modal。

## 核心亮点

1. **补齐浮层重量梯度里的关键一格**：在 Tooltip（纯展示）与 Modal（强阻断）之间补上「锚定式轻确认」这一生产高频原语，明确「危险 / 普通」两类语义与就地确认、就地反馈的闭环，可直接用于后台列表、设置页、会员 / 订阅场景。
2. **智能锚定 + 指向箭头的轻量浮层编排**：气泡与箭头一体的弹性入场、基于实时几何的方位翻转与钳制、resize / 滚动一致性处理，区别于居中 modal 的打断感，做到「确认不离开上下文」。
3. **真实可用的异步提交状态机**：确定按钮内联 loading、提交期锁定防重复、成功关闭并驱动列表行变化、失败保留气泡可重试——覆盖真实业务里「确认即请求」的完整链路，而非只做显隐玩具。
4. **完整 ARIA 与焦点安全**：非模态 dialog 语义、`aria-haspopup/expanded/controls` 关联、打开聚焦「取消」这一危险操作安全默认、Tab 陷阱、Esc / 外点关闭、确认后焦点精确归还，并尊重减弱动效。

## 历史案例对比（进入 Ready 前必填）

- **检查范围**：src/playground.js 全部 60 个注册案例（id / 标题 / 描述 / tags）+ playground/effects、playground/components、playground/pages 物理目录（12 effects / 45 components / 3 pages，与注册数一致）+ 活动池 IDEA-001～IDEA-025 + rejected.md（当前为空）+ completed.md（当前为空）。
- **相似案例**：
  - `modal`（Native Modal Dialog）：最接近的「确认对话框」近亲，同样承载取消 / 确定与焦点陷阱；但它是**居中、强阻断、带高斯模糊全屏遮罩**的重对话框，本 Idea 是**锚定在触发元素旁、小体量、无重遮罩（非模态）**的轻确认，视觉重量、定位方式（锚点 + 箭头 + 边缘翻转）与打断程度完全不同。
  - `tooltip`（Smart Tooltip）：同样是「锚定触发元素 + 智能边缘碰撞翻转 + 小卡片 + 弹性动效」的浮层近亲；但 Tooltip **只读、无交互按钮、悬停即显**，本 Idea 内含标题 / 图标 / 取消 / 确定按钮组、点击触发、焦点陷阱与异步确认状态机，承载的是「需要用户决策」的确认动作而非信息展示。
  - `context-menu`（右键上下文菜单）：同样是非全屏、带边缘翻转与键盘导航的浮层；但它是右键 / 长按唤起的**多动作嵌套菜单**，无锚定指向箭头的单一提问结构、无取消 / 确定二元确认与异步提交语义。
  - `drawer`（Slide Drawer）：带遮罩与焦点陷阱的四向滑出面板，承载大块内容，属重浮层；本 Idea 体量小、就地锚定、不锁整屏。
  - `guided-tour`（新手引导）：挖空 + 气泡卡片指向目标元素，技术形态（锚点气泡）相近；但它是**多步、只读讲解、遮罩挖空**的导览流，本 Idea 是**单步、含决策按钮、由用户操作触发**的确认框，目的与交互结构不同。
  - `notification-center` / 在池 IDEA-003 Toast / IDEA-006 FAB Speed Dial：通知中心是铃铛下拉的只读消息列表、Toast 是操作后的即时反馈堆叠、FAB 是收纳动作的开合菜单；均无「先问一句再执行」的确认决策结构。
  - `avatar-stack`（悬停名片）/ `mega-menu`（全宽导航）：同样有边缘避让的浮层，但分别承载资料卡与站点导航，无确认按钮组与提交状态机。
  - 活动池 IDEA-001～IDEA-025（日期 / 轮播 / Toast / 标签 / 步骤 / FAB / 液态下载 / 聊天页 / SVG 图表 / 级联 / 评分 / 分页 / 时间选择 / 开关合集 / View Transitions / 灯箱 / 贝塞尔工坊 / 翻牌 / 表情 / 提及 / 横滑列表 / 滑块验证码 / 方向感知图廊 / 穿梭框 / 刮刮乐）无任何 Popconfirm / 锚定式二次确认主题。
- **差异说明**：核心创意是「**锚定触发元素、带指向箭头、智能边缘翻转的非模态轻量二次确认气泡 + 取消 / 确定决策与异步提交状态机**」。历史案例中没有任何 Popconfirm 原语：与最接近的 `modal` 相比，浮层重量（轻 / 重）、定位（锚点气泡 / 居中）、遮罩（无或极淡 / 全屏模糊）、打断程度均不同；与 `tooltip` 相比，从只读提示升级为可决策、可提交、带焦点安全的交互浮层；与 `context-menu` / `guided-tour` 在目的（单一二元确认）、触发（点击危险操作）与结构（标题 + 双按钮 + loading）上也存在实质差异。差异体现在核心创意、视觉表达（锚点小气泡 + 一体箭头 + 危险语义）、交互方式（点击确认链路 / 异步态 / 焦点归还）与整体表现上，不属于换颜色、文案或微调参数类重复。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库、零 CDN，双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 演示场景与全部图标使用内联 SVG 与原生元素构造，不引用其他案例代码、不引入动画 / 图标库；异步确认为纯前端模拟（定时器占位），不发起真实网络请求、不依赖外部图片 / 字体。
- 浮层定位基于实时视口 / 锚点几何计算（固定或绝对定位 + transform 合成层属性），箭头与气泡一体；打开、翻转、resize / 滚动处理须保证不溢出、不错位；同一时刻至多一个打开实例。
- 打开 / 关闭 / 提交为单一可信状态机（关闭中、loading 中重复触发以状态机判定为准），避免连点造成多删或状态错乱。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊；如需参数控制使用默认折叠的 Micro-HUD（`H` / `Esc`、事件防穿透）。
- 尊重 `prefers-reduced-motion`；窄屏与触控热区达标；卸载 / 切换案例时清理监听、定时器与任何 rAF。
