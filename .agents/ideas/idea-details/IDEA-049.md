## 创意概述

做一类电商、导览、产品营销与信息图场景里被大量验证的高频组件——**在一张图像 / 图解上放置坐标锚定的可交互热点（hotspot），点击或聚焦即可在图旁弹出该位置的详情卡片**。典型真实用途包括：可购商品图（shoppable image，点模特身上的穿搭单品看名称 / 价格 / 加购入口）、园区与展馆 / 商场楼层导览地图（点设施、出入口、展位看介绍与方向提示）、产品功能点图解（点设备的接口、按键、结构部位看功能说明）、以及带标注的信息图。它解决的是「一张图承载多个可探索信息点」时，纯静态图无法点选、纯弹窗列表又脱离空间位置的体验缺口。

当前案例库 60 个注册案例与在池 48 个 Ready 中**没有任何「以一张图 / 图解为底、以自由坐标锚定可交互标记体系 + 信息弹层 + 分类筛选 + 顺序导览」的组件**：`tooltip` 只是无坐标体系的纯文本气泡；`guided-tour` 是对页面 DOM 遮罩挖空的多步讲解流，不在图上标点；`image-zoom` / `image-comparison-slider` / `image-cropper` 虽属图像交互，但分别做放大镜、前后对比与裁剪，无热点信息体系；在池 IDEA-043 影院选座是规则网格 + 库存语义的点选，IDEA-040 的卖点 callout 是滚动叙事中的被动标注，均非自由百分比坐标的标注导览组件。本案例以**数据驱动**的方式渲染热点，并内置至少两套零外部资源的内置图解（拟真产品功能图解 + 园区平面导览），既是可直接落地生产网页的组件，也是能横向对比不同热点视觉语言（脉冲光点 / 编号徽章 / 图标标记）的交互展厅。

## 预期展示效果

- **构图与整体风格**：
  - 页面视觉重心是一张大比例**图解舞台**（响应式，桌面约 16:9 / 4:3，窄屏自适应），底图由内联 SVG 配合多层 CSS 渐变 / 模糊光斑构造（如一件拟真数码产品的立面功能图解，或一个俯视园区平面示意图），有克制的体积感与光影但不喧宾夺主；热点标记以**百分比坐标**锚定在图解之上，随舞台尺寸等比缩放、永不漂移。
  - 舞台之外：顶部一行分类筛选 chips（如产品场景的「外观 / 接口 / 功能」、园区场景的「设施 / 商铺 / 出入口」）与图例色点；舞台下方为「上一个 / 下一个」顺序导览控件与 `当前 n / 共 N` 进度；侧边或下方可附一份与热点数据同源的**语义化信息索引列表**（桌面作为快速跳转，无 JS 时是完整退化形态）。
  - 延续项目暗色、低饱和、Anti-Slop 审美：近黑 / 深炭底，热点以一种克制强调色为主、分类色为辅（不同分类用可区分但和谐的色点，不整屏霓虹）；信息卡为毛玻璃面板配细边框与柔和投影；右上角固定项目统一的点阵色 Title 胶囊；默认折叠的 Micro-HUD 提供场景切换、热点视觉语言切换、脉冲动画与「常显标签」开关、reduced-motion 状态显示。
- **主要视觉元素**：
  - **热点标记（多形态可切换的展厅属性）**：
    - 脉冲光点（默认）：实心小圆点 + 向外扩散的涟漪光环，呼吸节奏克制、不频闪；
    - 编号徽章：圆形描边徽章内显 1、2、3…，与顺序导览 / 图例对应，信息不靠颜色单通道传达；
    - 图标标记：小圆底 + 内联 SVG 语义图标（如接口、餐饮、出入口）。
    - 三态明确：默认（呼吸涟漪 / 描边）→ hover 与键盘聚焦（轻微放大、光环增强、出现朝向卡片的小箭头）→ 激活打开（实心强调、涟漪停止、信息卡展开）；被分类筛选隐藏的热点整体淡出且不可聚焦。
  - **信息卡（弹层）**：毛玻璃卡片，含分类色点 + 标题、一到两行说明、可选的场景化操作区（产品场景：价格与「查看详情」样式 CTA；园区场景：简短方位提示），带指向热点的小箭头；同一时刻单开，点另一个热点即切换内容。
  - **连接与引导（可选、克制）**：激活热点与信息卡之间可有细引导线 / 箭头；顺序导览时被激活的热点在图上平滑接管，卡片内容做轻量交叉淡入，而非生硬闪现。
  - **双场景内置图解（数据驱动复用）**：同一热点组件挂载两套数据——「产品功能图解」与「园区平面导览」，底图、热点坐标、分类与卡片内容随场景切换整体替换，直观展示组件的数据驱动能力与真实落地广度。
- **层次、材质、光影与关键细节**：
  - 层次：底图（最底，静态氛围）→ 热点标记与涟漪（交互层）→ 信息卡 / 引导箭头（解说层）→ 筛选 chips / 导览控件 / 索引列表（操作台）→ Title 胶囊 / HUD（固定层）；层级靠明度、模糊（毛玻璃 backdrop-filter）与投影区分。
  - **坐标锚定与碰撞避让是工程底线**：热点位置以相对舞台的百分比表达（宽 / 高两个方向各自归一化），舞台任意尺寸下标记与底图部位严格对齐；信息卡基于热点实时位置与舞台 / 视口边缘做**四向智能翻转避让**（上方空间不足翻下方、靠右超出翻左侧等），箭头同步换向，窄屏自动转为舞台底部的通栏卡片条，绝不出现卡片溢出视口或遮住被点热点的情况。
  - 动效克制：仅做 transform / opacity / filter 等不触发布局的属性；脉冲柔和可关闭；信息不仅靠颜色编码（编号、图标形状、文案、aria 状态共同承载语义）。

> 设计文档约束最终体验与设计意图；具体内置图解的题材与数量、热点坐标与文案数据、卡片是否带 CTA、三种热点形态的具体尺寸参数、筛选分类的命名、引导线是否常显、HUD 暴露哪些开关，由实现阶段按手感与篇幅统一决定，不在此过早钉死；但「零外部资源的图解底图 → 百分比坐标热点 → 点击 / 聚焦锚定弹层并边缘避让 → 分类筛选 + 顺序导览 → 数据驱动多场景、键盘与 reduced-motion、无 JS 信息不丢失」这条链路必须真实成立，不允许用纯 hover tooltip 拼图或依赖外部商品图冒充。

## 动态与交互

- **触发方式（指针 + 键盘双通道，移动端点按可用）**：
  - 桌面：指针移入或键盘聚焦热点给出预览反馈（放大 / 光环增强，可选浮出轻量标题），**点击 / 回车 / 空格才锁定打开详情卡**（hover 不独占信息，保证触屏与键盘等价可达）；点击舞台空白处、按 Esc 或点击另一热点即关闭 / 切换。
  - 移动端：热点点按直接打开信息卡；窄屏卡片以舞台底部通栏条 / 轻量弹层呈现，热区不小于移动端可点按尺寸，卡片不遮挡全部热点以便继续切换。
- **顺序导览**：「上一个 / 下一个」按钮（及键盘 ←/→ 在舞台聚焦区内）按当前筛选后的可见热点顺序循环，每次跳转自动聚焦并打开对应热点、播放轻量接管动效，进度读数 `n / N` 实时更新；让键盘用户像 guided-tour 一样逐点看完全图，但顺序由空间数据驱动、随时可跳出自由点选。
- **分类筛选**：chips（单选「全部」+ 各分类）即时过滤热点：隐藏项淡出、移出 Tab 序列与顺序导览计数，激活中的热点被筛掉时优雅关闭卡片；筛选组具备可识别的 ARIA 分组语义（如 radiogroup / tablist 模式之一），状态不仅以颜色表示。
- **场景切换（Micro-HUD）**：在「产品功能图解 / 园区平面导览」至少两套数据间切换，底图与全部热点、分类、卡片内容整体替换并回到初始态，展示同一组件的数据驱动复用。
- **视觉语言切换（Micro-HUD，默认折叠，`H`/`Esc` 切换、事件防穿透）**：脉冲光点 / 编号徽章 / 图标标记三种热点形态实时切换；开关脉冲涟漪、切换标签常显 / 仅激活显隐；实时显示当前场景、热点总数 / 可见数、激活索引与 reduced-motion 生效状态。
- **可访问性（一等路径）**：
  - 每个热点是真实 `<button>`，具备 `aria-expanded` / `aria-controls` 与可读 `aria-label`（名称 + 分类 + 序号）；信息卡由热点 `aria-controls` 关联，打开时焦点移入或卡片进入可感知顺序，关闭（Esc / 空白 / 切换）后**焦点归还原热点**；Tab 按空间或索引顺序可遍历全部可见热点，筛选隐藏的热点不可达。
  - 全部信息以与热点数据**同源的语义列表 / `<figure><figcaption>` 结构**存在于 DOM：无 JS 或辅助技术按文档流阅读时，图解与每个热点的标题、说明完整可读，热点按钮未增强时退化为页内锚点 / 静态标记，信息获取零损失；状态变化（打开、筛选、导览进度）以 `aria-live` 礼貌播报或非视觉可读方式传达，不逐帧刷屏。
  - `prefers-reduced-motion: reduce`（或 HUD 关闭动效）时停止脉冲涟漪与接管位移，卡片即时显隐，信息与操作完整保留；文字 / 控件对比度达 WCAG AA，焦点环清晰可见。
- **响应式与生命周期**：热点用百分比坐标天然随舞台缩放；窗口 resize / 横竖屏切换 / 场景切换后重新计算卡片定位与可见性，不错位、不溢出；iframe 销毁 / 案例切换时移除全部监听与临时节点，无后台动画（本案例无音频）。

## 核心亮点

1. **真实高频的生产级组件**：可购热点图、园区 / 展馆 / 楼层导览、产品功能图解、标注信息图都是可直接用于电商与营销网页的成熟形态（实用性 5 分）；库内 60 案例 + 在池 48 Ready 无一覆盖「图像 × 坐标热点 × 信息弹层 × 筛选导览」这一具体形态。
2. **完整的热点交互体系，而非单个气泡**：百分比坐标锚定、四向碰撞避让弹层、分类筛选、顺序键盘导览、单开切换与焦点管理构成完整闭环，与 `tooltip`（无坐标 / 无体系）和 `guided-tour`（遮罩挖空、面向页面 DOM 的只读讲解）有本质区别。
3. **数据驱动的双场景展厅**：同一组件挂载「产品功能图解 + 园区导览」两套数据，加上脉冲光点 / 编号徽章 / 图标标记三种视觉语言实时切换，既是即用组件，也可横向对比热点设计语言，兼具教学与拷贝价值。
4. **零资源离线与工程鲁棒**：底图完全由内联 SVG 与 CSS 渐变 / 光影构造，零外部图片 / 字体 / 库，双击离线即可演示；百分比定位 + resize 重算保证任意视口下标记不漂移、卡片不溢出，窄屏有专门的底部卡片条形态。
5. **信息零损失的渐进增强**：热点数据同源渲染语义索引，无 JS 可静态读完全部信息；button 语义、序贯键盘导览、Esc 焦点归还、reduced-motion 与多重状态编码完整，符合项目铁律与 Anti-Slop 准则。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库、零图标库 / 字体库 / CDN、零外部图片 / 音频；图解底图必须由**内联 SVG + CSS 渐变 / 光影**构造（热点组件若依赖外部商品图则无法离线运行），图标一律内联 SVG；双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 热点位置以相对舞台宽 / 高的**百分比坐标**表达，随舞台等比缩放；信息卡定位基于热点实时位置计算并做舞台 / 视口**四向碰撞翻转避让**，窗口 resize、横竖屏切换与场景切换后重新求值，窄屏改走底部通栏卡片条，任何情况下不溢出视口、不永久遮住被激活热点。
- 信息卡的打开必须由 click / 键盘显式触发（hover 仅预览），同一时刻单开；每个热点是真实 `<button>` 并具备 `aria-expanded` / `aria-controls` / 可读 `aria-label`，Esc 与空白点击关闭后焦点归还；筛选隐藏的热点移出 Tab 与导览序列；顺序导览与筛选状态对辅助技术可感知。
- 全部热点的标题 / 说明必须以**同源语义结构（索引列表 / figure-figcaption）**存在于 DOM，无 JS 时图解与各点信息完整可读；`prefers-reduced-motion: reduce`（或 HUD 开关）下停止脉冲与位移动效，功能不缩水。
- 至少内置两套数据驱动场景（如产品功能图解 + 园区导览）与三种可实时切换的热点视觉语言（脉冲光点 / 编号徽章 / 图标标记）；动效仅写 transform / opacity / filter，卸载 / 切场景时清理监听与临时节点。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊（强制）；场景与视觉语言切换、脉冲 / 常显标签开关、热点计数与 reduced-motion 状态等通过默认折叠的 Micro-HUD 提供（`H`/`Esc`、事件防穿透）。
