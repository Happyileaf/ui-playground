- **更新时间**：2026-10-12

## 创意概述

一个把「密码输入」升级为可交互安全分析仪器的纯原生组件：用户输入或现场生成密码后，组件实时给出香农熵比特估算、离线暴力破解时间（多档攻击速率场景）、字符构成分解、常见弱口令/键盘连续模式命中提示，以及合规规则清单的逐条达成反馈。它解决普通注册页里「一个彩条 + 弱/中/强标签」信息密度过低、无法解释「为什么弱、弱在哪、怎么改」的体验问题，同时刻意以**全部计算在本地完成、不发任何网络请求**作为核心信任表达。

## 预期展示效果

- **构图与整体风格**：暗色「实验仪器」展台。中央为一张大号分析卡片：上方是带显隐切换的密码输入舱，下方是横向五段能级仪表（极弱 / 弱 / 一般 / 强 / 极强），仪表颜色随等级沿琥珀 → 翡翠光谱过渡但始终保持克制不刺眼；卡片下半区分为三块仪表板——熵读数（比特数 + 等份刻度弧）、破解时间读数（大字主场景 + 小字多速率对照）、构成分解条（字符类别等比堆叠条 + 图例）。右侧或下方为规则清单与诊断告警列表。
- **主要视觉元素**：
  - 五段式能级仪表，段间留细缝，激活段有缓慢呼吸辉光，能级跳变时仪表以一次轻微弹性过冲完成重排；
  - 熵比特用大号等宽数字呈现，数字变化走短促滚动插值；
  - 破解时间随密码长度呈指数级拉开（「瞬间 → 秒 → 年 → 世纪 → 宇宙年龄量级」），超长时读数切换为科学计数法等宽排版；
  - 构成分解堆叠条：小写 / 大写 / 数字 / 符号 / 其他各占一段，悬停高亮并浮出该类字符数；
  - 诊断告警以图标 + 一句话的列表呈现：命中内置弱口令字典、键盘连续路径（如 qwerty、1qaz）、重复连续字符、日期/年份片段、同字符长游程等，每条可点击定位说明。
- **层次、材质、光影与关键细节**：卡片为深色磨砂面板配 1px 半透明描边；仪表读数区用极细网格刻度底纹暗示「仪器」气质但不喧宾夺主；危险告警与正向达成项在色彩上明确分系（暖红/琥珀 vs 翡翠），且不仅依赖颜色——同时有图标与文案。空输入态展示引导性虚线轮廓与「输入或生成一个密码开始体检」的静默提示，杜绝无意义的初始告警噪声。

## 动态与交互

- **实时分析**：`input` 事件即时重算（可对极长输入做轻量节流），所有读数同步更新；能级变化时仪表段以 stagger 方式点亮/熄灭，破解时间数字做短插值滚动。
- **显隐切换**：眼睛按钮在 password / text 间切换，配套 `aria-pressed` 与焦点不丢失。
- **规则清单**：长度下限、大小写、数字、符号、非常见弱口令等条目逐条即时勾选/取消，达成时有轻柔的颜色与对勾描边动效；未达成项不标红惊吓，仅保持中性待办态（失焦或点击「提交体检」后才升级为错误语义，避免输入过程中的情绪噪音）。
- **安全生成器**：一个「生成强密码」操作，按当前可选项（长度滑杆、字符类别开关、排除歧义字符如 0/O/l/1）使用 `crypto.getRandomValues` 在本地生成密码，一键填入并自动切换为明文预览 2 秒左右再恢复遮蔽，旁边提供复制按钮（Clipboard API，带降级）。
- **攻击速率切换**：破解时间读数支持在「离线慢速哈希 / 离线快速哈希 / 大规模并行破解」几档每秒猜测次数之间切换，读数即时换算，让用户直观理解量级差异。
- **键盘与触控**：全部控件可 Tab 到达、开关可用空格/回车操作；触控目标不小于 44px；`prefers-reduced-motion` 下关闭呼吸辉光、过冲与数字滚动，直接呈现终值。
- **信任表达**：页面显著位置标注「全部分析仅在你的浏览器本地完成，不产生任何网络请求」；可在 Micro-HUD 中提供一个实时网络请求计数（恒为 0）的趣味佐证。

## 核心亮点

1. **从「彩条打分」到「可解释仪器」**：不是再实现一个规则彩条，而是熵比特、指数级破解时间、字符构成分解、具体模式诊断四层信息并列，回答「为什么弱、差在哪」。
2. **破解时间的量级叙事**：随输入长度实时跨越秒—年—世纪—宇宙年龄的指数刻度，是既有案例中没有的教育性、戏剧性读数体验。
3. **内置本地弱模式诊断**：弱口令字典命中、键盘连续路径、日期/重复游程等启发式检测给出可执行的修改建议，而非笼统的「太弱」。
4. **密码学正确的生成器**：使用 Web Crypto 的 CSPRNG 而非 `Math.random`，类别开关、歧义字符排除与本地零网络共同构成可信任的工具属性。
5. **隐私即设计**：全程本地计算 + 零请求明示，把安全主题的信任感做成视觉与交互的一部分。

## 实现约束（仅记录该案例必要的约束）

- 所有分析与生成必须 100% 在浏览器本地完成，禁止任何网络请求与第三方安全 API；生成随机数必须使用 `crypto.getRandomValues`（拒绝 `Math.random`）。
- 内置弱口令/键盘模式数据以小型常量数组内嵌（保持零 CDN、双击离线可用），体积克制，不追求完整字典。
- 熵估算需明确为基于字符集与香农信息熵的启发式近似，UI 文案不得宣称精确安全保证；破解时间为基于可选每秒猜测速率的数学换算展示，需在界面上以小字注明假设。
- 遵守统一 HUD 规范（右上角点阵色 Title 胶囊，Micro-HUD 默认折叠、H/Esc 开关、事件防穿透）与暗色 Anti-Slop 审美。
- 复制能力走 Clipboard API 并提供非安全上下文下降级（如选中文本提示）；满足 WCAG AA 对比度，告警不仅以颜色区分。
