## 创意概述

Emoji Picker 是评论区、即时通讯、邮件、工单、富文本编辑器与社区发帖框里的高频刚需控件：用户点击输入框旁的笑脸按钮，一块浮层在触发钮附近展开，按分类浏览、用关键词秒搜、选中后表情精确插入到光标位置——而这一切在 GitHub、Slack、Linear、飞书等产品中几乎是肌肉记忆式的存在。全仓 60 个已注册案例中，浮层与选择类原语已相当齐全（`combo-box` 可搜索下拉、`color-picker` 取色器、`context-menu` 右键菜单、`tooltip` / `mega-menu` / `notification-center` 边缘避让浮层），但**没有一个面向富文本输入场景、以「分类网格 + 搜索 + 光标处插入」为核心的可复用 Emoji Picker 组件**；全仓唯一的 Emoji 形态是活动池 IDEA-008（实时对话工作台页面）输入区里一个“少量常用 Emoji”的内嵌小面板，且它只是整页 IM 拟真中的局部手段，不是可独立复用的选择器。本案例做一个纯原生、零依赖、双击即用的**生产级表情选择器**：触发按钮唤起毛玻璃浮层面板，面板内含搜索框、分类标签栏（与网格滚动双向联动）、精选常用、最近使用（localStorage 持久化）、肤色修饰选择，以及 Unicode 字符表情网格（零图片、零字体文件、零 CDN）；选中表情在**保存并还原的光标位置**插入 textarea / 输入框，字符计数实时联动。组件具备完整键盘漫游（roving tabindex 网格、↑↓←→/Home/End/PageUp/PageDown、搜索态回车插入首个结果、Esc 关闭归还焦点）、ARIA grid 语义与播报、视口边缘碰撞翻转、`prefers-reduced-motion` 降级。它可直接用于任何真实网页的评论 / 聊天 / 发帖输入区，是技术域 1「现代高可访问性 UI 组件」与技术域 5「按钮与表单交互」交叉处一个覆盖面空白、实用性直达生产的组件。

## 预期展示效果

- **构图与整体风格**：
  - 延续项目统一深色质感，视觉主体是一个**社论 / 社区评论框演示场景**：页面中部一张内容卡片（一段纯 CSS / 内联 SVG 构造的帖文或话题占位，零外部图片），卡片底部是评论输入区——多行 textarea、字数统计、左下角一枚圆形笑脸触发按钮、右下角发送 / 提交按钮（仅演示插入与点亮逻辑，不发请求）。整体留白克制，不铺满屏控件。
  - 点击笑脸后，一块**毛玻璃浮层面板**在触发钮上方弹出（空间不足时自动翻转到下方 / 平移到视口内）：面板自上而下为「搜索框行 → 肤色选择与预览行 → 表情网格（带分区）→ 底部分类标签栏」，也可将分类栏置于顶部，关键是层级清晰、滚动区域只有网格本身，搜索与分类固定不滚走。
  - 面板为圆角矩形浮层，投影柔和、边缘有极细高光描边；网格是规则的正方形单元矩阵，表情以系统字体原生渲染（Unicode 字符），不使用任何图片 / 雪碧图 / 自定义字体。
  - 右上角为统一点阵色 Title 胶囊（遵循 HUD 规范：毛玻璃胶囊 + 固定主题色呼吸点，指示灯颜色不随面板状态联动）。组件自身即交互主体，不需要额外的 Micro-HUD 调参面板。
  - 窄屏（手机视口）下面板宽度收敛为接近输入区宽度、最大高度受限，网格保持可触达尺寸（单元不小于典型触控热区），页面其余部分不被误滚动。
- **主要视觉元素**：
  - **表情网格（核心视觉）**：每格一个 emoji 字符按钮，默认状态安静整齐；悬停 / 聚焦时该格轻微放大并浮起、底色提亮，相邻格不位移（用 transform 放大而非改变布局尺寸），顶部浮出极小的名称 tooltip；按下有轻微回弹。网格按分区组织（如笑脸与情绪 / 手势与人 / 动物自然 / 食物饮料 / 活动 / 旅行地点 / 物体 / 符号 / 旗帜，具体分区以数据集为准），每区有小号粘性分区标题。
  - **分类标签栏**：一排仅含图标（内联 SVG，不用 emoji 当图标以免递归）的分类按钮，当前分区以滑动 / 高亮胶囊指示；网格滚动时指示胶囊随分区切换，点击分类则网格平滑 / 即时滚动到对应分区，双向联动。
  - **搜索态**：搜索框聚焦后输入关键词（中文别名或英文名称均可命中），网格切换为扁平的搜索结果列表并高亮命中单元；无结果时给出明确空状态（图标 + 文案 + “清除搜索”），不显示空白面板。
  - **最近使用与精选**：首次使用前无“最近”分区；插入过表情后，下次打开顶部出现“最近使用”行（去重、有上限），无记录时自然不渲染该行，不留空位。
  - **肤色修饰**：预览行提供 Fitzpatrick 六档肤色小圆点（含默认黄手档），选择后所有支持肤色修饰的表情（如手势类）在网格与插入时均使用所选肤色；当前档有明确选中态。
  - **浮层动效**：打开时面板从触发钮附近做一次短促的 scale + fade + 轻微位移入场（带阻尼感、约 200ms 内结束），关闭反向收敛；遮罩不使用全屏压暗（避免打断评论场景），仅以浮层投影与描边确立层级。
- **层次、材质、光影与关键细节**：
  - 材质关键词：**深色磨砂玻璃浮层 + 细腻网格 + 柔和内聚投影**。面板用半透明深色底 + `backdrop-filter` 模糊（与仓库既有 tooltip / context-menu 语言一致），边框是低透明度亮线而非硬黑边；投影短而柔，让面板“贴”在输入区上方。
  - 反 AI Slop 细节：表情大小、网格间距与分区标题构成严谨的模数节奏，不使用彩虹渐变描边、不堆叠发光；悬停放大只服务于“指哪选哪”的确认感；搜索高亮、当前分类指示、选中肤色等状态**颜色 + 形态双编码**，不单靠颜色。
  - 表情本身的色彩完全来自系统 emoji 字形，面板容器保持中性深色调，避免与多彩字形互相抢戏；不支持彩色 emoji 的环境允许字形降级为单色文本，组件结构与功能不崩。
  - 遵循 `prefers-reduced-motion`：偏好减弱时取消 scale / 位移入场、悬停放大与平滑滚动，面板即时显隐、分类跳转瞬时定位，插入、搜索、键盘操作全部保留。

## 动态与交互

- **唤起与定位**：点击笑脸按钮切换面板开合；打开时锚定触发钮，优先向上展开，并做视口碰撞检测（上方 / 左右空间不足时翻转或平移，始终完整落在视口内）；窗口滚动与尺寸变化时实时重定位。面板打开期间点击面板外部、按 Esc 或再次点击触发钮即关闭；外点不得把点击误传给底层内容（事件防穿透）。
- **光标位置保存与插入（核心机制）**：面板打开与焦点移入搜索框会使 textarea 失焦，因此组件必须在打开瞬间及输入区失焦前保存选区（selectionStart / selectionEnd）；选中表情时还原选区并在光标处插入字符（等价于 `setRangeText` 的效果），插入后光标落在新表情之后，并同步更新字数统计与发送按钮点亮态；用户也可以先在输入框中点好位置再打开面板。面板关闭后焦点归还触发钮或输入区（以打开前焦点来源为准）。
- **分类与滚动联动**：网格内滚动到某分区时，分类栏激活态通过分区观察（如 IntersectionObserver 或带节流的滚动计算）切换；点击分类按钮滚动到对应分区并同步激活态。搜索态下分类栏暂时收起或禁用，清除搜索恢复分区浏览。
- **搜索**：搜索框输入即时过滤，精选一份规模适中（数百个量级）的精选 emoji 数据集，每个字符带中文别名与英文名称关键词（数据内嵌于 JS，零网络请求）；结果为空有空状态；回车在有结果时插入第一个结果并可保持面板继续输入，Esc 清空 / 退出搜索；搜索结果数通过视觉隐藏的 `aria-live` 区域克制播报。
- **最近使用与肤色**：每次插入将该表情写入“最近使用”（去重、固定上限、最前展示），通过 localStorage 持久化；file:// 或存储不可用时 try/catch 静默降级为仅本次会话内存记录，不报错。肤色档全局生效，对支持修饰符的表情以 Unicode 肤色修饰 / ZWJ 序列生成，不支持的表情保持原样；不支持肤色修饰序列的环境优雅降级。
- **键盘与可访问性（硬性）**：
  - 触发钮为真正的 `<button>`，有 `aria-expanded` 与可访问名称（“选择表情”）；面板打开后焦点进入搜索框（或上次停留的网格单元）。
  - 面板内 Tab 序在「搜索框 → 肤色选择 → 分类栏 → 表情网格」间有序移动；网格采用 roving tabindex：只有当前单元在 Tab 序列中，↑↓←→ 在矩阵内漫游（自动跨行），Home/End 到行首行尾、PageUp/PageDown 或直接到首 / 末单元（具体绑定以实现为准，但必须完整可达），Enter / Space 插入当前表情；搜索态 ↑↓ 选择结果、回车插入。
  - 每个表情单元有以中文名称构成的 `aria-label`（如“喜极而泣”），网格具备 `role="grid"` / `gridcell`（或经验证等价的 listbox 语义）与可访问名称；Esc 永远可关闭面板并归还焦点；所有可聚焦元素有清晰可见的 focus-visible 焦点环。
- **移动端触控**：单指点击唤起、滚动浏览、点选插入；网格单元触控热区足够大，面板内部滚动与页面滚动隔离（面板打开时不引发背景长页面误滚）；触屏外点关闭。
- **生命周期**：iframe 卸载 / 面板关闭时移除全部监听与浮动节点、解除观察器；无持续 rAF（重定位仅在滚动 / resize / 开合时发生）。

## 核心亮点

1. **填补全仓「面向文本输入的 Emoji 选择器」空白，实用性直达生产**：60 个历史案例与活动池 IDEA-001~018 中无任何可复用表情选择器（唯一沾边的是 IDEA-008 页面内少量常用 emoji 的内嵌小面板）。Emoji Picker 是评论、IM、邮件、编辑器的标配组件，实用性 5/5，成品可直接嵌入真实网页输入区。
2. **有真实工程深度的交互细节**：焦点移入浮层后仍能把表情插入 textarea 的**原光标位置**（失焦前保存选区、插入时还原）、分类与网格滚动双向联动、中文别名即时搜索、Fitzpatrick 肤色修饰 / ZWJ 序列生成、localStorage 最近使用（含 file:// 降级）——这些是“能用的选择器”与“玩具面板”的分水岭。
3. **完整的高可访问性模型**：roving tabindex 网格漫游、矩阵方向键跨行、搜索态回车插入、ARIA grid 语义与逐格中文名称、aria-live 结果播报、Esc / 外点关闭、焦点来源感知与归还、可见焦点环、颜色 + 形态双编码状态、减弱动效完整降级，达到可直接交付的无障碍水准。
4. **零依赖离线与稳健浮层**：精选 emoji 以 Unicode 字符 + 内嵌关键词数据呈现，零图片、零字体文件、零 CDN、零网络请求；浮层优先利用浏览器顶层呈现能力（支持时使用 Popover API 等原生 top-layer 机制），不支持时降级为锚定定位 + 碰撞翻转，任何现代浏览器双击 index.html 均为完整作品。

  - **IDEA-004 标签输入（Tags Input，Ready）**：同属输入区增强组件，但它处理多值芯片的录入 / 退格 / 去重，不涉及表情网格、浮层与光标插入。

  - 活动池其余 Ready 项（日期 / 轮播 / Toast / 步骤 / FAB / 液态按钮 / 对话工作台 / SVG 图表 / 级联 / 评分 / 分页 / 时钟表盘 / 开关合集 / 视图转场 / 灯箱 / 贝塞尔工坊 / 翻页倒计时）均无表情网格或文本插入选择器语义。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生零 CDN、零框架、零库，双击 index.html 独立离线运行（通用项目铁律，不重复）。
- Emoji 一律以 **Unicode 文本字符**由系统字体渲染，不引入图片、雪碧图、自定义字体或任何网络资源；精选数据集（数百个量级，含中文别名与英文名称关键词）以内嵌 JS 数据提供，体积可控；分类图标使用内联 SVG，不用 emoji 充当分类图标。
- 肤色修饰使用标准 Unicode 肤色修饰符 / ZWJ 序列生成，对不支持修饰的字符与环境优雅降级；“最近使用”用 localStorage 持久化但必须 try/catch 包裹，file:// 或隐私模式不可用时降级为内存记录，绝不抛错阻断插入。
- 插入语义必须正确处理可编辑控件失焦：打开面板与焦点离开输入区前保存选区，插入时还原到原光标位置（textarea 用 selectionStart / selectionEnd / setRangeText 类能力），插入后光标位于新字符之后并联动字数统计；演示场景至少完整覆盖 textarea。
- 浮层定位：支持时优先用原生 Popover API 等 top-layer 能力，不支持时降级为固定 / 绝对定位 + 视口碰撞翻转；打开时锚定触发钮，滚动 / resize 实时重定位；Esc、外点、再次点击触发钮关闭，事件防穿透；不使用全屏压暗遮罩。
- 可访问性为硬性要求：`aria-expanded` 触发钮、grid / gridcell（或经验证等价）语义与逐格中文 `aria-label`、roving tabindex 矩阵漫游（方向键跨行 + Home/End 等）、搜索框与结果数 aria-live 播报、完整可见焦点环、关闭后焦点归还、状态颜色 + 形态双编码；`prefers-reduced-motion` 下取消入场 / 悬停 / 平滑滚动但功能完整。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊（指示灯颜色不联动）；组件自身即主交互，不另设参数 Micro-HUD。
- 响应式：窄屏面板宽度与最大高度受限、网格触控热区达标、面板滚动与背景页面滚动隔离；iframe 卸载时移除监听与浮层节点、断开观察器，无持续 rAF。
