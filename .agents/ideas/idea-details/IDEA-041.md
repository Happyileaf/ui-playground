## 创意概述

甘特图是项目管理、研发排期、工程交付与资源计划类 SaaS 中最高频、最不可替代的调度界面：左侧是工作分解结构（WBS）任务清单，右侧是一条连续的日期时间轴，每个任务是一根「位置=起止日期、长度=工期」的条形，任务之间用带箭头的有向连线表达前置依赖，一条「今天」线把计划与现实对齐。它与普通图表的本质区别是：图表回答「数据是多少」（只读呈现），甘特图回答「安排在何时、先后约束是否成立」——它是一个**运行着调度约束的可编辑时间模型**：拖一根条形改变排期、拉两端手柄改工期、依赖关系实时校验（前置任务没结束，后置不能提前开始），非法操作当场被拒绝并给出自动顺延建议。

本案例做一个纯原生、零依赖、零第三方库（无图表库、无日期库）、零 CDN、零外部图片/字体、双击离线即用的**交互式甘特排期图**：一张深色后台工作台风格的拟真项目排期面板，预置一个跨数周、含若干分组与里程碑、带完成到开始（FS）依赖关系的演示项目（约十余项任务，覆盖未开始/进行中/已完成/逾期四种状态）。左栏为任务表面板（分组泳道、任务名、负责人、进度、状态胶囊、完成勾选），右栏为日期时间轴（日/周/月三档缩放、周末与非工作日阴影带、月份/周次/日期分层表头、今天线）；任务条可指针拖拽按网格吸附移动、两端手柄调整工期、条内进度填充联动、里程碑为不可拉伸的菱形；依赖关系以 SVG 正交折线 + 箭头绘制，悬停连线高亮其两端任务，并支持从任务条连接锚点拖出新依赖、选中后删除；拖拽产生的依赖冲突以红描边 + 抖动 + 行内警告与「自动顺延」建议表达，释放后非法修改回退、绝不写入脏数据；全部结构性编辑进入撤销/重做栈。可访问性是一等公民：语义化 ARIA grid（row/column header、gridcell），方向键在任务行与日期格间漫游，选中任务条后 ←/→ 按吸附步长推移日期、Shift+←/→ 增减工期、Enter 打开详情弹层，aria-live 播报每次排期变更；窄屏下左栏可收拢、时间轴横向滚动，触控拖拽与桌面完全等价。

当前案例库 60 个已注册案例中，数据表达类仅有 `animated-charts`（在池 IDEA-009：环形/柱状/折线的只读统计图，描边入场与悬停读数）、`contribution-graph`（离散热力矩阵）、`count-up`（单数字动效）、`resizable-table`（行列表格）、`virtual-list`（长列表窗口化）与 `kanban-board`（四列离散状态看板），**没有任何基于连续日期坐标、以条形长度编码工期、并带依赖约束校验的排期/调度类组件**；全仓与活动池检索 `gantt / 甘特 / 排期 / 工期 / milestone / 里程碑 / roadmap / 依赖 / dependency / schedule`，无同主题案例（"排期"一词仅出现在其他 Idea 详情的散文叙述中）。这是项目管理类产品最日常的核心界面，实用性 5 分。

## 预期展示效果

- **构图与整体风格**：
  - 一张拟真的「项目排期工作台」面板：顶部为极简工具栏（项目名与日期范围摘要、日/周/月缩放切换、撤销/重做、重置演示数据、依赖线/周末带/今天线显隐）；其下主体分两栏——**左栏任务表**（固定宽度，分组泳道头可折叠，每行：完成勾选、任务名、负责人、进度、状态胶囊）与**右栏时间轴**（外层：分层日期表头 sticky；下层：与左栏逐行严格对齐的条形轨道），两栏共享垂直滚动，时间轴可独立横向滚动且表头同步；面板像真实 PM 工具的一个页面，而非孤立 demo。
  - 延续项目深色后台美学（与 kanban-board、resizable-table、virtual-list 气质协调）：近黑中性底、极淡行分隔线与网格竖线、半透明深色卡片与细描边；任务条用一组有明度层次的同调性强调色按分组或状态区分（不做满屏彩虹），今天线是全场唯一高对比强调色的细虚线，周末/非工作日为极淡的纵向阴影带，逾期态用描边/纹理 + 警示图标双重编码而非只靠变红。
  - 桌面端左右双栏并排，宽屏信息密度接近真实工具；平板左栏收窄、右栏横向滑动；手机上左栏可整体收拢为一条可展开的窄轨（或抽屉），时间轴保留完整缩放与拖拽能力，触控热区（条形、两端手柄、连接锚点、勾选框）不小于触控标准；任何宽度下左右行高严格一致、标签不溢出、连线不穿帮。
- **主要视觉元素**：
  - **时间轴与网格**：日期表头随缩放档切换分层标签（月：月份跨度；周：周次/周起止；日：星期+日期，周末标签弱化）；纵向网格线极淡，周末与节假日以阴影带区分；一条贯穿轨道区的「今天」虚线 + 顶部小三角标记，今天线位置随真实日期与横向滚动正确计算。
  - **任务条（核心）**：圆角矩形，横向位置与长度由起止日期经统一的「日期↔像素」映射得出；条内左侧为任务名（空间允许时），右侧或底部有按比例的进度填充（进行中可见一道柔和高光），完成态整体降饱和/打勾语义；**里程碑**为菱形标记（零工期、不可拖手柄）；逾期任务有描边/细纹理 + 小图标警示；条的两端是可拖拽的调期手柄，悬停/聚焦时显形并改变光标，条身中部是移动热区；选中态有明确描边与焦点环（不仅靠颜色）。
  - **依赖连线**：SVG 层覆盖轨道区，在前置任务条右端锚点与后置任务条左端锚点之间画正交折线（横-竖-横）+ 箭头，默认极细克制灰；非法/冲突的依赖以警示色提示；连线在条形移动、缩放、折叠泳道、缩放档切换时实时重算，始终吸附锚点不漂移；悬停或键盘聚焦一条连线时加粗高亮并联动高亮两端任务。
  - **左栏任务表**：可折叠分组泳道头（折叠/展开时右栏对应条形同步显隐并有克制的高度过渡）、负责人以纯 CSS 首字母圆角色块表示（零头像图片）、进度以细迷你条 + 百分比文字、状态为小胶囊（文案 + 形状双重编码）；任务名支持点击进入行内编辑；完成勾选与条形状态双向联动。
  - **详情弹层与冲突提示**：点击/Enter 任务条弹出锚定式详情层（名称、起止日期、按工作日计算的工期、负责人、进度、前置任务列表，内含日期步进控件）；拖拽触发依赖冲突时，条形红描边轻抖、跟随指针出现日期预览气泡，释放后回位并在该行显示一句具体警告与「自动顺延到合法日期」按钮。
- **层次、材质、光影与关键细节**：
  - 视觉四层：时间轴网格/周末带（最底）→ 依赖连线 SVG 层 → 任务条/里程碑（核心操作对象）→ 表头/今天线/工具栏/弹层/HUD（固定信息层）；层级靠明度、描边与投影明确区隔，条形有极轻投影使其浮于网格之上但不过度拟物。
  - **日期映射与调度状态必须确定性、单一数据源**：所有条形位置/长度、连线折点、今天线、周末带均由同一份内存数据模型 + 同一个日期↔像素映射函数计算渲染；任何一次移动/缩放/依赖变更先在模型上校验合法性，合法才提交并重渲染，非法回退——同一数据状态刷新后永远呈现同一画面，不允许拖拽预览态泄漏为真实态、不允许累积 transform 越拖越偏。
  - 拖拽反馈克制而精确：移动中条形跟手（rAF 同帧读写、只改 transform/位置，落位才写数据），按当前吸附粒度（天/半天）显示对齐参考线与「M/D ～ M/D（n 个工作日）」气泡；冲突不是粗暴弹窗打断，而是条形本体的红描边/抖动 + 行内文案 + 一键顺延建议；撤销/重做保证任何探索都可回退。
  - 工期与工作日用原生 Date 计算（无日期库），正确处理月末、跨年与周末跳过；进度、逾期、依赖等信息不仅靠颜色（图标、纹理、文案、形状共同编码）；右上角统一点阵色 Title 胶囊为强制项。

> 设计文档约束最终体验与设计意图；演示项目的具体任务文案、数量（约十余项）、分组方式、配色具体色值、条形高度/行高/列宽像素、缩放档每档的具体像素粒度、缓动曲线与 HUD 暴露参数，由实现阶段按真实感与手感统一决定，不在此过早钉死；但「左表右轴双栏对齐 + 日期↔像素统一映射 + 条形可拖拽移动/两端改工期 + FS 依赖连线实时校验（非法不落数据）+ 日/周/月缩放重算 + 今天线/周末带/里程碑 + 全键盘 ARIA grid 操作 + 撤销重做 + reduced-motion 与触控等价」这条链路必须真实成立，不允许用静态图片/纯 CSS 摆拍假甘特、不允许拖拽与数据模型脱钩、也不允许引入图表库/日期库/框架或任何外部资源。

## 动态与交互

- **触发方式（指针拖拽主导，键盘完全等价，非自动播放）**：
  - **指针（鼠标/触控/手写笔统一 Pointer Events + setPointerCapture）**：在任务条中部按下拖拽=按时间网格吸附移动排期；在两端手柄按下拖拽=调整起止（工期）；里程碑只可移动不可伸缩；拖拽中显示日期/工作日气泡与对齐参考线，依赖冲突实时判定并给红描边反馈；在空白轨道区的滑动/触控板滚动归时间轴滚动条所有，不误触发任务拖拽（仅在条形热区按下才捕获）；悬停或聚焦连线高亮链路两端；从任务条右端连接锚点拖向另一任务条=新增 FS 依赖（命中合法目标高亮、非法目标提示）。
  - **键盘（ARIA grid）**：容器具备 grid 语义（rowheader/columnheader/gridcell），方向键在任务行与时间轴单元格间移动焦点，Home/End 跳到行首行尾、PageUp/PageDown 横向翻屏；焦点落在任务条上时 ←/→ 以当前缩放吸附步长（天/周/月）前后推移整个任务，Shift+←/→ 缩短/延长工期一天（或一个吸附步长），Enter/Space 打开详情弹层（弹层内焦点循环、Esc 关闭还焦点），Delete 在连线获焦时删除该依赖、在任务获焦时不做破坏性删除（删除依赖以外的破坏性操作需二次确认或不提供）；Ctrl+Z / Ctrl+Shift+Z（或 Ctrl+Y）撤销/重做；焦点环始终清晰可见。
  - **点击**：任务名行内编辑；完成勾选切换完成态（进度与条形状态联动）；泳道头折叠/展开；工具栏切换缩放档与图层显隐；详情弹层的日期步进控件可精确改期；「自动顺延」按钮接受调度建议；「重置演示数据」恢复初始项目。
- **调度引擎（核心逻辑）**：
  - 单一内存数据模型（分组、任务：id/名称/起止/进度/负责人/状态/前置 id 列表、里程碑标记）；统一日期↔像素映射函数驱动全部渲染（条形、连线、今天线、周末带、表头）；工作日工期由原生 Date 计算（跳过周末，正确处理月末/跨年）。
  - 每次拖拽/键盘改期先在模型副本上做合法性校验：后置任务不得早于其全部前置的结束（FS 约束），非法时预览态给冲突反馈、释放则放弃变更回退原位，并提供「自动顺延到最早合法日期」；合法变更提交、重渲染并压入撤销栈；aria-live 区域以一句简洁文案播报（如「设计评审已移动到 10 月 21 日，工期 3 个工作日」）。
  - 依赖增删、完成态切换、日期步进同样走校验 → 提交 → 入栈；撤销/重做以结构化操作快照实现，撤销后画面与焦点正确恢复；重置不经过撤销栈直接恢复初始模型。
  - 缩放档切换（日/周/月）重算列宽、表头分层与全部几何，正在进行的操作不残留错位；横向滚动时 sticky 表头与今天线标记同步，左右两栏垂直滚动严格同步。
- **控制与可配置项（Micro-HUD 默认折叠，`H`/`Esc` 切换、事件防穿透）**：当前缩放档与吸附粒度、依赖线/周末带/今天线显隐、冲突检测开关、reduced-motion 生效状态、任务/依赖/里程碑计数；右上角统一点阵色 Title 胶囊为强制项。
- **可访问性（一等路径）**：
  - 语义结构：左表右轴共同构成一张可被屏幕阅读器理解的 grid——行含任务名称、负责人、起止、工期、进度、状态与前置关系等可读文本信息（图形不承担唯一信息）；连线/依赖关系在任务的文本描述中体现；所有改期结果经 aria-live（polite）播报；状态、逾期、选中均以图标/纹理/文案/形状 + 颜色多重编码；文字对比度达 WCAG AA。
  - `prefers-reduced-motion: reduce`：关闭拖拽跟手中的过渡、冲突抖动、泳道折叠与重排动画，几何位置直接更新（功能与校验一个不少）；入场不做装饰动画。
- **移动端与触控**：条形、手柄、锚点、勾选与滚动条均具备充分触控热区；条形拖拽与页面滚动手势按「按下起点是否在热区」明确区分，不抢页面滚动；窄屏左栏可收拢、右栏保留横向滚动与全部操作；横竖屏与容器尺寸变化后重算映射，不错位；不支持 pointer capture 的旧环境提供等价鼠标降级。
- **生命周期**：案例卸载（iframe 销毁）/页面隐藏时取消 rAF、释放 Pointer Capture、移除全部监听与 aria-live 残留；重新进入从干净初始状态开始；不产生持续后台动画，本案例无音频。

## 核心亮点

1. **补齐全仓最高频的调度类界面空白**：甘特图是 PM/研发/工程类 SaaS 的核心工作台组件（实用性 5 分），库内 60 案例与在池 40 个 Ready 无一覆盖；它不是又一种统计图，而是「连续日期坐标 + 条形长度编码工期 + FS 依赖约束实时求解」的可编辑时间模型，落地即可用于真实排期、 roadmap、资源计划页面。
2. **真正运行约束的拖拽调度，而非静态摆拍**：移动/伸缩/依赖增删全部基于单一数据模型与统一日期↔像素映射，先校验后提交、非法不落脏数据、释放回退 + 一键自动顺延、撤销/重做可回溯；拖拽预览态与提交态严格分离，任何刷新与正反向操作后画面与数据自洽。
3. **SVG 依赖图 × 时间网格的双层视觉**：正交折线依赖连线在任何移动、缩放、折叠下实时重算并始终吸附锚点，悬停/聚焦连线联动高亮两端任务；今天线、周末带、里程碑菱形、进度填充与逾期双重编码构成信息密度高但不嘈杂的专业后台观感，保持 Anti-Slop 克制配色。
4. **生产级全键盘可访问性**：ARIA grid 行/列语义、方向键漫游、快捷键推移/伸缩任务、Enter 详情层、连线删除、aria-live 排期播报、状态多重编码、AA 对比、可见焦点，配日/周/月三档缩放与触控等价交互，达到真实 PM 工具的完整度而非「能拖就行」的 demo。
5. **零依赖工程约束**：不引图表库、日期库与任何框架，工作日/月末/跨年计算、几何映射、约束校验全部原生实现；零外部图片字体（负责人用 CSS 首字母），双击离线完整可用，reduced-motion 下功能不降级。

  - 在池 **IDEA-032 可视化节点流编辑器（node-flow-editor）**：表面最像——都有「节点 + SVG 连线 + 拖拽」。但节点画布是**自由二维空间的拓扑编辑器**：节点位置任意（自由 x/y），连线表达无时间语义的任意工作流边，落点自由、无刻度无吸附约束；本案例是**结构化时间坐标系**：y 轴是与左表一一绑定的任务行、x 轴是带工作日/周末刻度的日期，条形的位置与长度编码排期与工期，连线是参与合法性校验的 FS 有向调度约束（后置不得早于前置结束），拖拽有网格吸附、步长快捷键与约束拒绝/自动顺延。数据模型（自由图 vs 时间调度）、视觉（自由贝塞尔画布 vs 行列对齐时间轴）与交互目标（编排流程 vs 求解排期）均不同。
  - `kanban-board`（拖拽看板）：同属项目管理语境与拖拽交互，但其拖拽是在**四个离散状态列**间分类重排卡片（Pointer Capture + 占位符 + 键盘 Alt+方向键），没有时间维度、没有时长概念、没有坐标映射与依赖图；本案例的核心变量是连续日期与工期长度，交互语义完全不同。
  - `resizable-table` / `virtual-list`（数据表 / 虚拟滚动）：左栏任务表在表格观感上邻近，但二者分别解决列宽/排序/过滤与万级行窗口化渲染，均无右侧图形时间轴、条形几何与调度逻辑；本案例的难点恰在左右双栏逐行对齐与垂直滚动同步之上的图形编辑层。
  - `vertical-timeline`（垂直时间线）：含「时间线」字样，但是按时间排列的**展示性里程碑事件卡**（左右交替、IO 一次性揭示、脊柱填充），无任务条、无工期长度、不可编辑、无依赖，方向（纵向叙事）与用途（只读回顾）均不同。
  - 在池 **IDEA-028 行内原地编辑（inline-edit）**：本案例任务名行内编辑复用同类微交互思想，但那只是左栏的一个从属细节；IDEA-028 是通用单字段查看/编辑态切换组件，无时间轴与调度模型。
  - 在池 **IDEA-001 日期选择器 / IDEA-013 环形时间选择器 / IDEA-010 级联选择器**：都是表单内的日期/时间/层级**选择控件**，服务单个字段录入；本案例是多任务、多依赖的排期视图，日期计算服务全局约束而非单值选择。
  - `range-slider` / `split-pane` / `image-cropper`：同有「指针映射几何」手法，但分别服务区间取值、分栏比例与图片裁剪，不表达时间数据、无依赖与工作日语义。
  - 其余注册案例与在池 IDEA 逐一核对：`contribution-graph`（离散热力）、`count-up`（数字动效）、IDEA-033 骨架屏、IDEA-012 分页器、IDEA-038 Bento 网格等均无排期/时间调度主题；检索确认无历史（含已删除）`gantt-chart` id 或物理目录冲突，rejected.md/completed.md 为空，无淘汰或完成记录；"排期"关键词仅命中 IDEA-014/015 等详情中的散文用词（如"已排期日期、轮播…"），不构成同主题。
- **差异说明**：核心创意是「**左表右轴双栏对齐的项目排期工作台：任务条在连续日期坐标上以位置与长度编码起止/工期，FS 依赖以 SVG 正交连线表达并参与实时约束校验，拖拽/手柄/快捷键改期先校验后提交、非法回退并可自动顺延，配合日/周/月缩放、今天线、周末带、里程碑、撤销重做与全键盘 ARIA grid 操作的零依赖可编辑时间模型**」。差异同时体现在：核心创意（可编辑调度模型 vs 只读统计图/自由节点图/离散看板列）、视觉表达（行列对齐的时间轴 × 条形进度 × 依赖折线 × 今天线/周末带）、交互方式（吸附拖拽 + 两端改工期 + 约束拒绝/顺延 + 键盘步长改期 + 撤销栈）与整体表现（PM 类 SaaS 核心工作台）；不属于换颜色、文案或微调参数类重复。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库（明确禁止图表库与 date-fns/moment 等日期库）、零图标库/图标字体、零 CDN、零外部图片/字体/音频；负责人头像用 CSS 首字母色块，全部图标内联 SVG；日期与工作日（跳过周末、月末/跨年边界）用原生 Date 计算；双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 必须以单一内存数据模型 + 统一「日期↔像素」映射驱动全部渲染（条形、连线、今天线、周末带、表头、对齐）；任何改期/依赖变更先在模型上做 FS 约束校验，合法才提交、非法回退且不写入脏数据；拖拽预览态与提交态分离，无累积 transform、无刷新后状态漂移；结构变更进入撤销/重做栈并可重置演示数据。
- 指针交互统一 Pointer Events + setPointerCapture，任务拖拽与页面/时间轴滚动手势按热区明确区分、不抢滚动；rAF 同帧读写、只更新 transform/几何属性；卸载/隐藏时取消 rAF、释放捕获并移除监听；本案例无音频。
- 必须具备 ARIA grid 语义（row/column header、gridcell）、方向键漫游与快捷键改期、可见焦点环、aria-live 变更播报、状态不仅靠颜色（图标/纹理/文案多重编码）与 WCAG AA 对比；`prefers-reduced-motion: reduce` 下仅去除运动表现、功能与校验完整保留。
- 视觉为克制深色后台工作台美学（同 kanban-board / resizable-table 气质），强调色按分组/状态有明度层次而非彩虹轮转；桌面/平板/手机自适应（左栏可收拢、右栏横向滚动、触控热区充分、双栏行高始终一致）。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊（强制）；缩放档/吸附粒度、依赖线/周末带/今天线显隐、冲突检测开关、reduced-motion 状态、任务计数等通过默认折叠的 Micro-HUD 提供（`H`/`Esc`、事件防穿透）。
