## 创意概述

注册、改密、设备加密等场景里，「再输入一个密码」几乎是用户每天都会遇到的表单动作，但绝大多数页面对密码质量的反馈只有一句冰冷的红色「密码太短」或四条永远差一格的彩色小方块——用户既不知道**为什么**弱、弱到什么程度，也不知道自己离「够用」还差哪一步。本案例做一个纯原生的**密码强度工坊**：以一张拟真的「创建账户 / 设置密码」表单卡承载，用户每敲一个字符，下方就实时给出三件事——**一条会生长、分段着色、带克制辉光的强度计量带**；**一个可读的等级标签与「离线破解大约需要多久」的生活化估算文案**（从「瞬时」到「数世纪」的直观时间尺度）；以及**一份逐条点亮、带对错状态的清单**（长度、大小写、数字、符号、避免常见弱口令 / 键盘连续串 / 重复字符）。

核心不是又一个正则校验器，而是把「字符多样性 → 熵（bits of entropy）→ 分级 → 人类可读的破解耗时」这条真实可解释的评估链路做成看得见、摸得着、玩得起来的微交互：输入过程中强度带随输入平滑生长与变色、清单逐条点亮、达成关键里程碑（如跨入「强」）时计量带给一次克制的脉冲庆祝；同时展示/隐藏密码、确认密码一致性、Caps Lock 提醒、输入框聚焦光影等真实注册表单该有的细节一个不少。全程纯前端本地估算，**不存储、不上报、不发起任何网络请求**，并在界面上明确告知用户「你的密码不会离开这台设备」，双击 `index.html` 断网即用。

当前案例库 60 个已注册案例中，表单输入类已有 `otp-input`（分段验证码）、`payment-card-input`（银行卡分组）、`combo-box`（可搜索选择）、`range-slider`、`tags input`（在池 IDEA-004）等，但**没有任何一个案例以「密码 / 凭据强度评估」为核心**；全仓检索 `password / strength / entropy / 密码 / 强度 / meter` 均无命中（payment-card-input 与 OTP 是格式化录入，不评估内容质量）。这是高频生产组件方向上一处干净的空白。

## 预期展示效果

- **构图与整体风格**：
  - 画面中央是一张克制的深色玻璃拟态「设置密码 / 创建账户」表单卡，宽度适合单列注册表单（桌面约一张窄卡，平板 / 手机自适应收边距），浮于带极微弱环境光（一抹低饱和径向光晕 + 细腻噪点/网格底）的深色背景之上，延续项目暗色、低饱和、拒绝蓝紫渐变堆砌的 Anti-Slop 审美。
  - 卡内自上而下为真实的注册语义结构：标题与一句副标题 → 邮箱（或账户名）字段（可预填示例，非重点）→ **密码字段（视觉主角）** → 密码可见性切换图标 → **强度计量带 + 等级标签 + 破解耗时文案** → **要求清单** → 确认密码字段（含一致 / 不一致反馈）→ 主提交按钮（强度不足时按钮文案/状态给出引导而非直接报错）。
  - 强度反馈区位于密码框正下方、在输入过程中自然展开（高度/透明度过渡），不产生生硬的布局跳动；整卡留白、字号层级、圆角与描边克制度对齐现有组件案例（如 modal / drawer / payment-card-input 的玻璃质感）。
  - 右上角按工作台 HUD 规范放置点阵色 Title 胶囊（固定于案例视口内）。
- **主要视觉元素**：
  - **强度计量带（Strength Meter）**：一条分段或连续的细轨道（可用 4–5 段分段条，也可用连续填充轨道，实现阶段择优），随输入长度/质量**平滑生长**；按等级分段着色，颜色不仅承担信息（同时配等级文字与图标），色板在「很弱→弱→一般→强→很强」之间做低饱和递进（如暖红警示 → 琥珀 → 青绿），到达最高档时给一次极克制的辉光，而非刺眼荧光。
  - **等级标签与破解耗时**：计量带旁/下方一行高对比文字给出等级（如「很弱 / 弱 / 一般 / 强 / 很强」），其下一行次要色小字给出生活化时间估算（「瞬时可破」「几分钟」「几天」「几年」「几个世纪」级别），并可附极简「约 N bit 熵」读数（在 Micro-HUD 或次级信息里，避免对普通用户造成负担）。
  - **要求清单（Checklist）**：一组带状态图标的条目（长度下限、同时含大小写、含数字、含符号、避开常见弱口令如 `password/123456/qwerty`、避开键盘连续串 `asdf/qwerty/1234`、避免过长重复字符如 `aaaa`），满足项的图标与文字做点亮 + 轻微到位动效（描边勾绘制 / 颜色与透明度过渡），未满足项保持中性灰，不逐项红字惊吓用户；清单随输入实时更新。
  - **确认密码一致性**：第二个密码框在两者都非空时给出「一致 ✓ / 不一致」的即时、克制反馈（图标 + 文字）。
  - **可见性切换与 Caps Lock 提示**：输入框右端的眼睛图标在「密文 / 明文」间切换；检测到 Caps Lock 开启时在字段下方出现一行小提示。
- **层次、材质、光影与关键细节**：
  - 视觉三层：深色环境背景（弱光晕 / 噪点）→ 玻璃表单卡（细描边、柔和投影、内层微光）→ 强度反馈前景（计量带辉光、清单点亮、里程碑脉冲）；聚焦的密码框有一圈很轻的 focus ring 光影引导视线。
  - 计量带生长使用 transform/宽度等合成友好属性 + 统一缓动，跟手但有一点点黏弹余韵；等级变化（尤其跨入更强档）时辉光与标签做一次短促、收敛的脉冲，不持续闪烁、不满屏特效。
  - 删除字符导致等级下降时，计量带与清单能正确「回落/熄灭」，证明评估是真实双向的，而非只增不减的假动画。
  - 空输入、仅长度够但全是常见弱口令、超长重复字符等边界都有准确而不夸张的反馈；弱态使用克制的暖色而非大面积红底，错误文案具体、可执行（告诉用户「再加什么」而不只是「不行」）。
  - 全程无外部图片 / 字体 / 图标库资源：状态图标（眼睛、勾、叉、锁/盾等）一律内联 SVG 构造。

> 设计文档约束最终体验与设计意图；熵估算的具体公式（字符集大小与长度的组合估算、对常见模式的惩罚）、分段阈值、破解耗时换算假设（每秒猜测次数的取值）、分段还是连续轨道、精确色值与尺寸由实现阶段按观感与合理性统一决定，不在此过早钉死；但「字符多样性/模式 → 熵 → 分级 → 可读耗时」这条可解释链路必须真实成立，不允许用与输入内容无关的伪随机或写死进度冒充评估。

## 动态与交互

- **触发方式（实时输入 + 指针 + 键盘统一）**：
  - 在密码字段 `input` 时实时（可带轻量防抖/直接同步）重算字符构成、常见模式与熵，更新计量带宽度/段色、等级标签、破解耗时文案、清单逐条状态与提交按钮可用性；增、删、粘贴、清空都即时正确响应。
  - 眼睛图标点击（pointerdown/click）或键盘聚焦后 Enter/Space 切换明文/密文（切换 `type` 与图标、`aria-pressed`/可访问名同步）；Tab 可顺序遍历邮箱、密码、可见性切换、确认密码、提交等全部控件。
- **表单级交互细节**：
  - 确认密码一致性在两框非空时实时比对；提交时若强度低于门槛或两次不一致，焦点移动到对应字段并给出具体、可访问的错误说明（不使用 `alert`）。
  - Caps Lock：通过 `getModifierState('CapsLock')`（支持时）在 keyup/keydown 上检测并提示，不支持的环境优雅降级（不报错、不阻塞）。
  - 密码管理器自动填充（浏览器 autofill）后强度应能正确刷新（监听 input/change，必要时兼容 autofill 场景）。
  - 达到/越过「强」门槛一次时给一次收敛的里程碑脉冲；用户可反复清空重填体验不同输入（`123456`、`Aa1!`、长口令短语、超长重复串等）观察反馈差异。
- **可访问性（一等路径）**：
  - 字段使用真实 `label`/`for` 关联与 `autocomplete`（如 `new-password` / `email`），强度计量用 `role="meter"`（或 `progressbar` 的合适语义）+ `aria-valuenow/min/max` 与可访问名，等级与破解耗时用 `aria-live="polite"` 礼貌播报（注意节流，避免逐字符刷屏：可在**等级变化时**播报而非每次按键）。
  - 清单每项满足/未满足状态同时用图标 + 文字表达，不仅靠颜色；错误信息关联到字段（`aria-describedby` / `aria-invalid`）。
  - 全键盘可达：Tab 顺序合理，Enter 提交，可见性切换按钮可聚焦可键盘触发；焦点样式清晰。
  - 尊重 `prefers-reduced-motion`：关闭/大幅减弱计量带辉光脉冲、清单到位动效与背景漂移，保留即时的颜色/文字/宽度等功能反馈（评估信息一条不少）。
- **隐私与离线（核心卖点之一）**：所有评估只在页面本地内存进行，不写 localStorage（避免留存密码）、不打印完整密码到控制台、不发起任何网络请求；界面明确标注「仅在本机实时估算，密码不会被保存或上传」；切换/卸载案例时清理引用与监听。
- **移动端触控**：单指点击眼睛/提交，触控热区充分；输入时页面不因反馈区展开而跳动（预留/过渡空间），视口窄时卡内信息纵向自然排布、不横向溢出；合理设置 `inputmode`/`autocomplete`，避免移动端不必要的缩放。
- **可选 Micro-HUD**（默认折叠，`H`/`Esc` 切换、事件防穿透）：展示当前估算熵 bit 数、字符集类别计数、命中的常见模式、假设的每秒猜测次数与对应耗时换算，并提供「减弱动效对照」「常见弱口令样例一键填入（仅演示）」等把玩项；非必需时至少保留右上角 Title 胶囊。任何演示样例填入都仅在本地输入框内，不做提交。

## 核心亮点

1. **补齐高频生产组件空白**：库内 60 个案例与在池 30 个 Ready Idea 中没有任何「密码/凭据质量评估」主题；注册/改密是真实网页最高频的表单动作之一，本组件可直接用于生产环境的注册、重置密码、设备加密等页面（实用性 5 分），且区别于已有的 OTP、银行卡号等「格式化录入」组件。
2. **可解释的真实评估链路而非装饰条**：把「字符构成（长度/大小写/数字/符号）+ 常见模式惩罚（弱口令字典、键盘连续串、重复字符）→ 熵 bits → 分级 → 人类可读破解耗时」完整打通，每一档反馈都对得上输入内容；增删字符双向实时更新，破解耗时用「瞬时/几分钟/几年/几个世纪」的生活化尺度，让用户真正理解强弱，而非看一个不知所云的进度条。
3. **表单微交互的质感合集**：强度带平滑生长与档位辉光脉冲、清单逐条点亮/熄灭、里程碑庆祝、聚焦光影、可见性切换、Caps Lock 提醒、确认密码一致性、提交引导——把一个常见表单做出克制而精致的高级感，是「微交互与光影动效（域 2）+ 按钮与表单交互（域 5）+ 高可访问性（域 1）」三个技术域的交叉展示。
4. **隐私友好 + 零资源离线完整**：纯本地内存估算、不存储不上报、明确隐私告知、无任何网络/图片/字体/图标依赖，双击 `index.html` 断网即可完整体验，完美满足案例独立性铁律，也顺带传递安全产品应有的信任感。
5. **可访问性是设计的一部分**：meter 语义、等级变化节流 aria-live 播报、label/aria-describedby 关联、不仅靠颜色、全键盘路径、prefers-reduced-motion 下信息一条不少地保留——可作为「带实时反馈的可访问表单」范式，而不只是视觉特效。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库、零 CDN，双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 评估必须真实可解释：依据输入的长度、字符集类别（小写/大写/数字/符号）与常见弱模式（内置小型常见弱口令表如 `password/123456/qwerty` 等、键盘连续串、重复/序列字符）估算熵并映射为等级与可读破解耗时；增删字符双向实时更新，禁止用与内容无关的写死进度/随机动画假冒。弱口令表与每秒猜测次数等假设可在实现中内置常量，但须在 Micro-HUD/注释层面自洽可说明。
- 隐私：仅在本地内存评估，**禁止**把密码写入 localStorage/sessionStorage/cookie、禁止上报或任何网络请求、禁止把完整密码打印到控制台；卸载/切换案例时清理监听与引用；界面需有「仅本机估算、不保存不上传」的明确告知。
- 图标（眼睛、勾、叉、锁/盾、Caps Lock 等）一律内联 SVG，不引用任何外部图片/字体/图标库。
- 动效仅使用 transform/opacity/宽度等合成友好属性，统一缓动与短促时长；组件在 iframe 挂载/卸载时统一清理事件监听与定时器/rAF，无残留；不默认使用 Web Audio（如加入极轻的档位提示音，须手势懒激活、默认关闭，非必需）。
- Pointer 与键盘统一且键盘为一等路径：真实 label 关联、`autocomplete="new-password"` 等语义、强度区使用 meter/progressbar 语义并在**等级变化时**以 aria-live 节流播报、错误以 aria-invalid/aria-describedby 关联、信息不仅靠颜色；可见性切换可聚焦可键盘触发。
- 尊重 `prefers-reduced-motion`（关闭辉光脉冲/清单动效/背景漂移，保留即时评估信息）；移动端单指可用、热区充分、反馈展开不引起布局跳动、不横向溢出。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊（强制）；把玩项（熵读数、字符类别、命中模式、猜测速率假设、弱口令演示样例、减弱动效对照）使用默认折叠的 Micro-HUD（`H`/`Esc`、事件防穿透）。
