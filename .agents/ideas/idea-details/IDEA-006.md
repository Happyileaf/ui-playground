## 创意概述

悬浮动作按钮（FAB）+ 展开式快捷操作（Speed Dial）是移动端与内容型 Web 应用中最高频的「收纳次要高频动作」原语之一：界面保持极简，只露一个主入口；点击后一组相关动作（新建邮件、拍照、上传文件、设定提醒……）以有方向感的弹簧扇形/线性序列展开，主按钮图标在「加号 ↔ 关闭」之间形变。历史案例库中已有大量弹层（modal、drawer、context-menu、mega-menu、notification-center）、常驻导航（dynamic-dock、menu-morph、capsule-tabs）与微交互控件，却没有「角部常驻 FAB 收纳动作、按需展开」这一经典交互。本案例做一个纯原生、零依赖、可直接投产的 FAB Speed Dial：真实内容页（邮件/动态流 mock）右下角常驻主按钮，支持多方向（上/左/右，角部自适应）展开、动作项错峰弹簧入场与图标标签浮现、主按钮图标形变与旋转、悬停/点击/焦点/键盘/触屏多路径操作、完整 ARIA 菜单语义与焦点管理、外点/Esc 收起与焦点归还，并以「选择动作后给出克制反馈」收尾。

## 预期展示效果

- **构图与整体风格**：
  - 以一个**真实内容场景**承载（推荐「收件箱 / 动态信息流」mock 页：顶部搜索与标题、若干拟真列表行），避免 FAB 悬浮在空背景上缺乏使用上下文；整体延续项目深色玻璃质感、圆角、克制留白与柔和投影语言。
  - FAB 锚定在内容视口角部（默认右下角，距安全边距），主按钮为高强调圆形（或圆角方形）浮动按钮，带层级投影与极轻的悬浮抬升；展开前界面只有这一个浮动入口。
  - 展开时动作项沿选定方向依次「浮」出，每个动作项由「小型圆形/胶囊动作按钮 + 外侧文字标签（chip）」组成；主按钮同步从加号形变为关闭（×），背后可升起一层极淡的、不阻断列表浏览但能收束注意力的压暗层（scrim，可选且很轻）。
- **主要视觉元素**：
  - **主 FAB**：常态为主强调色实心 + 白色/高对比内联 SVG 图标（加号）；hover/focus 轻微抬升与亮度变化；按下（active）有快速缩放反馈；展开态图标做「+ → ×」的旋转 + 形变（描边旋转/中线消隐的连贯形变，而非生硬切换）。
  - **动作项（Speed Dial Action）**：比主按钮小一号的圆形/胶囊按钮，每项一个内联 SVG 图标 + 一个紧贴外侧的文字标签胶囊；标签在按钮展开到位后轻微淡入，避免与位移打架；动作项可带危险/普通的语义色弱区分（如「删除草稿」类用克制的警示色，不喧宾夺主）。
  - **展开排布**：默认自 FAB **向上**线性扇形排列（最经典）；同时演示方向变体（向左 / 向右 / 或弧线 fan 排布），处于贴近视口边缘时自动选择不溢出的方向并预留安全间距。
  - **压暗层 scrim（可选）**：展开时在内容上铺一层很淡的深色，营造层级收拢；其透明度与淡入淡出克制，列表仍可辨认；不使用浓重全屏遮罩（区别于 modal/drawer）。
- **层次、材质、光影与关键细节**：
  - 主按钮投影随展开略增强（从普通悬浮投影过渡到「菜单展开中」的更高层级投影），动作项投影依次更轻，形成主—从的层级纵深；玻璃/磨砂质感与项目现有毛玻璃语言一致。
  - 动效统一使用弹性/阻尼缓动（与项目 spring 语言一致），动作项按索引**错峰（stagger）**入场，节奏短促（约每项 20–40ms 错峰、单项 200–300ms 量级），收起时反向、略快；位移 + 透明 + 轻微缩放组合，避免单纯 slide 的呆板。
  - 标签胶囊为深色玻璃/高对比实心底 + 细描边，指向按钮一侧可有极小三角/缺口暗示，但保持克制；动作项 hover 有抬升或光环，focus-visible 焦点环清晰且独立于 hover。
  - 选择动作后：菜单以「被点击项轻确认（短暂高亮/涟漪）→ 整体错峰收起 → 主按钮图标复位」收尾，同时在场景内给出与动作对应的克制反馈（如顶部 Toast/内联提示「已新建草稿」），反馈与项目现有通知语言协调、不使用 confetti 等庆祝彩带。
  - 右上角固定点阵色 Title 胶囊（统一 HUD 规范）。

## 动态与交互

- **展开/收起触发（多路径）**：
  - 指针：点击主 FAB 切换；可选支持鼠标悬停在 FAB 区域时展开（须可在 HUD 中切换，且触屏不依赖 hover）；
  - 键盘：主 FAB 获得焦点时按 `Enter`/`Space`/`ArrowUp`/`ArrowDown` 展开；展开后焦点移入第一个（或上次）动作项；
  - 触屏：点按展开，点按动作项执行；滑动误触不展开。
- **菜单内导航（完整键盘）**：
  - 展开态 `↑/↓`（或按展开方向的 `←/→`）在动作项间循环移动焦点；`Home/End` 跳首/末项；
  - `Enter/Space` 激活当前动作项；`Esc` 收起并把焦点归还主 FAB；`Tab` 离开菜单时收起（焦点自然移出，不抢夺焦点）。
- **外部点击与滚动**：点击菜单/scrim 之外区域收起；页面滚动时可选择收起（避免 FAB 与展开项错位），以状态一致为准；窗口 resize / 边缘变化时重新计算展开方向。
- **动作反馈**：激活某动作项后，先给该项一次轻确认反馈，再错峰收起菜单、图标复位，并在内容场景内呈现与动作语义对应的结果（新建/上传/提醒等用统一的轻提示或列表内变化承载；纯前端演示，不产生真实网络请求）。
- **方向与边缘自适应**：提供方向切换演示（上/左/右，及可选弧线 fan）；当 FAB 靠近视口边缘或动作数量较多时，展开方向自动翻转/钳制，动作项与标签均不溢出视口。
- **可访问性**：主按钮带 `aria-haspopup="menu"`、`aria-expanded`；动作列表使用 `role="menu"`、动作项 `role="menuitem"`，标签通过可见文本或 `aria-label` 可被读屏识别；展开/收起与焦点移动对读屏友好；动效遵循 `prefers-reduced-motion`（关闭弹性位移与错峰，改为即时或仅淡入淡出，功能与语义完整）。
- **可选 Micro-HUD**：默认折叠的统一 Micro-HUD（`H`/`Esc` 切换、事件防穿透），可切换展开方向、悬停展开开关、动效强弱/scrim 开关等；非必需时至少保留右上角 Title 胶囊。
- 移动端触控热区达标（主按钮与动作项不小于常规触控尺寸），窄屏下标签不遮挡、不溢出。

## 核心亮点

1. **有明确功能语义的收纳式动作入口**：不是为动而动的悬浮按钮，而是解决「界面极简 vs 多个高频创建动作」矛盾的真实生产原语；以邮件/信息流 mock 承载，动作触发后在场景内闭环反馈，可直接用于生产。
2. **弹簧错峰 + 图标形变的连贯编排**：动作项按索引错峰弹簧浮入、主按钮投影层级提升、加号到关闭的连贯旋转变形、标签延迟淡入、收起反向略快——整套动效在叙事上清楚表达「动作集合被打开 / 被收束」，而非简单显隐。
3. **方向与边缘自适应**：支持上/左/右（及可选弧线）展开，贴近视口边缘自动翻转、标签与按钮统一钳制不溢出，resize/滚动后保持状态一致，覆盖桌面角部与移动端拇指热区两类真实用法。
4. **完整 ARIA 菜单语义与焦点闭环**：`menu/menuitem`、`aria-expanded/haspopup`、方向键/Home/End/Esc/Tab 全键盘操作、外点与滚动收起、激活或 Esc 后焦点精确归还主 FAB，并尊重减弱动效偏好。

## 历史案例对比（进入 Ready 前必填）

- **检查范围**：src/playground.js 全部 60 个注册案例（id / 标题 / 描述 / tags，实测 effects 12 / components 45 / pages 3）+ playground/effects、playground/components、playground/pages 目录 + rejected.md（当前为空）+ completed.md（当前为空）。
- **相似案例**：
  - `dynamic-dock`（动态鱼眼坞台）：同为「一组动作图标 + 弹性物理 + Web Audio」的浮动操作集合，但 Dock 是**常驻、水平排布、靠光标距离连续放大**的 macOS 坞台，没有「单个 FAB 收纳、点击展开/收起」的开合状态机、没有 `+→×` 主按钮形变、没有菜单 ARIA 语义与焦点陷阱式归还；
  - `menu-morph`（汉堡形变导航）：同样有「图标形变 + 展开/收起」，但其本质是**汉堡按钮触发的全屏遮罩站点导航**，链接错峰上滑、焦点循环在全屏层内；本案例是角部小型动作菜单，非全屏、非导航、动作即时执行后收起，视觉体量与交互模型完全不同；
  - `context-menu`（右键上下文菜单）：同为 `menu/menuitem` 语义与键盘导航，但是由右键/长按在指针位置唤起的**层级嵌套上下文菜单**，无固定角部 FAB、无扇形错峰展开、无主按钮图标形变与展开态；
  - `mega-menu`（全宽下拉导航）：悬停展开的**全宽多列站点导航**，为信息浏览而非动作执行，无 FAB、无弹簧扇形编排；
  - `notification-center`（通知中心）：由铃铛徽标唤起的**下拉内容列表**，承载通知数据与已读筛选，非动作快捷入口，无方向自适应展开与图标形变；
  - `drawer` / `modal`：同为浮层容器，但承载大块内容、强遮罩与焦点陷阱；本案例轻量、瞬时、scrim 很淡且不阻断浏览；
  - `capsule-tabs`（胶囊标签）/ `tooltip` / `guided-tour`：在「错峰 / 标签浮现 / 分步气泡」层面有零星相似元素，但均非收纳式动作菜单；
  - 活动池中 `IDEA-001~005`（Date Picker、Carousel、Toast、Tags Input、Step Wizard）：分别为日期选择、内容轮播、轻提示、多值输入、多步流程容器，与角部 FAB 动作菜单无重叠。
- **差异说明**：核心创意是**「角部常驻单 FAB 收纳高频动作 + 开合状态机 + 方向自适应的弹簧错峰展开 + 主按钮图标形变」**。历史案例中没有任何「FAB / Speed Dial」原语；与最接近的 dynamic-dock（常驻坞台 vs 收纳开合）、menu-morph（全屏导航 vs 角部动作菜单）、context-menu（指针位置嵌套菜单 vs 固定 FAB 扇形展开）在核心创意、视觉表达（角部 FAB + 错峰动作项 + 外侧标签 + `+→×` 形变）、交互方式（开合状态机/方向自适应/动作执行后收起）与整体表现上均存在实质差异，不属于换色、换文案或微调参数类重复。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生零 CDN、双击 index.html 独立离线运行（通用项目铁律，详情不重复）。
- 演示场景（邮件/信息流 mock）与所有图标使用内联 SVG 与原生元素构造，不引用其他案例代码、不引入动画/图标库；动作结果为纯前端演示反馈，不产生真实网络请求。
- 展开/收起为单一可信开合状态机，过渡进行中重复触发（快速连点/连按）以状态机判定为准，避免动作项与主按钮状态错乱；位移与透明度优先使用 transform/opacity 合成层属性。
- 展开方向、边缘翻转与安全间距基于实时视口/元素几何计算，resize、滚动与触屏场景下不溢出、不错位。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊；如需参数控制（方向 / 悬停展开 / 动效强弱 / scrim），使用默认折叠的 Micro-HUD（`H`/`Esc`、事件防穿透）。
- 尊重 `prefers-reduced-motion`；窄屏与触控热区达标；卸载/切换案例时清理监听、定时器与任何 rAF/音频上下文（如启用可选触感音效，须手势懒激活 AudioContext）。
