## 创意概述

做一类在 Medium、Kindle Cloud Reader、Notion、语雀、各大新闻阅读器里被反复验证的高频阅读增强原语——**用户在一段只读正文上拖选文字后，在选区附近自动浮现一枚轻量操作条，对当前选区执行即时操作**（复制、划重点高亮、收为引用笔记、生成可分享的段落锚点等），选区折叠、点击空白或按 Esc 时操作条收起。它解决的是「读完一段想收藏 / 引用 / 分享，却只能靠浏览器右键菜单或手动进编辑器」的体验缺口：上下文操作锚定在选中的文字旁边，零页面跳转、零弹层打断。

当前案例库 60 个注册案例与在池 49 个 Ready 中**没有任何「监听只读文本选区（Selection/Range）、在选区矩形附近智能定位浮动操作条、并对选区执行高亮包裹 / 复制 / 引用收集」的组件**：最邻近的 `rich-text-toolbar` 是常驻 **contenteditable 编辑区**里「选中文本后施加格式（加粗 / 标题 / 链接）」，其 `getSelection` 仅用于失焦前保存光标再还原；在池 IDEA-019 表情选择器、IDEA-020 提及输入同样是「可编辑控件失焦前保存光标位置，再把字符 / 实体插入输入框」；IDEA-028 行内编辑是查看态↔输入态就地切换。它们都作用于**可编辑控件、面向内容生产**，而本案例作用于**只读阅读区、面向内容消费与标注**。本案例以一篇排版精良的暗色长文（专栏 / 文档式阅读页）为舞台，提供真实可用的高亮（多色划重点）、复制、收为引用笔记、分享段落锚点等操作，并内置一份与标注同源的「我的标注」侧栏 / 面板，是可直接落地阅读类、资讯类、文档类网页的生产级组件。

## 预期展示效果

- **构图与整体风格**：
  - 页面视觉重心是一篇**沉浸式长文阅读舞台**：居中、舒适行长（约 65–75 字符）的正文栏，配真实可读的多段中文文案（标题、若干小标题与长段落，避免 Lorem 占位的廉价感），正文背景为近黑 / 深炭阅读底，正文区可有一张由内联 SVG + CSS 渐变构造的头图 / 分隔装饰，零外部图片。
  - 阅读区之上是**选区浮动操作条**：一枚小而克制的玻璃质感工具胶囊（backdrop-filter 毛玻璃、细边框、柔和投影、圆角），内部是一排内联 SVG 图标按钮（高亮、复制、引用、分享锚点等），按钮间细分隔线；操作条下方或上方带一枚指向选区的小三角。操作条在选区矩形（`range.getBoundingClientRect()`）的水平中点、垂直上方优先定位，靠近视口上 / 左 / 右边缘时自动翻转 / 平移避让，绝不遮挡当前选区、绝不溢出视口。
  - 阅读区一侧（窄屏折叠为可呼出的抽屉 / 底部面板）是**「我的标注」面板**：与高亮 / 引用数据同源，按出现顺序列出每条标注的摘录短句、类型（高亮颜色 / 引用）、可点击「跳回原文位置」，支持单条删除与一键清空；空态给克制插画式提示（内联 SVG，无外部图）。右上角固定项目统一的点阵色 Title 胶囊；默认折叠的 Micro-HUD 提供动效开关、定位策略 / 避让可视化、reduced-motion 状态显示等。
- **主要视觉元素**：
  - **浮动操作条（核心）**：默认隐藏；用户在正文内拖出非空选区（`selectionchange` / `mouseup` / 键盘选择）后，先做一小段弹性 / 淡入位移动画出现并吸附到选区上方；继续拖选调整选区时操作条跟随移动（可做轻阻尼或直接重定位，避免抖动闪烁）；选区清空、点击操作条之外或按 Esc 时淡出收起。操作条按钮具备 hover / focus / active 三态与清晰焦点环，危险 / 高频操作有视觉主次。
  - **划重点高亮**：点击高亮按钮（或先展开 2–3 个克制的高亮色点）把当前选区包裹为语义化 `<mark>`（携带稳定标注 id 与颜色），呈现半透明荧光笔质感（不用刺眼纯色，注意暗色底上的可读性）；多次高亮可叠加到不同片段；点击已有高亮可在操作条 / 面板中改色或移除；跨元素选区的包裹需正确处理（在合法边界切分 Range，不破坏段落结构）。
  - **复制 / 引用 / 分享锚点**：复制把选中文本写入剪贴板并给短暂「已复制」成功态反馈；引用把摘录连同来源上下文收进「我的标注」并附引号样式；分享锚点为该段落 / 选区生成可写进地址栏的定位标识（实现可为最近段落锚点 + 字符偏移，刷新后尽量回位），并给出复制链接反馈。
  - **标注面板**：摘录列表与正文高亮一一对应、数据同源；跳回时正文对应高亮做一次克制的呼吸强调（不频闪）。
- **层次、材质、光影与关键细节**：
  - 层次：阅读底与正文（最底）→ `<mark>` 高亮层（内嵌正文，不脱离排版）→ 浮动操作条（吸附浮层）→ 标注面板（操作台）→ Title 胶囊 / HUD（固定层）；层级靠毛玻璃、明度与投影区分，操作条永远在选区之上但不压死正文。
  - **选区几何与碰撞避让是工程底线**：以 `Selection` / `Range` 的实时矩形定位，水平居中于选区、垂直优先选区上方（空间不足翻下方并翻转箭头），左右超界时钳制到视口内安全边距；窗口滚动 / resize / 软键盘弹出 / 横竖屏切换后重新求值；选区跨多行时以选区首行矩形或整体包围盒合理定位，不出现工具条飞离视口。
  - **失焦保活是体验分水岭**：点击操作条按钮会让正文选区失焦，必须在交互前保存 Range（或让操作条容器不抢占选区，必要时用 `mousedown` 阻止默认失焦 / pointer-events 技巧），操作完成后既能对原选区完成包裹 / 复制，又不丢高亮目标。
  - 动效克制：仅写 transform / opacity / filter；出现 / 收起短促弹性，不做炫技；信息不仅靠颜色编码（图标形状 + 文案 title / aria-label + 类型标签共同承载）。

> 设计文档约束最终体验与设计意图；具体文章题材与段落数量、高亮色数量与色值、操作条包含哪几项操作（复制 / 高亮 / 引用 / 锚点中的取舍与顺序）、面板是侧栏还是抽屉、锚点采用段落 id 还是字符偏移、是否提供改色等，由实现阶段按手感与篇幅统一决定，不在此过早钉死；但「只读正文拖出非空选区 → 操作条在选区矩形附近弹性浮现并边缘避让 → 点击按钮在失焦情况下仍准确作用于原选区（高亮 `<mark>` 包裹 / 复制 / 引用 / 锚点）→ 标注与面板数据同源可回看可删除 → 选区折叠 / Esc / 外点收起 → 键盘可选、触屏可点、reduced-motion 与无 JS 退化信息不丢」这条链路必须真实成立，不允许用 hover tooltip 或仅一个复制按钮冒充。

## 动态与交互

- **触发方式（指针 + 键盘 + 触屏三通道）**：
  - 桌面指针：在正文内按下拖选，松开且选区非空（去空白后长度达标）时操作条在选区上方弹性浮现；拖选过程中不抢焦点；再次拖选改变范围时操作条平滑跟随；选区被点击 / 折叠清空时收起。
  - 键盘：把焦点放到正文阅读区后，Shift + 方向键扩展选区同样唤起操作条；操作条出现后焦点不被强制夺走，可通过快捷键或 Tab 进入操作条按钮（每个操作按钮有清晰焦点环），Esc 关闭并把焦点还给正文。
  - 移动端 / 触屏：手指拖选或双击选词 / 长按选择后，操作条在选区附近以足够热区的形态出现，位置避开手指与软键盘，点按操作可用；不依赖 hover。
- **操作条动作**：
  - **高亮**：将原选区包裹为带 id / 颜色的 `<mark>`，立即给出视觉反馈（荧光淡入）并写入标注数据；支持对已高亮片段再次操作（改色 / 取消高亮）。
  - **复制**：写剪贴板（优先 Clipboard API，`file://` / 非安全上下文降级到隐藏 textarea + execCommand 拷贝），按钮短暂变为「已复制」成功态，失败有可读提示，不报错吞掉。
  - **引用 / 收藏**：把摘录收进「我的标注」面板，附来源段落上下文与类型；面板计数即时更新。
  - **分享锚点**：生成并复制可定位到该段落 / 选区的链接（hash），打开链接时页面滚动并短暂强调目标；给出复制反馈。
- **收起时机**：选区折叠为空、点击操作条与正文之外、按 Esc、滚动导致选区完全离开视口（可选）时淡出；正在操作条上交互时不误收起。
- **标注面板**：列出摘录、类型与高亮色点；「跳回」平滑滚动到原文对应 `<mark>` 并做一次呼吸强调；单条删除同时解除正文高亮且数据同步；一键清空需二次确认；空态有引导文案。
- **可访问性（一等路径）**：
  - 操作条按钮为真实 `<button>`，带可读 `aria-label`（如「高亮所选文字」「复制所选文字」「收为引用」）与 `title`；操作条容器可具 `role="toolbar"` / `aria-label="选区操作"`，出现时辅助技术可感知但不逐帧刷屏；动作结果（已复制、已高亮、已收藏）以 `aria-live="polite"` 克制播报。
  - 正文保持为可读的语义化文章结构（`article` / 标题层级 / 段落）；高亮用 `<mark>` 语义而非纯底色 span，无 JS 时正文完整可读（增强型交互不阻塞阅读）；键盘用户可完整完成选择与操作，焦点环可见，Esc 后焦点归还正文。
  - `prefers-reduced-motion: reduce`（或 HUD 关闭动效）时操作条即时显隐、无弹性位移，功能不缩水；正文、高亮与控件对比度达 WCAG AA，高亮色在暗色底上同时保证底色与文字可读；状态不仅靠颜色编码。
- **响应式与生命周期**：滚动 / resize / 横竖屏 / 软键盘 / 场景尺寸变化后重算定位与避让；iframe 销毁或案例切换时移除 `selectionchange` / 滚动 / resize 等全部监听、清除定时器与临时节点，无后台动画（本案例无音频）。

## 核心亮点

1. **真实高频的生产级阅读增强原语**：Medium / Kindle / Notion / 语雀 / 新闻阅读器的划词工具条是可直接用于阅读类、资讯类、文档类网页的成熟形态（实用性 5 分）；库内 60 案例 + 在池 49 Ready 无一覆盖「只读选区 × 选区矩形定位 × 浮动操作条 × 高亮 / 引用标注体系」这一具体形态。
2. **真实工程深度，而非一个复制按钮**：Selection/Range 矩形定位、四向碰撞翻转避让、滚动 / resize / 软键盘重算、**点击工具条失焦前保存 Range 仍准确作用于原选区**、跨多元素选区的合法 `<mark>` 包裹与解除——这些是「能用的划词工具」与「玩具浮层」的分水岭。
3. **从一次性操作到可回看的标注体系**：高亮 / 引用 / 锚点与「我的标注」面板数据同源，可跳回、改色、删除、清空，演示了选区工具条背后的真实数据模型，而不是操作完即消失。
4. **三通道等价可达 + 零资源离线**：指针拖选、键盘 Shift+方向键、触屏点按 / 长按均能唤起并操作；Clipboard API 非安全上下文降级；正文与高亮零外部图片 / 字体 / 库，双击离线即可完整演示。
5. **克制的 Anti-Slop 审美**：暗色阅读栏 + 毛玻璃胶囊 + 荧光笔式高亮出现在真实长文排版中，弹性动效短促、信息多重编码，不做霓虹泛滥 / 粒子堆砌。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库、零图标库 / 字体库 / CDN、零外部图片 / 音频；正文头图 / 装饰与空态插画由内联 SVG + CSS 渐变构造，图标一律内联 SVG；双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 操作条定位必须基于 `window.getSelection()` 的 `Range.getBoundingClientRect()` / `getClientRects()` 实时计算：水平居中选区、垂直优先上方，做视口上 / 左 / 右边缘的翻转与钳制避让，箭头同步换向；滚动、resize、软键盘、横竖屏切换后重新求值；任何情况下不溢出视口、不永久遮挡被选文字。
- 点击操作条导致正文失焦前必须保存 / 维持原 Range（阻止按钮 mousedown 默认失焦或缓存 Range），保证高亮包裹 / 复制 / 引用准确作用于原选区；跨多个元素的选区包裹必须在合法边界切分 Range 生成 `<mark>`，解除高亮时还原为正常文本节点且不破坏段落结构。
- 剪贴板优先 Clipboard API，并在 `file://` / 非安全上下文提供隐藏 textarea + 传统拷贝的降级路径，失败有可读反馈；分享锚点在刷新 / 打开链接后能滚动回位并强调目标。
- 操作必须三通道等价可达：指针拖选、键盘 Shift+方向键、触屏点按 / 长按均可唤起操作条并完成操作；按钮为真实 `<button>` 带 `aria-label` / 焦点环，容器具备 toolbar 语义，结果以 `aria-live` 礼貌播报，Esc 后焦点归还正文；正文用语义化文章结构 + `<mark>` 高亮，无 JS 时正文与信息完整可读；`prefers-reduced-motion` 下即时显隐、功能完整；动效仅写 transform / opacity / filter，卸载 / 切场景时清理全部监听、定时器与临时节点。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊（强制）；动效开关、定位 / 避让可视化、reduced-motion 状态等通过默认折叠的 Micro-HUD 提供（`H`/`Esc`、事件防穿透）。
