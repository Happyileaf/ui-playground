## 创意概述

相册、作品集、电商商品图、资讯配图等真实网页都有同一个高频需求：点击缩略图后进入**全屏、专注、可连续浏览、可放大细看**的图片查看体验。全仓 60 个已注册案例虽已覆盖弹窗、抽屉、放大镜、图片对比、裁剪器、轮播等大量组件，却**没有一个全屏沉浸式图片灯箱（Lightbox）**：技术域 4「卡片与内容展示」明确列出的「图片画廊」方向长期空缺。本案例做一个纯原生、零依赖的**全屏图片灯箱**：拟真相册网格点击任一缩略图后，图片以共享元素 FLIP 形变从网格位置「长」入全屏查看器；在灯箱内可左右连续切换（按钮 / 方向键 / 触屏滑动 / 边缘点击）、双击或滚轮缩放并拖拽平移细看、通过底部缩略图条跳转、查看标题与序号；关闭时图片沿原路回缩回网格。与活动池 IDEA-015 依赖 View Transitions API 的「对等视图替换」不同，本案例的核心是**覆盖式图片浏览体验**，且展开 / 切换动效用纯原生 FLIP 与 transform 手动实现，**不依赖 `startViewTransition`**，保证任何浏览器双击打开观感与功能完全一致——是一份可直接照搬到真实相册、电商与作品集站点的生产级灯箱范式。

## 预期展示效果

- **构图与整体风格**：
  - 延续项目统一深色玻璃质感。页面主体是一个**拟真相册 / 作品集画廊**：简洁的页头（标题与一行说明）、规整的响应式缩略图网格（桌面 3–4 列、平板 2 列、手机 1–2 列），缩略图统一圆角、细描边、柔和投影，悬停轻微抬升并浮现查看提示。
  - 点击后进入**全屏覆盖式灯箱**：近黑、带轻微高斯模糊的遮罩压暗整页；中央为当前大图（按视口等比适配，完整可见），左右悬浮上一张 / 下一张圆形玻璃箭头，右上角为关闭按钮，底部为半透明信息条（图片标题 / 说明 + `当前 / 总数` 计数），更下方是一条可横向滚动的**缩略图条（filmstrip）**，当前项高亮。
  - 右上角统一点阵色 Title 胶囊（遵循 HUD 规范）；视觉重心始终是被查看的图片，控件克制、安静，无操作时可自动降低存在感。
- **主要视觉元素**：
  - **共享元素展开 / 收合（核心视觉）**：被点击的缩略图沿 FLIP 路径——从网格中的实际位置与尺寸——连续位移、放大、圆角与阴影插值，过渡为全屏大图；反向关闭时原路回缩到对应网格位。灯箱遮罩与控件在此期间分层淡入淡出。
  - **方向感切换**：上一张 / 下一张时，大图按切换方向做短距离滑移 + 淡入淡出（前进向左、后退向右），新图承接旧图位置，节奏轻快克制；底部缩略图条当前指示同步移动。
  - **缩放查看态**：双击（或双击触屏）在适配态与放大态之间切换，放大后图片可跟随指针 / 手指拖拽平移，边界有柔和阻尼；滚轮 / 双指可连续缩放，超出最大 / 最小倍率时不给生硬跳变。
  - **零资源图集**：所有图片以纯 CSS 渐变、几何图形、内联 SVG 构造为风格统一的系列「摄影 / 插画」封面（参照既有 image-zoom 零外部图片做法），每张配标题与简短说明，零外部图片、零字体、零网络请求。
- **层次、材质、光影与关键细节**：
  - 展开的图片是唯一视觉主角：转场期间浮于遮罩与控件之上，圆角从缩略图态连续收敛到灯箱态、投影随放大增强，营造「拿起照片凑近看」的浮起感；遮罩不是死黑一块，而带极轻的内容模糊与明暗层次。
  - 箭头、关闭按钮、信息条、缩略图条统一半透明玻璃材质 + 细描边，hover / focus 有明确但克制的高光；缩略图当前项用强调色描边 + 轻微放大指示，切换时指示位置平滑滑动而非硬跳。
  - 时长与缓动统一：展开 / 收合用一条带轻微减速的曲线，遮罩淡入略先于图片到位、文字信息最后淡入，形成层次；连续快速切换时以最后一次操作为准，不出现图序错乱、残影或动画堆叠。
  - 键盘焦点在灯箱内清晰可见；`prefers-reduced-motion` 下展开 / 滑移降级为即时或极短淡入淡出，但浏览、缩放、键盘、手势全部功能保持完整。

## 动态与交互

- **打开灯箱（核心触发）**：点击 / 轻触网格缩略图（或键盘聚焦后 Enter / Space），记录源缩略图位置，播放 FLIP 共享元素展开动画进入灯箱；打开期间锁定背景页面滚动，焦点移入灯箱并在控件间形成焦点陷阱（参考既有 modal / drawer 的焦点管理范式）。
- **连续浏览（四种等价方式）**：左右箭头按钮点击；键盘 `←` / `→`（`Home` / `End` 跳到首 / 张末张）；触屏在图片上左右滑动（带跟手位移与阈值判定，未达阈值弹性回弹）；点击图片两侧边缘区域。相邻图片在打开灯箱与浏览时做低优先级预加载（内置数据下即预构造），切换无白屏。可配置是否循环（末张→首张）。
- **缩放与平移**：双击 / 双指在适配与放大态切换；放大态下指针拖拽平移并有边界阻尼；滚轮（按住修饰键或直接滚轮，以不与页面滚动冲突为准）连续缩放，倍率钳制在合理区间并显示当前倍率；再次双击或缩小回适配倍率时复位。缩小态下禁用平移，切换图片自动复位到适配态。
- **缩略图条与信息**：底部 filmstrip 可直接点击跳转任意图片，当前项高亮且自动横向滚动到可视区；信息条展示标题、说明与 `序号 / 总数`；Micro-HUD 可切换循环开关、缩略图条显隐、动效强度（完整 / 减弱）等。
- **关闭与焦点还原**：关闭按钮、`Esc`、点击遮罩空白处三种方式关闭；播放原路 FLIP 收合动画回到网格，解锁背景滚动并把焦点还原到触发时的缩略图；若源缩略图因视口变化已不可见，退化为整体淡入淡出且不报错。
- **可访问性与减弱动态**：灯箱具备合适的 dialog 语义与 `aria-label`（如图集名称、图片标题、序号），图片说明可被读屏获取，箭头与关闭有可读名称；遵循 `prefers-reduced-motion` 关闭形变与滑移，仅保留即时 / 极短淡入；控件 Tab 顺序合理，`Esc` 可退出。
- **移动端触控**：窄屏网格自适应单列 / 双列；灯箱箭头不遮挡主要画面、触控目标足够大；支持滑动切换与双指缩放；横屏下图片按高度适配仍完整可见。

## 核心亮点

1. **填补全仓「全屏图片灯箱」空白**：60 个历史案例与活动池 IDEA-001~015 中没有任何覆盖式全屏图片查看器；技术域 4「卡片与内容展示」列出的图片画廊方向此前无人认领。灯箱是相册、电商、作品集、资讯站点的标配能力，实用性直接拉满，可整段照搬到生产页面。
2. **共享元素 FLIP 的空间连贯叙事**：缩略图从网格原位连续「长」成全屏大图、关闭原路回缩，配合遮罩分层淡入与信息延迟入场，建立明确的「拿起—细看—放回」心智；且该动效以纯原生 FLIP 手动实现，不依赖 View Transitions API，全浏览器观感一致、离线可用。
3. **一个案例覆盖真实看图的完整交互面**：四种等价切换方式（箭头 / 键盘 / 滑动 / 边缘点击）、双击 + 滚轮 + 双指缩放、带阻尼的拖拽平移、filmstrip 跳转、序号与说明、相邻预载、焦点陷阱与焦点还原、背景滚动锁、循环与减弱动效开关——工程完整度对标成熟图库组件。
4. **零资源、零依赖的生产级质感**：图集以 CSS / 内联 SVG 构造，断网双击即用；玻璃材质控件、方向感切换、边界阻尼、连续操作去抖等细节共同规避「AI 廉价感」，达到可直接上线的完成度。

- **相似案例**：
  - 活动池 **IDEA-015（view-transitions，Ready）**：同为「点网格图看大图」的心智、也有缩略图到大图的形变，是最需要区分的一条。但 IDEA-015 是**两个对等视图（网格视图 ↔ 详情视图）之间的替换式转场**，技术核心是原生 View Transitions API / `view-transition-name` 命名元素与 `history.pushState` 历史栈，辅线是筛选排序的 FLIP 重排；本案例是**覆盖在原页面之上的全屏查看浮层**，技术核心是图片浏览体验本身（连续切换、缩放平移、filmstrip、触屏手势、相邻预载），展开动效用**纯 FLIP 手动实现、不依赖 `startViewTransition`**，也不引入浏览器历史栈。两者的核心创意、交互面与技术依赖均不同（一个讲「视图间如何过渡」，一个讲「如何专注地看图」）。

  - `image-zoom`（商品放大镜）：都涉及「看清图片细节」，但它是**页内圆形镜片跟随指针的局部放大**，无全屏覆盖、无图集、无切换与手势；本案例是全屏等比适配 + 倍率缩放 + 拖拽平移 + 连续浏览。
  - `image-comparison-slider`（前后对比滑块）/ `image-cropper`（八向手柄裁剪器）：都以图片为主角，但核心分别是**前后两态 clip-path 对比**与**裁剪工作流**，非沉浸式查看与图集浏览。
  - 活动池 **IDEA-002（Carousel 内容轮播，Ready）**：都有「上一张 / 下一张」，但轮播是**内嵌在页面版面中的内容轮换**（带 Hero 展示叙事），不夺取全屏焦点、无遮罩、无缩放平移、无 filmstrip 与灯箱焦点管理；本案例是进入全屏专注模式的覆盖式查看器。
  - `swipe-card-deck`（拖拽卡牌堆）/ `avatar-stack`（头像名片）/ `spotlight-cards`（聚光卡片）：含拖拽或图片元素，但分别是卡牌决策交互、头像信息名片与卡片光标描边，与全屏看图无关。
- **差异说明**：核心创意是**「纯原生拟真相册中，以不依赖 View Transitions API 的 FLIP 共享元素展开进入覆盖式全屏灯箱，提供四种等价切换、缩放平移、filmstrip、触屏手势与完整焦点管理的沉浸式图集浏览，并在关闭时原路回缩」**。与最接近的 IDEA-015（对等视图替换 + View Transitions/历史栈 vs 覆盖式看图器 + 纯 FLIP）、modal/drawer（通用浮层容器 vs 专用图片浏览交互面）、image-zoom（页内局部放大 vs 全屏连续浏览缩放）、IDEA-002（内嵌轮播 vs 全屏灯箱）在核心创意、视觉表达（共享元素展开 + 方向感切换 + 缩放阻尼）、交互方式（点击打开 / 箭头 / 键盘 / 滑动 / 边缘点击 / 双击滚轮双指缩放）与整体表现（沉浸式图集查看器）上均有实质差异，非换色、换文案或微调参数。全仓检索确认无历史（含已删除）同名 id 或目录，案例 id 定为 `image-lightbox`。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生零 CDN、零框架、零库，双击 index.html 独立离线运行（通用项目铁律，不重复）。
- 展开 / 收合动效用**纯原生 FLIP（首末位置插值 + transform / opacity transition）手动实现**，不依赖 `document.startViewTransition`，以保证所有现代浏览器观感与行为一致；`prefers-reduced-motion` 下降级为即时 / 极短淡入淡出。
- 图集所有画面一律以 CSS 渐变 / 几何图形 / 内联 SVG 构造，**不得引入外部图片、图标库、字体或任何网络资源**；图集为内置静态数据（标题、说明、图形配置），切换、预载、循环逻辑全部本地完成。
- 打开时锁定背景滚动、实现灯箱内焦点陷阱与关闭后焦点还原（参照既有 modal / drawer）；关闭须支持按钮 / Esc / 点击遮罩三种路径；源缩略图在收合时若已不在视口或 DOM 中，退化为整体淡入淡出，不得抛错或定位错乱。
- 缩放以 transform 实现（translate + scale 合成），倍率设上下限，平移有边界钳制 / 阻尼；滚轮缩放不得与页面滚动冲突，触摸需区分「滑动切换」与「双指缩放」手势，避免误触发。
- 连续快速切换 / 缩放时要有明确的中止 / 以最后一次为准策略，切换新图自动复位适配态；统一在 iframe 卸载时移除事件监听、取消未完成动画与定时器、释放指针捕获。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊；演示调节项（循环开关、缩略图条显隐、动效强度）使用常驻演示控件 + 默认折叠 Micro-HUD（`H`/`Esc`、事件防穿透）。本案例默认不需要音效。
