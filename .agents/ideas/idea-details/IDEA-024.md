## 创意概述

后台管理、权限分配、角色成员配置、表单字段编排等场景里，用户常常需要「从一大批候选项中挑选若干项移入已选集合」。普通多选下拉（multi-select）在候选项多、需要反复对照「还剩哪些 / 已选哪些」时体验拥挤且不可见；而经典的**穿梭框（Transfer / Shuttle）**用**左右两栏并列清单 + 中间方向按钮**，把「候选」与「已选」两个集合同时摊开在视野里：勾选候选项后点「向右」或直接双击即穿梭到右栏，反向同理，移动过程用一次短促的方向动效把「数据跨过中缝」的空间关系表达清楚。本案例做一个纯原生、零依赖、可直接投产的**双栏穿梭选择框**：两栏各自带**搜索过滤、全选/半选（indeterminate）、计数、禁用项、空状态**，中间方向按钮随「当前栏有无勾选」智能启停，支持**单击勾选 / 双击单项直穿 / 方向按钮批量穿梭 / 拖拽排序已选项 / 完整键盘操作（焦点漫游、空格勾选、Enter 穿梭、栏内搜索）**，并用一个**拟真的「为角色分配系统权限 / 成员选择」场景**承载（候选权限点或成员列表 + 已选区 + 实时提交预览），让它是真实页面模块而非孤立 demo。结论不仅靠颜色：勾选、计数、方向、禁用均有文本与状态多重表达，适配 `prefers-reduced-motion` 与触屏。

## 预期展示效果

- **构图与整体风格**：
  - 用一个**拟真后台配置场景**承载：克制的深色中性背景（延续项目统一语言，微弱色温倾向、拒绝蓝紫霓虹渐变），页头有区块标题与一句副文案（如「为「运营专员」角色配置可访问功能」），主体是居中的穿梭框组件，下方放一条只读的「已选结果实时预览」区（已选项以可删除芯片或纯文本列表回显），构成真实的配置—确认闭环。
  - 穿梭框为**三列结构**：左栏「待选/候选」、中间**竖向方向按钮组**（向右穿梭、向左移出）、右栏「已选」；三列在桌面端水平排列，窄屏（手机视口）自适应为**上下堆叠或两栏收窄**的可用布局（按钮方向与排列在小屏有明确取舍，不溢出、触控达标）。
  - 每栏为统一圆角、细描边、柔和投影的面板：栏头是一行**标题 + 计数（如「3/12」表示已勾选数/总数）+ 全选复选框**，其下是**搜索框**（候选项较多时），再下是**可滚动选项列表**（固定可视高度、内部滚动）；底部或栏头显示当前勾选数。面板描边、圆角、投影语言与项目既有组件（如 combo-box / cascader / kanban 等）一致。
  - 右上角统一点阵色 Title 胶囊（遵循 HUD 规范），主题指示灯固定不随组件内部状态变色；底部居中可配一条极简操作指引胶囊（说明「勾选后点中间按钮或双击选项穿梭」）。
  - 配色克制：两栏用相同中性面板色，仅用**一处**有明度层次的强调色服务于「勾选态 / 主穿梭方向 / 焦点」；已选与候选的差异主要靠**栏位、标题、计数与勾选状态**表达，而非高饱和色块；正文对比满足 WCAG AA。
- **主要视觉元素**：
  - **双栏集合对照（核心视觉）**：左右两个等权重列表把「候选」「已选」同时呈现，用户无需展开/记忆；每栏标题、计数、全选、搜索齐备，栏间是明确的中缝与方向按钮。
  - **方向按钮组**：中间两枚带左右箭头的按钮（可含第三态「全部移动」的次级入口，具体取舍实现阶段定），按钮的**可用/禁用态**由「来源栏当前是否有勾选」实时决定；主方向（通常向右加入）视觉权重略高。
  - **选项行的状态层次**：默认行、hover、勾选（复选框 + 行高亮）、禁用（降低对比且不可选、不参与全选）、键盘焦点（清晰 focus-visible 环）多态明确；每行以「复选框 + 主要文本 + 可选次级说明/图标」构成，信息一眼可扫。
  - **穿梭动效**：被移动的项从中缝一侧以轻微位移 + 淡出错落、在另一侧淡入就位（FLIP 式列表重排），表达「跨过中缝」；动效短促、合成友好（transform/opacity），不做夸张飞入。
  - **搜索与空状态**：搜索时实时过滤并高亮命中关键词（可选），无命中显示明确空态（图标 + 文案）；整栏为空（如已选栏初始）显示引导性空文案而非空白。
  - **结果预览区**：组件下方以芯片/文本实时回显已选集合，可单独移除，强化「这是一个会产出值的表单控件」的真实感。
- **层次、材质、光影与关键细节**：
  - 面板为深色中性卡片 + 细描边 + 柔和投影，选中行用一层很淡的强调色底 + 左侧或复选框的强调描边表达层级，不靠重阴影；中缝按钮用与面板协调的实心/描边按钮，禁用态明显但不发灰到不可读。
  - 全选复选框的 **indeterminate 半选态**必须正确：勾了一部分时为「半选」、全勾为「选中」、全不勾为「未选」；禁用项不计入可全选范围，逻辑边界清晰。
  - 计数口径明确：栏头显示「本栏勾选数 / 本栏总数」，随搜索过滤与穿梭实时更新；搜索过滤下的「全选」只作用于当前过滤结果（是否含被过滤隐藏项须有一致、可解释的规则，实现阶段定但要自洽）。
  - 列表内部滚动平滑、滚动条样式克制；穿梭后保持/归还焦点有讲究（见交互节），避免焦点丢失。
  - 状态可辨且非颜色单通道：勾选（复选框 + 行底）、禁用（文字 + 光标 + aria）、方向（箭头图标 + 按钮可用态）、焦点（焦点环）多重表达；任何信息不仅靠红绿等颜色区分。
  - 窄屏与触屏：三列在手机视口重排为不溢出、可操作的形态（如两栏收窄 + 中间按钮保留，或候选/已选上下堆叠 + 方向按钮相应转向），触控目标 ≥44px，按钮内文字单行不折行。

## 动态与交互

- **勾选与全选**：单击选项行或其复选框切换勾选（点击目标覆盖整行，复选框状态同步）；栏头全选框在未选/半选/全选三态间切换，仅作用于该栏当前**可选项**（跳过禁用项）；勾选变化即时更新计数、全选态与中间方向按钮的启停。
- **穿梭（核心交互）**：
  - 勾选若干项后点击中间「向右 / 向左」按钮，被勾选项**批量**从来源栏移到目标栏并清除勾选；移动项做短促方向位移 + 淡出错落、目标栏列表淡入重排。
  - **双击某选项**可直接单项穿梭（无需先勾选），并给出即时反馈；触屏无双击依赖，以勾选 + 方向按钮为主路径。
  - 方向按钮在来源栏「无有效勾选」时禁用；穿梭后若目标栏因此由空变非空，更新空态与计数。
- **搜索过滤**：在任一栏搜索框输入即按文本（可含主文本/次级文本）实时过滤列表；过滤不改变真实勾选/已选数据，仅收窄可见与全选作用域；清空搜索恢复完整列表；搜索框可清空（× 按钮）。
- **已选排序（增强项，可取舍）**：右栏已选项支持**拖拽排序或上移/下移**，结果预览与最终值顺序随之更新；若实现拖拽须用 Pointer Events 统一鼠标/触控并有键盘等价操作（如 Alt+方向键），无法兼顾键盘则退化为上移/下移按钮，不做只有鼠标可用的排序。
- **结果预览与移除**：下方结果区实时列出已选项，芯片可单独 × 移除（等价于向左穿梭回候选）；提供「重置」可恢复初始集合（纯前端演示，不发请求）。
- **键盘与可访问性**：
  - 完整 WAI-ARIA 语义：两栏列表以 `listbox`/`option`（`aria-selected`、`aria-disabled`、`aria-multiselectable`）或等价的可访问复选框列表（`role="group"` + `checkbox`/`option`）实现；栏头全选框为标准 `checkbox` 并正确设置 `aria-checked="mixed"` 表达半选；方向按钮有明确 `aria-label`（如「把 3 个勾选项加入已选」并随数量更新）；搜索框有关联 label。
  - Tab 可依次聚焦左栏搜索、左栏选项、方向按钮、右栏选项、右栏搜索；列表内 ↑/↓ 漫游选项、Space 切换勾选（禁用项跳过）、Enter 触发当前焦点项的单方向穿梭（或用方向按钮批量穿梭）；焦点在穿梭后移动到目标栏对应项或保持在合理位置，不丢到页面顶部。
  - 列表区域用 `aria-live="polite"` 或状态播报元素，在穿梭后播报「已加入 N 项，已选共 M 项」，供读屏用户感知结果变化。
- **移动端触控**：Pointer Events 统一点按；行点按勾选、中间方向按钮点按批量穿梭为主要路径，整行/按钮触控达标；三列布局在窄屏重排不溢出，搜索与滚动顺畅。
- **动效降级**：`prefers-reduced-motion` 下关闭穿梭位移/错落与列表 FLIP 动画，项即时出现/消失、状态即时更新，但勾选、穿梭、搜索、键盘、移除、重置功能全部保留。

## 核心亮点

1. **补上全仓「双栏穿梭框（Transfer）」这一后台高频生产级控件空白**：60 个注册案例与 23 个 Ready Idea 已覆盖单值/搜索下拉（combo-box）、级联（cascader）、区间滑块、文件树、滑删列表、标签输入、看板拖拽等大量选择与列表交互，却没有「候选/已选两集合并列、勾选跨栏中转」的穿梭框；它是权限/成员/字段配置可直接复用的成熟表单模式，而非一次性炫技。
2. **把「两集合 + 跨中缝」的空间模型做扎实**：左右等权重栏位、实时计数与全选/半选、方向按钮随勾选启停、双击直穿、批量穿梭的方向动效与 FLIP 重排，让「数据跨过中缝」的关系既可见又跟手，而非两个互不相干的多选列表。
3. **完整生产级细节而非玩具**：每栏搜索过滤、禁用项不参与全选、indeterminate 三态、空态引导、已选排序（含键盘等价）、结果实时预览与单项移除、重置，覆盖真实权限配置场景最易缺失的边角。
4. **完整可达与多端**：WAI-ARIA listbox/checkbox 语义、半选 `aria-checked="mixed"`、方向按钮动态 `aria-label`、↑↓/Space/Enter 键盘操作与穿梭后焦点管理、`aria-live` 结果播报、触屏主路径与窄屏重排、`prefers-reduced-motion` 降级，使其是可投产组件完整度而非鼠标专属 demo。

- **相似案例**：
  - `combo-box`（可搜索下拉选择框）/ 活动池 `IDEA-010`（Cascader 级联选择器）：同属「从候选中选择」，但 combo-box 是**单栏下拉单选/单选式过滤**、cascader 是**多列逐级联动的层级选择**；二者都不提供「候选/已选两个持久并列集合 + 勾选批量跨栏移动 + 各自搜索/全选/计数」，核心数据模型（单值/路径 vs 两集合互转）与交互结构不同。
  - `swipe-card-deck`（卡牌堆）/ 活动池 `IDEA-021`（Swipe Action List 横滑露出操作列表）：同有「把元素向某方向移动」的手势，但分别是**卡牌飞出取舍**与**列表项横滑露出操作按钮**，不是两栏集合之间的勾选穿梭，无候选/已选双栏与中转按钮。
  - `kanban-board`（拖拽看板）/ `resizable-table`（列宽可调数据表，含勾选/排序）/ `virtual-list`（万级虚拟滚动列表）：同含列表、勾选或拖拽，但分别是**跨列拖拽卡片的看板**、**单表列宽/排序/过滤**、**定高虚拟滚动性能方案**，均无「左候选右已选 + 方向按钮批量中转 + 双栏搜索全选计数」的穿梭框结构。
  - `range-slider`（双拇指区间）/ `dual-range`：名字含「双」，但它是**同一连续区间的两个拇指取值**，与双栏集合无关。
  - 活动池 `IDEA-004`（Tags Input 多值芯片输入）：同样产出「多值集合」，但交互是**在一个输入框内键入/回车生成芯片**，候选不持久可见、无两栏对照与跨栏穿梭；本案例强调从**可见候选清单勾选中转**，面向候选项已知且较多的配置场景。
  - 活动池 `IDEA-005`（Step Wizard 步骤向导）、`IDEA-006`（FAB Speed Dial）、`IDEA-012`（Pagination）等：同属后台控件家族，但分别是表单流程容器、展开快捷菜单、分页，均非选择器；其余 IDEA-001~003、007~009、011、013~020、022、023 为日期/轮播/通知/标签/下载按钮/IM 页/图表/评分/时钟/开关/转场/灯箱/缓动/翻牌/表情/提及/验证码/方向悬停图廊等，无穿梭框。
  - `tree-view`（文件树，含多选式键盘与过滤）：是**单棵层级树的展开/过滤/选中回显**，无左右两集合与跨栏中转；如未来做「树形穿梭框」也应在本案例之后作为带层级的独立增强，不构成当前重复。
- **差异说明**：核心创意是**「候选与已选两个持久并列集合，配合勾选、各自搜索/全选/计数与中间方向按钮，把选中项批量（或双击单项）跨中缝穿梭，并以方向动效与 FLIP 重排表达两集合互转」的双栏穿梭选择框**。与最接近的 combo-box/cascader（单栏下拉/级联单值路径 vs 两集合批量互转）、tags-input（键入生成芯片 vs 可见候选勾选中转）、kanban/resizable-table/virtual-list（跨列卡片/单表/虚拟滚动 vs 双栏穿梭结构）、swipe 系列（手势飞出/横滑操作 vs 勾选批量中转）在核心数据模型、视觉表达（左右等权重面板 + 中缝方向按钮 + 穿梭位移）、交互方式（勾选/全选半选/双击直穿/搜索过滤/键盘漫游与 Enter 穿梭）与整体表现（拟真权限/成员配置场景 + 结果实时预览）上均有实质差异；不属于换色、换文案或微调参数类重复。全仓检索 穿梭/transfer/shuttle/dual-list/双栏/多选/勾选 等关键字无历史（含已删除）id 冲突，案例 id 定为 `transfer`。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生零 CDN、双击 index.html 独立离线运行（通用项目铁律，详情不重复）。
- 候选项数据、图标（复选框/箭头/搜索/空态/芯片移除等）一律使用内置静态数据与**内联 SVG**，不引用外部图片/字体/图标库，不发起任何网络请求；演示为纯前端（不真实提交权限）。
- 统一使用 Pointer Events 处理鼠标/触控/手写笔；若实现已选拖拽排序，须提供键盘等价（Alt+方向键或上移/下移按钮），否则退化为按钮排序，禁止只有鼠标可用的关键路径。
- 穿梭动效仅使用 transform / opacity 等合成友好属性，统一缓动与短促时长；列表重排可用 FLIP 思路；组件在 iframe 挂载/卸载时统一清理事件监听与定时器，无残留；不默认使用 Web Audio（如加入极轻音效须手势懒激活、默认关闭，非必需）。
- 可访问性为硬性要求：listbox/option 或等价复选框列表语义、全选框 indeterminate 与 `aria-checked="mixed"`、方向按钮随勾选数量更新的 `aria-label`、↑↓/Space/Enter 键盘操作、穿梭后的焦点管理与 `aria-live` 结果播报；结论不仅靠颜色；`prefers-reduced-motion` 下关闭位移动效但功能全保留。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊（指示灯固定不随组件内部状态变色）；如需调参（动效开关、减弱动效、切换演示数据集）可用常驻演示控件 + 默认折叠 Micro-HUD（`H`/`Esc`、事件防穿透），非必需不强行加面板。
