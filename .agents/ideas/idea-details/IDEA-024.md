## 创意概述

一个由页面滚动驱动的「卡片堆叠覆盖」叙事组件：用户向下滚动时，多张全屏内容卡片依次在视口中吸附（sticky），后续卡片带着轻微缩放与位移从底部滑入、覆盖前一张，形成层层叠放的实体卡牌堆效果；每张卡片在被覆盖的过程中同步发生景深压缩（scale 递减）、圆角增大与柔和阴影加深，并联动侧边章节进度指示。

解决的体验问题：产品介绍、特性展示、长表单分步等落地页场景中，普通纵向滚动缺乏空间纵深与进度感；本组件用纯原生滚动驱动动画（CSS Scroll-Driven Animations 优先、rAF + 滚动位置计算兜底）把「滚动」转化为「翻牌叠放」的连续空间叙事，且零滚动劫持——用户依然使用原生滚动条与系统滚动手感，没有 JS 动画库接管滚动的惯性副作用。

## 预期展示效果

- **构图与整体风格**：
  - 深色高级感展台背景（与工作台现有暗色基调一致），中央为一组（建议 4–5 张）尺寸统一的大圆角内容卡，卡片在视口垂直居中位置 sticky 吸附。
  - 页面整体滚动高度 = 卡片数 × 约一屏的滚动行程，为逐张覆盖提供充足滚动距离；卡片自身高度略小于视口高度，露出已堆叠卡堆的顶部边缘层，强化「一摞牌」的纵深感。
  - 右上角按项目强制规范放置点阵色 Title 胶囊（中英文名）；右侧配极简章节进度点，右下角可放默认折叠的 Micro-HUD（遵循 `H` / `Esc` 快捷键与事件防穿透规范）。
- **主要视觉元素**：
  - 堆叠卡堆：每张卡片含序号/章节标识、标题、描述文案与一块纯 CSS（渐变、网格、模糊光斑、内联 SVG 几何）构造的无外部图片主视觉区。
  - 层叠边缘：已被覆盖卡片的顶部圆角边缘层层可见，配合逐级递减的亮度/饱和度，模拟真实卡堆厚度。
  - 进度指示：侧边圆点当前卡对应节点高亮放大，章节切换时节点间有克制的弹性过渡；可选底部细进度条映射整体行程。
  - 章节标题交接：当前卡片标题随覆盖进度做轻微上浮 + 透明度交接（前一张淡出、后一张淡入）。
- **层次、材质、光影与关键细节**：
  - 材质：卡片为微拟态磨砂/细腻描边质感（半透明深色底 + 1px 内高光描边），避免纯平色块的廉价感。
  - 光影：每张卡片阴影随其在堆中的深度变化——越靠底层阴影越柔和扩散、卡片整体 scale 略小（逐级递减数个百分点，具体数值实现时调校）、圆角逐级增大，产生真实按压堆叠的物理层次。
  - 景深：新卡从下方进入时带数个百分点的初始 scale 与短位移，吸附过程中回弹至 1；顶层卡始终最亮最清晰，底层卡轻微压暗。
  - 节奏：覆盖过程与滚动位置严格 1:1 绑定（触控板惯性、键盘滚页、移动端快速滑动均不错位），无跳变、无回弹抖动；松手停在任意滚动位置时画面是确定的中间态。

## 动态与交互

- **触发方式**：纯滚动驱动（鼠标滚轮 / 触控板 / 触屏滑动 / 键盘 PageDown·Space·方向键），不做滚动劫持、不锁定 body 滚动、不强制整屏 snap。
- **核心动效**：
  1. 卡片进入：从视口下方 sticky 吸附，伴随 scale 由小到大、圆角由大到小、阴影由散到聚的连续补间；
  2. 被覆盖：后一张滑入时前一张 scale 递减、圆角增大、阴影加深、轻微压暗，顶部边缘留在卡堆中可见；
  3. 进度联动：章节圆点与可选细进度条按整体滚动进度实时更新，当前章节切换有克制的弹性高亮；
  4. 反向滚动：向上回滚时所有过渡完整可逆，卡堆逐张「抽走」还原。
- **移动端触控**：依赖原生滚动，触屏天然支持；小屏下卡片内边距、圆角与进度点尺寸自适应，单卡行程可适当缩短。
- **减弱动态偏好**：`prefers-reduced-motion: reduce` 下关闭 scale/圆角/阴影补间，卡片以普通 sticky 分段呈现并保证内容完整可读，进度指示仍同步。
- **可选 Micro-HUD**（默认收起）：调节堆叠行程感、缩放幅度、圆角变化强度，并提供「跳到指定卡」按钮；遵循项目 HUD 规范支持 `H` / `Esc`，键盘事件不穿透页面。

## 核心亮点

1. **现代 CSS Scroll-Driven Animations 的原生实践**：优先使用 `animation-timeline: view()`（必要时配合 `scroll-timeline`）把覆盖进度直接绑定到滚动时间线，不占 JS 主线程；在不支持的浏览器中以 rAF + 滚动位置/IntersectionObserver 计算做等价兜底，同一套 DOM 与视觉、体验不降级。
2. **真实物理层次的卡堆美学**：scale、圆角、阴影、亮度四维联动，且已覆盖卡片保留可见层边，区别于常见的「整页淡入淡出」伪堆叠；滚动任意位置都呈现确定的层叠中间态。
3. **零劫持的可访问叙事**：原生滚动条、键盘翻页、触屏惯性全部保留；章节节点带 aria-current、reduced-motion 路径完整，是可直接放进生产落地页的实用组件而非纯展示作品。
4. **与既有滚动类、卡片类案例正交**：项目内滚动相关案例均不具备「sticky 堆叠覆盖 + 滚动时间线绑定」的空间叙事形态（见历史对比）。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML/CSS/ES6+，零框架、零 CDN、零外部图片（卡片主视觉用纯 CSS 渐变 + 内联 SVG 构造），双击 `index.html` 独立完整运行。
- CSS Scroll-Driven Animations 需特性检测（`@supports` / CSS.supports），不支持时以 rAF + 滚动位置/IntersectionObserver 兜底；两条路径视觉终态与中间态一致，不支持环境下不得布局错乱。
- 不得做滚动劫持（禁止改写 scrollTop 模拟分页、禁止强制整屏 snap 破坏原生滚动惯性），确保键盘翻页与触屏惯性可用。
- 遵循项目统一 HUD 规范：强制右上角 Title 胶囊；Micro-HUD 若引入必须默认折叠、支持 `H`/`Esc` 与事件防穿透。
- 必须适配 `prefers-reduced-motion`，并在移动端视口可用；动画只驱动 transform/opacity/filter 等合成属性，避免重排卡顿。
