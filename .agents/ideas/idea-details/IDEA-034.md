## 创意概述

「同一个图标，自己长成另一个状态」——状态化形变图标（Stateful Morphing Icon）是现代产品中最高频的微交互原语之一：播放/暂停、菜单/返回箭头、搜索/关闭、书签描边/实心、爱心空心/填充、喇叭/静音、展开/收起、锁开/锁合……它们共同的体验承诺是：**按钮的状态不依赖两个图标的硬切换，而由同一枚内联 SVG 的路径连续形变（path morph）来表达**——线条之间逐点流动、彼此真正「变成」对方，用户的视线无需在两个符号间跳跃，状态归属关系被动效本身直接讲述。Material Design、iOS SF Symbols、Heroicons/Lucide 社区与 Framer Motion 生态都把同构路径插值（等命令数、等锚点数的 path 数据在相同命令序列间插值）与 `stroke-dashoffset` 描边生长作为这类图标的标准手法；它解决的不是「按钮好不好看」，而是一套**状态机驱动、可键盘操作、对辅助技术诚实**的图标按钮交互范式。

当前案例库 60 个案例中，与 SVG 形变相关的只有两处：`menu-morph` 用 CSS transform 把汉堡三条线旋转平移成关闭叉（单一一对状态、且服务于全屏导航遮罩这一页面级模式），`capsule-tabs` 的六款胶囊风格中有一款使用 SVG Gooey 滤镜做标签粘滞融合（是滤镜层面的液态融合，并非路径数据插值）；另有大量案例把内联 SVG 图标当作静态装饰元素使用，活动池中 IDEA-007（液态下载按钮）含「下载→停止→对勾」的图标小形变、IDEA-014（日夜开关合集）含太阳月亮符号切换——但图标形变在二者中都只是更大组件的从属子效果，全库**没有任何以「等锚点 SVG 路径插值 + 描边生长」为核心技术、以「状态化图标按钮体系」本身为展品的案例**，技术域 8（SVG 滤镜与形态形变）在图标层面仍是单点覆盖。本案例做一个纯原生、零依赖、零图标库、双击离线即用的 Stateful Morphing Icon Buttons：一个按使用语义分组的状态图标按钮画廊（媒体控制 / 导航 / 搜索与关闭 / 收藏与点赞 / 声音 / 展开收起 / 锁定等至少多组），每个按钮驱动一次有性格、可回放的同构路径形变或描边生长，配合按压回弹、悬停起笔、状态色微移与可选触感式细节；全部按钮是真实可用的 `aria-pressed` / 双态 `aria-label` 控件（含切换态与三态播放组），键盘一等、`prefers-reduced-motion` 下即时切态且状态语义完整，并遵循统一 HUD 规范。

## 预期展示效果

- **构图与整体风格**：
  - 案例视口主体是一块**图标按钮陈列舞台**：按使用语义分区（媒体控制、导航与返回、搜索/关闭、收藏、声音、展开收起、锁定等），每个分区一行或一组等大圆形/圆角方形容器按钮，容器为安静的暗色哑光面与极细描边；图标统一为同一种线条语言（统一描边粗细、圆角线帽、视觉磅重与 24×24 画板留白），整组放在一起像同一套图标家族，而非东拼西凑的剪贴画。
  - 舞台配一条极简演示控制条：「全部播放一遍」（让所有按钮按索引错峰自动形变一次，用于一眼看全家族动效）、动效性格切换（如标准 / 弹性回弹 / 干脆利落几档曲线）、描边生长开关（允许在「路径插值」与「擦除重绘」两类形变语言间对照）、减弱动效说明；右上角按工作台 HUD 规范放置点阵色 Title 胶囊。
  - 延续项目克制的暗色玻璃审美：形变是唯一的主角，颜色只在状态确认时做低饱和微移（如收藏态填充克制的暖色、播放态不刺眼的强调色），拒绝满屏霓虹、图标拖尾粒子与高饱和发光的 AI Slop 廉价感；无任何外部图标字体 / 图片 / 网络请求，全部路径手写。
  - 首屏默认所有按钮处于未激活态，可用指针逐个点按体验；桌面宽屏下分区多列舒展，平板两列、手机单列或紧凑双列，触控热区不小于移动端可点标准，不横向溢出。
- **主要视觉元素**：
  - **同构路径形变（Path Morph）**：成对/成组状态的图标使用命令序列与锚点数量一致的手写 path（必要时用重合锚点、零长度段补齐结构），状态切换时在两套 `d` 值间逐点插值，线条连续流动变形（如播放三角的三个锚点滑成暂停的两竖、汉堡中线生长为左箭头而上下线收拢消失、放大镜手柄上扬并入圆环成为关闭叉）。
  - **描边生长/擦除（Stroke Draw）**：另一类图标用 `pathLength` + `stroke-dasharray` / `stroke-dashoffset` 完成「旧线收笔、新线起笔」（如书签描边先勾出轮廓再在激活态填实、锁梁打开弧线收起后锁环闭合、对勾一笔画出）；与路径插值两种语言可在控制条对照。
  - **容器与状态微反馈**：点击时容器轻微下沉/回弹（active scale），切换完成有一次极克制的确认反馈（填充淡入、状态色微移或小勾的弹性过冲）；悬停时图标可有极轻微的「预备」起笔（如线条偏移 1px 以内），不喧宾夺主。
  - **分组语义陈列**：至少覆盖多组生产高频语义（建议媒体：播放/暂停、上一首/下一首可作三态播放组；导航：菜单/返回、菜单/关闭；检索：搜索/关闭；收藏：书签切换、爱心切换；声音：喇叭/静音；展开：加号/叉或 chevron 翻转；安全：开锁/锁定），每组旁有极简功能名标注，让画廊可直接当作复制即用的组件目录。
- **层次、材质、光影与关键细节**：
  - 视觉三层：暗色舞台背景 → 哑光按钮容器阵列 → 流动的图标线条层；容器只承担「可点区域与归属」的安静底托，线条是唯一高对比焦点，状态色面积小而明确。
  - 形变必须「讲得通」：每一对状态的锚点对应关系经过设计，形变过程中线条不扭曲成不可辨认的乱麻、不出现凭空闪烁/透明度糊弄；同组图标起止状态几何居中、视觉重量一致，切换后不发生容器尺寸跳动。
  - 真实边界有明确反馈：快速连点时动画被正确取消并从当前姿态反向/正向接续（不跳变、不抖动），三态播放组状态互斥正确；所有动画可被 reduced-motion 即时降级为状态硬切，功能与播报不丢失；卸载时无悬挂 rAF / 监听。

> 设计文档约束最终体验与设计意图；具体图标数量与分组、插值时长与缓动曲线数值、容器尺寸、状态色具体取值、是否用 rAF 手写插值或 Web Animations API 等由实现阶段按画质与手感统一决定，不在此过早钉死。

## 动态与交互

- **触发方式（指针 / 键盘统一）**：
  - **点按切换**：每个图标按钮在两个（或一组）状态间切换，触发同构路径插值或描边收笔/起笔，配容器按压回弹与状态确认微反馈；键盘聚焦时 Enter / Space 完全等价触发，焦点环清晰可见。
  - **悬停预备（指针设备）**：悬停仅做极轻微起笔预备与容器提亮，不改变状态；触屏无悬停态也不损失任何功能。
  - **三态/互斥组**：至少一组按钮演示非双态语义（如播放/暂停同键双态，或媒体组中上一首/播放/下一首互斥与禁用态），禁用按钮有明确视觉与 `disabled`/`aria-disabled` 语义且不响应触发。
  - **画廊演示控制**：「全部播放一遍」按索引错峰自动演示全部形变后停在各自终态，再次播放可逆序复原；曲线性格（标准/弹性/干脆）与形变语言（路径插值/描边生长对照）即时切换，仅影响观感不影响状态正确性。
- **状态机语义**：每个按钮是显式的状态机（双态为 `inactive ↔ active`，播放组为 `idle/playing/paused` 之类），视觉形变进度与逻辑状态严格一致；快速连点时取消在途动画并从**当前视觉姿态**重新插值到目标状态（使用统一的时间驱动插值，而非粗暴重启动画），杜绝瞬移与半程卡死。
- **键盘一等路径**：全部按钮为原生 `<button>`，Tab 顺序按分区自然排列、焦点环可见；Enter / Space 触发切换；Esc 不产生破坏性动作；容器/图标不以非语义 div 实现。
- **可访问性**：
  - 双态按钮使用 `aria-pressed` 表达按压状态，或随状态切换 `aria-label`（如「播放」/「暂停」、「已收藏」/「收藏」），让辅助技术读到的是动作/状态而非「图标」；三态组以合适的 pressed/label 组合表达；装饰性容器对 AT 隐藏。
  - 状态绝不只靠形变与颜色传达：按钮附带的功能名标注、可选的状态文案与 `aria` 属性共同承载语义；暗色主题下线条与底色对比可读。
- **减弱动效与移动端**：
  - 尊重 `prefers-reduced-motion`：关闭路径插值、描边生长与回弹动画，图标在两态间即时切换（终态完全正确），按压/键盘/状态播报/禁用逻辑 100% 保留。
  - 移动端触控热区充分，分区在窄口折行或紧凑排布不横向溢出；「全部播放」错峰演示在小屏同样完整；无依赖 hover 才能触达的功能。
- **生命周期**：连续形变用单一时间驱动（rAF 或 WAAPI）实现，页面隐藏/案例卸载时取消在途动画与所有指针/键盘监听；无悬挂 rAF、定时器与监听器。
- **可选 Micro-HUD**（默认折叠，`H` / `Esc` 切换、事件防穿透）：显示当前各按钮逻辑状态、动画进行中/完成、当前曲线档与形变语言、减弱动效是否生效、reduced-motion 媒体查询值，便于验证「视觉姿态始终等于逻辑状态」；非必需时至少保留右上角 Title 胶囊。

## 核心亮点

1. **补齐 SVG 形态形变在图标层面的空白**：库内 60 个案例中 `menu-morph` 仅做汉堡↔叉单对状态（CSS transform 旋转平移，且从属全屏导航模式），`capsule-tabs` 的 Gooey 是滤镜融合而非路径数据插值，IDEA-007 / IDEA-014 的图标变化只是更大组件里的子效果；全仓无 `getPointAtLength` 路径采样与 `d` 值插值用法。本案例首次以「等锚点路径形变 + 描边生长」为核心技术、以状态化图标按钮体系本身为展品，命中技术域 8（SVG 滤镜与形态形变）最薄弱的一环。
2. **「线条真正变成线条」的可验证手感**：成对状态手写同构 path（命令序列/锚点数严格一致，用重合点补结构），快速连点从当前姿态接续插值而非重放——形变过程中符号始终可辨、无闪烁糊弄；并可在「路径插值」与「描边生长」两种形变语言间即时对照，技术含量肉眼可见。
3. **生产级组件目录而非动画摆拍**：覆盖媒体、导航、搜索、收藏、声音、展开、锁定等多组高频语义，含双态切换、三态/互斥播放组与禁用态，每个都是可直接搬进产品工具栏的真实 `<button>`，「全部播放一遍」只负责演示，不替代真实交互。
4. **克制审美 + 完整可达性**：统一线条语言的图标家族、哑光安静容器、小面积状态色微移，规避霓虹拖尾的廉价感；`aria-pressed`/动态 `aria-label` 状态播报、状态不只靠颜色与动效、键盘全操作、prefers-reduced-motion 终态即时正确。
5. **零资源纯手写**：全部路径人工编写、零图标库零图标字体零图片零 CDN，断网双击即可完整点按全部形变；与全库「禁止引入外部图标库」的既有取向一致，并把这一约束下的手写 SVG 工艺做成展示项。

## 历史案例对比（进入 Ready 前必填）

- **检查范围**：src/playground.js 全部 60 个注册案例（id / 标题 / 描述 / tags）+ playground/effects、playground/components、playground/pages 物理目录（实测 12 effects / 45 components / 3 pages）+ 活动池 IDEA-001～IDEA-033（全部 Ready）+ rejected.md（当前为空）+ completed.md（当前为空）。
- **相似案例**：

  - `capsule-tabs`（胶囊标签动效展厅）：六款风格中的「SVG 粘滞流体」使用 SVG Gooey（feGaussianBlur + feColorMatrix）做标签融合，属**滤镜域的液态粘滞效果**，不涉及路径数据插值、无状态图标语义；本案例是 path 数据同构形变 + 描边生长的图标控件，技术路线（路径插值 vs 滤镜融合）与交互对象（图标按钮 vs 标签指示）均不同。
  - `button`（现代按钮系统）：静态样式合集（波纹、conic 炫光边框、霓虹、毛玻璃），展示**按钮皮肤**而无任何图标状态机与形变；本案例展示的是状态语义驱动的图标运动语言，不做皮肤合集。
  - 活动池 **IDEA-007**（Gooey 液态下载按钮）：含「下载→停止→对勾」的小图标切换（对勾用 stroke-dashoffset 画出），是观感上最接近的活动 Idea；但它的核心是**液态进度容器 + 下载流程状态机**（进度填充、水滴动画、完成态），图标形变仅是单一流程内的从属点缀，无图标家族、无可复用的双态按钮范式、无路径插值体系。本案例不做进度与液态容器，聚焦「可复用状态图标按钮库」本身。
  - 活动池 **IDEA-014**（日夜形变开关合集）：含太阳↔月亮符号切换，但核心是**开关（track/thumb）控件合集与主题叙事**，符号是 thumb 上的装饰元素、随轨道滑动而非自形变；本案例以图标按钮（无轨道）为对象、以路径同构插值为技术主体。
  - 其余大量使用内联 SVG 图标的案例（like-button 爱心、otp-input、command-palette、combo-box、rate 星级、emoji-picker 等）：图标均为静态或简单缩放/填充反馈，无路径形变；其中 `like-button` 虽含双态（空心→填充），但以填充缩放粒子反馈为主、无路径插值与描边生长，且只是单个按钮而非体系化画廊。
  - 活动池 IDEA-001～IDEA-033 全表无「动效图标库 / 状态图标按钮 / SVG path morph」主题；多条详情（如 IDEA-008、IDEA-016、IDEA-020 等）反而明确要求「不引入外部图标库、图标手写内联 SVG」，与本案例零图标库取向一致而非冲突。
  - 全仓检索 `getPointAtLength / stroke-dashoffset / stroke-dasharray / pathLength / path morph / 路径插值 / 形变图标`：代码命中仅 menu-morph 的 CSS transform 形变（无 path 插值）、IDEA-009 类描边生长图表属数据可视化用途（活动池 IDEA-009，圆环/柱图描边，非图标状态机）；「Glassmorphism」含 morph 子串为假阳性（毛玻璃，与形变无关）。确认无历史（含已删除）`morphing-icon-buttons` id 或物理目录冲突。
- **差异说明**：核心创意是「**手写同构 SVG path 的逐点插值形变 + stroke-dashoffset 描边生长，双语言驱动的一组可复用、有完整状态机与可达性的状态化图标按钮**」。与 `menu-morph` 相比，差异在「图标形变体系/路径插值技术 vs 单对状态 CSS transform + 全屏导航模式」；与 `capsule-tabs` 相比，差异在路径数据形变 vs Gooey 滤镜融合、图标控件 vs 标签；与 IDEA-007 / IDEA-014 相比，差异在「以图标按钮为核心展品 vs 进度按钮/开关合集的从属装饰」；与 `button` / `like-button` 相比，差异在连续形变运动语言 vs 静态皮肤/填充粒子反馈。差异同时体现在核心创意、视觉表达（统一线条家族 × 多组语义 × 两种形变语言对照）、交互方式（双态/三态/禁用、快速连点接续插值、全键盘）与整体表现上，不属于换颜色、文案或微调参数类重复。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库、零图标库/图标字体、零 CDN、零外部图片，双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 全部图标为手写内联 SVG，成对状态的 path 必须命令序列与锚点数量一致（可用重合锚点/零长度段补齐结构），插值在两套 `d` 值间按统一时间驱动（rAF 或 Web Animations API 均可）逐点进行；描边生长类使用 `pathLength` 归一化 + dasharray/dashoffset；不得用透明度硬切冒充形变（reduced-motion 降级除外）。
- 快速连点/重复触发必须从当前视觉姿态取消并重接插值，禁止动画瞬移、半程卡死或终态与逻辑状态不一致；每个按钮实现显式状态（至少双态，含一组三态/互斥与禁用态），页面隐藏或卸载时取消在途动画并清理全部监听/rAF。
- 控件语义：使用原生 `<button>`，双态以 `aria-pressed` 或随状态切换的 `aria-label` 表达，三态/禁用语义完整；状态不仅靠动效与颜色传达；Tab/Enter/Space 全操作、焦点环可见。
- 尊重 `prefers-reduced-motion`：关闭一切形变/回弹动效改为终态即时切换，状态机、键盘、播报、禁用逻辑完整保留。
- 视觉为统一描边语言的图标家族（统一线粗/线帽/画板/视觉重量），容器哑光克制、状态色小面积低饱和；桌面/平板/手机视口自适应不横向溢出，移动端热区充分。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊（强制）；如需参数控制（曲线档、形变语言对照、各按钮状态、减弱动效开关等）使用默认折叠的 Micro-HUD（`H` / `Esc`、事件防穿透）。
