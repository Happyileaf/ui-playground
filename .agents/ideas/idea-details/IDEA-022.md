## 创意概述

一个可直接用于生产网页的悬浮操作钮（Floating Action Button）径向快捷菜单（Speed Dial）：点击主钮后，子动作按钮像被「挤」出的液滴一样沿设定方向依次涌出，并通过 SVG `feGaussianBlur` + `feColorMatrix` Gooey 滤镜与主钮实时融合、粘连、拉丝，再圆润断开；收回时液滴被反向「吸回」主钮，主钮自身的加号同步形变为叉号。核心解决普通 FAB 展开生硬、层级感弱、缺少品牌记忆点的体验问题，是移动端发布/创建类场景与桌面端角落快捷操作的高频实用组件。

## 预期展示效果

- **构图与整体风格**：
  - 页面为一个贴近真实产品的轻量演示场景（如一篇内容卡片流或一张极简工作台画布），右下角（可切换为左下 / 右上 / 左上）悬浮一枚主操作钮，营造真实 App 内的召唤感。
  - 整体延续项目暗色、克制、高级的视觉语言；Gooey 液体部分使用饱和度适中、彼此协调的主题色（主钮深色实底 + 子动作同色系或互补色实底），避免糖果色廉价堆砌。
- **主要视觉元素**：
  - 一枚圆形主 FAB 与 4–5 枚等径（或略小）圆形子动作按钮，每枚子钮配一枚线性图标与一个展开时淡入的文字标签胶囊。
  - 一个全局 SVG 滤镜容器（`feGaussianBlur` + `feColorMatrix` alpha 阈值合成），仅作用于参与融合的圆形元素层。
  - 主钮中心的「+」图标在展开/收回间以旋转 + 描边形变过渡为「×」。
  - 可选的 Micro-HUD 控制面板（默认折叠，`H`/`Esc` 唤起），用于切换展开方向、涌出错峰节奏与模糊/阈值强度实时预览。
- **层次、材质、光影与关键细节**：
  - 按钮为实底圆形 + 柔和投影（双层阴影：近距接触影 + 远距环境影），与页面内容拉开层级；展开态主钮与子钮同处 Gooey 层，标签胶囊位于融合层之外、不被滤镜污染。
  - Gooey 质感关键在「先粘连拉丝、再收窄断开」：子钮与主钮接触瞬间边缘融合成连续液体，随位移增大颈部被拉细、最终弹断，断开有极轻微的回弹（squash & stretch），而非硬切。
  - 收回时顺序反向且略快，子钮缩入主钮瞬间被「吞入」，主钮在最后一颗子钮融合完成时有一次细微的按压回弹。
  - 主钮 hover 有轻微抬升与高光增强；激活（展开）态保持明确的视觉常驻（颜色加深或环形描边），让用户清楚菜单处于打开状态。
  - 滤镜边界预留足够 padding，防止模糊后的液体边缘被 SVG filter region 裁切。

## 动态与交互

- **触发方式**：
  - 点击 / 触摸主钮展开与收起；子按钮按距离错峰（stagger）依次涌出/吸回，位移使用带轻微 overshoot 的弹性曲线。
  - 悬停（具备 hover 能力的设备）时主钮预暗示（抬升 + 加号微旋）。
- **展开形态（三种可切换，作为本案例的展示重点）**：
  1. 线性扇形：子钮沿展开方向（上 / 左等）等距直线排列，逐个与主钮发生融合—拉丝—断开。
  2. 圆弧扇形（quarter fan）：子钮沿 90° 弧线等角分布，液滴沿弧线路径滑出。
  3. 拖拽挤压（增强亮点）：按住主钮做小范围拖拽时，主钮像液滴一样被指针牵引形变（尾部拉伸粘连于锚点），松开会弹回；该模式作为可选演示，不影响基础点击可用性。
- **子项操作反馈**：点击任一子动作，选中项以一次液体「啵」的缩放反馈后菜单自动收回，并在演示场景中给出轻量 toast/状态回执（纯演示，不依赖后端）。
- **外部关闭与焦点**：展开后点击遮罩层 / 页面空白处、按 `Esc` 均收回；焦点在展开时进入首个子项，子项间支持 `↑↓←→` 与 `Tab` 循环漫游，收回后焦点归还主钮。
- **键盘与可访问性**：主钮使用 `aria-expanded`、`aria-haspopup="menu"` 与 `aria-controls`；子项列表使用 `role="menu"` / `role="menuitem"`；新增子项通过 `aria-live` 轻量播报。完整尊重 `prefers-reduced-motion`：开启减弱动态时，跳过 Gooey 位移与弹性动画，子项即时（或极短淡入）出现在目标位置，功能不缩水。
- **移动端触控**：命中区域不小于 44×44 CSS px；展开方向避开系统手势区；页面在菜单展开时可锁定背景滚动（参照项目既有抽屉处理方式）。
- **音效（可选）**：如引入 Web Audio，必须在首次用户手势后懒激活 AudioContext，音色为极轻的液态「啵/嗒」，并可在 HUD 中静音。

## 核心亮点

1. **真·SVG Gooey 液体融合**：基于 `feGaussianBlur` + `feColorMatrix` alpha 阈值的经典 Gooey 技法，呈现接触融合—拉丝—弹断—吸回的完整液态生命周期，质感靠曲线节奏与 squash/stretch 细节，而非堆素材。
2. **一套组件三种形态**：线性扇形 / 圆弧扇形 / 拖拽挤压三种展开模式同场可切换，既是生产可用的 Speed Dial，也是 Gooey 技法的系统级展示，复用价值高。
3. **图标形变与液体动效统一**：主钮「+ → ×」形变与液体吞纳节奏严格对齐，开/合是两段互为倒放、手感不同的编排动画。
4. **可访问性不妥协**：完整 roving-focus 键盘操作、ARIA 菜单语义、焦点归还与 reduced-motion 降级，达到与项目现有 drawer/context-menu 同级的无障碍标准。
5. **零资源依赖**：全部形态由内联 SVG 元素与 CSS/JS 计算，无图片、无 CDN、无框架，双击 `index.html` 离线完整运行。

## 历史案例对比（进入 Ready 前必填）

- **检查范围**：当前 `main` 上 `src/playground.js` 全部 60 个注册案例的 id / 标题 / 描述与 tags；`playground/effects`、`playground/components`、`playground/pages` 目录清单；`.agents/ideas/rejected.md`（当前为空）；已合并但已不在 main 的历史 PR（PR #38）。
- **相似案例**：
  - `capsule-tabs`（胶囊标签动效展厅）：其 6 种动效中包含一个「SVG 粘滞流体」tab 切换变体，是当前 main 上唯一出现 Gooey 技法的案例。
  - `context-menu`（右键上下文菜单）、`drawer`（弹性四向抽屉）、`menu-morph`（汉堡形变全屏导航）：同属「唤出式菜单 / 遮罩面板」交互大类。
  - `dynamic-dock`：同具弹性物理与 Web Audio 触感反馈。
  - 历史案例（已不在 main）：PR #38（2026-10-09 合入，合并提交 `3f0a13b`）曾新增一个 `speed-dial` 案例，但其后随整批案例从 main 移除（同批的 `choice-control`、`ring-progress`、`text-scramble` 均已不存在，仅 `effects/scroll-reveal/` 后来在正确路径重新留存）；且该批次文件落在仓库根路径 `components/` 而非 `playground/components/`，注册路径为 `components/speed-dial/`，与当前案例目录约定不符。当前 main 的注册列表、物理目录、`.agents/ideas/rejected.md` 中均不存在 FAB / Speed Dial / Gooey 组件。
- **差异说明**：
  - 对历史 `speed-dial`（PR #38）：该案例是一枚毛玻璃 FAB（仅 `backdrop-filter` 模糊背景），动作项向上 / 向左 / 扇形弹性展开，全程不使用任何 SVG 滤镜，圆形元素之间没有像素级融合—拉丝—弹断；也没有「+ → ×」主钮形变、拖拽挤压与三形态系统切换。本案例以真·SVG Gooey 液体融合为核心表现手法（`feGaussianBlur` + `feColorMatrix` alpha 阈值），并补齐线性 / 圆弧 / 拖拽三种形态与完整液态生命周期，属于交互模型与视觉材质的双重升级，且将严格落在 `playground/components/gooey-fab/` 规范路径。
  - 对 `capsule-tabs`：Gooey 在该案例中只是胶囊指示器在两个等宽 tab 位之间水平滑动时的一种融合皮肤，元素不脱离轨道、无径向布局、无液滴涌出/吸回生命周期；本案例把 Gooey 作为独立组件的核心表现手法，主体是主钮与多颗自由位移的圆形液滴，包含线性/弧线/拖拽三种空间布局与完整的粘连—拉丝—弹断编排，并承担 FAB Speed Dial 的真实功能，核心创意与交互模型本质不同。
  - 对 `context-menu` / `drawer` / `menu-morph`：三者均为矩形面板/全屏遮罩的位移出现，不使用 SVG 滤镜融合，也没有 FAB 锚点 + 径向液滴布局；本案例是圆形元素经 Gooey 滤镜实时融合的角落悬浮操作钮，视觉表达（液体材质）与交互方式（径向召唤）均有实质差异。
  - 对 `dynamic-dock`：其放大效果基于高斯曲线插值的尺寸缩放（元素并不真正融合），本案例的「融合」来自像素级 alpha 阈值合成，且是菜单组件而非停靠栏。
  - 结论：当前 main 上不存在独立的 SVG Gooey 组件，也不存在有效的 FAB / Speed Dial 类案例（历史上仅有一个无液体融合、且已随错误路径批次移除的 speed-dial）；本案例差异同时体现在核心创意（液体融合）、视觉表达（Gooey 材质）与交互方式（径向菜单 + 三种展开模式）上，非配色/文案级微调。

## 实现约束（仅记录该案例必要的约束）

- Gooey 效果必须由内联 SVG filter（`feGaussianBlur` + `feColorMatrix`）对真实 DOM 圆形元素合成实现，不得用序列帧 / GIF / 视频伪造。
- SVG filter 的 `x/y/width/height` 需预留负向扩展区域，避免液滴与阴影被裁切。
- 必须提供 `prefers-reduced-motion` 降级路径，降级后布局与功能完整、仅移除弹性与位移动效。
- 遵循项目统一 HUD 规范：右上角毛玻璃 Title 胶囊必备；Micro-HUD 控制面板若引入须默认折叠，支持 `H`/`Esc` 且按键事件防穿透。
- Web Audio 若使用须手势后懒激活；其余为通用项目约束（纯原生、零框架、零 CDN、双击离线运行），不另列。
