## 创意概述

「点了加入购物车，东西真的飞进了购物车」——飞入购物车（Fly to Cart / Parabolic Add-to-Cart）是电商产品里最经典的空间连续性微交互之一：用户在商品卡上点击「加入购物车」后，商品缩略图从点击位置**沿一条带重力下坠感的抛物线**飞向顶栏购物车图标，落入瞬间购物车轻微晃动承接、角标数字弹性 +1，购物车抽屉里的商品行淡入就位。它背后是一条明确的体验承诺：**用户的操作与其结果在空间上被连续地连接起来**（spatial continuity），眼睛跟随飞行物自然落到「数量变化」这一结果上，不需要 Toast、不需要弹窗确认，「加购成功」与「购物车在哪、里面有几件」被一次半秒的运动同时讲清楚。淘宝/天猫、京东、Amazon 移动端与无数 DTC 品牌站都长期使用这一模式；它也是 FLIP 动画技术（First-Last-Invert-Play：记录元素起止位置、反向 transform 还原首帧、再播放到零位）与合成友好属性（只动 `transform` / `opacity`）最典型的教学级应用场景。

当前案例库 60 个案例中没有任何电商加购链路：与「抛物线/飞行」沾边的只有 `like-button`（双击点赞时心形碎片向四周迸发，是原地粒子爆裂、无目标点、无空间导航）与 `confetti-burst`/`fireworks`（庆祝粒子），活动池 IDEA-024 的穿梭框文档中仅出现过一次「不做夸张飞入」的否定性表述（其穿梭动效是列表内 FLIP 重排，与跨区域飞行无关）；全库更没有购物车、角标计数或加购反馈这一完整产品场景。本案例做一个纯原生、零依赖、零图片、零 CDN、双击离线即用的 Fly to Cart：以一个暗色精品电商商品网格为舞台，点击加购即生成商品缩略克隆体，沿可感知重力的抛物线飞向固定的购物车锚点，落点触发车包弹性承接与角标 +1，连点时多个飞行物排队/并行不冲突，并配一个真实可用的购物车抽屉（数量增减、行移除、合计联动）作为反馈闭环的落点；全程指针/键盘统一、`prefers-reduced-motion` 下降级为即时且语义完整的加购确认，遵循统一 HUD 规范。

## 预期展示效果

- **构图与整体风格**：
  - 案例视口是一个**拟真但克制的暗色电商精品店首页局部**：顶部一条细购物栏（左侧极简品牌字标，右侧固定的购物车图标按钮 + 数量角标），其下是 2×2 或网格排布的商品卡阵列（卡片含商品图、品名、简短规格、价格与一枚「加入购物车」按钮）；购物车图标是飞行轨迹的**唯一目标锚点**，位置固定、视觉可被瞬间找到。
  - 商品图全部由**纯 CSS 渐变/几何构造**（零外部图片），每张卡的配色与图形有区分度但共享同一套哑光材质语言；卡片为安静的深色玻璃/哑光面 + 极细描边 + 柔和大圆角，价格与按钮是仅有的两处高对比元素。
  - 延续项目克制的暗色审美：运动是主角，颜色只承担品类区分与「落点确认」的一次小面积强调（角标/车包承接的微光），拒绝满屏粒子、拖尾星光与高饱和霓虹的 AI Slop 廉价感；无任何图片、图标库、字体或网络请求，图标手写内联 SVG。
  - 桌面宽屏商品多列舒展，平板两列、手机单列或紧凑双列；购物车栏在视口缩放/滚动时始终可作为落点（顶栏吸附或飞行基于实时坐标计算），页面不横向溢出。
- **主要视觉元素**：
  - **抛物线飞行克隆体**：点击瞬间从商品图位置「取」出一个缩略克隆（FLIP 的 First：记录起点与车包终点的实时视口坐标），克隆体沿水平方向近似匀速逼近锚点、垂直方向先轻抬再受「重力」加速下坠的弧线飞行（Invert + Play：用 transform 位移/缩放驱动，可叠加轻微旋转与缩小，像被抛入车中），轨迹有明确弧度而非直线漂移；抵达锚点时克隆体收敛进车包并消失。
  - **落点承接反馈**：飞行物没入瞬间，购物车图标做一次小幅度弹性晃动/「吞入」缩放（像车包轻轻接住），数量角标以弹性过冲的方式更新（旧数淡出/被顶开、新数弹入），可配一次极克制的微光描边；多次连点时车包按每次落达连续轻晃、角标数字正确累加且动画从当前姿态接续，不错乱不丢数。
  - **购物车抽屉（反馈闭环落点）**：点击车包打开右侧/底部滑出抽屉，内含已加购商品行（小缩略图、品名、单价、步进器数量增减、行删除）、件数与合计金额实时联动；新飞入的商品对应行以短暂高亮/淡入就位表达「它刚到了」；空购物车有明确空态。抽屉是反馈的语义落点，不是装饰弹窗。
  - **加购按钮状态微反馈**：点击瞬间按钮自身有极短按压反馈，飞行期间可呈短暂「已加入」确认态后复原（允许连续加购同一商品），不使用阻塞式弹窗。
- **层次、材质、光影与关键细节**：
  - 视觉三层：暗色店铺舞台 → 商品卡阵列 → 飞行克隆体（最高层、脱离文档流、`pointer-events:none`，绝不干扰后续点击）；飞行物有明确的层级提升（阴影/缩放）让用户相信它「被拿起来了」。
  - 轨迹必须「讲物理」：弧线有一致的重力性格（先扬后落、水平收敛），多商品连点时各飞行物时长接近、按各自起点独立计算弧度（靠近车包的商品弧度小、远处弧度大），不出现直角折线、瞬移、透明度糊弄或终点对不准车包；飞行终点基于触发瞬间实时获取的车包位置计算，窗口/布局变化不导致飞偏。
  - 真实边界有明确反馈：快速连点同一/不同商品时，多个克隆体并行或错峰飞行互不覆盖、角标计数与抽屉数据严格等于真实加购次数（视觉运动与逻辑状态解耦——动画被中断或 reduced-motion 时数据仍正确）；飞行结束克隆体节点立即回收，不堆积 DOM；卸载时无悬挂 rAF / 定时器 / 监听。

> 设计文档约束最终体验与设计意图；商品卡数量、弧线曲率与飞行时长等具体数值、缓动曲线形态、克隆体缩放/旋转幅度、角标与车包动效的具体实现（rAF 手写 vs Web Animations API vs FLIP 工具式手写函数）、抽屉方向等由实现阶段按手感统一决定，不在此过早钉死。

## 动态与交互

- **触发方式（指针 / 键盘统一）**：
  - **指针加购**：点击/触控商品卡「加入购物车」按钮，立即生成克隆体沿抛物线飞向车包，落点触发承接与角标更新；触屏同样以 Pointer Events 统一处理，无 hover 依赖。
  - **键盘加购**：按钮原生可聚焦，Enter / Space 触发完全等价的加购流程；键盘场景下飞行克隆仍可呈现（轨迹基于几何坐标，不依赖指针位置），焦点始终停留在触发按钮上不被飞行物夺走。
  - **车包与抽屉**：点击车包按钮或键盘聚焦后 Enter/Space 打开购物车抽屉，Esc 关闭并把焦点归还车包；抽屉内步进器、删除按钮可 Tab 操作；抽屉打开不影响后台加购逻辑（可选：抽屉打开时加购，对应行直接高亮 +1）。
- **反馈节奏**：按钮按压（即时）→ 克隆体起飞（0 延迟或极短延迟，连点不排队阻塞）→ 弧线飞行（半秒级，视距离可有自然差异）→ 落点承接 + 角标弹性 +1（与克隆体没入严格对齐）→ 抽屉内行就位高亮；整条链路总时长克制，不做夸张慢动作。
- **连点与状态正确性**：逻辑购物车数据（商品 id → 数量、件数、合计）是唯一事实源，飞行动画只是它的可视化；连点、快速切换商品、飞行途中再点、reduced-motion 降级、抽屉打开中加购等任何路径下，角标、步进器、合计与数据严格一致，不出现多飞一次而数量没加、或动画中断导致数据丢失。
- **可访问性**：
  - 加购结果以非视觉方式可达：使用 `aria-live` 礼貌播报（如「已加入购物车，当前 N 件」，注意连点时播报节流/合并，不刷屏）；车包按钮带显式 `aria-label`（含当前件数），角标不仅靠颜色传达数量。
  - 飞行克隆体对辅助技术隐藏（`aria-hidden`），reduced-motion 用户与屏幕阅读器用户获得的是即时、语义完整的加购确认而非信息缺失；抽屉具备 `dialog`/`aria-modal` 语义、焦点陷阱与焦点归还。
- **减弱动效与移动端**：
  - 尊重 `prefers-reduced-motion`：关闭抛物线飞行、车包晃动与弹性角标，加购后角标即时更新为正确数字（可保留一次极轻的颜色/描边确认），抽屉行即时就位，购物车数据、键盘、播报、抽屉操作 100% 保留。
  - 移动端热区充分、抽屉以合适方向滑出、页面不横向溢出；飞行坐标在滚动/视口变化下仍准确命中车包。
- **生命周期**：飞行动画使用统一时间驱动（rAF 或 WAAPI），克隆体在动画结束或被中断（页面隐藏/卸载）时立即移除；页面隐藏或案例卸载时取消在途动画与所有监听/定时器，无 DOM 堆积与泄漏。
- **可选 Micro-HUD**（默认折叠，`H` / `Esc` 切换、事件防穿透）：实时显示购物车数据（总件数、各商品数量、合计）、当前在途飞行物数量、reduced-motion 是否生效、最近一次落点是否命中，便于验证「视觉运动与逻辑状态始终一致」；非必需时至少保留右上角 Title 胶囊。

## 核心亮点

1. **补齐电商加购链路与空间连续性反馈的空白**：库内 60 个案例无任何购物车/加购场景；`like-button` 是原地碎片迸发（无目标锚点、无空间叙事），`confetti-burst`/`fireworks` 是纯庆祝粒子，活动池 IDEA-024 仅以否定句提及「不做夸张飞入」（其为列表内 FLIP 重排）。本案例首次把「操作 → 抛物线飞行 → 落点承接 → 数量结果」这条生产高频反馈闭环完整做成展品，命中技术域 2（微交互与光影动效）× 技术域 5（按钮交互）的交叉空白。
2. **FLIP + 重力弧线的技术展示性**：起止坐标实时测量、只动 transform/opacity 的合成友好飞行、水平收敛 × 垂直加速的可信抛物线、多飞行物并行与落点对齐——是讲解 FLIP 与空间连续性动画最经典的可运行样本，轨迹手感（先扬后落、近小远大）肉眼可辨。
3. **真实闭环而非动画摆拍**：落点不是纯特效——配有数据驱动的购物车抽屉（步进器、行删除、空态、件数与合计联动），角标与抽屉是同一事实源的两个视图；新到商品行高亮就位，反馈有始有终。
4. **「运动与状态解耦」的工程严谨性**：连点、中断、reduced-motion、抽屉打开中等边界路径下数据绝不丢、不重、动画可降级而结果语义完整；克隆体用完即回收，无 DOM 堆积；`aria-live` 节流播报让非视觉用户同样获得「加购成功、共几件」的确认。
5. **零资源纯手工**：商品图纯 CSS 渐变/几何构造、图标手写内联 SVG，零图片零图标库零 CDN，断网双击即可完整加购、开抽屉与结算演示。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库、零图标库/图标字体、零 CDN、零外部图片（商品图以 CSS 渐变/几何构造，图标手写内联 SVG），双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 飞行动画只使用合成友好的 `transform` / `opacity` 驱动，起止位置在触发瞬间实时测量（商品缩略图起点、车包锚点终点），轨迹具备一致的重力抛物线性格（先扬后落、水平收敛、近小远大），终点必须准确命中车包；克隆体脱离文档流、最高层级、`pointer-events:none` 且 `aria-hidden`，动画结束或中断立即回收，禁止 DOM 堆积。
- 购物车数据（商品/数量/件数/合计）必须是唯一事实源，角标与抽屉为其视图；连点、动画中断、reduced-motion、抽屉打开中加购等任何路径下数据不丢不重，视觉运动与逻辑状态解耦；页面隐藏或卸载时取消在途动画并清理全部监听/rAF/定时器。
- 指针与键盘统一（Pointer Events + 原生 button 的 Enter/Space），焦点不被飞行物夺走；车包以 `aria-label` 表达件数，加购结果通过节流/合并的 `aria-live` 播报；抽屉具备 dialog 语义、焦点陷阱、Esc 关闭与焦点归还。
- 尊重 `prefers-reduced-motion`：关闭抛物线、车包晃动与弹性角标，角标即时更新为正确数字、抽屉行即时就位，数据/键盘/播报/抽屉逻辑完整保留。
- 视觉为暗色哑光克制的精品电商风格，状态色小面积低饱和，拒绝粒子拖尾霓虹廉价感；桌面/平板/手机视口自适应不横向溢出，车包锚点在滚动/缩放时仍可被准确命中，移动端触控热区充分。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊（强制）；如需参数/状态观察（购物车数据、在途飞行物数、reduced-motion、命中情况）使用默认折叠的 Micro-HUD（`H` / `Esc`、事件防穿透）。
