## 创意概述

下载/提交类 CTA 的「空闲 → 进行中 → 完成」状态切换是网页里最常见的反馈断点之一：普通做法是按钮文案在「下载 / 下载中… / 已下载」之间生硬跳变，进度条另起一个控件，状态之间没有视觉连续性。本案例做一个纯原生、零依赖、可直接投产的**多状态液态形变下载按钮**：点击后胶囊按钮内部的液体（由 SVG `feGaussianBlur` + `feColorMatrix` 合成的 Gooey 滤镜驱动）像被注入一样升起、填充，液面随进度起伏并挂着融合的圆形气泡；按钮同步从「下载 + 下载图标」收缩形变为进度胶囊，图标形变为停止/取消语义；进度到 100% 时液面漫过整体、以一次「咕嘟」回弹把按钮形变为成功态（对勾描边 + 颜色语义变化），随后可复位再下载；并演示一个受控的失败/重试分支。它是项目第 8 大技术域（SVG 滤镜与形态形变）的独立代表作——历史上 gooey 仅作为胶囊标签切换器内部的一个变体出现，从未有「以液体融合为核心语言、贯穿一个完整任务状态机」的组件。

## 预期展示效果

- **构图与整体风格**：
  - 用一个**拟真的文件下载场景**承载（推荐「资源卡片 / 导出面板」mock：1 个主下载按钮 + 文件名、体积、预计耗时等元信息，旁置 1–2 个可选资源行可切换演示），避免按钮孤立悬浮；整体延续项目深色玻璃质感、圆角胶囊、柔和投影与克制留白的语言。
  - 主控件为一个横置胶囊（pill）按钮，初始态左图标右文案；进入进行态后宽度可收缩为更紧凑的进度胶囊（液体填充占主体、百分比数字叠加其上），完成态再展开或原地切换为成功胶囊。整个按钮是唯一的视觉主角，其余 mock 元素低调衬托。
  - 场景中可并列放置一个「弱网/失败模拟」开关或第二个资源，让成功与失败两条状态分支都能被看到，但默认演示走成功路径。
- **主要视觉元素**：
  - **液体与气泡（核心）**：按钮体内底部一整块「液体」由若干圆形/椭圆 blob 组成，统一施加内联 SVG Gooey 滤镜（高斯模糊 + 对比度/alpha 阈值矩阵），相邻 blob 接触时自然融合出黏稠的液面与拉丝；液面随进度上升，顶部 blob 做缓慢的水平漂移与轻微起伏，进度推进时可从底部「吐出」新的气泡上浮并在液面融合。
  - **状态图标形变**：左侧下载图标（向下箭头 + 托盘的描边）在点击时形变为进行态的停止/暂停语义（如竖条或 ×，用同一套内联 SVG 路径形变/旋转完成，而非切图）；完成时再形变为对勾描边（对勾以描边生长 `stroke-dashoffset` 方式画出）。
  - **进度数字**：百分比以等宽数字（tabular-nums）叠加在液面上下，随液面越过数字时自动做颜色反色/裁切，保证在液体与底色上都清晰；数字跳动用轻微滚动而非硬切。
  - **成功语义**：100% 瞬间液面做一次轻微过冲（略高于顶边）再回弹落定，对勾描边生长，按钮呈现克制的成功色（不使用彩带/烟花）；复位时液体以一次「退潮」收干，图标回到下载态。
- **层次、材质、光影与关键细节**：
  - 液体使用有明度层次的同色系填充（主体色 + 顶部高光 blob + 内阴影），营造「装在玻璃胶囊里的液体」而非一块平涂色；按钮体本身保持半透明玻璃与内描边，液体在其下层被 `overflow`/圆角裁切。
  - 投影在按下、进行、完成三态间做细微层级变化（按下下沉、进行态稳定、成功态轻提一下），动效统一使用短促的弹性/阻尼缓动，与项目 spring 语言一致。
  - Gooey 的模糊半径与 alpha 阈值需调到既融合又不发虚、文字不被滤镜波及（滤镜只作用于液体层，图标与文字在滤镜外单独渲染）；液体动画始终在按钮几何边界内，不产生锯齿毛边或越界。
  - 失败分支：进度停在某值、液面停止起伏并轻微回落一点，按钮转为克制的警示色与「重试」图标，可点击重新从 0（或从断点）开始；不弹刺眼红屏。
  - 右上角固定点阵色 Title 胶囊（统一 HUD 规范）。

## 动态与交互

- **触发（多路径）**：指针点击主按钮启动一次模拟下载（纯前端定时器/进度推进，不产生真实网络请求；可选地用真实生成的 Blob + `URL.createObjectURL` 触发一次本地下载以增强真实感，但不依赖网络）；进行态再次点击为取消（液面退潮、回到空闲态）；失败态点击为重试。
- **进度与液体编排**：进度非线性推进（起步稍快、中段可带轻微停顿模拟分块、末段平滑收敛），液体高度与百分比实时绑定；blob 漂移/气泡上浮用独立的循环动画，与进度解耦，使任何进度值下液体都是「活」的；100% 触发过冲—回弹—对勾生长的收束编排。
- **键盘**：按钮为标准可聚焦控件（原生 `<button>`），`Enter`/`Space` 启动、进行中 `Enter`/`Space` 取消、成功/失败态再次按键复位或重试；焦点环 `focus-visible` 清晰且独立于 hover；模拟进行期间不锁定页面其余键盘操作。
- **可访问性**：按钮在不同状态通过 `aria-busy`（进行中）、`aria-live` 的状态文本（如「下载中 42%」「下载完成」「下载失败，可重试」）对读屏播报进度与结果，可见百分比不承担唯一语义；状态切换不依赖颜色 alone（有图标与文案）；动效遵循 `prefers-reduced-motion`——关闭液体漂移、气泡与过冲弹性，改为高度随进度线性变化 + 即时/淡入淡出的状态切换，功能与状态语义完整。
- **可选 Micro-HUD**：默认折叠的统一 Micro-HUD（`H`/`Esc` 切换、事件防穿透），可调节液体速度/粘稠度（模糊与阈值）、切换失败分支开关、减弱动效开关；非必需时至少保留右上角 Title 胶囊。
- 移动端触控热区达标；窄屏下胶囊文案可精简为图标 + 百分比但不溢出、不错位；窗口缩放/旋转时液体裁切边界正确。

## 核心亮点

1. **以 Gooey 液体为核心语言贯穿完整任务状态机**：不是一个静态「液体按钮好看」，而是让液态填充在「空闲 → 进行（含取消/失败）→ 成功 → 复位」全过程连续叙事，液面即进度、气泡即活性、过冲回弹即完成反馈，状态之间零硬切。
2. **填补第 8 技术域的独立案例空白**：全仓 SVG 滤镜/形变仅在 capsule-tabs 内作为标签指示器的一个变体出现；本案例把 `feGaussianBlur + feColorMatrix` Gooey 合成、内联 SVG 路径形变与描边生长做深做透，成为该域可被直接复用的代表作。
3. **生产可用的 CTA 原语**：下载/导出/生成类按钮是高频真实需求，组件以拟真资源卡承载、可接真实 Blob 下载，具备取消、失败重试、完成复位的完整工程分支，而非一次性动效 demo。
4. **质感与可访问性兼顾**：玻璃胶囊 + 分层液体 + 过冲回弹保证无 AI Slop 廉价感，同时 `aria-busy`/`aria-live` 进度播报、等宽数字反色、图标+文案双编码、reduced-motion 降级让视觉炫技不牺牲可达性。

- **相似案例**：
  - `capsule-tabs`（胶囊标签动效展厅）：全仓**唯一**出现 SVG Gooey（`feGaussianBlur stdDeviation=5` + `feColorMatrix` alpha 阈值）的案例，但其 gooey 仅用于「滑动高亮胶囊与两端圆形融合」这一标签指示器变体，服务的是**标签切换的选中指示**；本案例把 gooey 用作**随进度升降的液体填充 + 气泡融合**，并承载下载任务的多状态机，核心创意、视觉主体与交互模型均不同。
  - `button`（现代按钮系统）：波纹、锥形渐变炫光边框、霓虹、毛玻璃四种**无状态/点击瞬间**按钮样式，无进行/完成状态机、无液体填充与进度。
  - `top-loading-bar`（顶部加载进度条）：trickle 推进的**顶部细条**路由进度，无按钮容器、无 gooey 液体、无图标形变与成功/失败分支。
  - `scroll-progress-bar`（阅读进度条）：顶部 `scaleX` 阅读进度 + 章节导航，是滚动位置指示而非任务状态按钮。
  - `file-dropzone`（拖拽上传区）：上传面板，含模拟进度与缩略图，但主体是**拖放区域与文件列表**，不是单一液态形变 CTA，也不使用 SVG gooey。
  - `range-slider` / `image-comparison-slider`：同为「滑块/进度」类控件，但服务区间选择与图片对比，与液体按钮无关。
  - `menu-morph`（汉堡形变导航）：有 SVG/线条形变，但是**汉堡 ↔ 关闭图标 + 全屏导航**，非液体、非任务进度。
  - 活动池中 `IDEA-001~006`（Date Picker、Carousel、Toast、Tags Input、Step Wizard、FAB Speed Dial）：分别为日期选择、内容轮播、轻提示、多值输入、多步流程容器、角部收纳动作菜单，均非液态进度 CTA；其中 Step Wizard 是多步表单容器、Toast 是被动轻提示，与本按钮无重叠。
- **差异说明**：核心创意是**「Gooey 液体填充即进度的多状态下载 CTA，液体在 空闲/进行/取消/失败/成功/复位 状态机中连续形变叙事」**。与最接近的 capsule-tabs（gooey 仅作标签指示器 vs 液体作为唯一进度语言 + 完整任务状态机）、button（无状态样式集合 vs 多状态形变）、top-loading-bar（页外细条 vs 按钮内液体 + 图标形变 + 成败分支）在核心创意、视觉表达（玻璃胶囊内分层液体、融合气泡、图标路径形变、对勾描边生长、数字反色）、交互方式（启动/取消/重试/复位、进度实时绑定、aria 进度播报）与整体表现上均有实质差异，不属于换色、换文案或微调参数类重复。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生零 CDN、双击 index.html 独立离线运行（通用项目铁律，详情不重复）。
- Gooey 滤镜以**内联 SVG filter**（feGaussianBlur + feColorMatrix）实现并本地定义，不引用外部 SVG/库；滤镜只作用于液体层，文字与图标不被滤镜模糊；液体被按钮圆角边界裁切，任何进度下不越界、无明显毛边。
- 状态机为单一可信来源（idle / loading / success / error，含取消与复位/重试），过渡进行中重复触发（连点/连按）以状态机判定为准，避免液体高度、百分比与图标状态错乱；动画优先使用 transform/opacity/高度等合成友好属性，并在卸载/切换案例时清理定时器、rAF 与任何音频上下文（如启用可选触感音效，须手势懒激活）。
- 进度为纯前端模拟、不依赖网络；如触发本地文件下载，使用运行时生成的 Blob + objectURL 并在用后 revoke，不内置外部资源。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊；如需参数控制（液体速度/粘稠度、失败分支、减弱动效），使用默认折叠的 Micro-HUD（`H`/`Esc`、事件防穿透）。
- 尊重 `prefers-reduced-motion`；窄屏触控热区达标；百分比使用等宽数字并在液面上下保持对比度。
