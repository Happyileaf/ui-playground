## 创意概述

做一套编辑设计 / 品牌落地页里最常见、最被验证的高级文案手法——**滚动联动的逐词点亮排版**：一段或多段大字号宣言式文案（manifesto copy）纵向铺在可滚动页面上，随着文案穿过视口，其中的词按阅读进度**连续、可正反向、任意时刻定格自洽地**从「未读的弱化态」过渡到「已读的点亮态」（对比度提升、可叠加极轻微的上浮 / 字距 / 模糊去除），就像阅读时注意力被逐词点亮。它不是元素一次性淡入，也不是打字机式按时间吐字，而是**滚动位置与每个词的显影进度一一映射**的连续 scrub：滚到哪里亮到哪里，停住即定格，往回滚沿原路径退回，刷新后同一位置呈现同一状态。

解决的核心体验问题：高端品牌页、产品发布文案、SaaS 首页 Hero 之下的「价值主张长文案」、杂志化专题与年报页面，普遍用这种低成本、高质感的排版动效引导视线、强化叙事节奏（实用性极高、可直接落地生产网页），但当前案例库 60 个注册案例与在池 47 个 Ready 中**没有任何以文字逐词为单位、由滚动连续驱动的排版动效**：最接近的 `scroll-reveal` 是元素级一次性入场（上移/缩放/滑入/模糊，进视口播放一次即解除观察），`typewriter` / 在池 IDEA-037 乱码解码是按时间播放的字符动效，在池 IDEA-040 滚动叙事产品页虽同为 scroll-scrub，主体却是 sticky 定格舞台上的产品多图层编排而非排版本身。本案例聚焦「把一段真实文案做成可滚动阅读的显影排版」，并提供一组可切换的显影风格（明度点亮 / 模糊去焦 / 遮罩擦入 / 逐词上浮），既是即取即用的落地组件，也是能直观对比不同文字显影语言的排版展厅。

## 预期展示效果

- **构图与整体风格**：
  - 一个纵向滚动的编辑式排版页面：上方为简短引导，其下依次排列 3～5 个**全屏或大半屏高的文案段（verse）**，每段是一整块大字号展示文案（display type），短句断行讲究、留白充分，文案块在视口中下部到中部之间完成显影；段与段之间有呼吸留白与极细分隔或小号段标（如 `01 / 宣言`），形成「一章一句」的阅读节奏。
  - 延续项目暗色、低饱和、Anti-Slop 审美：近黑 / 深炭底，未读词为低对比中性灰（克制、不发脏），已读词点亮为高明度近白并带极克制的强调色倾向（仅在个别关键词或整段点亮收尾时轻微着色，拒绝整屏彩虹与霓虹）；排版用系统无衬线 / 系统字体栈，字号大、字重对比明确、行高舒适，强调编辑设计感而非特效堆砌。
  - 右上角固定项目统一的点阵色 Title 胶囊；默认折叠的 Micro-HUD 提供显影风格切换、逐词 / 逐字粒度切换、过渡软硬（每词显影区间宽度）调节与减弱动效状态显示，便于观察同一文案在不同显影语言下的差异。
- **主要视觉元素**：
  - **词单元**：加载后由脚本把每段文案智能切分为以词为单位的 inline 元素（保留原始空白、换行与标点归属，中文按字符 / 语义断行、西文按空格分词，标点不独立跳动），每个词单元的显影状态由其在滚动进度中的位置决定。
  - **显影进度带**：视口侧边或段落边缘可有一条极细的、随当前段进度填充的阅读进度指示（可选、克制），段标随当前段切换；它只是附属指示，主体始终是文字本身。
  - **多种显影风格（可切换的展厅属性）**：
    - 明度点亮（默认）：未读低对比灰 → 已读高明度，当前正在经过的词处于中间过渡，形成一道随滚动下移的「亮词边界」；
    - 模糊去焦：未读词轻微虚化 + 低透明 → 已读清晰，营造对焦感；
    - 遮罩擦入：每个词内部以渐变遮罩 / 裁剪沿阅读方向被擦亮（文字本身不位移，靠遮罩过渡）；
    - 逐词上浮：词由极小的下移 + 透明差值归位（幅度小、成组连续，而非整段一次性入场）。
  - **关键词强调（可选细节）**：文案中可标记少量关键词，在其被点亮时呈现更亮字重或一次克制的强调色 / 下划线生长，作为叙事重音，但不改变逐词显影的总体机制。
- **层次、材质、光影与关键细节**：
  - 层次极简：背景（最底）→ 大字号文案（绝对主体）→ 段标 / 进度（附属指示）→ Title 胶囊 / HUD（固定层）；视觉张力全部来自排版、对比与显影节奏，不依赖任何图片 / 粒子。
  - **显影必须连续且确定性是底线**：每个词的显影量是「段落元素相对视口的滚动进度」映射到词序列的连续值（含过渡带内的插值），正滚、倒滚、刷新、跳转到任意锚点后同一滚动位置呈现完全一致的显影状态；不允许进入视口后改由 CSS 无限动画自行播放导致与滚动位置脱钩，也不允许累积型 transform。
  - 过渡边界干净：相邻词在过渡带内自然交叠，亮 / 暗边界随滚动平滑移动而无逐词硬跳（可通过每词的区间宽度与缓动调节软硬）；仅写不触发布局的属性（透明度 / 滤镜 / transform / CSS 变量），长段文案在移动端同样顺滑、无明显掉帧。

> 设计文档约束最终体验与设计意图；具体文案内容与段数、分词策略的中西文细节、每词显影区间与缓动参数、是否启用进度带与关键词强调、HUD 暴露哪些档位，由实现阶段按排版节奏与手感统一决定，不在此过早钉死；但「真实文档纵向滚动 → 每段相对视口进度 → 逐词连续显影、正反向任意帧自洽 → 多风格可切换、reduced-motion 下文案完整可读」这条链路必须真实成立，不允许用一次性入场动画或按时间播放的字符动画冒充滚动联动排版。

## 动态与交互

- **触发方式（滚动主导，非自动播放）**：
  - 滚轮 / 触控板 / 触屏纵向滑动走浏览器**原生文档滚动**（真实文档高度，不用 transform 伪造滚动、不锁页面、不禁断默认行为）；文案段随页面正常流动，不强制 sticky 定格（与 IDEA-040 的定格舞台明确区分），词的显影由该段相对视口的位置连续驱动。
  - 键盘 PageDown/PageUp/Space/方向键为浏览器原生滚动即自然 scrub；段标 / 进度指示可作为锚点，Tab 聚焦后 Enter 用 `scrollIntoView` 跳到对应段，焦点环可见。
- **滚动联动求值（核心逻辑）**：
  - 一个 `requestAnimationFrame` 循环（可配合滚动方向节流 / 仅在有段处于激活区间时更新）读取各文案段相对视口的位置，将「段进入激活区 → 离开激活区」归一化为 0→1 进度，再按词序号与每词显影区间（含可调的过渡带宽 / 软硬）映射为每个词的显影量；切换标签页（visibilitychange）或卸载时取消 rAF，回到页面后从真实滚动位置重新求值，状态不漂。
  - 同帧内完成读 / 写，写仅作用于不触发布局的属性或少量 CSS 变量；可选极轻 Lerp 阻尼，但滚动停止后必须收敛到真实进度，不长期漂移。
  - 不做任何自动播放 / 自动轮播：首屏停在初始态，文案只能被用户自身的滚动 / 锚点跳转点亮；正滚逐词点亮、倒滚逐词回退、中途停手即在该帧定格。
- **风格与参数控制（Micro-HUD，默认折叠，`H`/`Esc` 切换、事件防穿透）**：
  - 在明度点亮 / 模糊去焦 / 遮罩擦入 / 逐词上浮至少四种显影风格间实时切换，同一段文案立即以新语言重新显影，便于横向对比；
  - 可切换逐词 / 逐字（中文按字）粒度、调节每词过渡区间（显影软硬 / 一次点亮的词数）、显隐侧边进度带与关键词强调；实时显示当前激活段索引 / 段进度与 reduced-motion 生效状态。
- **可访问性（一等路径）**：
  - 文案必须是真实、完整、可选择 / 可被屏幕阅读器朗读的文本（仅在外层包裹词元素，不破坏语义与复制），未读态的对比度降低不得低于正常可读下限或配合 `prefers-reduced-motion` / 无 JS 时整段直接全亮，**保证任何情况下文案都可完整阅读**；提供 `aria-hidden` 装饰层与可读原文分离等合理处理，不让朗读重复每个词。
  - `prefers-reduced-motion: reduce`（或 HUD 关闭动效）时，取消逐词连续显影与位移 / 模糊 / 遮罩过渡，文案以正常静态排版全部可读呈现（可保留极轻的一次性整体显现或直接全亮），锚点导航与键盘浏览完整保留——信息获取零损失。
  - 文字 / 控件对比度达 WCAG AA，焦点可见，当前段 / 激活状态不仅靠颜色（辅以段标、进度、字重等多重编码）。
- **移动端与触控**：手机纵向滑动即原生 scrub，文案字号 / 断行 / 行距响应式重排后仍逐词正确映射（视口变化后重新计算各段区间，不错位、不跳词）；触控不与锚点点按冲突，三视口下排版不横向溢出、不显影错乱；HUD 与胶囊不遮挡核心文案。
- **生命周期**：案例卸载（iframe 销毁）/ 页面隐藏时取消 rAF 与全部监听；重新进入从干净状态、真实滚动位置开始；不产生持续后台动画或音频（本案例无音频）。

## 核心亮点

1. **真实高频的落地排版组件**：滚动逐词点亮是品牌站、产品发布文案、SaaS 价值主张与杂志化专题里被大量验证的高级文案手法，可直接用于生产网页引导阅读、强化叙事（实用性 5 分）；库内 60 案例 + 在池 47 Ready 无一覆盖「文字逐词 × 滚动连续显影」这一具体形态。
2. **连续、确定性的逐词显影，而非一次性入场 / 定时吐字**：每个词的显影量是段落滚动进度的连续函数，正放、倒放、刷新、锚点跳转到任意位置都自洽，亮词边界随滚动平滑移动；与 `scroll-reveal`（元素一次性入场）、`typewriter` / IDEA-037（按时间播放字符）有本质机制区别。
3. **可横向对比的显影语言展厅**：同一真实文案可在明度点亮 / 模糊去焦 / 遮罩擦入 / 逐词上浮间实时切换，并调节粒度与过渡软硬，把抽象的「文字显影手感」做成可感知、可比较、可直接拷贝用法的互动展台，兼具组件与教学价值。
4. **零资源、纯排版的高级感与工程鲁棒**：不依赖任何图片 / 字体 / 三方库，仅以系统字体、对比与遮罩 / 滤镜即可呈现编辑设计质感；中西文分词、同帧 rAF 只写合成层属性、视口变化重算、切后台 / 卸载回收，保证长文案在桌面与移动端都顺滑稳定。
5. **可读性优先的可访问性设计**：文案始终真实完整存在，未读态不低于可读下限，reduced-motion / 无 JS 下整段静态全亮、信息零损失，锚点键盘导航与多重状态编码完整，符合项目铁律与 Anti-Slop 准则。

- **检查范围**：`src/playground.js` 全部 60 个注册案例（id / 标题 / 描述）+ `playground/effects`（12）、`playground/components`（45）、`playground/pages`（3）物理目录 + 活动池 IDEA-001～IDEA-047（全部 Ready）+ `rejected.md`（当前为空）+ `completed.md`（当前为空）；另全仓 / 全详情检索 `scroll / scrub / 逐词 / 逐字 / kinetic / 排版 / 高亮 / text highlight / mask reveal` 等关键词。
- **相似案例**：
  - `scroll-reveal`（滚动入场揭示，effects）：机制最接近的滚动文字动效。它以 IntersectionObserver 监听**整个元素**进入视口，加 class 播放**一次性**入场（上移 / 缩放 / 左右滑入 / 模糊四形态），播完即 `unobserve`；无「词」粒度、无连续进度、不能倒放、无逐词亮 / 暗边界，整段文字是同时显现。本案例以**词为最小单位**、由段落相对视口进度**连续映射**显影量，正反向任意帧自洽，并提供多显影风格与参数实时切换；两者是「元素触发式一次性补间」与「逐词连续 scrub 时间线」的本质差异。
  - `typewriter`（打字机文字，effects）与在池 **IDEA-037 文本乱码解码器**：同属文字逐字符动效，但二者都由**时间 / 重播驱动**（按固定节奏打字删除、逐字符随机解码），与滚动位置无关、不可随滚动正反向逐帧联动；本案例的进度输入是原生滚动而非计时器，且主体是大段展示文案的显影排版，不是单行字符序列播放。
  - 在池 **IDEA-040 滚动叙事产品页**：同属 scroll-scrubbed、同样强调「滚动位置 ↔ 状态连续映射、任意帧自洽」，是机制气质上最相近的一项。但其主体是 `position: sticky` **定格舞台上纯 CSS/SVG 产品的 3D 姿态、屏幕点亮、描边仪表与卖点标注多图层编排**，文案只是附属标注；本案例不做定格舞台、不构造产品，页面正常纵向流动，**主体与唯一焦点就是逐词显影的文字排版本身**，并以多显影风格展厅为落点——核心创意（可阅读的显影排版 vs 产品多图层叙事）、视觉对象（大字号文字 vs 拟物产品 + 引导线标注）与页面结构（非定格的编辑长文 vs sticky 一镜到底舞台）均不同。
  - `scroll-progress-bar`（阅读进度条 / 章节圆点 / 回顶）、`vertical-timeline`（时间线卡片揭示）：含滚动进度或滚动触发，但前者进度是**只读指示物**、不驱动任何文字状态，后者是事件卡片的一次性 IO 入场与脊柱填充；均无逐词排版显影。
  - `count-up`（进视口一次的数字爬升）、`logo-marquee`（CSS 无缝跑马灯）、`glitch-text` / `particle-text`（故障 / 粒子化文字特效）、`breathing-dot`（状态指示）：或为一次性触发、或为与滚动无关的自动 / 指针文字特效，均不消费滚动连续进度，也不服务于「阅读一段文案逐词点亮」的叙事场景。
  - 其余注册案例与在池 IDEA 经逐条核对均无「文字逐词 × 滚动连续显影」语义；确认无历史（含已删除）`scroll-kinetic-type` id 或物理目录冲突，`rejected.md` / `completed.md` 当前为空，无淘汰 / 完成项需规避。
- **差异说明**：核心创意是「**以真实文案的词为最小单位，把每段文字相对视口的滚动进度连续映射为逐词显影量（正反向 / 任意帧自洽），并提供明度点亮 / 模糊去焦 / 遮罩擦入 / 逐词上浮多语言可切换的纯排版动效**」。差异同时体现在核心创意（逐词连续显影排版 vs 元素一次性入场 vs 定时字符播放 vs 产品定格舞台）、视觉表达（大字号编辑排版 × 亮词边界 × 零资源对比质感）、交互方式（原生滚动 scrub + 锚点跳段 + HUD 风格 / 粒度 / 软硬实时切换，可正放倒放任意帧停留）与整体表现（可直接落地品牌 / 产品长文案的非定格滚动排版页）；不属于仅换颜色、文案或微调参数的重复。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库、零图标库 / 字体库 / CDN、零外部图片 / 音频；排版使用系统字体栈，图标（若有）内联 SVG；双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 文案必须是 DOM 中真实、完整、可选择与可朗读的文本；分词在加载后由脚本将原文切分为词 / 字单元包裹，须正确处理中西文分词、空白、换行与标点归属，不破坏复制与语义。
- 显影必须基于**原生文档滚动**（不强制 sticky、不 transform 伪造滚动、不锁页 / 不阻止默认滚动），由 rAF 读取段落相对视口进度连续求值，仅写 transform / opacity / filter / CSS 变量等不触发布局的属性；同一滚动位置在正放、倒放、刷新、锚点跳转后呈现一致状态，无累积漂移、无停止后脱钩自走；可选阻尼在滚动停止后必须收敛。
- 故事推进只能由用户输入驱动（滚轮 / 触屏原生滚动、键盘原生滚动、锚点跳转、HUD 切换），**不得自动播放**；visibilitychange / 卸载时取消 rAF、释放监听，无后台动画泄漏；本案例无音频。
- 至少提供明度点亮 / 模糊去焦 / 遮罩擦入 / 逐词上浮四种可实时切换的显影风格，并支持粒度（逐词 / 逐字）与每词过渡区间（软硬）调节；未读态对比度不得低于正常可读下限，无 JS 或 `prefers-reduced-motion: reduce` 时文案完整静态全亮、信息零损失，锚点与键盘浏览保留；移动端三视口响应式重排后逐词映射正确、视口变化实时重算、不横向溢出。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊（强制）；风格切换、粒度、过渡软硬、进度带 / 关键词强调显隐、当前段 / 进度与 reduced-motion 状态等通过默认折叠的 Micro-HUD 提供（`H`/`Esc`、事件防穿透）。
