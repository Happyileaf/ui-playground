## 创意概述

一个落地页 / 营销页中高频出现的「磁吸 CTA（Magnetic Call-To-Action）」交互系统：当指针进入可交互元素周围的引力场时，元素不是静止等待点击，而是被指针「吸引」——整体沿指针方向平滑位移、轻微形变趋附，内部文字 / 图标以不同强度做分层视差，营造「按钮有生命、主动迎向你」的高级触感；指针离开后以带回弹的弹簧曲线归位。组件以一个主 CTA 为核心，配以同一套磁吸原语驱动的次级磁吸元素（图标按钮、链接胶囊、导航项等），并提供引力强度 / 吸附半径 / 弹簧手感的可视化对比，而非单一按钮的一次性特效。

解决的体验问题：普通 CTA 在悬停时往往只有换色、放大等扁平反馈，缺乏「界面在回应我」的空间纵深感与操作邀请感；磁吸微交互是当前高端产品发布页（如 Apple、SaaS Hero 区）最常用的精致细节之一，能显著提升点击欲与页面质感，而当前案例库尚缺这种「以元素本体为主体、对靠近指针产生引力响应」的组件——现有跟随光标类案例改写的是全局光标，并非被操作的目标元素。

## 预期展示效果

- **构图与整体风格**：
  - 单屏呈现一个深色高级质感的 Hero / 行动区：居中或视觉重心处放置一枚体量饱满的主磁吸 CTA（胶囊或圆角矩形主按钮，内含文字 + 箭头 / 图标），周围错落布置若干次级磁吸目标（圆形图标按钮、文字链接胶囊、导航 / 工具项），形成一个「可被指针引力牵动的交互场」。
  - 画面保持克制留白，磁吸元素在静止时是规整、可信的界面控件；一旦指针进入引力场，元素才被「唤醒」产生位移与内部视差，动与静形成对比，避免满屏乱飘的廉价感。
  - 顶部保留项目统一的点阵色 Title 胶囊，可配默认折叠的 Micro-HUD 控制引力强度 / 半径 / 是否启用，便于对比不同手感。
- **主要视觉元素**：
  - 主 CTA：高辨识主色填充、清晰文字标签、一枚内联 SVG 箭头或图标；悬停磁吸时内部文字与图标分层移动（如图标位移幅度更大、文字略随）。
  - 次级磁吸目标：描边 / 玻璃质感的图标按钮、下划线链接胶囊等，各自有独立但统一语言的磁吸强度。
  - 引力场的可选可视化（仅在调试 / 演示态）：指针进入吸附半径时元素边缘出现极轻的高光或一圈柔光，暗示「已被捕获」；常态下不显示任何辅助圈。
- **层次、材质、光影与关键细节**：
  - 被吸附的元素带轻微投影，位移时投影方向 / 柔化度随偏移微调，强化「被提起、迎向指针」的层级感，而非平面平移。
  - 内部内容分层视差：外壳、文字、图标按不同系数（外壳最弱、图标最强）响应指针，形成微妙的纵深；靠近引力场中心时趋附更明显，边界处平滑衰减，不出现突变。
  - 按下（active）时整体轻微收缩、回弹更紧，给出明确的点击确认；离开引力场后以弹簧曲线（轻微过冲）归位，所有磁吸元素归位节奏统一而不机械。

> 设计文档约束最终体验与设计意图；具体的引力半径、位移系数、弹簧参数、色值与元素数量由实现阶段按整体视觉统一决定，不在此过早钉死。

## 动态与交互

- **触发方式（Pointer Events 统一鼠标 / 触控 / 手写笔）**：
  - 指针在元素吸附半径内移动时，实时计算指针相对元素中心的偏移，元素整体与内部各层按各自强度做带阻尼 / lerp 的平滑跟移（非硬绑定，有惯性迟滞感），越靠近中心吸引越强。
  - 指针离开吸附半径：停止吸引，元素以带回弹的弹簧动画归位，内部文字 / 图标各自回正。
  - 点击：主 CTA 与次级目标都是真实可激活的控件（按钮 / 链接语义），磁吸只改变视觉位置、不影响命中与功能；按下有收缩反馈，激活可触发示意性的状态变化或页面锚点。
- **多目标与手感对比**：同一页面多枚磁吸目标各自独立计算、互不干扰；可提供主 CTA 与一枚「关闭磁吸 / 仅颜色悬停」的对照，或强度档位，直观展示磁吸带来的差异。
- **键盘与可访问性**：
  - 磁吸行为是纯指针增强，键盘聚焦（`:focus-visible`）时提供清晰焦点环与等效的悬停 / 激活视觉态，确保不使用指针的用户能完整识别与操作；Tab 顺序符合视觉顺序，Enter / Space 激活。
  - 尊重 `prefers-reduced-motion`：开启减弱动效后禁用元素位移、分层视差与回弹，控件退化为常规但完整可用的悬停 / 聚焦 / 激活态，功能不缺失。
  - 磁吸位移不得造成布局抖动、内容裁切或可点击区域移出视口；使用 transform 合成层位移，不触发布局重排。
- **移动端触控**：触控设备没有悬停态，磁吸应优雅降级——触摸点按下时给予克制的按压 / 轻微趋附反馈，松手归位；不依赖 hover，保证在手机视口模拟器与真机上功能与观感完整，且不与页面滚动 / 其他手势冲突（合理设置 touch-action）。

## 核心亮点

1. **以元素本体为主体的引力响应**：区别于「改写全局光标」的跟随特效，本组件让被操作的按钮 / 图标主动趋附靠近的指针，空间邀请感与点击欲更强，是高端发布页标志性微交互。
2. **外壳 / 文字 / 图标分层视差 + 弹簧归位**：不是整体生硬平移，而是多层不同强度的跟移、靠近衰减、按下收缩与带过冲的回弹，细节决定高级感。
3. **一套磁吸原语驱动多目标**：主 CTA 与若干次级磁吸元素共用同一套可配置原语（半径 / 强度 / 弹簧），并提供手感对比，具备可复用为真实页面通用组件的工程价值，而非单按钮 Demo。
4. **增强而不牺牲可达性**：纯指针增强、键盘与焦点完整等价、减弱动效优雅降级、触控无 hover 可用，符合项目对高可访问性微交互的要求。

## 历史案例对比（进入 Ready 前必填）

- **检查范围**：`src/playground.js` 全部 60 个注册案例（id / 标题 / 描述）+ `playground/effects`、`playground/components`、`playground/pages` 目录 + 活动池 IDEA-001～IDEA-043 + `rejected.md`（当前为空）+ `completed.md`（当前为空）。
- **相似案例**：
  - `cursor-follow`（Fluid Cursor Trail · 多层跟随光标）：同样使用 lerp 物理并在描述中提到 “magnetic element hover”，但它的作用主体是**全局自定义光标**（替换系统光标、尾迹、速度形变），磁吸只是光标靠近元素时的一个效果；本案例**不替换系统光标**，作用主体是被操作的 CTA 元素本体，几何关系与表现目标相反。
  - `capsule-tabs`（胶囊标签动效展厅）：其中“磁吸瞬动”是**胶囊指示器在两个 Tab 之间的落点吸附动画**，属于选项卡内部指示物的位移动效，与指针位置无关，也没有元素对指针的引力响应。
  - `button`（现代按钮系统）：提供波纹、conic shimmer 描边、霓虹、毛玻璃等按钮样式，但没有指针引力位移与分层视差。
  - `like-button` / 各类悬停卡片（`card`、`spotlight-cards` 等）：`like-button` 是点击态形变，卡片类是 3D 倾斜 / 聚光跟随，均非“元素整体被指针磁吸并分层视差、弹簧归位”的 CTA 语言。
  - 在池 `IDEA-013`（环形拨盘时间选择器）的“磁吸”指指针绕圆心拖拽时**量化吸附到离散时刻度**，几何为角度量化；本案例是指针靠近时的连续引力趋附，两者概念与交互完全不同。
- **差异说明**：核心创意差异在「**以可交互元素本体为主体、对靠近指针产生连续引力响应的 CTA 系统**」——外壳 / 文字 / 图标多层不同强度的分层视差、靠近中心增强 / 边界衰减、按下收缩与弹簧归位、一套原语驱动主 CTA 与多个次级目标。视觉表达上聚焦静止规整、被指针“唤醒”的对比与投影层级；交互上是纯指针增强且键盘 / 减弱动效 / 触控完整兜底。这些均不见于任何历史 / 在池案例，不构成仅换颜色、文案或微调参数的重复。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库、零 CDN，双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 指针计算统一用 Pointer Events（兼容鼠标 / 触控 / 手写笔），位移使用 transform（`translate3d`）走合成层，配合 rAF + lerp / 弹簧，避免布局重排与主线程密集计算。
- 磁吸为纯增强层：键盘 `:focus-visible` 焦点环与激活态完整，尊重 `prefers-reduced-motion`，触控无 hover 时优雅降级，正确设置 `touch-action` 不与页面滚动冲突。
- 内联 SVG 图标，不使用任何外部图片 / 字体资源；遵循项目统一的右上角点阵色 Title 胶囊与默认折叠 Micro-HUD 规范。
