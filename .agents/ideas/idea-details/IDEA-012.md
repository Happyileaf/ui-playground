## 创意概述

分页是后台管理系统、数据表、搜索结果、内容归档中出现频率最高的导航控件之一。全仓 60+ 已注册案例覆盖了数据表（列宽可调）、无限滚动信息流、面包屑、标签切换、级联/下拉选择等大量数据展示与导航形态，却**没有任何经典的「分页器 / Pagination」控件**——无限滚动（`infinite-feed`）与分页是两种互补而非替代的浏览范式，长列表精确定位、跳页、总览页数时分页不可替代。本案例做一个纯原生、零依赖、可直接投产的**分页器组件**：覆盖完整的页码折叠算法（首页/末页/当前页邻页 + 省略号窗口）、上一页/下一页/首末页跳转、每页条数切换与指定页码跳转输入；视觉核心是一枚在页码按钮间**用 FLIP 技术平滑滑动的胶囊高亮指示器**，翻页时胶囊沿弧形/弹性轨迹移动、被越过的页码轻微让位，配合上方真实数据表的数据切片切换与「第 X–Y 条 / 共 Z 条」范围文案，让它成为一个真实可用的数据浏览模块而非孤立按钮组。具备完整 WAI-ARIA `nav` + 链接/按钮语义与全键盘操作。

## 预期展示效果

- **构图与整体风格**：
  - 用一个**拟真的数据列表场景**承载：场景中心是一张深色玻璃质感内容卡片（半透明深底 + 细描边 + 柔和投影，延续项目统一语言），卡片上半部为**数据区**——若干行拟真记录（如订单/任务/日志列表，字段克制：序号、标题、状态胶囊、时间），翻页时数据区做一次极短的错峰淡入/位移切换，并显示范围文案「显示第 X–Y 条，共 Z 条」；卡片下半部居中放置**分页器主体**。
  - 分页器自左至右为：首页（«）、上一页（‹）、**页码按钮序列**（折叠后含省略号）、下一页（›）、末页（»）；其右侧或上方次级区域放**每页条数选择**（如 8/12/24 条/页，原生 select 或同款胶囊选择器）与**跳页输入**（「前往 [ ] 页」）。
  - 面板提供少量常驻演示控件：总数/页数切换（如 3 页、8 页、48 页三档数据规模，便于演示不同折叠形态）、滑动指示器开关（展示有/无 FLIP 胶囊的对比）；另有统一的右上角点阵色 Title 胶囊（遵循 HUD 规范）。
  - 配色克制：默认页码为低对比文字态，悬停为浅底，当前页由**强调色胶囊**承载（具体色值不在本阶段限定），强调色只出现在当前页指示与范围文案数字上；首末页/上下页在边界态（第 1 页时上一页/首页、末页时下一页/末页）呈现明确的禁用视觉（不单靠颜色，辅以降透明与 `aria-disabled/disabled`）。
- **主要视觉元素**：
  - **FLIP 滑动胶囊（核心技术）**：当前页码背后有一枚绝对定位的圆角胶囊，翻页时先记录旧/新页码按钮位置（First / Last），再以 `transform` + 舒展缓动（可带轻微回弹）滑动过去；胶囊宽度随目标按钮宽度平滑过渡。跨多页（如从第 2 页跳到第 9 页）时胶囊做一次稍快的长距离滑行，省略号重排不产生跳动闪烁。
  - **页码折叠窗口**：始终展示第 1 页与最后一页；当前页两侧各保留固定数量邻页；窗口外的连续区段折叠为单个省略号（…），省略号不可点击但可被读屏正确跳过；当前页靠近首/末时窗口对称收敛，不出现孤立省略号。
  - **边界与禁用态**：到边界时方向按钮禁用；快速连点不产生错乱（翻页过渡期间的输入按明确规则排队或忽略，按钮状态始终与数据一致）。
  - **数据切片联动**：翻页、改每页条数后，数据区切片即时更新并做一次统一节奏的入场（短、轻，不喧宾夺主）；范围文案与可选总页数同步变化；每页条数变化时当前页按合理规则钳制（如超出新总页数则回到末页）。
  - **跳页输入**：输入非法值（非数字、超范围、空值）时即时、非破坏性地提示并钳制到合法页，回车或失焦提交。
- **层次、材质、光影与关键细节**：
  - 分页器保持扁平、轮廓清晰，胶囊是唯一强动效元素；按钮统一为等宽方形页码格，保证 FLIP 胶囊位移规整、数字不抖动（使用等宽数字 `tabular-nums`）。
  - 动效统一一条舒展的缓出/轻回弹曲线：胶囊滑行 200–350ms 量级，数据区切换比胶囊更短更克制；省略号出现/消失用淡入淡出，避免布局硬切。
  - 悬停、按下、焦点、当前、禁用五种状态清晰可辨：键盘焦点有明确 `focus-visible` 环且不与胶囊混淆；当前页同时有胶囊、`aria-current="page"` 与字重区分，不单靠颜色。
  - 触控目标不小于触控标准，窄屏下组件可横向收缩（优先省略折叠窗口、隐藏文字只留箭头，跳页/条数收纳为第二行），不出现横向页面滚动；省略号与方向按钮带轻投影或描边分隔，层级分明。

## 动态与交互

- **翻页**：点击页码、上一页/下一页、首末页均可翻页；胶囊以 FLIP 从旧页码滑向新页码，数据区切片同步切换并短入场；边界按钮在首页/末页禁用，禁用不产生动画与状态变化。
- **省略号折叠**：页码序列按总页数与当前页实时计算折叠窗口；翻页跨越省略号时序列重排、省略号淡入淡出，胶囊始终在实际渲染出的按钮间取位，不穿越被折叠的不存在按钮。
- **每页条数**：切换每页条数后重新计算总页数与当前页（超范围钳制到末页），数据切片、范围文案、折叠窗口即时更新；当前为第 1 页时胶囊不动、仅数据更新。
- **跳页输入**：输入页码回车/失焦跳转；非法或超范围输入给出克制的行内提示并钳制/还原，不弹 alert；跳转后焦点按可访问性惯例移动到新页码按钮或数据区开头（避免焦点丢失在被折叠移除的旧按钮上）。
- **键盘与可访问性**：分页器使用 `<nav aria-label="分页">` 语义容器；页码为按钮或链接，当前页 `aria-current="page"`；方向按钮有可读名称（首页/上一页/下一页/末页）；Tab 可顺序聚焦，左右方向键在页码间移动焦点、Home/End 到首末页码、回车/空格激活；跳页结果与范围变化通过 `aria-live` 礼貌播报（如「第 3 页，共 12 页」），状态不以颜色为唯一载体。
- **减弱动态与移动端**：遵循 `prefers-reduced-motion`——胶囊改为直接落位（无滑动/回弹），数据区直接切换，仅保留必要淡入或无动画，全部翻页、折叠、条数切换、跳页与键盘功能完整；窄屏自适应折叠与换行，触控热区达标。

## 核心亮点

1. **补上全仓「分页器」类型空白**：60+ 案例有数据表、无限滚动、面包屑、标签切换却无经典分页；分页是后台/搜索/归档场景的高频刚需，可直接作为生产页面模块落地。
2. **FLIP 胶囊把枯燥控件做出记忆点**：当前页指示在任意两页间平滑滑动并自适应宽度，跨多页长距离滑行、省略号折叠重排均不闪烁，是「实用组件 + 动效细节」结合的典型，而非为动而动。
3. **完整的折叠算法与边界工程**：首页/末页/邻页窗口 + 省略号折叠的对称收敛、边界禁用、快速连点一致性、每页条数切换的页码钳制、非法跳页校验，覆盖真实分页组件的全部边角情况。
4. **真实数据切片联动 + 完整可达性**：数据区、范围文案、条数选择、跳页输入构成完整可用模块；`nav`/`aria-current`/方向键/Home/End/aria-live 播报、等宽数字、reduced-motion 降级与窄屏自适应齐备，达到可投产组件完整度。

## 历史案例对比（进入 Ready 前必填）

- **检查范围**：src/playground.js 全部 63 个注册案例（id / 标题 / 描述 / tags）+ playground/effects、playground/components、playground/pages 三个目录（effects 12 个、components 45 个、pages 3 个）+ rejected.md（当前为空）+ completed.md（当前为空）+ 活动池 IDEA-001~011。
- **相似案例**：
  - `capsule-tabs`（胶囊标签动效展厅）：视觉上同样有「胶囊指示器在选项间移动」，但它是**同页内容分区切换的标签控件**，主体是对比 6 种动效曲线的展厅，无页码语义、无多页数据切片、无折叠省略号、无首末页/跳页/每页条数；本案例的胶囊只是翻页指示的一种呈现，核心是**带折叠算法的多页数据导航与数据切片联动**，信息模型（离散等权标签 vs 有序数值页码 + 总页数）与交互完全不同。
  - `infinite-feed`（无限加载信息流）：同属长列表浏览范式，但是**滚动驱动的无限追加**，无页码、无总页数、无精确定位与跳页；两者互补，本案例演示的是「精确翻页」范式，且不使用 IntersectionObserver 哨兵那一套。
  - `resizable-table`（列宽可调数据表）：同属数据展示且都有后台场景，但它聚焦**列宽拖拽、排序与过滤**，数据是一次性 12 行静态展示、无分页；本案例聚焦**分页导航本身**，数据行仅为演示切片的载体，不做列宽/排序（可在演示数据中保留状态胶囊等静态字段）。
  - `scroll-progress-bar`（阅读进度条与章节导航）：同样是「位置指示 + 导航」，但它映射的是**连续滚动位置**（scaleX 进度条 + 章节锚点），无离散页码、无翻页数据切换；本案例映射离散页索引。
  - `breadcrumb`（面包屑）/ `tree-view`（文件树）/ `context-menu` / `combo-box`：同为导航/选择类控件，但分别表达层级路径、树形结构、上下文命令与单选过滤，均无页码序列与分页语义；跳页输入可能借用输入校验手法，不构成创意重复。
  - `range-slider`（区间滑块）/ `otp-input`（分段输入）：跳页输入与页码步进涉及数字输入与步进，但它们是表单取值控件，无导航序列、无 FLIP 指示与数据切片。
  - 活动池 `IDEA-001~011`（Date Picker、Carousel、Toast、Tags Input、Step Wizard、FAB Speed Dial、Gooey 下载按钮、Chat Workspace、Animated Charts、Cascader、Star Rating）：依次为日期选择、内容轮播、轻提示、多值输入、多步表单、角部动作菜单、液态 CTA、即时通讯、SVG 图表、逐级联动选择、评分。其中 Carousel（IDEA-002）虽有「上一项/下一项」翻页，但它是**内容展示轮播**（自动播放、指示点、滑动姿态），面向 Hero 内容浏览而非数据定位，无页码折叠窗口、无每页条数/跳页/总数范围语义；Step Wizard 是线性流程步骤，不可任意跳转浏览数据。均非分页数据导航，不构成重复。
- **差异说明**：核心创意是**「以 FLIP 滑动胶囊为当前页指示、带完整省略号折叠算法与边界处理的经典数据分页器，联动真实数据切片、每页条数与跳页，做成可投产的后台数据浏览模块」**。与最接近的 capsule-tabs（等权标签切换展厅 vs 有序数值页码多页导航）、infinite-feed（滚动无限追加 vs 精确翻页）、resizable-table（列宽/排序静态表 vs 分页切片联动）在核心创意、视觉表达（FLIP 页码胶囊、省略号折叠窗口、范围文案、条数/跳页控件）、交互方式（首末页/邻页跳转、折叠重排、页码钳制、非法跳页校验、键盘页码导航）与整体表现（带数据切片的后台模块）上均有实质差异；不属于换色、换文案或微调参数类重复。全仓检索 pagination/pager/page-nav 等关键字无历史（含已删除）id 冲突，案例 id 定为 `pagination`。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生零 CDN、双击 index.html 独立离线运行（通用项目铁律，详情不重复）。
- 图标一律使用**内联 SVG**（首/末/上/下页箭头），**不得引入图标库、UI 框架、动画库或外部字体/图片资源**；演示数据为内置静态数据（总量足够覆盖小/中/大三档页数即可），不发起网络请求。
- FLIP 胶囊须基于渲染前后实际按钮位置（getBoundingClientRect 或等价测量）以 `transform` 实现位移与宽度过渡；页码折叠重排导致按钮挂载/卸载时，胶囊只在实际存在的新旧按钮间过渡，省略号节点不参与取位；使用 `tabular-nums` 保证数字稳定。
- 统一使用 Pointer Events 处理点击/触控；翻页过渡期间的并发输入要有明确一致的状态规则（忽略过渡中指令或终态对齐），任何时刻按钮禁用态、范围文案、数据切片与当前页严格一致。
- 动效优先使用 transform / opacity 等合成友好属性；组件在 iframe 挂载/卸载时统一清理事件监听、rAF 与定时器，无残留。
- 可访问性为硬性要求：`<nav aria-label>` 容器、当前页 `aria-current="page"`、方向按钮可访问名称、`focus-visible` 清晰；Tab + 左右方向键 + Home/End 键盘操作齐备；翻页结果经 `aria-live` 礼貌播报；焦点在折叠重排后不丢失；当前页不单靠颜色区分。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊；如需调节（数据规模、胶囊开关、每页条数、重播入场、减弱动效），常驻控件 + 默认折叠 Micro-HUD（`H`/`Esc`、事件防穿透）。
- 尊重 `prefers-reduced-motion`：胶囊直接落位、数据区直接切换（或极短淡入），翻页、折叠、条数切换、跳页、键盘功能完整。
