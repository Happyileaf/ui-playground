## 创意概述

轮播是落地页首屏 Hero、产品推荐、图文专题中最高频的「分页内容展示」原语之一，但站内现有案例只覆盖了「无限平移跑马灯」「卡牌堆叠飞出」与「单图放大/对比/裁剪」，**没有一个具备离散分页、拖拽吸附、指示点、自动播放与完整 ARIA carousel 语义的通用轮播**。本案例做一个纯原生、零依赖、零外部图片的 Hero 内容轮播：多张大画幅幻灯片按页切换，支持指针拖拽跟手 + 阈值吸附切换、箭头/指示点跳转、键盘漫游、悬停/聚焦暂停的智能自动播放、循环与首尾边界处理，以及 WAI-ARIA `role="group"`/`aria-roledescription="carousel"`/实时状态播报，可直接作为生产环境首屏组件使用。

## 预期展示效果

- **构图与整体风格**：
  - 以一个真实的落地页首屏场景承载：页面顶部为克制的品牌导航，主体是一张占据首屏黄金比例的大画幅轮播（约 16:9 / 21:9 宽幅），下方为轮播控件与轮播内容对应的要点区，避免出现脱离上下文的孤立盒子。
  - 每张幻灯片为「视觉区 + 文案区」的真实 Hero 卡片：大标题、副标题、主次行动按钮；不同页有可辨识的主题差异（不同渐变氛围与排版重心），但共享统一的版式骨架与深色玻璃质感，延续项目既有视觉语言。
  - 轮播浮于内容之上但不遮挡导航；控件（左右箭头、底部指示点、自动播放开关）位置稳定，切换时不产生布局跳动（CLS 为零）。
- **主要视觉元素**：
  - 幻灯片轨道（track）横向排列，当前页居中、相邻页在视口边缘以极轻微的缩放/透明度暗示连续性（是否露出相邻页由设计取舍，不强求多卡片模式）。
  - 底部指示点为一排小胶囊/圆点：当前页指示点伸长或填充为主色，其余为低对比描边；hover 态与键盘焦点态分开表达。
  - 左右箭头为圆形（或圆角方形）玻璃按钮，含内联 SVG 箭头；禁用态（非循环且处于首尾）明显变暗且不可点。
  - 幻灯片切换伴随文案的错峰入场（标题/副标题/按钮依次淡入上移），让每一页都有「内容被重新讲述」的层次感。
- **层次、材质、光影与关键细节**：
  - 轮播容器为圆角大卡片，1px 高光描边与柔和投影，视觉背景由纯 CSS 多层径向/线性渐变 + 模糊光斑（blurred orb）构造出景深与氛围，**零外部图片**。
  - 当前页与相邻页之间有细微的明度/饱和度落差，配合轨道位移形成纵深；拖拽时页面跟随指针实时平移并可带轻微倾斜或阻尼感（克制，不做廉价 3D）。
  - 指示点当前态切换使用宽度/颜色过渡而非生硬跳变；箭头 hover 有柔和提亮与轻微位移反馈。
  - 自动播放开启时有一个不抢眼的细进度环/进度条提示「距下一页的时间」，暂停（hover/聚焦/手动拖拽）时该进度同步冻结。
  - 入场为 opacity + 轻微位移的缓动；轨道切换使用带阻尼感的 cubic-bezier，吸附时有明确但不过冲的 settle 手感。

## 动态与交互

- **指针拖拽（鼠标 + 触控统一 Pointer Events）**：在幻灯片区域按下并水平拖拽时轨道实时跟手移动；松开时依据位移阈值/速度（轻扫 fling）判定切换到上一页或下一页，未达阈值则弹性吸附回当前页；拖拽过程中暂停自动播放，结束后按规则恢复。纵向滚动不被劫持（仅在接近水平手势时接管）。
- **箭头与指示点**：点击左右箭头翻页；点击指示点直接跳到对应页（允许跨越多页，轨道一次滑行到位）；循环模式下首页「上一张」到末页、末页「下一张」到首页，非循环模式下到边界即禁用对应箭头。
- **键盘操作（WAI-ARIA Carousel 模式）**：轮播容器可聚焦，← →（或在按钮焦点时 Home/End）切换/跳到首尾；指示点与箭头可正常 Tab 到达，焦点环清晰；提供「自动播放开关」按钮并带 `aria-pressed`，屏幕阅读器可感知播放状态；当前页与总页数通过 `aria-live`（礼貌播报）或 `aria-label` 表达（如「第 2 张，共 5 张」），自动播放时避免频繁打断。
- **自动播放**：默认开启或默认关闭由设计取舍，但必须可被用户开关；鼠标悬停轮播、键盘焦点进入轮播、正在拖拽时自动暂停，离开后恢复；尊重 `prefers-reduced-motion`——开启减弱动效时默认不自动播放且切换为即时/极短淡入。
- **切换动效与文案编排**：轨道位移用一次完整缓动到位；进入页文案按索引错峰淡入上移，离开页文案淡出；快速连续操作时取消未完成的入场编排，不出现动画堆叠/错位。
- **响应式与移动端**：窄屏全屏宽、文案尺寸与间距自适应，触控热区足够大；箭头可保持可见或改为边缘半隐式，指示点不与文案重叠；横竖屏与窗口缩放时轨道位置按当前页索引重新校准，不错位。
- **生命周期**：切换案例或卸载时取消所有 rAF / 定时器 / 惯性动画并移除事件监听，重新挂载状态干净。

## 核心亮点

1. **跟手拖拽 + 阈值/速度吸附的完整手势模型**：不是只能点箭头的轮播，而是 Pointer Events 统一鼠标触控、支持位移阈值与轻扫速度判定、未达阈值弹性回弹、且不劫持纵向滚动的生产级手势体验。
2. **智能、可干预的自动播放**：hover/聚焦/拖拽暂停、可开关、带进度提示，并完整尊重 `prefers-reduced-motion`，规避自动轮播常见的可访问性与可用性陷阱。
3. **完整 WAI-ARIA carousel 语义**：`aria-roledescription`、`aria-label` 页码播报、`aria-pressed` 播放开关、键盘漫游与清晰焦点环，达到可直接投产的无障碍完成度。
4. **零外部资源的电影感 Hero**：纯 CSS 渐变 + 模糊光斑 + 文案错峰入场，构造出有景深、有氛围、切换有叙事感的大画幅首屏，且双击离线可用。

## 历史案例对比（进入 Ready 前必填）

- **检查范围**：src/playground.js 全部 60 个注册案例（id / 标题 / 描述 / tags）+ playground/effects（12）、playground/components（45）、playground/pages（3）物理目录 + rejected.md（当前为空）+ completed.md（当前为空）。
- **相似案例**：
  - `logo-marquee`（无缝跑马灯）：同为「横向轨道持续运动」，但它是纯 CSS、轨道复制平移 50% 的**无限、无分页、无主动导航**跑马灯，用于 Logo 墙；本案例是离散分页、可拖拽吸附、有指示点/箭头/自动播放开关与 ARIA carousel 语义的受控内容轮播。
  - `swipe-card-deck`（弹性拖拽卡牌堆）：同样有指针拖拽与阈值飞出，但它是 Tinder 式**堆叠卡牌逐张飞出/撤回**，方向是斜向飞出并伴随印章，没有横向轨道、分页指示点与循环；信息架构与手势语义完全不同。
  - `image-zoom` / `image-comparison-slider` / `image-cropper`：均为**单张图**上的局部放大、前后对比或裁剪，无多页轨道与轮播状态机。
  - `capsule-tabs`（胶囊标签动效展厅）：同有「切换」与多种缓动，但它是**原地切换的分段控件**，面板不横向平移、无拖拽手势与自动播放。
  - `infinite-feed`：垂直方向的无限加载信息流，靠哨兵追加数据，无轨道分页与轮播控件。
- **差异说明**：核心创意是**离散分页的横向轨道 + 跟手拖拽吸附状态机 + 智能自动播放 + ARIA carousel 语义**，与全部历史案例在核心创意（分页轨道轮播）、视觉表达（大画幅 Hero + 指示点进度）、交互方式（拖拽阈值/轻扫 + 全套键盘 + 可干预自动播放）上均无实质重叠；不是对 marquee 换文案或对 swipe-deck 换方向的微调，不属于换色/换文案/调参数类重复。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生零 CDN、双击 index.html 独立离线运行（通用项目铁律，详情不重复）。
- Hero 视觉背景一律使用纯 CSS 渐变/模糊光斑构造，**不引用任何外部图片或网络资源**。
- 手势统一使用 Pointer Events（配合 setPointerCapture），区分水平拖拽与页面纵向滚动；动画基于 `requestAnimationFrame`/transform，卸载时取消 rAF、定时器与监听。
- 轨道位移与页码以索引为单一数据源，窗口 resize / 横竖屏切换后按当前索引重新校准，杜绝错位与布局跳动。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊；自动播放/循环等模式切换控制使用默认折叠的 Micro-HUD。
- 尊重 `prefers-reduced-motion`（默认不自动播放、切换即时化）；移动端满足触控热区标准。
