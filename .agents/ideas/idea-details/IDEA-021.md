## 创意概述

一个纯原生、零依赖、可离线运行的星级评分组件：一行五颗星既是输入控件也是情绪表达器——指针滑过时按位置即时点亮并弹出分值/文案预览，点击落点提交评分，伴随星星弹性过冲、高光扫过与可关闭的轻盈粒子反馈；支持整星与半星（甚至小数）两种精度、键盘逐档增减、清除重评、只读展示与评分分布条。它覆盖电商评价、内容打分、满意度反馈等网页高频场景，在「精确数值输入」与「情绪化即时反馈」之间取得平衡，并以完整 ARIA 滑块/评分语义达到组件库级可达性。

## 预期展示效果

- **构图与整体风格**：
  - 画面以一张克制的「评价卡片」为视觉中心：上方是被评对象标题与一行大号星级行，下方依次为当前分值数字、随分值变化的情绪文案、可选的评分分布条（5→1 星各档占比横条）。
  - 卡片采用项目统一暗色体系：深空中性底（微带冷色温的深蓝灰）、细 1px 半透明描边、柔和大半径投影；不使用高饱和蓝紫渐变。
  - 星级行占据视觉焦点，星星尺寸明显大于常规图标，星间距宽松，整体留出呼吸感。
- **主要视觉元素**：
  - 五颗内联 SVG 五角星，具备清晰的多态：未选（暗灰描边/低填充）、悬停预览（半亮）、已选（暖金渐变实心）、半星（左半实、右半空，以渐变遮罩精确呈现 0.5 档）。
  - 当前分值用大号数字 + 情绪文案呈现（如 1「很不满意」、3「还不错」、5「非常满意」），文案随悬停实时预览、提交后落定。
  - 提交瞬间被点亮的星星触发一次高光扫过与轻微弹性缩放；可配置少量金色微粒从星尖迸出（数量克密、可关闭）。
  - 只读模式下星级行弱化交互态、降低强调，分布条用细横条 + 百分比呈现整体口碑。
- **层次、材质、光影与关键细节**：
  - 已选星星使用克制的暖金到琥珀的纵向微渐变 + 顶部 1px 内高光，呈现金属星章质感而非扁平 emoji；未选星仅保留低对比描边，避免「一片灰星」的廉价感。
  - 悬停预览态与已确认态在亮度/饱和度上可辨区分：预览更通透、确认更沉稳，防止用户误判已提交状态。
  - 弹性动效遵循短位移、快回弹（spring/cubic-bezier 过冲），单星动效在 200ms 内收敛；多星不做级联长动画。
  - 焦点键盘用户有清晰可见的焦点环（不限于当前悬停星）；所有状态对比满足 WCAG AA，不仅依赖颜色传达分值（辅以数字与文案）。

## 动态与交互

- **指针交互（统一 Pointer Events）**：
  - 指针在星级行上移动时，按指针所在星（半星模式按左右半区）实时点亮 1→N 星并预览对应分值与文案；移开行外时恢复到已确认值，而非停留在最后悬停值。
  - 点击（pointerup）落点提交分值；提交瞬间触发被点亮星星的高光扫过 + 弹性过冲，数字与文案落定，并以 `aria-live` 播报「已评分 X 星」。
  - 支持一键清除（星级行旁的小清除按钮，或再次点击当前已选最高星取消），允许重新评分；重复提交同一分值不产生异常状态。
- **精度模式**：
  - 整星模式：最小步进 1，值域 0–5；
  - 半星模式：最小步进 0.5，半星以遮罩/渐变精确呈现；值域仍为 0–5。
  - 两种模式共用同一套键盘与 ARIA 值语义，仅步长不同。
- **键盘交互（完整可达性）**：
  - 星级行作为单个可聚焦控件（`role="slider"` 配 `aria-valuemin/max/now` 与 `aria-valuetext`，或 `radiogroup` 风格的 roving 方案二选一，保持语义单一不自相矛盾）。
  - `→`/`↑`/`+` 增加一个步长、`←`/`↓`/`-` 减少一个步长，`Home` 到最低、`End` 到满分；`Enter`/`Space` 在「悬停预览焦点值」场景下确认当前值；`Esc` 放弃预览回到已确认值。
  - 焦点可见且不依赖悬停；键盘调值同样驱动点亮与文案预览，提交同样有动效与播报。
- **只读 / 展示态**：
  - 通过属性切换为只读：屏蔽输入与悬停改值，支持展示非整数平均分（如 4.6 星以部分填充表达），可配评分人数与 5→1 星分布条；分布条悬停可高亮对应档位。
- **移动端触控**：统一 Pointer Events；星星可点区域不小于 44×44px（视觉星可小、热区外扩），窄屏下星级行与文案不溢出、不依赖 hover 才能看到分值（点击即预览即提交，触摸有明确反馈）。
- **减弱动效**：尊重 `prefers-reduced-motion`：开启时关闭弹性过冲、高光扫流与粒子，仅保留状态颜色/填充的即时切换，反馈不丢失。

## 核心亮点

1. **悬停即预览、离开即回退、落点才提交的三段式状态机**：把「想看看几分」与「确认打几分」分离，预览态与确认态视觉可辨，是评分组件最具辨识度的交互细节，也直接支撑键盘用户的同款体验。
2. **精确值与情绪反馈兼得**：整星/半星双精度、数字 + 情绪文案 + 星章金属质感与弹性高光，让一个数值输入控件同时具备评分场景所需的情绪表达；粒子反馈克密且可关、可减，不喧宾夺主。
3. **输入态与只读口碑态一体**：同一组件既能让用户打分，也能以非整数平均分 + 评分分布条展示群体口碑，覆盖商品详情页「看评分 → 我要评分」的完整链路。
4. **组件库级严谨度**：单一不矛盾的 ARIA 值语义、全键盘增减与 Home/End、焦点可见、aria-live 提交播报、清除重评、44px 触控、WCAG AA 与 reduced-motion 适配，达到可直接用于生产页面的完成度。

  - IDEA-018 拟物旋转旋钮（在途 #61）——单值输入，但走极坐标角度映射 + 硬件拟物，服务调音/温控等连续旋钮场景；本案例是水平有序图标行的评级语义，视觉语言与使用场景实质不同。
  - `contribution-graph`（只读热力网格）、`avatar-stack` / 各卡片类——仅有图形化数据展示或悬浮名片，不含评分输入与有序等级状态机。
- **差异结论**：核心创意（五级/半级有序评分的预览—提交状态机 + 情绪反馈 + 口碑只读态）、视觉表达（金属星章多态填充与半星遮罩）、交互方式（星级行悬停预览 + 键盘步长增减 + 清除重评）三个维度在历史与在途案例中均无重合，非换色/换文案/参数微调。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML/CSS/ES6+，零框架、零 CDN、零第三方图标/动画库；星星使用内联 SVG，半星用渐变/遮罩或 clip 实现，不引入图片资源。
- 双击 `index.html` 离线可用；演示文案、分布数据全部内置，不请求任何网络资源；粒子（如实现）用少量 DOM 或轻量 canvas，数量受控、可关闭，且视觉反馈在无粒子时依然完整。
- 动效使用 CSS transition / transform（短位移、快回弹），统一 `prefers-reduced-motion` 降级为即时状态切换；不得有密集计算或持续后台循环。
- 遵循项目统一 HUD 规范：组件类案例沿用右上角 Title 胶囊（固定主题色呼吸点）；参数面板非必需，如加入则默认折叠、`H`/`Esc` 唤收且事件防穿透。
- 统一 Pointer Events；触控命中区 ≥ 44px；正文与控件对比满足 WCAG AA；分值不仅靠颜色传达（数字/文案兜底）。
