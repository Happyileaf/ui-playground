## 创意概述

一个高度拟真的移动端「列表项横滑露出操作按钮」交互组件（Gmail 邮件、iOS 提醒事项、Apple Mail 式手势语言）。在一行待办 / 邮件 / 通讯录条目上向左或向右拖动，行底层的操作按钮（如完成、归档、删除、更多）随拖动逐档显露并伴随图标缩放与背景色推进；松手后依据拖动速度与越过阈值，自动吸附到「关闭 / 半露操作区 / 触发主动作」三个档位之一。桌面端无触控也可通过鼠标按住拖动操作，并始终提供可见的备用操作入口与完整键盘支持，保证可访问性。

解决的体验问题：在长列表中对单条记录做高频快捷操作（完成、删除、归档）时，传统方案需要逐项点击更多菜单，路径长、打断浏览流；横滑手势把「定位条目」与「执行操作」合并为一次自然手势，是移动端列表最高频的肌肉记忆之一，而当前案例库尚缺这类纯指针手势驱动的列表微交互。

## 预期展示效果

- **构图与整体风格**：
  - 单屏居中的一张移动端风格卡片容器（顶部带简洁的列表标题、条目计数与一个示意性的分段切换），内部是一列左右可滑动的列表行；外层延续工作台一贯的深色高级质感，但列表行本体采用克制的浅色或深色玻璃拟底，确保操作按钮的高饱和语义色成为视觉焦点。
  - 每行由「前景行（内容层）」与「背景操作层（左右两侧动作区）」两层叠加构成：前景层在上、可整体水平平移；背景层在下、固定不动，按钮分置左右两端，前景滑开时逐层显露。
- **主要视觉元素**：
  - 前景行：圆形头像 / 类型图标、标题、次要描述文字、右侧时间或状态元信息、未读 / 已完成的状态点或勾选态。
  - 背景动作区：左滑显露右侧动作（如「归档」「删除」），右滑显露左侧动作（如「完成」）；每个动作一个语义色底 + 内联 SVG 图标 + 可选文字标签。
  - 档位吸附后的「已激活主动作」反馈（如整行继续滑出并收起为删除动画，或行首出现完成勾选）。
- **层次、材质、光影与关键细节**：
  - 前景行带有细微投影与圆角，滑动时随横向位移产生极轻微的阴影加深 / 倾斜，营造「行被抓起来在轨道上拖动」的层级感。
  - 背景图标随拖动进度做弹性缩放与位移（初始略缩小、接近阈值时放大并轻微过冲），颜色底块可随推进方向做宽度 / 明度的渐进填充，给出明确的「再拖一点就触发」暗示。
  - 越过吸附阈值的瞬间，主动作图标可出现一次脉冲 / 形变确认；松手吸附用弹簧曲线（带回弹），未越过阈值则阻尼回到关闭位。
  - 触发删除时行高平滑坍缩、其余行 FLIP 式上移补位并错峰；触达终态（如全部处理完）有空状态与「撤销」入口，避免操作不可恢复的廉价感。

> 设计文档约束最终体验与设计意图；具体的阈值数值、弹簧参数、色值与行数由实现阶段按整体视觉统一决定，不在此过早钉死。

## 动态与交互

- **触发方式（Pointer Events 统一鼠标 / 触控 / 手写笔）**：
  - 在前景行上水平按下并拖动：前景实时跟手平移，背景动作随进度显露、图标弹性反馈；垂直方向位移占优时主动放弃，避免与页面竖向滚动冲突（方向锁）。
  - 松手吸附三档：位移与瞬时速度共同判定——回弹关闭 / 吸附到半露操作区 / 吸附并触发主动作（越过最大阈值或快速甩动即触发）。
  - 同一时刻只允许一行展开：拖动或点开新行时，已展开行自动平滑收起（单选手风琴式互斥）。
  - 点击背景露出的动作按钮执行对应操作（完成切换、归档、删除、更多）；删除带行坍缩 + 其余行补位动效，并提供短暂的撤销提示。
- **桌面端兜底**：鼠标可按住拖动；每行右侧提供一个低调的「更多 / 手柄」可视入口，点击即把该行吸附到半展开操作区，确保无触控设备也能发现并使用功能。
- **键盘与可访问性**：
  - 列表行可聚焦，`←` / `→` 方向键在「关闭 / 左操作区 / 右操作区」之间切换并播放同等吸附动效；对应动作按钮可 Tab 到达、Enter/Space 执行；`Esc` 收起当前展开行并把焦点归还该行。
  - 动作具备清晰的 ARIA 语义（如行容器 `role="group"`、动作为带可访问名称的按钮、动作结果通过 `aria-live` 礼貌播报「已删除 / 已完成 / 已撤销」）。
  - 尊重 `prefers-reduced-motion`：减弱动效下禁用跟手弹性与过冲，行直接在档位间即时切换、删除即时坍缩，功能完全保留。
- **移动端触控**：使用 Pointer Events + setPointerCapture，处理 touch-action（水平手势与纵向滚动不互相抢占），保证在手机视口模拟器与真机上都顺滑、无选择文本 / 误滚动。

## 核心亮点

1. **拟真的三档手势物理**：不是简单的跟手平移，而是「位移 + 甩动速度」双判定、带回弹的弹簧吸附，覆盖关闭 / 半露 / 触发三态，复刻主流邮件与待办 App 的真实手感。
2. **背景动作的渐进式视觉反馈**：图标随拖动进度弹性缩放、语义色底推进填充、越阈瞬间脉冲确认，把「还差多少会触发」持续、明确地反馈给用户。
3. **完整的操作闭环**：删除行高坍缩 + 列表 FLIP 补位 + 撤销恢复 + 终态空状态，而非只做一个会滑动的静态 Demo。
4. **跨输入方式的高可访问性**：指针手势、鼠标、键盘三套等价操作路径，方向锁避让纵向滚动，并适配减弱动效偏好——在追求炫酷手势的同时不牺牲可达性。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库、零 CDN，双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 手势统一用 Pointer Events + setPointerCapture，并做水平 / 垂直方向锁，正确设置 `touch-action`，避免与页面竖向滚动冲突。
- 动效用原生 CSS transition / transform（或 rAF 弹簧），尊重 `prefers-reduced-motion`；不引入会引起主线程卡顿的密集计算。
- 内联 SVG 图标，不使用任何外部图片 / 字体资源。
