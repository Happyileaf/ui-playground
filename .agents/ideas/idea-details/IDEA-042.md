## 创意概述

旋钮（Rotary Knob / Dial）是硬件世界里密度最高、手感最经典的连续数值控制器：调音台通道增益、均衡器（EQ）频点与增益、合成器滤波器截止、监听音量、灯光亮度、仪表盘阈值……它用「绕一根固定轴旋转的角度」编码一个有界连续量，相比线性滑块，在占用极小面板面积的同时提供了精确的环形工作区、天然的首尾边界（死区）与一眼可读的指针方位。桌面端与移动端的软件控制（DAW、直播控制台、智能家居、监控大屏、视频调色）大量复刻这种形态，但库内 61 个已注册案例与在池 41 个 Ready Idea 中，**没有任何「绕轴旋转、以角度编码数值」的硬件式连续调节控件**：`range-slider` 是水平双拇指线性区间，IDEA-013 Time Picker 是时钟面上选一个时刻的弹层选择器，IDEA-029 Lucky Wheel 是点击后自动旋转、由概率决定落点的营销转盘，IDEA-006 FAB Speed Dial 只是借了 dial 之名的动作菜单。

本案例做一个纯原生、零依赖、零 CDN、零外部图片/字体、双击离线即用的**拟真旋转旋钮控制台**：一张深色硬件控制台风格的拟真面板（主题设定为一台紧凑的监听/混音控制条），上面并置若干枚可独立工作的旋钮——主输出音量、耳机音量、低/中/高三段 EQ 增益等，每枚旋钮有明确的量程、单位、默认值与步进；旋钮用「绕轴径向拖拽」驱动（向上/向右拖增大、向下/向左减小，配合距轴心的径向距离决定灵敏度，这是专业软件旋钮的标准手势，而非强迫指针画圆），并同时支持滚轮/触控板滚动手势、方向键/Home/End/PageUp/PageDown 全键盘操作、双击回到默认值；拖过最小/最大端点时有明确的边界阻尼与端点触感，转动按步进量化、越靠近刻度越有轻微吸附，环周刻度与进度弧实时跟随，中心或下方有等宽数字读数与单位，数值变化经 aria-live 克制播报。面板还提供一条与旋钮状态实时联动的响应曲线/电平预览，使「转动一个硬件旋钮 → 立即看到它控制的结果」的因果关系成立，而非孤立的摆件。可选 Web Audio 在用户首次手势后懒激活，提供极轻的机械刻度咔嗒与端点反馈（默认克制、可关、零音频文件、完全可静音），不自动发声。

## 预期展示效果

- **构图与整体风格**：
  - 一张拟真的「硬件控制条」面板：顶部为面板标题区（设备名、总开关/静音、预设切换与复位），其下主体是一排等距排布的旋钮单元（约 5～7 枚，按主输出/耳机/EQ 分段组织，段间有极淡分组分隔与小标签）；底部或侧部是一条与旋钮数值实时联动的结果预览区（如三段 EQ 的频响曲线 + 主输出电平表），让每个旋钮的作用可被直接看见。面板像真实桌面音频接口/控制器的一个截面，而非零散 demo 拼贴。
  - 延续项目深色硬件美学（与 dynamic-dock 的微拟态磨砂、IDEA-039 步进鼓机的设备面板气质协调）：近黑金属拉丝/磨砂底、嵌入式单元凹槽（内阴影）、旋钮本体是顶部受光的圆柱体（径向渐变 + 底部接触阴影 + 顶部高光弧），面板螺丝、刻度丝印等细节点到为止；强调色克制（仅进度弧、当前激活单元与电平峰值用有明度层次的同调强调色），不做满屏彩色 LED 廉价感。
  - 桌面端整排并排、信息密度贴近真实控制器；平板等宽缩放、保证触控热区；手机上自动折为两行或可横滑的单元排，读数与刻度不溢出；任意宽度下旋钮保持正圆、刻度环不变形。
- **主要视觉元素**：
  - **旋钮本体（核心）**：圆柱形旋钮帽，正面有一条明确的指针指示（刻线/荧光点/楔形槽，三选一为主、形状+明度+颜色共同编码当前方位），随数值在量程对应的有效扫掠角内旋转；旋钮帽有受光面、暗部与顶面细微同心圆纹理，按下/拖拽时有极轻微的轴向下沉（模拟捏住旋钮），释放回弹。
  - **环周刻度与进度弧**：旋钮外围一圈极细的刻度丝印（主刻度 + 次刻度），只分布在有效扫掠角内（两端留出对称死区）；一道细进度弧从最小值位置扫到当前角度，端点（min/max）有更明显的端点刻度；当前刻度附近可选轻微高亮。刻度读数也可以纯文字形式（0…10、-12…+12 dB）存在，图形不是唯一信息源。
  - **读数与标签**：每枚旋钮下方是参数名、等宽数字读数（tabular-nums，避免跳宽）与单位（如 dB、%、Hz），默认值有小标记；被调节瞬间读数可做一次极克制的明度/微放大反馈；负增益/正增益、静音等状态不仅靠颜色（方向、符号、文案共同编码）。
  - **联动预览区**：底部频响曲线（三段 EQ 旋钮改变曲线形状，拐点位置/增益方向正确）或电平/亮度等直观结果随旋钮实时变化；主输出为 0 或静音时电平表明确归零。预览让旋钮「控制了什么」一目了然。
- **层次、材质、光影与关键细节**：
  - 视觉四层：面板金属底纹与凹槽（最底）→ 刻度环/进度弧/丝印 → 旋钮圆柱本体（唯一可操作对象）→ 读数、标签、HUD、预览曲线（信息层）；旋钮靠接触阴影与顶面高光浮于凹槽之上，转动过程光影随角度有极细微变化但不喧宾夺主。
  - **角度↔数值必须是单一确定性映射**：所有视觉（指针转角、进度弧、读数、预览曲线）都由同一份状态经同一个「数值↔角度」函数计算，刷新后同一数值永远呈现同一画面；拖拽中的临时显示与提交后的状态一致，不允许累积 transform 越拖越偏、不允许指针方位与数字读数脱钩。
  - 手感细节：径向拖拽以「指针相对上次位置的位移投影到旋钮纵轴/绕轴增量」计算（专业软件通用的上下拖+距轴灵敏度模型，避免在死区附近角度跳变），按步进量化；越过端点后继续拖拽有阻尼（增益递减）而非无限跟随，松手有极轻回弹；双击复位、键盘按住连走；所有非必要运动都短而克制。
  - 右上角统一点阵色 Title 胶囊为强制项；Micro-HUD 默认折叠。

> 设计文档约束最终体验与设计意图；旋钮数量、各参数量程/单位/默认值/步进的具体数值、有效扫掠角大小、死区角度、阻尼曲线、咔嗒音音色、面板金属与强调色具体色值、旋钮像素尺寸等由实现阶段按拟真度与手感统一决定，不在此过早钉死；但「绕轴角度编码有界连续值 + 径向拖拽/滚轮/键盘/双击复位多输入等价 + 端点死区与边界阻尼 + 步进量化吸附 + 角度↔数值单一映射 + 可见结果联动 + 全键盘 ARIA + reduced-motion 与触控等价」这条链路必须真实成立，不允许用纯 CSS 摆拍一个不会随输入正确映射的假旋钮，不允许只支持拖拽而无键盘/滚轮，也不允许引入任何框架、旋钮库或外部资源。

## 动态与交互

- **触发方式（指针径向拖拽主导，滚轮与键盘完全等价，非自动播放）**：
  - **指针（鼠标/触控/手写笔统一 Pointer Events + setPointerCapture）**：在旋钮帽上按下即「捏住」（轴向微下沉）并捕获后续移动；垂直拖拽为主映射——向上拖增大、向下拖减小，水平方向同向辅助，指针距旋钮轴心越远（在合理范围内）同等像素对应越小数值变化（精细调节区），可在指针移出一定半径后进入微调模式；拖拽全程按各旋钮的步进量化，越过 min/max 后端点阻尼（继续拖增益迅速衰减），不反向绕圈、不跳值；松开回弹并提交最终值。旋钮**不要求**指针绕圆心画圆弧（那是易错、在死区会跳变的劣化手势），但指针方位始终与数值一致。
  - **滚轮 / 触控板**：旋钮悬停或聚焦时滚轮上下按步进增减（带自然的逐格刻度感），preventDefault 仅作用于旋钮热区、不锁死整页滚动；快速滚动受同一量程钳制，支持 Shift 加速/Alt 细调（若实现须在 HUD 或提示中说明）。
  - **键盘（ARIA slider 语义）**：旋钮以 `role="slider"`（或等价的可旋转 button + aria-valuenow 方案）暴露 `aria-valuemin/max/now`（及带单位的 `aria-valuetext`）；↑/→ 增一个步进、↓/← 减一个步进，PageUp/PageDown 大步进，Home/End 直达最小/最大，双击（键盘为快捷键，如键盘焦点下按 R 或双击旋钮）回到该参数默认值；焦点环始终清晰可见；旋钮组内可用 Tab 顺序遍历，不劫持 Tab。
  - **双击**：双击旋钮帽回到默认值并播报；双击热区仅限旋钮本体，不误伤面板。
  - **结果联动**：每次值变更实时驱动预览区（EQ 频响曲线形状/电平表/其他直观输出），因果即时；静音/归零等特殊态有明确视觉与文本反馈。
- **参数与状态模型**：
  - 每枚旋钮一份配置：参数名、单位、min/max、step（可含大步进 pageStep）、default、初始值、可选非线性映射（如音量的对数/dB 映射，保证小音量区精度）；统一「归一化值 0..1 ↔ 角度」与「业务值 ↔ 归一化值」两个纯函数，所有渲染只读数不算手势。
  - 值变更走唯一提交入口：钳制到量程、量化到步进、更新状态、同步 DOM（转角/弧/读数/预览/aria），拖拽过程中的高频移动用 rAF 合帧，避免布局抖动。
  - 预设切换/全部复位为显式操作，恢复后每个旋钮的指针、弧、读数、预览与 aria 全部一致。
- **控制与可配置项（Micro-HUD 默认折叠，`H`/`Esc` 切换、事件防穿透）**：有效扫掠角（行程角）、死区显示、线性/非线性映射对照、刻度咔嗒音效开关与音量、吸附强度、reduced-motion 生效状态、各旋钮当前值一览与一键复位；常用操作（单枚复位、静音、预设）直接在面板可见，核心控制不藏进 HUD。
- **可访问性（一等路径）**：
  - 每枚旋钮是可被屏幕阅读器操作的 slider：有可读名称（参数名 + 分组）、`aria-valuemin/max/now` 与带单位的 `aria-valuetext`（如「主输出音量，-6.0 分贝」）；拖拽中不逐像素刷屏播报，释放/键盘步进/复位等离散提交时经 aria-live（polite）播报一句；静音、端点、默认值等状态以形状/符号/文案 + 颜色多重编码；文字对比度达 WCAG AA。
  - `prefers-reduced-motion: reduce`：关闭旋钮帽下沉/回弹、刻度高亮闪动与非必要过渡，转角与弧直接到位（所有输入、钳制、量化、联动与键盘功能一个不少）；咔嗒音不受动效偏好控制而由独立音效开关控制。
- **移动端与触控**：旋钮与触控热区不小于触控标准，单指径向拖拽与鼠标完全等价；垂直拖拽旋钮时不与页面滚动手势冲突（按下起点在旋钮热区才捕获，捕获期间手势归旋钮）；横竖屏与容器尺寸变化后旋钮保持正圆、映射不变；不支持 pointer capture 的旧环境提供等价鼠标/触摸降级。
- **生命周期**：案例卸载（iframe 销毁）/页面隐藏时取消 rAF、释放 Pointer Capture、移除全部监听、挂起/关闭可选 AudioContext；重新进入从干净初始状态开始；无自动播放动画、无自动发声，音频严格在首次用户手势内懒创建。

## 核心亮点

1. **补齐全仓唯一的「绕轴旋转连续数值」硬件控件空白**：61 个注册案例（实测 components 46 / effects 12 / pages 3）与在池 41 个 Ready 中，线性滑块、开关、取色、转盘、时钟选时皆有，唯独没有硬件式 Rotary Knob；它是 DAW/直播/智能家居/调色/监控面板的高频生产控件，成品可直接作为真实控制台模块落地，实用性 5/5。
2. **专业手感的径向拖拽模型，而非强迫画圆**：上下拖为主 + 距轴距离调节灵敏度 + 步进量化吸附 + 端点死区与过拖阻尼 + 双击/快捷键复位，规避了「角度 atan2 直读」在死区分界线跳变、反向绕圈的经典劣化；角度↔数值单一确定性映射，转角、进度弧、读数、aria 与预览永不脱钩。
3. **三输入等价 + 结果可见**：指针径向拖拽、滚轮/触控板、全键盘（方向键/PageUp-Down/Home/End/复位）操作同一提交入口与量程钳制，触觉与视觉一致；底部 EQ 频响曲线/电平预览让「旋钮控制了什么」即时可见，旋钮是真实控制器而非静态拟物摆件。
4. **硬件拟真但克制的材质语言**：圆柱旋钮受光/暗部/顶面纹理、嵌入式凹槽与接触阴影、环周主次刻度丝印与细进度弧、按下轴向微沉与释放回弹，配合深色金属面板，达到桌面音频接口的拟真密度，同时避免满屏彩灯与浮夸投影的 AI Slop 廉价感。
5. **生产级可达性与零依赖工程约束**：ARIA slider + aria-valuetext + 离散提交播报 + 多重编码 + AA 对比 + 可见焦点 + reduced-motion 只去动效不降功能；零框架/零旋钮库/零图片字体（全部 CSS/内联 SVG 程序化绘制），可选咔嗒音由 Web Audio 手势内合成、零音频文件，双击离线完整可用。

- **相似案例**：
  - 在池 **IDEA-013 环形拨盘时间选择器（Time Picker）**：视觉上最接近——都有圆形盘面与绕心角度。但它是**从弹层时钟面上选择一个时刻的选择器**：对象是离散的时/分（12/24 与 60 刻度双态切换），主交互是在时钟面上**点按刻度/拖指针选一个时间点**，结果回填输入框，选完弹层关闭；没有固定轴旋钮本体、没有连续量程参数、没有「捏住旋钮上下径向拖拽 + 距轴灵敏度」的硬件手感、没有端点死区/过拖阻尼、没有滚轮与多参数面板、也不持续控制任何输出。本案例是**持续在线的连续数值控制器集合**，交互范式（捏住旋钮的径向拖拽 vs 在时钟盘面上定位指针）、数据语义（有界连续量 vs 时钟时刻）与使用场景（控制台调参 vs 表单选时）均不同。
  - 在池 **IDEA-029 幸运抽奖转盘（Lucky Wheel）**：同为「圆形 + 旋转」，但它是「圆盘旋转、指针固定」、**点击 GO 后由加权概率决定结果并自动旋转播放**的营销组件，用户不直接连续控制角度、无数值量程、无步进/吸附调节，概率与动画解耦；本案例是用户全程直接控制、转角严格等于数值映射的输入控件，无自动旋转、无随机性。
  - 在池 **IDEA-006 极速拨号菜单（FAB Speed Dial）**：仅借 dial 之名，实为 FAB 展开的动作菜单（图标径向/纵向弹出），无角度编码、无数值、无拖拽。
  - `range-slider`（双拇指区间滑块）：同属有界连续值输入且同样具备步进、钳制与全键盘，是功能语义上最近的亲属——但它的几何是**线性轨道上的拇指平移**，无绕轴旋转、无环形死区、无径向拖拽手势与旋钮拟真材质；二者是「直线 vs 绕轴」两种经典输入硬件的平行实现，本案例补齐的正是旋转这一极。
  - `color-picker`（HSL 三滑块）、`split-pane`（分栏拖拽）、`image-comparison-slider`（对比滑块）：同为指针映射几何，但均为线性/比例调节，无角度、无旋钮；`color-picker` 中任何一维都不以绕轴角度编码。
  - 在池 **IDEA-039 步进鼓机音序器（Step Sequencer）**：同属音频硬件面板语境且其各轨音量/主音量目前以 range 表达——这恰恰说明库内音频控制缺一枚真正的旋钮；鼓机主体是可编程节拍网格与合成调度，本案例是通用连续值旋钮原语（可被未来音频类案例复用），不含音序器、不发声成乐（可选仅刻度触感音）。
  - `dynamic-dock`（鱼眼坞台）、`capsule-tabs`（含 SVG Gooey 胶囊）：有圆形/弹性微交互与可选触感音，但不编码连续数值、无角度量程与端点语义。
  - `breathing-dot` / `spotlight-cards` 等：仅在「极坐标/角度视觉元素」层面远邻，无输入控件语义。
  - 其余注册案例与在池 IDEA 逐一核对：无任何调音台/合成器/EQ/仪表盘旋钮主题；检索 `knob/rotary/dial/音量/mixer/混音/均衡/brightness` 仅命中上述案例的散文用词（如鼓机的「各轨音量以 range 表达」、FAB 的 dial 命名、他案的亮度脉冲描述），确认无历史（含已删除）`rotary-knob` id 或物理目录冲突；rejected.md/completed.md 为空，无淘汰或完成记录。
- **差异说明**：核心创意是「**一组绕固定轴旋转、以扫掠角编码有界连续量的硬件式旋钮：专业径向拖拽手势（上下拖 + 距轴灵敏度）配合步进量化吸附、端点死区与过拖阻尼，滚轮与全键盘等价操作，角度↔数值单一确定性映射，并实时驱动可见结果（EQ 频响/电平）的拟真控制台**」。差异同时体现在：核心创意（持续在线的绕轴连续控制器 vs 时钟时刻弹层选择 / 概率自动转盘 / 线性滑块 / 动作菜单）、视觉表达（金属面板凹槽内圆柱旋钮 + 环周刻度进度弧 vs 时钟面数字盘 / 彩色抽奖扇区 / 直轨道）、交互方式（捏住旋钮径向拖拽 + 滚轮 + 方向键/Page/Home/复位 vs 点选刻度 / 点击后自动播放 / 拇指平移）与整体表现（硬件控制条 + 结果联动预览）；不属于换颜色、文案或微调参数类重复。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库（明确禁止任何旋钮/仪表/图表库）、零图标库/图标字体、零 CDN、零外部图片/字体/音频文件；旋钮、凹槽、刻度、进度弧全部用 CSS（径向/圆锥渐变、transform）与内联 SVG 程序化绘制，数字读数用系统字体栈 + tabular-nums；双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 必须以统一的「业务值 ↔ 归一化值 ↔ 扫掠角」纯函数作为唯一映射，所有视觉（指针转角、进度弧、刻度高亮、读数、aria-valuetext、联动预览）只从同一状态读取渲染；支持可选非线性映射（如音量 dB/指数）且映射与手势解耦；任何输入先钳制量程、量化步进后再提交，拖拽预览态与提交态一致，无累积 transform、无刷新后漂移。
- 指针交互统一 Pointer Events + setPointerCapture：旋钮热区按下才捕获，采用垂直拖拽为主、水平辅助、距轴距离调节灵敏度的径向模型，避免 atan2 直读在死区分界的跳变与反向绕圈；端点有死区与过拖阻尼；滚轮仅在旋钮热区拦截且不锁死页面；rAF 合帧、只改 transform/合成为主的属性；卸载/隐藏时取消 rAF、释放捕获并移除监听。
- 必须具备 ARIA slider 等价语义（aria-valuemin/max/now、带单位的 aria-valuetext、可读名称）、↑↓←→/PageUp/PageDown/Home/End 键盘操作、双击（与键盘等价方式）复位默认值、可见焦点环、离散提交时的 aria-live 克制播报、状态不仅靠颜色（符号/形状/文案多重编码）与 WCAG AA 对比；`prefers-reduced-motion: reduce` 下仅去除下沉/回弹/闪动等运动表现，全部控制功能完整。
- 可选触感音（刻度咔嗒/端点）必须在首次用户手势内懒创建/恢复 AudioContext，可静音、默认克制、零音频文件（Web Audio 实时合成）；不自动播放任何声音；页面隐藏/卸载时挂起或关闭 AudioContext。
- 视觉为克制深色硬件控制台美学（同 dynamic-dock / IDEA-039 设备面板气质），强调色有明度层次而非彩灯堆砌；桌面/平板/手机自适应（旋钮恒正圆、触控热区充分、单元排可折行/横滑、读数不溢出）。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊（强制）；行程角、死区、映射对照、吸附强度、音效开关、reduced-motion 状态与各旋钮数值一览/复位等通过默认折叠的 Micro-HUD 提供（`H`/`Esc`、事件防穿透）。
