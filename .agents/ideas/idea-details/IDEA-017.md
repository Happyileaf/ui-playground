## 创意概述

做一组把「开关（Switch / Toggle）」本身作为主角的高可访问性微交互组件：同一个布尔语义下并排呈现多种“状态形变语言”——滑块滑行、图标路径形变（勾 ↔ 叉 / 日 ↔ 月）、SVG 液态融合（Gooey）填充、以及按下即结算的“瞬时胶囊（Tap Toggle）”，并把它们放进一个真实可信的「通知与偏好设置」面板里，展示开关状态与受控内容（描述文案、预览氛围、子选项）的即时联动。重点解决原生 checkbox“能点但不精致、无开关语义、无加载/禁用/受控反馈”的体验缺口，做成可直接搬到生产环境的无障碍开关参考实现。

## 预期展示效果

- **构图与整体风格**：
  - 深色哑光卡片式设置面板居中，面板分若干“设置行（setting row）”，每行结构一致：左侧图标 + 标题 + 随状态改写的副文案，右侧为一枚开关。重复、克制、有秩序的列表韵律让“多种开关形变”成为唯一视觉焦点。
  - 顶部分组小标题（如「通用 / 外观 / 隐私」），底部一个“恢复默认”次级按钮，营造真实系统设置的可信感，而非孤立控件罗列。
- **主要视觉元素**：
  - 多款开关：经典滑块（thumb 带投影与按压缩放）、图标形变开关（开启瞬间 SVG path 在勾/叉或日/月间平滑形变）、液态融合开关（开启时内部色块以 Gooey 滤镜膨胀融合吞没轨道）、瞬时结算胶囊（无长轨道，点按即弹性点亮/回弹）。
  - 一枚「异步保存」开关：点击后进入 loading（轨道内嵌旋转指示），短暂延迟后才落位为开/关，可被中途取消，展示 pending 状态。
  - 受控联动示范：某个总开关关闭时，其下属两行子开关整体降透明度、收起并禁用（受控联动）；“深色模式”开关可让面板局部氛围做一次柔和明暗过渡（仅作用于面板预览，不喧宾夺主）。
- **层次、材质、光影与关键细节**：
  - 轨道为内凹质感（`inset` 阴影），thumb 为带柔和投影的悬浮小球；开启色与面板强调色统一，关闭态为低饱和中性色。
  - 焦点可见：键盘聚焦时出现高对比、不依赖颜色的 focus ring（轮廓 + 轻微外发光），满足无鼠标可达。
  - 形变图标使用同一画布尺寸内的 path 插值/交叉淡变，避免跳变；Gooey 效果由内联 SVG filter（`feGaussianBlur` + `feColorMatrix`）实现，零图片。
  - 所有开关均有明确的“开/关”状态文本或可被读屏朗读的状态，颜色永远不是唯一信息载体。

> 设计文档应充分约束最终体验与设计意图，但除非属于创意不可缺少的约束，不要过早限定具体算法、代码组织、精确尺寸或颜色值。

## 动态与交互

- **触发方式**：
  - 指针：点击轨道/thumb 切换；按下时 thumb 有轻微压缩或拉伸，释放后以弹性曲线（overshoot）落位；支持在轨道上横向拖拽 thumb 直接拨动（带阻尼与吸附阈值，松手按阈值结算，不产生中途态脏数据）。
  - 键盘：作为 `role="switch"`（或功能等价的原生 checkbox 增强）控件，`Space` / `Enter` 切换；Tab 顺序逐行可达；聚焦环清晰。
  - 只读/禁用态：禁用开关不可点且不进入 Tab 序列，视觉降透明度。
- **反馈与节奏**：切换为 200–300ms 级别的轻快弹性动效；图标形变与轨道填充同步；异步开关有独立的 loading→成功/失败（失败回退到原态并给一次轻抖动反馈）节奏。
- **联动反馈**：总开关关闭时子选项收起并禁用；恢复默认会让所有开关以轻微错峰（stagger）方式回到初始态，形成一段有序的复位编排。
- **移动端触控**：遵循项目统一 Pointer Events 规范，触控目标足够大（不小于常用可点尺寸），拖拽与页面滚动不冲突（横向手势不触发纵向滚动）。
- **减弱动效**：尊重 `prefers-reduced-motion`，开启后用即时/极短交叉淡变替代滑行、Gooey 流动与弹性回弹，但状态与可访问性不受影响。
- **Micro-HUD（按需、默认折叠）**：遵循项目统一 HUD 规范，支持 `H` / `Esc` 唤出与事件防穿透；可提供“强调示焦点环”“朗读状态（演示用）”等开关，辅助展示无障碍特性，不喧宾夺主。

## 核心亮点

1. **把最常用却最容易做糙的表单控件做成主角**：开关是生产环境高频控件，但全库尚无以其为核心的案例；本案例一次给齐“滑行 / 图标形变 / 液态融合 / 瞬时胶囊”四种状态语言，兼具参考价值与观赏性。
2. **完整的真实状态机，而非只演示开/关**：覆盖 开 / 关 / 异步 loading / 成功落位 / 失败回退抖动 / 禁用 / 键盘聚焦 / 父子受控联动 / 批量复位，直接对标真实业务里的偏好设置场景，可复用性高。
3. **无障碍优先的工程示范**：正确的 switch 语义与读屏状态、纯键盘可达、颜色非唯一信息载体、可见焦点环、`prefers-reduced-motion` 降级，可作为项目后续表单控件的无障碍样板。
4. **纯 CSS/SVG 的高级形变**：图标 path 形变与 SVG Gooey 液态融合全部内联实现，延续项目“零图片、零 CDN、零框架”的原生上限展示。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML/CSS/ES6+，零框架、零 CDN、零外部图片/字体；双击 `index.html` 在 `file://` 下完整可用。
- 无障碍：使用 `role="switch"` + `aria-checked`（或语义等价的原生 checkbox 增强方案），提供可被读屏理解的名称与状态；完整键盘可达；焦点环可见；颜色不作为唯一状态信息。
- 图标形变与 Gooey 液态效果以内联 SVG / SVG filter 实现，不引用任何外部资源；不支持 Gooey filter 的环境需有可接受的降级（普通填充），功能不报错。
- 动效必须响应 `prefers-reduced-motion`；HUD 遵循项目统一规范（默认折叠、`H`/`Esc`、事件防穿透、Title 胶囊）。
- 异步开关使用 `setTimeout` 等本地模拟即可，不发起真实网络请求；计时器、监听器与事件在卸载/重复操作时正确清理，可取消、无竞态脏数据与内存泄漏式累积。
- 拟定案例目录 id 为 `morph-switch`（kebab-case，与现有 60 个 id 及已删除/废弃 id 不冲突，已核对）。
