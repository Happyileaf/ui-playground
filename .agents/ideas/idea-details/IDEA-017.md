## 创意概述

缓动曲线（timing function）是所有界面动效的「手感来源」，但 `cubic-bezier(x1, y1, x2, y2)` 的四个数值对绝大多数设计师与前端都非常抽象：不拖一拖、不并排比一比，根本无法预判 `0.68, -0.55, 0.27, 1.55` 会得到怎样的回弹。全仓 60 个已注册案例几乎都是「使用某条曲线做出某种动效」，活动池 IDEA-001~016 也全部是具体业务组件 / 特效，**没有一个「反过来理解、调校并导出缓动曲线本身」的开发者 / 设计师工具**。本案例做一个纯原生、零依赖、双击即用的 **CSS 贝塞尔缓动工坊**：在一张时间（横轴）× 进度（纵轴）坐标图上用指针 / 键盘拖拽两个贝塞尔控制柄实时塑形曲线，曲线变化即时驱动多组并列的预览动画（位移方块、缩放、旋转、淡入、弹性过冲），支持常用预设曲线一键载入与收藏、曲线 A/B 对比赛跑、时长与循环设置、数值手动精修，并一键复制可直接粘贴进 CSS 的 `cubic-bezier(...)` 代码。它既是技术域 2「微交互与光影动效」与技术域 3「导航与页面切换」共同依赖的动效基础设施，也是一个可日常留在浏览器书签栏里的生产工具——对标 Chrome DevTools 缓动编辑器与 cubic-bezier.com，但以本仓统一深色玻璃质感与更完整的「对比 + 多形态预览 + 键盘可达」体验呈现。

## 预期展示效果

- **构图与整体风格**：
  - 延续项目统一深色玻璃质感，整体是一个**专业但克制的动效实验室工作台**：左侧 / 主区域为大尺寸**曲线编辑画布**，右侧为参数与预设面板，底部（或画布下方）为一整条**多形态实时预览轨道**。窄屏时面板折叠到画布下方，编辑区始终保持足够的拖拽命中面积。
  - 曲线画布：浅色细网格 + 对角参考虚线（linear 基准），一条带柔和辉光的强调色贝塞尔曲线贯穿固定端点 (0,0)→(1,1)；两个控制柄以**带描边的圆形手柄**呈现，端点到手柄之间有细控制线（手柄切线）；手柄可被指针 / 键盘拖出 0–1 边界以制造回弹 / 预缩（anticipation）效果，越界区域的曲线用区别于正常区间的微妙色调提示「过冲区」。
  - 右上角统一点阵色 Title 胶囊（遵循 HUD 规范）；所有数值与代码以等宽字体呈现，强调「这是工具，不是装饰」。
- **主要视觉元素**：
  - **实时曲线（核心视觉）**：拖拽手柄时曲线即时重绘（内联 SVG path 或 Canvas 矢量绘制，线条平滑、端点与控制柄层级清晰），曲线上可叠加一个沿曲线行进的「采样小球」，与下方预览动画同步起跑，直观演示「时间—进度」映射（包括 y<0 预缩、y>1 过冲时小球跑出边界的行为）。
  - **多形态预览轨道**：同一曲线同时驱动 4–5 个小预览格——水平位移、缩放弹入、旋转、透明度淡入、高度 / 圆角等——每格独立重播按钮，一眼看出同一条曲线作用在不同属性上的性格差异。
  - **A/B 赛跑对比**：可锁定一条参考曲线（灰色 ghost），与当前编辑曲线驱动两个方块在同一轨道同时起跑，直观对比快慢、过冲与收尾差异；参考曲线可随时替换为当前曲线。
  - **预设库与收藏**：一排语义化预设（linear、ease、ease-in/out、quint 强减速、back 回摆、弹性过冲等常见曲线），点击即载入；可把当前曲线加入本地收藏（localStorage 持久化，刷新不丢；在无 localStorage 环境降级为仅当前会话）。
  - **代码输出条**：底部一条等宽字体代码条实时显示 `cubic-bezier(0.25, 0.1, 0.25, 1)`，带一键复制按钮与「已复制」反馈；另给出 `transition: transform <时长> <曲线>` 的完整用法行。
- **层次、材质、光影与关键细节**：
  - 画布是视觉中心：网格、参考虚线、控制线、曲线、手柄按重要性分层用不同透明度与粗细；被选中 / 拖拽中的手柄放大并出现柔和投影与光环，未选中的手柄安静收敛。
  - 曲线辉光克制不刺眼；过冲（超出 0–1 纵轴）部分以淡色底带 + 曲线变色提示，而不是用刺眼警告色；手柄坐标以小气泡跟随显示两位 / 三位小数。
  - 预览轨道每个格子是一张小型玻璃卡片，当前正在播放时卡片有轻微高亮；重播、时长调整的反馈统一短促（150–250ms 量级，且自身也用合理缓动，形成「工具自己就是动效范例」的趣味闭环，但绝不喧宾夺主）。
  - 面板、代码条、预设胶囊统一半透明玻璃材质 + 细描边，hover / focus 有明确高光；复制成功、收藏成功等状态以颜色与文字双重反馈，不仅靠颜色传达。
  - 遵循 `prefers-reduced-motion`：偏好减弱时，预览动画改为极短时长 / 即时演示，但曲线拖拽、数值计算、复制等全部功能不受影响。

## 动态与交互

- **拖拽塑形（核心交互）**：指针在手柄上按下并拖动（Pointer Events + `setPointerCapture`，统一鼠标 / 触控 / 手写笔），手柄跟随指针映射到曲线坐标系，实时更新四个数值、重绘曲线、刷新代码条并**即时**反映到正在循环 / 下次播放的预览动画；横轴两个控制柄的 x 值按 CSS 规范钳制在 0–1（保证 `cubic-bezier()` 合法），纵轴 y 值允许超出（用于预缩 / 过冲）并设置合理上下限防止极端值，越界时有边界阻尼感而非生硬截断。
- **键盘精修（完整可达）**：手柄可 Tab 聚焦；`←`/`→`/`↑`/`↓` 以小步长（如 0.01）调整对应坐标，按住 `Shift` 以大步长（如 0.1）调整，`Home`/`End` 归 0 / 归 1；四个数值也提供数字输入框，键入非法 / 超范围值时钳制并提示，输入与拖拽双向同步。
- **预览与对比**：预览轨道持续循环或按需重播（可配置循环开关与统一时长滑杆，时长范围覆盖常用的 100ms–2000ms）；A/B 模式下两条曲线同帧起跑，可一键「以当前替换参考」；重播全部预览时所有格子同步起跑，便于横向比较。
- **预设与收藏**：点击预设胶囊载入曲线（手柄以动画方式走到新位置，而非硬跳，且该位移动画本身就是一次曲线演示）；收藏 / 取消收藏当前曲线，收藏以可删除的小胶囊形式持久保存；hover 预设可在画布上以 ghost 曲线「预览但不应用」，点击才正式载入。
- **复制输出**：点击复制按钮（或代码条获得焦点时按快捷键）复制标准合法的 `cubic-bezier(...)` 到剪贴板（Clipboard API，失败时降级为选中文本 + 提示手动复制），按钮呈现明确的「已复制」成功态并在短时间后恢复。
- **Micro-HUD**：默认折叠的演示控制面板（遵循统一 HUD 规范：常驻触发入口 + `H`/`Esc` 快捷键、事件防穿透），可切换预览循环、采样小球显隐、过冲提示显隐、网格密度、数值精度等；不承载核心功能，核心功能全部直接可见可达。
- **移动端触控**：窄屏纵向堆叠，画布占满宽度并保证手柄触控目标不小于舒适尺寸；支持单指拖手柄、滑杆与按钮触控；面板滚动不与画布手势冲突。

## 核心亮点

1. **填补全仓「动效基础设施 / 调校工具」空白**：60 个历史案例与活动池 IDEA-001~016 全是「使用动效的业务组件」，没有一个「理解与生产动效参数本身」的工具。缓动曲线编辑器是设计师与前端的高频刚需（浏览器 DevTools 内置、cubic-bezier.com 等常年被收藏），实用性 5/5，产出物可直接粘贴进任何真实项目的 CSS。
2. **抽象参数 → 可视直觉的转译**：时间×进度坐标、沿曲线行进的采样小球、y<0 / y>1 过冲区的明确视觉提示、同曲线多属性预览、A/B 赛跑对比，把四个冰冷数字变成「看得见的手感」，教学价值与实用价值兼备。
3. **完整严谨的交互面**：指针捕获拖拽（含触控笔）、完整键盘漫游与步长精修、数值双向同步与合法性钳制（x∈[0,1] 严格符合 CSS 规范）、预设 hover ghost 预览与点击载入、localStorage 收藏降级、Clipboard API 降级路径——工程完整度对标成熟在线工具而非演示 Demo。
4. **「工具自身即范例」的趣味闭环 + 零依赖离线**：界面每一次手柄到位、面板反馈都使用合理缓动，自身就是最好的展示；全部矢量绘制（SVG / Canvas）零图片零字体零网络请求，断网双击 index.html 即为完整工作台，规避「AI 廉价感」。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生零 CDN、零框架、零库，双击 index.html 独立离线运行（通用项目铁律，不重复）。
- 曲线以**内联 SVG path 或 Canvas 矢量**实时绘制，不引入任何图片、图标库、字体或网络资源；几何计算（三次贝塞尔采样 / 求包围盒用于过冲提示）自行实现，采样密度以曲线平滑且不产生性能问题为准。
- 输出代码必须是**合法 CSS**：两个控制柄的 x 坐标严格钳制在 0–1（与 CSS `cubic-bezier()` 规范一致），y 坐标允许负值与大于 1 的值以表达预缩 / 过冲，但须设置合理上下限；数值输入框与拖拽双向同步，非法输入钳制而非报错崩溃。
- 拖拽统一使用 Pointer Events + `setPointerCapture`；键盘操作覆盖 Tab 聚焦、方向键步长（Shift 加速）、Home/End；Clipboard API 失败、localStorage 不可用均须有降级路径（手动选中文本 / 仅会话内收藏）。
- 预览动画直接把编辑结果写入元素的 `transition-timing-function` / `animation-timing-function`（真实 CSS 生效，而非 JS 模拟进度），以保证「所见即所得、产出可复制」；A/B 对比须同帧起跑。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊；循环播放、采样小球、过冲提示、网格密度等调节项使用常驻演示控件 + 默认折叠 Micro-HUD（`H`/`Esc`、事件防穿透）。本案例默认不需要音效。
- iframe 卸载时移除事件监听、中止未完成动画与定时器、释放指针捕获；`prefers-reduced-motion` 下预览演示降级但编辑、键盘、复制功能完整保留。
