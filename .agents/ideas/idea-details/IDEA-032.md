## 创意概述

「拖出节点、从端口拉一条线到另一个节点、点击运行看数据沿连线流动」——节点式工作流编辑器（node-based flow editor）是 n8n、Node-RED、Unreal Blueprint、Unity Shader Graph、Zapier、Figma 原型连线面板与各类低代码 / AI 编排工具共同的核心交互原语：一块可以**平移与缩放的自由画布**，若干可以**任意定位的节点卡片**，节点两侧是带数据类型语义的**输入 / 输出端口**，从端口按下拖出一条**实时跟随光标的平滑曲线**，在兼容端口上吸附松手即建立连接，非法连接被拒绝；点击「运行」后，数据以**脉冲形式沿连线流动**，节点依次亮起执行状态。它解决的不是「画一张流程图图片」，而是提供一套有真实图结构（节点 / 边 / 端口 / 类型 / 执行序）的空间化编排体验。

当前案例库 60 个案例中，所有拖拽类交互都是**容器约束型**：`kanban-board` 在四列之间跨列拖卡片（落点是预定义列槽），`split-pane` / `image-cropper` 拖的是尺寸手柄，`resizable-table` 拖列宽，`range-slider` / IDEA-022 滑块验证码是单轴滑轨，`signature-pad` 虽有自由指针轨迹但留下的是无语义的原始笔迹；全库**没有任何案例在自由坐标系中摆放对象、从语义端口拉线建边，也没有可平移缩放的无限画布**。SVG 方面，`capsule-tabs` / `menu-morph` 只把 SVG 用于固定指示器形变与汉堡图标形变，IDEA-017 贝塞尔工坊只在固定图表面板里编辑单条缓动曲线的控制点——均无运行时动态生成、随对象位置实时重算的节点连线。本案例做一个纯原生、零依赖、双击离线即用的 Node Flow Editor：预置一组语义化示例节点（触发器 / 处理 / 条件分支 / 输出等）与一张示例流程图，支持节点拖拽、端口拉线与类型校验、连线选中删除、画布平移缩放、节点面板添加，以及一次纯本地模拟执行（拓扑排序驱动的数据脉冲与节点状态高亮），并遵循键盘可达、减弱动效与统一 HUD 规范。

## 预期展示效果

- **构图与整体风格**：
  - 案例视口即一整块近黑色的**点阵网格画布**（dot-grid，网格点随画布平移 / 缩放同步运动，提供空间参照而非装饰条纹），延续项目克制的暗色玻璃审美，拒绝蓝紫霓虹渐变堆砌的 AI Slop 廉价感。
  - 画布上散布若干**玻璃拟态节点卡片**：卡片有清晰的标题栏（节点类型图标 / 名称 / 类型色点）与正文（简短说明或内嵌关键字段），左侧为输入端口、右侧为输出端口；条件类节点可有两个语义输出（如「是 / 否」）。
  - 节点之间以 **SVG 三次贝塞尔曲线**相连，线从端口圆心出发、在另一端口圆心结束，控制点沿水平方向延展，走向自然不打结；已建立的连线细而克制，仅在悬停 / 选中 / 运行脉冲时加强发光。
  - 角落是极简工具条：运行 / 停止、缩放控制（放大 / 缩小 / 适应画布 / 复位 100%）、添加节点入口与只读的缩放比例指示；右上角按工作台 HUD 规范放置点阵色 Title 胶囊。
  - 首屏即展示一张**已连好的示例流程图**（而非空白画布），让用户立刻理解「节点—端口—连线—运行」的心智模型；桌面宽屏下节点舒展分布，平板 / 手机视口下默认缩放至整图可见、控件收进图标按钮或底部抽屉，不横向溢出。
- **主要视觉元素**：
  - **点阵网格世界背景**：网格点、SVG 连线层与节点层共享同一套世界坐标变换（平移 + 以光标为锚点的缩放），缩放时点距与节点同步、无错位重影。
  - **节点卡片**：半透明深色玻璃底 + 细边 + 柔和投影，按节点类型（触发 / 处理 / 条件 / 输出）以一小段克制的类型色点缀标题栏与端口；不同数据类型的端口用形状 / 颜色 / 标签**双重编码**（不仅靠颜色），拖动时端口有明确的兼容 / 拒绝态。
  - **贝塞尔连线**：固定于 SVG 图层的 `path`，描边有低强度辉光；从端口拉线过程中显示一条**实时跟随指针的临时路径**，合法目标端口高亮放大吸附，非法目标端口呈拒绝态；连线可被点选，选中态加粗发光并露出删除热区。
  - **模拟执行层**：点击运行后，从触发器出发沿边传播移动的光点 / 流光脉冲，被抵达的节点经历 `idle → running（呼吸高亮）→ success（确认态）`，条件节点只点亮实际走向的分支；脉冲速度与分支节奏可读、不闪烁刺眼；运行结束后状态自然回归或保留一次结果摘要。
- **层次、材质、光影与关键细节**：
  - 视觉三层：点阵网格底 → SVG 连线层 → 节点卡片前景；靠玻璃半透明、细边与克制辉光制造纵深，节点拖动时被拖卡片轻微上浮（阴影加深、层级置顶），与其相连的边实时跟随重算，始终连在端口上不脱开。
  - 类型色板为有限的低饱和同系色，辉光只用于反馈（悬停 / 选中 / 拒绝 / 执行），静态画面保持安静；临时拉线、拒绝抖动、吸附、节点状态切换均为短促有阻尼的微动效，不做长循环花哨动画。
  - 真实边界有明确视觉反馈：自环 / 重复连接 / 类型不兼容 / 拖到空白处均给出区别化的拒绝或取消反馈（端口拒绝色、轻微回弹、临时线消失），而非静默失败；孤立节点、删除节点导致边级联删除等状态变化在画面与播报中一致。
  - 平移缩放有边界与比例约束（限制最小 / 最大缩放、近边有阻尼），缩放以指针位置为锚点不跳变；节点位置、缩放与平移状态在运行期间稳定，脉冲叠加不改变布局。

> 设计文档约束最终体验与设计意图；节点尺寸、网格间距、缩放区间、贝塞尔控制点算法（水平 / 垂直延展比例）、脉冲数量与具体色值由实现阶段按画质与手感统一决定，不在此过早钉死。

## 动态与交互

- **触发方式（Pointer / 键盘统一）**：
  - **拖拽节点**：在节点标题栏 pointerdown 即可自由拖动（`setPointerCapture` + `touch-action: none`），拖动中该节点置顶、相连边每帧重算；点在端口上不触发节点拖动；Esc 取消并回落到拖动前位置。
  - **端口拉线**：在输出端口 pointerdown 开始连线，pointermove 实时绘制跟随光标的临时贝塞尔路径并高亮当前可吸附的兼容端口；pointerup 在合法输入端口上吸附建边，在空白 / 非法端口 / 自身 / 已存在的连接上松手则拒绝或取消（带区别化反馈）。允许从输入端口反向拉向输出端口。
  - **连线管理**：点击连线选中（加粗发光 + 删除热区），按 Delete / Backspace 删除；点击空白取消选择；删除节点时其所有关联边一并删除。
  - **画布平移缩放**：在空白处按住拖动平移；滚轮 / 触控板以指针为锚点缩放；工具条提供放大 / 缩小 / 适应画布 / 100% 复位；平移缩放过程中节点与连线不错位。
  - **添加节点**：从极简节点面板点击（或拖入）在当前视口中心加入新节点，新节点自动获得焦点并可立即操作。
  - **模拟运行**：点击运行（或按 R）后从触发器按拓扑序执行本地模拟：数据脉冲沿边流动，节点依序进入 running / success，条件节点按内置示例数据选择分支；运行中可再次点击停止并复位；执行是纯本地确定性模拟，不产生任何网络请求。
- **连接校验语义**：每个端口声明数据类型；建边规则至少覆盖——类型必须兼容、禁止自环、禁止重复边、禁止形成有向环（保证拓扑执行可终止）、条件分支输出端口有语义标签；非法操作在视觉拒绝的同时经 aria-live 说明原因。
- **键盘一等路径**：Tab / F6 可在节点、端口、工具条、列表面板间遍历焦点；节点聚焦时方向键小步移动、Delete 删除；端口聚焦时 Enter 进入拉线态，再聚焦目标端口 Enter 确认 / Esc 取消；`+` / `-` 缩放、`0` 复位、`R` 运行、`Esc` 取消当前操作与浮层；焦点环清晰可见。
- **可访问性**：节点、端口、连线具备语义角色与可访问名（节点名 / 类型 / 连接的两端名称）；建立 / 拒绝 / 删除连接、运行开始与完成、节点执行结果通过 `aria-live="polite"` 礼貌播报（节流，不逐帧刷屏）；端口类型不仅靠颜色区分（形状 + 文案）；脉冲信息不依赖颜色单一通道（节点状态有图标 / 明度差异）。
- **减弱动效与移动端**：
  - 尊重 `prefers-reduced-motion`：关闭流光脉冲循环与呼吸 / 回弹动效，运行改为节点与边的瞬时 / 慢速状态切换（保留拓扑执行与结果这一核心），全部编辑与运行功能完整。
  - 移动端单指拖动节点 / 在空白处平移 / 点端口拉线，双指捏合缩放（不支持捏合时以工具条按钮兜底），热区充分、节点面板进底部抽屉，任何视口下不横向溢出、不与页面滚动冲突。
- **生命周期**：脉冲动画用 `requestAnimationFrame` 驱动并在停止 / 卸载时取消，ResizeObserver 与全局 pointer / keydown 监听在卸载或切换案例时移除断开；无悬挂定时器、监听与 rAF。
- **可选 Micro-HUD**（默认折叠，`H` / `Esc` 切换、事件防穿透）：切换网格显隐、节点网格吸附、连线动画速度 / 开关、减弱动效对照，并显示当前缩放比例、节点 / 连线数量与执行序，便于验证图结构真实；非必需时至少保留右上角 Title 胶囊。

## 核心亮点

1. **补齐「自由画布 + 语义连线」方向空白**：库内 60 个案例的拖拽全部是列槽 / 手柄 / 单轴滑轨等容器约束型（kanban-board、split-pane、image-cropper、resizable-table、range-slider），signature-pad 的自由轨迹无语义端点；全库无运行时动态生成的 SVG 节点连线、无平移缩放自由画布。本案例首次实现「世界坐标画布 + 节点 / 端口 / 边图模型 + 端口拉线建边」这一 n8n / Node-RED / Blueprint 级别的高频编排原语，同时命中最薄弱的技术域 8（SVG 形态 / 路径）与技术域 6（自由指针交互）。
2. **有真实图语义而非画线玩具**：连接带数据类型校验、兼容吸附、自环 / 重复 / 有向环拒绝、条件分支语义端口、删节点级联删边；背后是显式的 nodes / edges / ports 数据模型而非视觉摆设，拒绝原因与结果可被播报和验证。
3. **统一世界坐标变换体系**：点阵网格、SVG 连线层、节点层共享同一套平移 + 以指针为锚点的缩放矩阵，提供屏幕 ↔ 世界坐标换算、缩放区间与边缘阻尼，拖动节点时所有关联贝塞尔边实时重算、端口不脱开——这是库内任何案例都没有的空间交互基础设施。
4. **连线「活起来」的本地模拟执行**：运行不是假进度条，而是按拓扑序从触发器沿有向边传播数据脉冲，节点经历 running / success 状态机、条件节点只点亮真实分支；纯本地确定性模拟、零网络，断网双击亦可完整演示。
5. **克制审美 + 完整可达性**：低饱和类型色板、玻璃三层纵深与仅用于反馈的辉光，避免满屏霓虹的廉价感；键盘可完成拉线在内的全部编排操作，aria-live 播报连接与执行结果，prefers-reduced-motion 保留执行核心、关闭脉冲，移动端单指 / 捏合可用且不溢出。

## 实现约束（仅记录该案例必要的约束）

- 必须纯原生 HTML5 + CSS3 + ES6+，零框架、零第三方库、零 CDN，双击 `index.html` 完整离线可用（沿用案例三件套 `index.html` / `style.css` / `script.js`）。
- 显式图数据模型：nodes（id / 类型 / 世界坐标 / 端口定义）、edges（id / 源端口 / 目标端口 / 可选分支标签）；连线为 SVG path，几何由两端端口世界坐标实时计算；网格层、连线层、节点层共用一套平移 + 缩放世界变换，并提供屏幕 ↔ 世界坐标换算；缩放有上下限与指针锚点，平移有近边阻尼。
- 统一 Pointer Events（pointerdown / move / up + setPointerCapture，交互面 `touch-action: none`）同时服务鼠标与触摸；拉线、拖节点、平移三类手势按起手目标（端口 / 节点标题栏 / 空白）明确区分、互不串扰。
- 建边必须实现校验：类型兼容、禁自环、禁重复边、禁有向环、条件分支端口语义；拒绝与取消有区别化视觉反馈；删除节点级联删除其边。
- 运行模拟纯本地、确定性：从触发节点做拓扑排序传播数据脉冲与节点状态机（idle / running / success，条件节点按内置示例数据选分支），禁止任何网络请求与后端依赖。
- 脉冲等连续动画用 requestAnimationFrame 驱动，停止 / 卸载时取消；ResizeObserver 与全局 pointer / keydown 监听在卸载或切案例时断开移除，无悬挂监听 / 定时器 / rAF。
- 键盘为一等路径（焦点遍历、方向键移动、Enter 拉线确认、Delete 删边删节点、R 运行、Esc 取消、缩放快捷键）；节点 / 端口 / 边具语义与可访问名，连接与执行结果经 aria-live 节流播报；类型与状态不仅靠颜色编码。
- 尊重 `prefers-reduced-motion`（关闭流光 / 呼吸 / 回弹，保留拓扑执行与状态结果，编辑功能完整）；移动端单指拖拽 / 拉线 / 平移、双指捏合或按钮缩放、面板进抽屉，不横向溢出、不劫持页面滚动。
- 遵循统一 HUD 规范：右上角固定点阵色 Title 胶囊（强制）；如需参数控制（网格 / 吸附 / 脉冲速度 / 减弱动效对照 / 缩放与图统计）使用默认折叠的 Micro-HUD（`H` / `Esc`、事件防穿透）。
