UI Playground 架构指南

1. 原生优先与零运行时冗余 (Native First)

每一个案例均纯粹基于原生 HTML5、现代 CSS3 与 ES6+ JavaScript 构建。绝无第三方打包器锁定，独立案例中零外部运行时框架依赖，还原极致原生 Web 性能。

2. 100% 独立离线运行保证 (Standalone Guarantee)

每个特效与组件均位于独立的专属目录中。脱离外壳直接在任何浏览器双击 index.html 即可 100% 完整运行，拥有完整视觉与交互体验。

📁 effects/ ├── fireworks/ (index.html, style.css, script.js) └── magnetic-button/ (index.html) 📁 components/ ├── button/ (index.html, style.css, script.js) └── card/ (index.html, style.css, script.js)
3. 极速自主扩展新案例 (Rapid Extension)

只需在 effects/ 或 components/ 下新建子文件夹，编写 index.html，并在 playground.js 中注册元数据即可瞬时接入沙箱工作台。
